# 数値定義の統一と総括原価の再計算

作成：令和８年８月３日
背景：引継ぎメモとの突合（`06_引継ぎメモの突合と作業履歴.md`）で判明した数値の食い違いに対する是正
成果物：`onagawa/output/女川町_水道_数値定義と確定値一覧.xlsx`（5シート）

---

## 0. 結論（2点）

1. **総括原価に、税抜／税込よりも大きな論点が見つかりました。**
   引継ぎメモの控除項目「長期前受金戻入益 ▲450,000千円（5年計）」は、令和７年度実績（334,252千円／年＝5年で1,671,262千円）の**約4分の1**です。これを実績ベースに是正すると、**総括原価は2,552,199千円 → 1,330,937千円とほぼ半減**します。

2. **有収水量推計にも構造的な弱点があります。**
   経営戦略（案）は有収水量の全量を「給水人口 × 1人1日あたり有収水量」で推計していますが、**家事用は有収水量の44.5％にすぎず、工業用が36.1％（わずか66件）**を占めています。55.5％は給水人口に連動しません。

この2点を是正すると、**必要改定率は＋327.2％から＋122.8％へ、給水原価は592.5円から277.2円へ**変わります。「1回の改定では不十分」という結論自体は変わりませんが、住民・議会に示す数値としては極めて大きな差です。

## 1. 数値の使用ルール（全成果物共通）

同じ名称で異なる値が並存すると、住民・議会説明で説明が破綻します。以下を全成果物に適用してください。

| 区分 | ルール |
|---|---|
| **消費税** | **原則は税抜。** 総務省指標・経営比較分析表との比較、原価計算、収支計画はすべて税抜。住民・議会説明で実際の支払額を示す場合のみ税込とし、必ず「（税込）」と明記 |
| **年度** | 指標には「令和○年度」を必ず併記。**異なる年度の指標を組み合わせて逆算しない** |
| **給水原価** | 算式が5通りある。用途に応じて使い分け、必ず出典を明記 |
| **有収水量** | 令和７年度実績は1,024,576㎥。将来推計は見直しが必要 |
| 単位 | 金額は円単位で保持し、表示のみ千円・百万円に丸める |
| 出典 | すべての数値に出典（決算書の該当表・シート名）を付す |

## 2【最重要】総括原価の再計算

### 2-1. 長期前受金戻入益の控除額

| 区分 | 5年計 | 年平均 | 根拠 |
|---|---:|---:|---|
| 引継ぎメモの控除額 | ▲450,000千円 | ▲90,000千円 | 「推計値・要確定後更新」と記載 |
| **令和７年度実績ベース** | **▲1,671,262千円** | **▲334,252千円** | 決算書の損益計算書 |

**3.7倍の差があります。**

長期前受金戻入益は、補助金等で取得した資産の減価償却費に対応して毎年度計上されるものです。
令和７年度末の未収益化残高は**7,491,683千円**、年間の戻入益は**334,252千円**ですので、**今後20年以上この水準が続きます**。年90,000千円まで下がる理由は見当たりません。

### 2-2. 総括原価（5年計・千円）

| 費目 | 引継ぎメモ | 是正後 | 備考 |
|---|---:|---:|---|
| 維持管理費 | 672,327 | 672,327 | 年平均134,465千円。令和７年度の平常時137,751千円とほぼ一致 |
| 減価償却費 | 2,032,440 | 2,032,440 | 年平均406,488千円。令和７年度実績393,746千円 |
| 既往債利息 | 50,585 | 50,585 | 年平均10,117千円 |
| 新規債利息 | 127,402 | 127,402 | 年平均25,480千円 |
| 資産維持費（3％） | 134,445 | 134,445 | 対象資産896,300千円×3％×5年 |
| 小計 | 3,017,199 | 3,017,199 | |
| 控除　長期前受金戻入益 | ▲450,000 | **▲1,671,262** | ★令和７年度実績×5年 |
| 控除　他会計補助金等 | ▲15,000 | ▲15,000 | |
| **総括原価** | **2,552,199** | **1,330,937** | **▲1,221,262（△47.9％）** |

### 2-3. 給水原価と必要改定率

| 前提 | 総括原価5年計 | 有収水量5年計 | 給水原価 | 必要改定率 |
|---|---:|---:|---:|---:|
| 引継ぎメモのまま | 2,552,199千円 | 4,307千㎥ | 592.5円 | ＋327.2％ |
| 控除額のみ是正 | 1,330,937千円 | 4,307千㎥ | 309.0円 | ＋122.8％ |
| **★控除額の是正＋有収水量の見直し** | **1,330,937千円** | **4,800千㎥** | **277.2円** | **＋122.8％** |
| （参考）資産維持費を算入しない場合 | 1,196,492千円 | 4,800千㎥ | 249.3円 | ＋100.3％ |

※ 引継ぎメモの給水原価572円は有収水量約4,462千㎥を前提とした値と推定されます。当方の線形補間値（4,307千㎥）との差（約4％）が592.5円との差であり、原価側の差ではありません。

### 2-4. 他の算定基準との整合

| 基準 | 必要改定率 | 位置づけ |
|---|---:|---|
| 平常時ベース（一過性を除く令和７年度実績） | ＋77.3％ | 現状維持の下限 |
| **総括原価ベース（資産維持費なし）** | **＋100.3％** | 将来の投資を織り込んだ水準 |
| **総括原価ベース（資産維持費3％）** | **＋122.8％** | 更新財源を確保する水準 |
| 令和７年度実績ベース（一過性込み） | ＋185.1％ | 江島の一過性費用を料金で回収する場合 |

これらは**整合的に説明できます。** 差額の内訳は次のとおりです（年平均）。

```
平常時ベース                211,886千円
 ＋ 減価償却費の増              +12,742千円  （R8〜R12は406,488、R7実績393,746）
 ＋ 新規債利息の増              +20,955千円  （将来の投資に伴う）
 ＋ 資産維持費                 +26,889千円  （3％）
 −  維持管理費の減               △3,286千円
 −  他会計補助金等                △3,000千円
─────────────────────────────
総括原価ベース              266,187千円  → 必要改定率 ＋122.8％
```

## 3. 有収水量推計の見直し

### 3-1. 1人1日あたり有収水量の実績

| 年度 | 有収水量 | 給水人口 | 1人1日 |
|---|---:|---:|---:|
| 令和５年度 | 1,039,302㎥ | 5,842人 | 487.4L |
| 令和６年度 | 1,019,321㎥ | 5,769人 | 484.0L |
| **令和７年度** | **1,024,576㎥** | **5,656人** | **496.3L** |
| **直近3か年平均** | | | **489.3L** |
| 経営戦略（案）の前提（令和８年度） | 901,000㎥ | 5,625人 | **439.0L** |

案の439Lは過去10年平均です。**震災復興期（有収水量が低く、復興作業員により給水人口が多かった時期）を含むため過小**になっています。

### 3-2. 見直し案

| 推計方法 | 令和８年度 | 令和17年度 | 案との差 |
|---|---:|---:|---:|
| 経営戦略（案）＝給水人口 × 439L | 901,000㎥ | 723,000㎥ | － |
| **見直し案Ａ＝給水人口 × 489L（直近3か年平均）** | **1,004,384㎥** | **805,073㎥** | **＋11.5％** |
| 見直し案Ｂ＝用途別（家事用は人口比例、非家事用は別トレンド） | 要試算 | 要試算 | － |

### 3-3【重要】用途区分別の有収水量シェア

調定データ（1か月分3,060件）から集計した結果です。

| 用途区分 | 件数 | 水量（㎥／月） | シェア |
|---|---:|---:|---:|
| **家事用** | 2,471 | 34,668 | **44.5％** |
| **工業用** | **66** | 28,067 | **36.1％** |
| 団体用 | 195 | 7,498 | 9.6％ |
| 営業用 | 298 | 6,908 | 8.9％ |
| 湯屋用 | 2 | 662 | 0.9％ |
| 臨時用・委託船舶 | 27 | 44 | 0.0％ |

**家事用は有収水量の44.5％にすぎません。工業用が36.1％をわずか66件で占めています（大半が水産加工業）。**

経営戦略（案）は有収水量の**全量**を「給水人口 × 1人1日あたり有収水量」で推計していますが、**55.5％を占める非家事用は給水人口に連動しません。** 推計方法そのものに構造的な弱点があります。

見直し案Ｂを採る場合、水産加工業の生産動向・事業所数の見通しについて町・事業者への確認が必要です。

なお、**給水人口の推計値（令和８年度5,625人）は令和７年度実績5,656人と整合**しており、こちらは差し替え不要です。

### 説明のストーリーへの影響

引継ぎメモ 6.1 の「二重表現」の整理は方向性としては適切ですが、**数値を入れ替える必要があります。**

| 用途 | 引継ぎメモ | 是正後 |
|---|---|---|
| 住民・議会向け「なぜ改定が必要か」 | 「現行の**半分**しか回収できていない」（52.87％） | 「現行料金は必要な費用の**35％**しか賄えていない」（令和７年度） |
| 将来財源の必要性 | 給水原価572円、1.5倍改定でも回収率34％ | 給水原価277円、必要改定率＋122.8％（総括原価ベース） |

**是正後のほうが、住民説明としてはむしろ「現状の深刻さ」が伝わり、かつ「必要改定率」は現実的な水準になります。** 説明のしやすさは改善されます。
