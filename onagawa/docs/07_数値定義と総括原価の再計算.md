### 3-1. 採用した推計

経営戦略（案）の4,316,000㎥に対し **＋11.2％** です。

### 3-2. なぜ見直し案Ａを採用したか

| 年度 | 有収水量 | 給水人口 | 1人1日 |
|---|---:|---:|---:|
| 令和５年度 | 1,039,302㎥ | 5,842人 | 487.4L |
| 令和６年度 | 1,019,321㎥ | 5,769人 | 484.0L |
| 令和７年度 | 1,024,576㎥ | 5,656人 | 496.3L |
| **直近3か年平均** | | | **489.26L** |
| 経営戦略（案）の前提 | | | **439.0L** |

① **案の439.0Lは過去10年平均で、震災復興期（有収水量が低く、復興作業員により給水人口が多かった時期）を含みます。** 直近3か年の実績は484.0〜496.3Lで、案の前提を10％以上上回っています。案の令和８年度推計901千㎥は令和７年度実績1,024,576㎥を12％下回り、初年度から実績と乖離します。

② **有収水量の実績はR2〜R7の6年間で1,020〜1,053千㎥とほぼ横ばい**です（年▲0.1％程度）。案の「R6の1,019千㎥からR8に901千㎥へ11.6％減」という想定は、実績の推移と整合しません。

③ **総務省マニュアルの標準的手法（給水人口 × 1人1日あたり有収水量）の枠組みを維持し、基礎数値だけを直近実績に差し替える方式**のため、経営戦略（案）本文の修正が最小で済み、令和８年９月末の中間報告に間に合います。

### 3-3. 採用しなかった案

**用途別推計（家事用は給水人口比例、非家事用は別トレンド）** … 理論的には最も妥当ですが、非家事用（有収水量の55.5％）のトレンド設定に水産加工業の生産動向・事業所数の見通しが必要で、中間報告までに確定できません。**次期の経営戦略改定時に移行することを推奨します。**

### 3-4. 案Ａの限界（本文に注記すべき事項）

案Ａは有収水量の全量に給水人口の減少率を適用します。実際には**非家事用（55.5％）は給水人口に連動しない**ため、非家事用が横ばいで推移する場合には過小推計となります。この意味で**案Ａは保守的（原価を高めに、改定率を高めに見積もる）側の推計**です。

| 用途区分 | 件数 | シェア |
|---|---:|---:|
| **家事用** | 2,471 | **44.5％** |
| **工業用** | **66** | **36.1％** |
| 団体用 | 195 | 9.6％ |
| 営業用 | 298 | 8.9％ |

なお給水人口の推計値（令和８年度5,625人）は令和７年度実績5,656人と整合しており、差し替えは不要です。

## 6【重要】実務上の含意　－　目標水準の再設定が必要です

**資産維持率1％でも必要改定率は＋157.6％です。** 20㎥の家庭料金は2,475円→6,377円になります。

| 資産維持率 | 必要改定率 | 20㎥家庭料金（税込） |
|---|---:|---:|
| 1％ | ＋157.6％ | 6,377円 |
| 2％ | ＋181.2％ | 6,959円 |
| 3％ | ＋204.7％ | 7,541円 |

**総括原価ベースの料金回収率100％を計画期間内に達成することは、現実的には困難と考えられます。**

したがって、経営戦略および料金改定提案では次の整理を推奨します。

| 項目 | 推奨する整理 |
|---|---|
| 計画期間内の目標 | 料金回収率100％ではなく、**経常収支比率100％（繰出基準外の他会計補助金を除いたベース）** |
| 料金回収率の目標 | 計画終期までに70％程度（中長期的に100％） |
| 改定の方式 | **段階改定**（第1段階＋35％、4年後に第2段階＋35％＝累積＋82.3％）。これで平常時ベースの料金回収率は102.8％に到達 |
| 総括原価の位置づけ | **「将来必要となる財源の総量」を示すもの**として提示し、「1回の改定では到達しない」ことの根拠に使う |

これは引継ぎメモ6.1の「二重表現」の考え方と同じ構造ですが、**数値を確定値に置き換えたものです。**
