## 0. 結論（3点）

1. **長期前受金戻入益の控除額が誤っていることを、原資料と財政シミュの直接照合で確認しました。**
   他の4費目（維持管理費・減価償却費・既往債利息・新規債利息）はすべて財政シミュの値と一致していますが、**長期前受金戻入益だけがプレースホルダ（▲450,000千円）のまま残っています。** 正しくは財政シミュの令和８〜12年度予測値の合計 **▲1,556,820千円**（3.46倍）です。

2. **加えて、`onagawa_cost_sim_v1.xlsx` の総括原価シミュレーションに数式の不具合があります。**
   【A】原価集計表の合計行がR9以降**累計値**になっており、5年合計が7,277,783千円（正しくは2,462,569千円）と約3倍になっています。この誤った合計を用いた【B】の給水原価1,686.2円・料金回収率8％も誤りです。**なお【C】感度分析は正しく計算されています。**

3. **【訂正】前回お伝えした必要改定率＋122.8％は誤りでした。**
   総括原価の年平均を令和７年度の給水収益で除しましたが、両者は有収水量の前提が異なります。分子と分母を同じ有収水量ベースで揃えると、**＋141.6〜187.2％**（資産維持率と有収水量の前提による）となります。

原資料の費目を、経営戦略試算シート【成行】財政シミュの値と1件ずつ照合しました。

原資料の備考には **「（推計値）財政シミュR6〜R7平均から推計。要精査。」** と明記されています。
ただし財政シミュのR6は334,202千円、R7は334,252千円ですので、**その平均から5年分を推計しても約1,671,000千円**となり、450,000千円にはなりません。

**他の4費目がすべて財政シミュと一致していることから、長期前受金戻入益だけが置き換えられないまま残ったプレースホルダと判断されます。**
財政シミュには令和８〜12年度の予測値（逓減を織り込んだもの）が入っていますので、これをそのまま使うのが正しい処理です。

## 2【訂正】前回の必要改定率について

前回（令和８年８月３日）に「必要改定率は＋327.2％から＋122.8％へ」とお伝えしましたが、**＋122.8％は誤りでした。**

総括原価の年平均（266,187千円）を令和７年度の給水収益（119,481千円）で除しましたが、
- 分子の総括原価は令和８〜12年度（有収水量 年平均863千㎥）
- 分母の給水収益は令和７年度（有収水量 1,025千㎥）

と、**有収水量の前提が異なっていました。**

分子と分母を同じ有収水量ベースで揃えると、上表のとおり **＋141.6〜187.2％** となります。
控除項目の是正が大きな効果を持つ（＋327.2％ → ＋157.6％）という結論は変わりませんが、水準は前回お伝えしたものより高くなります。

### 3-1. No.5 資産維持率の考え方

原資料（`tariff_cost_calc` 【D】）には次の整理があります。

| 設定 | 年間額 | 出典・考え方 |
|---|---:|---|
| 1.0％（試算シート現設定） | 約8,960千円 | 「従前それほど大きな修繕がないため1.0％と仮定」 |
| 0.688％（平泉町事例） | 約6,167千円 | 自己資本構成比率×企業債利率。改定率抑制のため別算出方式 |
| 2.3％（松山市事例） | 約20,615千円 | |
| **3.0％（日本水道協会要領の標準）** | 約26,889千円 | 最大の財源確保 |
| **★原資料の推奨：1.5〜2.0％** | 約13,440〜17,920千円 | 「料金改定率が大きくなりすぎない範囲で資産更新財源を確保する水準」 |

**引継ぎメモは3％を「正式ケース」としていますが、原資料は1.5〜2.0％を推奨しています。** どちらを採るかで必要改定率は＋145.6％〜＋157.6％（有収水量見直し後）の間で変わります。

なお、**下水道事業経営戦略（案）は「収支不足補てんに伴う基準外繰入金を計上している状態であるため、現状では資産維持費を加味していません」としています。** 水道は繰出基準外の他会計補助金166,434千円を受けている状態ですので、**同じ町の中で水道だけ3％を算入する理由の説明が必要になります。**
