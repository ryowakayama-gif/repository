## 1. 料金算定対象期間の設定

**令和９年度〜令和13年度（5年間）**

料金改定の施行を令和９年度からと想定し、その施行後5年間に発生する原価を料金で賄う形としました。したがって：

| 項目 | 設定 |
|---|---|
| 原価の算定期間 | 令和９年度〜令和13年度 |
| 対象資産の期首 | **令和８年度末** |
| 対象資産の期末 | **令和13年度末** |
| 有収水量 | 令和９〜13年度の合計 |

### 令和８〜12年度で算定した場合との差

| 項目 | R8〜R12 | **R9〜R13** | 差 |
|---|---:|---:|---|
| 対象資産（期首期末平均） | 2,633,094,719円 | **3,117,325,587円** | ＋18.4％ |
| 有収水量5年計 | 4,801,318㎥ | **4,690,698㎥** | △2.3％ |
| 長期前受金戻入益（控除） | ▲1,556,820千円 | **▲1,510,688千円** | 控除額が縮小 |
| 新規債利息 | 127,402千円 | **161,156千円** | ＋26.5％ |
| 必要改定率（1.0％） | ＋157.6％ | **＋184.4％** | ＋26.8pt |
| 必要改定率（3.0％） | ＋204.7％ | **＋241.4％** | ＋36.7pt |

**期間を1年後ろにずらすだけで必要改定率が27〜37ポイント上がります。** 主な理由は次の3点です。

1. **令和13年度は国庫補助金の計上がありません**（財政シミュ Row77がR13以降ゼロ）。長期前受金の増加が3,000千円のみとなり、対象資産が押し上げられます
2. **新規債利息が期間後半に急増します**（R9 18,507千円 → R13 42,991千円）
3. **有収水量が1年分後ろにずれるため減少します**（R8 1,004,512㎥ → R13 893,892㎥）

**算定対象期間の設定が結果に与える影響は小さくありません。** 施行時期を令和９年度とするか令和10年度とするかで、さらに数値が動きます。

## 4【重要】実務上の含意

**資産維持率1.0％でも必要改定率は＋184.4％です。** 20㎥の家庭料金は2,475円→7,038円になります。

**総括原価ベースの料金回収率100％を一度の改定で達成することは、現実的には困難です。** 次の整理を推奨します。

| 項目 | 推奨する整理 |
|---|---|
| 総括原価の位置づけ | **「将来必要となる財源の総量」**として提示し、「1回の改定では到達しない」ことの根拠に使う |
| 計画期間内の目標 | 料金回収率100％ではなく、**経常収支比率100％（繰出基準外の他会計補助金を除いたベース）** |
| 料金回収率の目標 | 計画終期までに70％程度（中長期的に100％） |
| 改定の方式 | **段階改定**（第1段階＋35％、4年後に第2段階＋35％＝累積＋82.3％）。これで平常時ベースの料金回収率は102.8％に到達 |

### 資産維持率の選択について

| 設定 | 出典・考え方 |
|---|---|
| 1.0％ | 試算シート現設定。「従前それほど大きな修繕がないため1.0％と仮定」 |
| 0.688％ | 平泉町事例。自己資本構成比率×企業債利率。改定率抑制のため別算出方式 |
| 1.5〜2.0％ | **原資料の推奨。**「料金改定率が大きくなりすぎない範囲で資産更新財源を確保する水準」 |
| 2.3％ | 松山市事例 |
| 3.0％ | 日本水道協会要領の標準 |

**下水道事業経営戦略（案）は「収支不足補てんに伴う基準外繰入金を計上している状態であるため、現状では資産維持費を加味していません」** としています。水道も繰出基準外の他会計補助金166,434千円を受けている状態ですので、**資産維持費を算入する場合はその理由の説明が必要**になります。

## 5. 有収水量（令和９〜13年度）　－　見直し案Ａを採用

**給水人口 × 489.26L／人日（直近3か年平均）**

| 年度 | 給水人口 | 有収水量 |
|---|---:|---:|
| （令和８年度） | 5,625人 | （1,004,512㎥） |
| 令和９年度 | 5,501人 | 982,388㎥ |
| 令和10年度 | 5,377人 | 960,264㎥ |

| 令和12年度 | 5,129人 | 916,016㎥ |
| 令和13年度 | 5,006人 | 893,892㎥ |
| **5年計（R9〜R13）** | | **4,690,698㎥** |

### 採用理由

| 年度 | 有収水量 | 給水人口 | 1人1日 |
|---|---:|---:|---:|
| 令和５年度 | 1,039,302㎥ | 5,842人 | 487.4L |
| 令和６年度 | 1,019,321㎥ | 5,769人 | 484.0L |
| 令和７年度 | 1,024,576㎥ | 5,656人 | 496.3L |
| **直近3か年平均** | | | **489.26L** |
| 経営戦略（案）の前提 | | | **439.0L** |

① 案の439.0Lは過去10年平均で、**震災復興期**（有収水量が低く復興作業員により給水人口が多かった時期）を含みます。案の令和８年度推計901千㎥は令和７年度実績1,024,576㎥を12％下回ります。
② 有収水量の実績は**R2〜R7の6年間で1,020〜1,053千㎥とほぼ横ばい**（年▲0.1％程度）で、案の想定と整合しません。
③ 総務省マニュアルの標準手法の枠組みを維持し基礎数値だけを差し替える方式のため、**経営戦略本文の修正が最小で済み9月末の中間報告に間に合います。**

**採用しなかった案：** 用途別推計（家事用は給水人口比例、非家事用は別トレンド）。理論的には最も妥当ですが、非家事用（55.5％）のトレンド設定に水産加工業の生産動向が必要で中間報告に間に合いません。次期改定時の移行を推奨します。

**案Ａの限界：** 有収水量の全量に給水人口の減少率を適用するため、非家事用（55.5％）が横ばいで推移する場合は過小推計となります。この意味で**保守的（原価を高めに、改定率を高めに見積もる）側の推計**です。

| 用途区分 | 件数 | シェア |
|---|---:|---:|
| **家事用** | 2,471 | **44.5％** |
| **工業用** | **66** | **36.1％** |
| 団体用 | 195 | 9.6％ |
| 営業用 | 298 | 8.9％ |
