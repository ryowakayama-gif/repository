# 令和７年度決算　精査メモ

対象：女川町　上水道事業会計／下水道事業会計（公共下水道事業・浄化槽事業）
作成：令和８年８月
出典：令和７年度 上水道事業会計決算書、下水道事業会計決算書、令和７年度水道分決算審査意見書（案・初稿）、令和６年度末／令和７年度末残高月報、

## 0. 結論（先に３点）

1. **経営戦略（案）の数値は、決算を入れ替えるだけでは足りない。前提そのものが崩れている。**
   水道の資金残高は令和７年度末で 50,296 千円。現行案が「令和17年度に約4千万円まで減少する」と見込んでいた水準に、計画の初年度で既に到達しています。

2. **令和７年度の巨額損失（水道 15.8億円）は、その大半が過年度会計処理の一括修正という一過性要因。**
   将来推計の母数から分離しないと、実力値を大きく誤ります。一方で、累積欠損金 27.3億円は事実として残り、経営戦略の記載に反映が必要です。

3. **浄化槽事業は既に法適用済の報告セグメントであり、経営戦略だけが空白。**
   下水道事業経営戦略（案）は対象を「公共下水道事業」に限定しているため、浄化槽事業は現状どの経営戦略にも含まれていません。

## 3. 論点として整理しておくべき事項

### 3-1. 水道　－　有収率低下は「一時的」か「構造的」か

有収率 73.64％の直接原因は、①鷲神浄水場系統の水質基準超過対策による捨水、②江島海底送水管破損に伴う応急給水です。
経営戦略の推計にあたって、**この２要因がいつ解消するかの前提を置く必要があります。**

- 鷲神浄水場 高度処理施設 … 完成時期
- 江島海底送水管 … 本復旧の時期と事業費、財源（災害復旧の対象となるか）

この２点が決まらないと、有収水量・動力費・修繕費・委託料のいずれも推計できません。**最優先の確認事項です。**

### 3-2. 水道と下水道で有収水量の動きが逆になっている

- 水道：有収水量 **+5,255㎥**。意見書は「営業用（水産加工販売・店舗販売）と工業用（製氷・冷凍・大口加工）の増加」が要因と記載。
- 下水道：有収水量 **△16,246㎥**。意見書は「工業用が前年度と比較して大きく減少」と記載。

下水道の有収水量は水道メーターで計測しているため、接続需要者については両者が連動するはずです。同一年度・同一用途区分で逆方向に動いているため、
**①増加分が下水道未接続区域（離半島部等）で生じているのか、②用途区分の付替えやデータ上の要因なのか**、の確認が必要です。
経営戦略の水需要予測はこの点の解釈に依存します。

### 3-3. 繰入金の整理

- 水道：他会計補助金 166,987 千円。**大半が繰出基準に基づかないもの**（意見書も同旨を指摘）。
- 下水道：他会計繰入金 241,311 千円。うち資本的収支の基準外が例年 1.5億円規模。
- 下水道経営戦略（案）にも「基礎年金拠出金に係る公的負担」「公営企業の脱炭素化の取組」を基準内として算定する検討の必要性が記載されています。

**基準内／基準外の区分を先に固めないと、経営指標も収支計画も動きます。** 一般会計との協議材料として、繰出基準（毎年度４月１日通知）に照らした洗い出しを先行させることを推奨します。

### 3-4. 未収金

水道の令和７年度末未収額 104,000 千円のうち、給水収益等は 751 千円で、残る 103,249 千円は国庫補助金 33,000 千円・他会計補助金 50,973 千円・消費税還付金 19,276 千円です。
料金の徴収率は良好（営業収益の収入率 99.43％）である一方、**補助金の年度内収入が実現していない**ことが資金繰りを圧迫しています。資金計画上の論点として整理が必要です。

## 4. 浄化槽事業　－　経営戦略策定の前提整理

| 項目 | 内容 |
|---|---|
| 法適用 | 令和４年４月１日から地方公営企業法（全部適用）。下水道事業会計の報告セグメント |
| 事業内容 | 市街化区域以外で整備により生活環境の改善を図る必要がある区域における、し尿・生活雑排水等の処理 |
| 経緯 | 令和２年度に下水道区域を縮小し浄化槽区域へ変更。離半島部は地区単位の大型合併処理浄化槽で対応する方針 |
| 規模（R7） | 収益 22,313千円／費用 22,524千円／資産 156,130千円／負債 147,411千円 |
| 収益構成（R7） | 浄化槽使用料 39.46％、長期前受金戻入益 38.48％、他会計補助金 21.57％、雑収益 0.49％ |
| 費用構成（R7） | 浄化槽施設管理費 58.11％、減価償却費 40.84％、総係費 0.73％、支払利息 0.32％ |
| 経営指標（R7） | 経常収支比率 99.06％／経費回収率 64.40％／有形固定資産減価償却率 19.17％ |
| 企業債 | 平成25年度以降、浄化槽事業として複数本を借入（利率 0.07％〜1.3％、最終償還は令和31年度） |

**論点：経営戦略を単独で策定するか、下水道事業経営戦略に「浄化槽事業編」として統合するか。**
事業規模が年間約2,200万円と小さいこと、人口推計・物価前提・組織を公共下水道と共有できることから、統合方式であれば期間・費用とも大幅に圧縮できます。
一方、総務省への報告や事業別の見える化の観点からは単独策定にも合理性があります。**予算要求の内容が変わるため、先に方針決定が必要です。**
