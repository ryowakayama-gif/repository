# 作業ルール（女川町 料金改定検討）

このディレクトリで作業するときの取り決め。全体像は `README.md`、
既知の不整合は `05_review/file_check_report.md` を参照。

## ファイルの扱い

- `01_source_evidence/` は**読み取り専用**。編集・上書きしない。
- 成果品を更新するときは `02_deliverables/` のファイルを直接更新する。
  生成スクリプトを書く場合は `scripts/` に置き、成果品を再生成できる形にする。
- ファイル名は**半角英数字のみ**（日本語・`㎥` 等の特殊文字は使わない）。
  ダウンロード時の文字化けを避けるための既存ルール。
- **受け渡し用にまとめる際も、必ず半角英数字のファイル名に置き換えること。**
  日本語名のままzipにすると、Windowsで開いたときにファイル名が文字化けする
  （圧縮時にUTF-8であることを示す情報が付かないため、Shift-JISとして読まれる）。
  `04_prefecture_unification/01_final_deliverables/` の6ファイルは日本語名のままなので、
  まとめるときは英数字名に変えたうえで、対応表（`00_filename_map.md`）を同梱する。

## Excelを扱うときの注意

成果品は openpyxl で生成されており、**数式の計算結果がファイルに保存されていない**。

- `openpyxl` の `data_only=True` で読むと数式セルは `None` になる。
  数値を検証したいときは数式を読んで再計算するか、LibreOffice でヘッドレス再計算してから読む。
- 既存ファイルを openpyxl で開いて保存し直すと、書式や結合セルが崩れることがある。
  更新は必要な範囲に限定し、保存後に結合セル範囲とシート構成を確認する。

## 資産維持率のマスターキー

`02_deliverables/01_rate_reform_simulation_MAIN.xlsx` の `01_前提条件` **B14セル**が
全シート連動のマスターキー。既定値は **3%**（業務仕様書の正式ケース）。

ここを変更すると 02〜08 シートが再計算される。ハードコードした数値を追加する場合は、
B14 の値と整合しているか必ず確認する（現に 02シートの注記文が1%ケースのまま残っている）。

## 総括原価の前提条件

経営戦略試算シートと成果品とで前提が食い違っている箇所があり、
`06_capital_plan_update/09_assumption_switch_cost_calc.xlsx` で項目ごとに切り替えられる。
総括原価の数値を扱うときは、どちらの前提に立っているかを必ず明示すること。

確定した前提（最新）は次のとおり。

- 長期前受金戻入益：経営戦略の実額（R8〜R12）を確定値として使用。
  成果品の推計値450,000千円は使わない。
- 一般会計繰入金：**基準内繰入金（他会計補助金272,997千円）を控除する**。
  控除しない場合は2.45倍。1.99〜2.45倍は控除条件のみを変えた比較値であり、
  上限・下限ではない（償却年数などを併せて変えると2.5倍を超える場合がある）。
- その他営業収益・受取利息・雑収益、雑支出：経営戦略の原価計算表に合わせ、控除・算入しない。
- 動力費・薬品費：単価算定に誤りがあるため実績単価に補正（R8〜R12で＋47,167千円）。
- 減価償却費：経営戦略の財政シミュレーションが計上する既存資産分
  （R6末取得分1,822,881千円＋R7取得分32,456千円＝1,855,337千円）に、
  調査票に基づく新規分147,642千円を加えた **2,002,979千円**。
  差引方式（2,032,440−218,421＋147,642）は既存分が41,318千円不足するので使わない。
- 建設改良費調査票の「財源構成割合(%)」欄：単純な割合で出せない事業があるため、
  入力された金額を正として扱う。様式の財源行の数式は割合前提のままなので、
  集計表の値は使わず入力金額から直接集計すること。

中間報告書（09_interim_report）の採用値：
総括原価5年計 1,175,810千円／給水原価 272.4円/㎥／総括原価回収割合 50.3%／
年間不足額 116,993千円/年／**必要改定率 1.99倍（試算値）**。

`09_interim_report/onagawa_adopted_calc.xlsx`（採用計算表）が本文の根拠。
`build/make_calc.py` で再生成でき、`07_本文照合表` が本文18項目との一致を検算する。
数値を変えたら必ずこの照合が通ることを確認する。
`02_deliverables/` の旧Excelは前提が古く一致しない。計算根拠として配らない
（受け渡し用zipでは `09_old_do_not_use/` に分離している）。

## 位置づけを落とさずに書く

次の4点は、数値だけを引用すると意味が変わる。必ず条件と一緒に書く。

- **1.99倍は確定した改定水準ではない。** 他会計補助金272,997千円の全額を基準内繰入金として
  控除できる場合の試算値。控除の根拠は町の資料で未確認で、控除しないと2.45倍。
- **口径別3-Aの「回収割合100％」は検証値ではない。** 総括原価と一致するよう水準係数を
  逆算した結果で、実際の調定データで確かめた値ではない。
- **産業用特例（3-B／D案）は未設計。** 適用の境界で料金が約6割下がる逆転があり、
  町全体の減収額も未算定。住民・議会説明や条例化の対象にしない。
- **議決と適用開始は別の時点。** 議決は令和9年3月議会、新料金の適用開始は令和9年4月以降。
  令和8年度の料金は現行のままで、増収額は通年ベースの試算値。

令和8年4〜6月請求分の基本料金・メーター使用料の免除（国の物価高騰対応重点支援
地方創生臨時交付金による）が給水収益に未反映。原典は未確認なので、町への確認事項として扱う。

現行料金の端数処理は1円未満の切捨て。条例案と試算の双方でそろえる。

北上川導水管は経営戦略の投資計画に計上されていない（更新投資額の内訳の「取・導水管」は全年度ゼロ）。
引継ぎメモと `01_前提条件` F27 の「北上川導水管」の記載は取り違えなので、そのまま使わないこと。

## 成果品の作成者情報

Word・Excel の作成者／最終保存者は **若山諒太** に統一する。
`scripts/set_document_author.py` が zip の `docProps/core.xml` だけを書き換えるので、
数式・書式・結合セルには影響しない。新しい成果品を追加したら TARGETS に加える。

受領資料は出所を残すため変更しない（`01_source_evidence/` および
`06_capital_plan_update/construction_cost_survey_R8toR17.xlsx`）。

生成スクリプトで Word を作る場合は、`doc.core_properties` に
title / subject / author / last_modified_by / comments を設定してから保存する。

## 成果品に書かないこと

- 作業手法や検証手法を指す用語（レビュー手法の名称など）は成果品に残さない。
- 情報処理・システム開発の用語や、機械的な処理をうかがわせる言い回しは使わない。
  「データセット」は「明細」、「シミュレーションモデル」は「試算」など実務語に置き換える。
  「モデル世帯」「モデルケース」は水道料金算定の実務語なのでそのまま使ってよい。

## 数値を書くとき

- 確定値と推計値を必ず区別し、推計値には出所と「要更新」の注記を付ける。
- 税区分を必ず明示する。料金表・利用者影響は税込、収支・総括原価・給水原価・供給単価は税抜。
  R7実績の供給単価は税込128.2円/㎥・税抜116.6円/㎥で、税抜の将来推計136.9円/㎥と比較するのは
  税抜の116.6円/㎥のほう。
- 「料金回収率」は決算指標（経営比較分析表の算式。R5で52.87%）を指す。
  資産維持費を加え基準内繰入金を控除した本件独自の割合は「総括原価回収割合」と呼び分ける。
- 給水原価は前提により変わるので、どのベースか明示する。
  - R5実績逆算ベース：約242円/㎥（住民説明用）
  - R8〜R12総括原価ベース（確定した前提）：272.4円/㎥
- 塩竈市「生産用水用」の表現ルール：
  - ✅「塩竈市には団地水産加工業協同組合向けの生産用水料金105円/㎥（税抜）という
    既存制度があり、女川町の激変緩和策を検討する際の有力な参考モデルとなる」
  - ❌「塩竈モデルを全県全水産加工業者に適用すべきである」
    （全県適用は収入減・補填財源・制度設計の論点を招くため）

## WBSと進捗

`10_wbs/build/wbs_data.py` が WBS・停滞事項・リカバリ・仕様書対応の定義データ。
ここを直して `make_wbs_xlsx.py` と `make_wbs_docx.py` を実行すると Excel と Word が更新される。
作業の状態が変わったら必ずここを直す（Excel・Wordを直接編集しない）。

業務名は「**上下水道**経営指標評価書作成等業務委託」。料金改定の検討はその一部にすぎず、
下水道の経営指標評価と、修正前後決算を含む指標分析（評価書の本体）が残っている。

`01_source_evidence/sewer_fee_analysis_memo.docx` は他団体向けに作成した
下水道使用料分析の手順書であり、女川町のデータは含まない。必要な入力データの一覧として使う。

業務仕様書の原本は未入手。照合できているのは `03_documents/spec_alignment_summary.md`
（令和8年6月2日作成）の記載のみなので、仕様書適合の断定は避ける。
