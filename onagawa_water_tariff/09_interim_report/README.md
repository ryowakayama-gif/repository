## 算定の基礎

| 指標 | 値 |
|---|---:|
| 総括原価（令和8〜12年度 5年計） | 1,175,810千円 |
| 　うち減価償却費 | 2,002,979千円 |
| 給水原価 | 272.4円/㎥ |
| 供給単価（令和8〜12年度・税抜） | 136.9円/㎥ |
| 総括原価回収割合 | 50.3% |
| 年間不足額 | 116,993千円/年 |
| **必要改定率** | **1.99倍** |
| 料金不足額（定義③） | ▲29,488千円/年 |

基準内繰入金（他会計補助金272,997千円）を控除する前提。
控除しない場合は総括原価1,448,807千円・給水原価335.7円/㎥・**2.45倍**。
1.99〜2.45倍は繰入金の控除条件のみを変えた比較値であり、上限・下限ではない
（償却年数などを併せて変えると2.5倍を超える場合がある）。

減価償却費は、経営戦略の財政シミュレーションが計上する既存資産分
（令和6年度末取得分1,822,881千円＋令和7年度取得分32,456千円＝1,855,337千円）に、
建設改良費調査票に基づく新規分147,642千円を加えたもの。
従前の差引方式では既存分が41,318千円不足していた。

## 各パターンの設計

### パターン1　現行体系維持案

現行の用途別・逓減の体系を維持し、基本料金・従量料金・メーター使用料に一律の改定率を乗じる。
+30％／+50％／+99％（1.99倍）の3水準で影響を示している。

### パターン2　赤字半減案

料金不足額（定義③）29,488千円/年の半減を目標とし、必要改定率1.125倍。
基準内繰入金を収入側に算入して算定している。
第1次改定（令和8年度内）→第2次改定（令和13〜17年度）の2段階。

定義③は資産維持費を含むため、実際の資金収支とは一致しない。
総括原価ベースの不足額を半減する場合は1.495倍となる。

### パターン3　口径別料金表案

**3-A 標準逓増型**：県内他団体のうち口径区分が細かい塩竈市の体系比率を参考に、
総括原価を全額回収する水準へ調整した料金表。

| 口径 | 13mm | 20mm | 25mm | 40mm | 50mm | 75mm | 100mm |
|---|---:|---:|---:|---:|---:|---:|---:|
| 基本料金 | 752円 | 1,396円 | 2,255円 | 5,369円 | 10,738円 | 21,476円 | 40,805円 |

| 水量区分 | 〜10㎥ | 11〜20㎥ | 21〜50㎥ | 51〜100㎥ | 101㎥超 |
|---|---:|---:|---:|---:|---:|
| 従量料金 | 89.1円/㎥ | 187.9円/㎥ | 252.3円/㎥ | 273.8円/㎥ | 316.8円/㎥ |

**3-B 産業配慮型**：3-Aに産業用特例（月500㎥以上の指定業種・基本料金なし・115円/㎥）を併設。
この設定案には境界の逆転がある（25mmで499㎥152,680円→500㎥57,500円、62.3%減）ため、
超過部分への適用・料金上限方式・減免率方式・年間認定の4方式を比較したうえで採用方式を決める。

## 影響のとりまとめ（第9章）

| 使用者区分 | ①現行体系維持 | ②赤字半減 | ③口径別3-A | ③口径別3-B |
|---|---:|---:|---:|---:|
| 標準家庭（20mm・20㎥） | 1.99倍 | 1.12倍 | 1.67倍 | 1.67倍 |
| 仮定事例（25mm・200㎥） | 1.99倍 | 1.12倍 | 2.50倍 | 2.50倍 |
| 仮定事例（50mm・1,000㎥） | 1.99倍 | 1.12倍 | 2.86倍 | 1.03倍 |
| 湯屋用（500㎥） | 1.99倍 | 1.12倍 | 4.30倍 | 4.30倍 |
| 総括原価回収割合 | 100.0% | 56.5% | 100.0% | 算定していない |

3-Aの倍率は口径と使用水量の組合せで変わるため、第8章に口径×水量の倍率表を掲載している。
値下げとなるのは13mmで月3㎥程度までに限られ、月6〜10㎥は13mmでも1,265円→1,465円に上がる。

水産加工業の19社は口径・水量を仮定した事例であり、合計額と町全体の減収額は算定していない
（100mmは1社の仮定が口径全体実績の約5.71倍、75mmは5社の仮定が口径全体を超過するため）。

## 指摘事項への対応（14件）

| No | 要点 | 対応 |
|---|---|---|
| R01 | 基準内繰入金の全額控除の裏付け | 控除する前提は維持し、条件付きの試算である旨と感応度を明示 |
| R02 | 減価償却費の既存資産分が41,318千円不足 | 財政シミュレーションの計上額に直接接続し、全数値を更新 |
| R03 | 資産維持費の対象資産の母数・期間 | 出所・推計である旨・期末日のずれ・感応度を明示 |
| R04 | 19社モデルを財政効果に使えない | 個別事例に限定し、合計額・減収額・3-Bの収入と回収割合を取り下げ |
| R05 | 税込・税抜の混在 | 橋渡し表を新設。令和7年度の税抜単価116.6円/㎥を明示 |
| R06 | 口径別案が実データ未検証 | 模型の限界と実データによる参考値（約2.10倍）を明示 |
| R07 | 赤字半減の定義 | 定義③を「料金不足額」と改称し、資金収支と異なることを明示 |
| R08 | 産業特例の境界の逆転 | 逆転を数値で示し、4方式を比較対象として提示 |
| R09 | 利用者影響の説明と料金表の矛盾 | 「10㎥以下は下がる」を削除し、口径×水量の倍率表を新設 |
| R10 | 需要予測と実施時期の接続 | 約12％の段差と年次資金収支の必要性を明示 |
| R11 | 料金回収率の分母 | 第4章以降を「総括原価回収割合」に改称し、用語定義表を新設 |
| R12 | 制度・比較・地域背景の説明 | 3％の位置づけ、気仙沼市の逓減、出島大橋開通など6点を修正 |
| R13 | 「2.38倍が上限」 | 上限表示を取りやめ、控除条件のみの比較値であることを明示 |
| R14 | 根拠資料の版と再現性 | 採用資料の一本化と表記ルールを第12章に明記 |
