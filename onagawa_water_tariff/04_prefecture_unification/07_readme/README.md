## 検証プロセスの再現方法

### 1. 料金構造の逆算検証(Python実行)

```bash
cd 03_verification_scripts/
python3 verify_all_rates.py
```

期待される出力:
- 気仙沼市: 14サンプル全件一致 ✓
- 石巻広域: 20サンプル以上全件一致 ✓
- 塩竈市: 14サンプル全件一致 ✓

### 2. 影響試算の再現

```bash
cd 03_verification_scripts/
python3 impact_simulation.py
```

出力内容:
- 個別事業者への影響率(単純統一時)
- 県全体への年間影響(単純統一vs塩竈モデル)
- 女川町中規模加工業者の政策シナリオ別比較

### 3. グラフの再生成

```bash
cd 04_chart_generation/
python3 generate_charts.py
```

Ubuntu環境では日本語フォントが必要:
```bash
sudo apt-get install fonts-noto-cjk fonts-ipafont-gothic
```

### 4. Word文書の再生成(必要な場合)

```bash
cd 05_document_generation/
npm install docx
node generate_report.js
```

## 主要な発見と論点

### 発見1: 女川町の料金水準
女川町の現行料金は、他3団体の約1/3水準。
これは女川町独自の「一般用逓減制」(101㎥超で110円/㎥)によるもの。

### 発見2: 単純統一の影響
4団体の加重平均的料金で単純統一した場合:
- 女川町水産加工業: +190%超の壊滅的負担増
- 他3団体: ±10%以内(むしろ減額)
- 県全体では-3.5%(約1億円減)

### 発見3(最重要): 塩竈市『生産用水用』区分
塩竈市には既に「生産用水用」(105円/㎥、基本料金なし)という
産業用優遇料金区分が存在。女川町の逓減制と実質同水準を実現している。

つまり「産業用優遇は女川町固有」という前提は誤りで、
県内2団体で既に同等水準の産業用優遇が運用中である。

### 発見4: 塩竈モデル統一の効果
塩竈市の「生産用水用」区分を全県統一料金体系に組み込むことで、
女川町水産加工業への影響を+190%超から+3%程度に抑制可能。

## 検証データの精度

すべての料金構造は、各団体の公表資料(条例別表・公式早見表)から
逆算検証を経て確定した確定値です。ただし以下は仮定・推計を含みます:

- 水産加工業者の規模分布(小5+中8+大5+超大1=19社モデル)
  → 女川町水産加工団地の構成を典型例として想定
- 各団体の水産加工業社数(気仙沼120社、石巻180社、塩竈90社)
  → 一般情報からの概算
- 統一料金水準の「加重平均」
  → 議論用の仮置きであり、実際の決定にあたっては各団体の
     財政条件・目標給水原価を踏まえた精緻な設計が必要
