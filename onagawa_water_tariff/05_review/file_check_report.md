## 3. 検出した不整合（詳細）

### 3.1 【高】総括原価の5年合計が約3倍に膨張

**対象**：`02_deliverables/02_total_cost_simulation.xlsx` シート「総括原価シミュレーション」15行目

```
現行:  C15 = SUM(C8:C14)     ← R8単年（正）
       D15 = SUM(C8:D14)     ← R8+R9 の累計（誤）
       E15 = SUM(C8:E14)     ← R8〜R10 の累計（誤）
       F15 = SUM(C8:F14)     ← R8〜R11 の累計（誤）
       G15 = SUM(C8:G14)     ← R8〜R12 の累計（誤）
       H15 = SUM(C15:G15)    ← 累計の合計 = 二重計上
```

**影響**：H15（5年間総括原価）およびそれを参照する B20・B21・B23・B25・B26 が全て誤り。

| 項目 | 現行数式の結果 | 正しい値 |
|---|---:|---:|
| 5年間総括原価（1%） | 7,277,783千円 | 2,462,569千円 |
| 給水原価（1%） | 1,686.2円/㎥ | 570.6円/㎥ |
| 5年間総括原価（3%） | 7,546,673千円 | 2,552,199千円 |
| 給水原価（3%） | 1,748.5円/㎥ | 591.3円/㎥ |

**修正**：`D15=SUM(D8:D14)`、`E15=SUM(E8:E14)`、`F15=SUM(F8:F14)`、`G15=SUM(G8:G14)` に変更。

**補足**：これは `spec_alignment_summary.md` 第5.1章で指摘済みの事象です。
本体ファイル `01_..._MAIN.xlsx` の02シートでは修正済み（`D15=SUM(D8:D14)`）ですが、
`02_total_cost_simulation.xlsx` には**修正が反映されていません**。

また同ブックの資産維持率（前提条件（入力）B7）が **1%** のままです。
仕様書の正式ケースは3%であり、MAIN（B14=3%）と食い違っています。
なお、同シートの【C】感度分析（30〜39行）は固定値 2,417,754 を基礎とする独立計算のため、
この不具合の影響を受けておらず、値は正しいことを確認しました。

### 3.2 【高】C案の年間増収額が桁違い

**対象**：`01_..._MAIN.xlsx` シート「07_改定案比較表」 D8

```
D8 = 5,386,479（千円）  ← C案（口径別・標準逓増案）の年間増収見込
```

現行の年間料金収入は約118,169千円です。年間増収5,386,479千円は現行収入の約45倍にあたり、
明らかに単位誤り（円/千円）または集計対象の誤りです。住民・議会資料に直結する表のため、要修正。

参考として、同ブック05シートの3-A料金表から再計算すると、
中規模（50mm/1,000㎥）で 111,980円 → 127,050円（+13.5%）であり、
全体増収は数千万円規模になるはずです。

**あわせて確認が必要**：同表の A案 D6=28,159千円 と B案 D7=196,136千円 も、
08シートの記載（A案「約35,000千円」・B案「約37,000千円」）と一致していません。
B案の196,136千円は04シートの「改定後収入」157,560千円とも合わず、
増収額なのか改定後収入なのか定義が揺れています。

### 3.3 【中】3-A案の水産加工業影響が資料間で真逆

同一の「口径別・標準逓増型（3-A / C案）」について、記載が2系統に分かれています。

| 出所 | 中規模（50mm/1,000㎥）の影響 |
|---|---|
| MAIN 05シート I11（3-A料金表からの試算） | 127,050円（**+13.5%**） |
| MAIN 06シート M7（19社モデル） | **+13.5%** |
| MAIN 06シート A13（注記） | **+140〜+190%** |
| MAIN 07シート G8（C案・比較表） | **+140〜+330%** |
| 引継ぎメモ 6.3 | **+141%** |

**原因**：05シートの3-A料金表で、100㎥超の単価が **121円/㎥** に設定されています（G7:G13）。
31〜100㎥の143円/㎥より安いため、名称は「標準逓増型」でも実質は**逓減制のまま**です。
大口の負担がほとんど増えないため、試算値が+13.5%にとどまっています。

一方、+140〜190%という数値は「県内他団体並みの本来の逓増型（100㎥超も250〜330円/㎥）」を
前提にした県内統一化検討側の試算であり、前提が異なります。

**要判断**：3-A案を「県内標準に合わせた真の逓増型」として設計し直すのか、
現行の緩やかな設計のまま「3-A（女川町版・緩和逓増）」と名称を改めるのか。
どちらにするかで、C案の評価も水産加工業影響の説明も変わります。

### 3.4 【中】02シートの解説文が1%ケースのまま

前提条件B14の既定値は **3%**（正式ケース）ですが、解説文は1%ケースの数値のままです。

| 記載箇所 | 記載値 | B14=3% での正しい値 |
|---|---:|---:|
| G23・A26 給水原価（総括原価ベース） | 572円/㎥ | **591.3円/㎥** |
| A25・A26 改定後回収率（192円） | 約34% | **約32.5%** |

計算セル（B21・B23）は数式で連動しているため正しく、**注記テキストだけが古い**状態です。
`spec_alignment_summary.md` 第5.2章も同じく572円ベースで記載されているため、
3%正式ケースへの統一時にあわせて更新が必要です。

### 3.5 【中】04シート 定義③の値が3通り

**対象**：`01_..._MAIN.xlsx` シート「04_パターン2_赤字半減案」

| セル | 記載 | 資産維持率3%での値 |
|---|---|---:|
| A8（定義③） | 約▲74,302千円/年（3%） | 実際は2.5%相当の値 |
| A12（B項リード文） | ▲78,704千円/年（3%ケース） | 利息年平均を35,519千円として計算 |
| B17（完全解消目標） | 78,783千円 | 利息年平均を35,597千円として計算 |

支払利息の年平均は (50,585+127,402)÷5 = **35,597千円** が正しく、
A12が用いる35,519千円は78千円の計算誤りです。
3%ケースのキャッシュ不足額は **▲78,783千円/年** に統一するのが適切です。

赤字半減目標（B15=39,392千円）はこの値の1/2として算定されているため、
半減目標そのものへの影響は軽微ですが、資料内で数値が3通りあるのは説明上のリスクです。

### 3.6 【低】08シート 住民議会用の3案比較表の列ずれ

**対象**：`01_..._MAIN.xlsx` シート「08_住民議会用要約」 11行目

本体行（12〜19行）は `B:C` / `D:F` / `G:I` の3ブロックに結合されていますが、
見出し行（11行）は `B11` / `C11` / `D11` / `E11:J11` と結合が異なります。
結果として「B案（赤字半減）」の見出しが本体のA案側にかかり、
「D案（産業配慮）」の見出しがB案側にかかって表示されます。

**修正**：11行目を `B11:C11`＝A案、`D11:F11`＝B案、`G11:I11`＝D案 に結合し直す。
住民・議会に直接配る想定のシートのため、体裁上の優先度は高めです。

## 4. 移行にあたっての技術的な注意点

### 4.1 数式の計算結果がファイルに保存されていない

成果品Excelは、数式の計算結果を保存しない形で作成されています。

- Excelで開けば自動再計算されるため、実務上の問題はありません。
- ただし Google スプレッドシート・LibreOffice のプレビューや、
  ファイルの中身だけを読み取る方法では **空欄または0** に見えます。
- 「給水原価が0円/㎥と表示される」といった見え方の問題が出た場合、
  数式そのものではなくこれが原因の可能性があります。

数値を確認する際は、Excelで一度開いて保存し直すか、数式を読んで計算し直す必要があります。

### 4.2 引継ぎメモのパスは移行前のもの

`handoff_memo.md` 第8章のパス（`/mnt/user-data/uploads/`・`/mnt/user-data/outputs/`）は
移行前のものです。本フォルダでのパスは `README.md` の対応表を参照してください。
