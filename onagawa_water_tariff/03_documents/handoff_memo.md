## 6. 重要な論点（引き継ぎ注意事項）

### 6.1 給水原価の「二重表現問題」（02シートに注記済み）

```
R5実績ベース（住民説明用）:
  給水原価: 約242円/㎥（料金回収率52.87%から逆算）
  1.5倍改定後: 供給単価192円/㎥ → 回収率79%に改善
  → 住民・議会向け説明で「現行の半分しか回収できていない」根拠

総括原価ベース（将来財源の必要性説明用）:
  給水原価: 約572円/㎥（R8〜R12の投資・減価償却を含む）
  1.5倍改定後: 回収率約34%にとどまる
  → 「1回の改定では不十分、段階改定が必要」の根拠
```

### 6.2 塩竈モデルの正確な表現（05シートに注記済み）

```
✅ 使うべき表現:
  「塩竈市には団地水産加工業協同組合向けの生産用水料金105円/㎥（税抜）という
   既存制度がある。これは県内において産業用特例料金が制度化されている先例であり、
   女川町の激変緩和策を検討する際の有力な参考モデルとなる。」

❌ 避けるべき表現:
  「塩竈モデルを全県全水産加工業者に適用すべきである。」
  理由: 全県適用では収入減・補填財源・制度設計が必要になり過大な含意を生む
```

### 6.3 口径別移行時の水産加工業への影響

```
現行（女川町逓減制）での大口使用者水準:
  1,000㎥/月（50mm）: 111,980円
  塩竈市生産用水用: 115,500円（ほぼ同水準）

口径別標準逓増型（3-A）に単純移行した場合:
  1,000㎥/月（50mm）: 推計+141%の負担増
  → 産業配慮案（3-B）または激変緩和措置が不可欠
```
