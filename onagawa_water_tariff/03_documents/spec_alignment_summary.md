# 女川町水道料金改定検討 整理表・業務仕様書整合確認まとめ

作成日：2026-06-02  
対象：女川町水道料金改定検討、宮城県水道料金体系統一化検討、水産加工業影響試算、令和8年度上下水道経営指標評価書作成等業務委託仕様書

## 1. 結論

女川町の料金改定検討資料は、**内部検討資料・論点整理資料としては有用**である。  
ただし、業務仕様書が求める正式成果物として見ると、現時点では**仕様書要求に対して一部不足**がある。

特に、仕様書では料金改定について次の3点が明確に求められている。

1. 資産維持費3％を原価に組み込むこと
2. 3パターンの料金改定シミュレーションを作成すること
3. 対住民・対議会で切り抜いて使用できる体裁にすること

現在資料は、県内統一化、水産加工業影響、塩竈市の生産用水用区分の検討に重点が置かれており、**女川町単独の料金改定試算3パターンとしては再整理が必要**である。

## 5. 現在資料の修正が必要な点

### 5.1 総括原価・給水原価の再計算

現時点で最も重要な修正点は、総括原価シミュレーションの表示不整合である。

確認した範囲では、総括原価シミュレーションで年度別総括原価が累計表示になっており、その累計値をさらに5年合計している可能性がある。  
1％資産維持費ケースでは、正しい5年総括原価相当額はおおむね次のとおりである。

| 費目 | 5年合計 |
|---|---:|
| 維持管理費 | 672,327千円 |
| 減価償却費 | 2,032,440千円 |
| 既往債利息 | 50,585千円 |
| 新規債利息 | 127,402千円 |
| 資産維持費 | 44,815千円 |
| 長期前受金戻入控除 | ▲450,000千円 |
| 他会計補助金等控除 | ▲15,000千円 |
| 正しい総括原価相当 | 2,462,569千円 |

一方、別シートでは5年間総括原価2,469,884千円、有収水量4,316,000㎥とされている。  
この場合、給水原価は次のとおりである。

```text
2,469,884千円 ÷ 4,316千㎥ ＝ 約572円/㎥
```

しかし、シート上では給水原価が約0円/㎥と表示されているため、明確に修正が必要である。

### 5.2 料金回収率の説明整理

現在資料では、R5実績から逆算した給水原価約242円/㎥に対し、現行×1.5倍改定後の供給単価約192円/㎥を用いて、料金回収率約79％と説明している。

この説明は、**R5実績ベース**としては成立する。  
ただし、R8〜R12総括原価ベースで見ると、給水原価は約572円/㎥であるため、同じ192円/㎥の料金回収率は約34％にとどまる。

| 区分 | 給水原価 | 改定後供給単価192円/㎥の回収率 | 説明上の位置づけ |
|---|---:|---:|---|
| R5実績逆算ベース | 約242円/㎥ | 約79％ | 過去実績ベースの改善説明 |
| R8〜R12総括原価ベース | 約572円/㎥ | 約34％ | 将来原価ベースではなお不足 |

したがって、資料上は次のように分けて説明する必要がある。

- R5実績ベースでは、1.5倍改定により料金回収率は約79％まで改善する。
- ただし、R8〜R12の更新投資・減価償却費・資産維持費を含む総括原価ベースでは、なお大幅に不足する。
- よって、1回の改定で100％回収を目指すのではなく、段階改定又は経過措置を組み合わせる必要がある。

### 5.3 塩竈モデルの表現修正

塩竈市の生産用水用105円/㎥は有力な参考事例である。  
ただし、制度上は塩釜市団地水産加工業協同組合への供給を前提とした限定的な料金区分であり、全県の全水産加工業者にそのまま適用できるとは限らない。

安全な表現は次のとおりである。

> 塩竈市には、団地水産加工業協同組合向けの生産用水料金105円/㎥という既存制度がある。これは、県内において水産加工業向けの特例的料金設定が制度化されている先例であり、女川町の水産加工業への激変緩和策を検討する際の有力な参考モデルとなる。

避けるべき表現は次のとおりである。

> 塩竈モデルを全県全水産加工業者に適用すべきである。

理由は、全県全水産加工業者に適用した場合、水道事業会計の収入減が大きくなり、補填財源・一般料金への転嫁・対象限定の制度設計が必要になるためである。

## 10. 最終評価

現在の資料は、女川町の料金改定検討において、以下の点で有用である。

1. 女川町の現行料金が大口使用者に有利な逓減制であることを示している。
2. 単純な口径別・逓増型への移行では、水産加工業への影響が大きいことを示している。
3. 塩竈市の生産用水用区分という、県内の産業用配慮制度の先例を確認している。
4. 経過措置や産業用特例の必要性を説明する材料になる。

一方で、業務仕様書上の正式成果物としては、以下の不足がある。

1. 資産維持費3％を正式条件とした総括原価・給水原価の確定が必要である。
2. 仕様書指定の3パターンの料金改定シミュレーションが未完成である。
3. 赤字半減案が独立した試算として整理されていない。
4. 女川町版の口径別料金表案が未作成である。
5. 住民・議会向けに切り抜いて使える資料体裁が不足している。

したがって、次工程では、県内統一化・塩竈モデルの議論を参考資料に位置づけたうえで、主資料としては**女川町単独の料金改定シミュレーション整理表**を作成することが適切である。
