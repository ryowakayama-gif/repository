# 建設改良費の改定と必要改定幅への影響

確認日：2026-09-08
対象：`construction_cost_survey_R8toR17.xlsx`（建設改良費調査票・女川町回答）
再計算：`recalc_capital_impact.py` → `recalc_output.txt`

---

## 1. 結論

建設改良費が **45.26億円 → 35.15億円（▲10.11億円・▲22.3%）** に縮小したため、
減価償却費・支払利息が減り、**必要改定幅は下方に動きます**。

| 指標（R8〜R12・資産維持率3%） | 旧計画 | 新調査票 | 差引 |
|---|---:|---:|---:|
| 総括原価 5年計 | 2,552,199千円 | 2,457,968千円 | ▲94,231千円 |
| 給水原価 | 591.3円/㎥ | 569.5円/㎥ | ▲21.8円/㎥ |
| 年間不足額 | 392,271千円/年 | 373,425千円/年 | ▲18,846千円/年 |
| キャッシュ不足額（定義③） | ▲78,783千円/年 | ▲74,875千円/年 | +3,907千円/年 |
| 赤字半減の目標増収額 | 39,391千円/年 | 37,438千円/年 | ▲1,954千円/年 |

**ただし、この結論はそのまま採用できません。** 下記2つの前提のどちらか一方でも変わると、
必要改定幅は逆に旧計画以上になります（第4章）。女川町への確認が先です。

---

## 2. 影響の伝わり方

```
建設改良費（調査票）
   ├→ ① 減価償却費        取得額 ÷ 償却年数        → 総括原価 ＋
   ├→ ② 長期前受金戻入益    補助財源 ÷ 償却年数      → 総括原価 －（控除）
   ├→ ③ 支払利息          企業債残高 × 利率        → 総括原価 ＋
   └→ ④ 企業債償還金       元利均等・据置後         → 資本的支出（総括原価には入らない）
                                                    ↓
                                        総括原価 ÷ 有収水量 ＝ 給水原価
                                                    ↓
                                          必要改定率・赤字半減目標額
```

R8〜R12の5年計での内訳は次のとおりです。

| 要素 | 影響額（5年計） |
|---|---:|
| ① 減価償却費の減 | ▲67,240千円 |
| ③ 支払利息の減 | ▲19,537千円 |
| ② 長期前受金戻入益の増（控除項目の増＝原価の減） | ▲7,454千円 |
| **総括原価への影響 計** | **▲94,231千円** |

④ 企業債償還金は総括原価には入りませんが、資金繰りには効きます。
R8〜R17の10年間で新規債の償還金は年▲7,268〜▲20,495千円軽くなります。

## 4. 結論を左右する2つの前提（★要確認）

| シナリオ | 建設改良費 | 給水原価 | 年間不足額 | 必要改定率 |
|---|---:|---:|---:|---:|
| ① 旧計画 | 4,526,000 | 591.3円/㎥ | 392,271千円 | 4.32倍 |
| ② 新調査票のまま | 3,515,000 | **569.5円/㎥** | 373,425千円 | 4.16倍 |
| ③ ②＋鷲神高度処理を20年償却 | 3,515,000 | **587.0円/㎥** | 388,512千円 | 4.29倍 |
| ④ ②＋北上川導水管6.7億円を復元 | 4,185,000 | **588.5円/㎥** | 389,806千円 | 4.30倍 |
| ⑤ ③＋④の両方 | 4,185,000 | **606.0円/㎥** | 404,893千円 | 4.43倍 |

### ★確認事項1：北上川導水管が調査票にない

旧計画では R9 の原水及び浄水施設費 670,000千円 が計上されており、
経営戦略報告書案にも「本町から24km離れた一級河川・北上川（石巻市）からの導水管」が
更新課題として明記されています。

しかし調査票の4事業（老朽管布設替・水道施設耐震化・鷲神高度処理・江島海底送水管）に
北上川導水管は含まれていません。

- **事業を取りやめ／R18以降に繰り延べた**のであれば、②の結論でよい
- **調査票への記載漏れ**であれば、④のとおり必要改定幅は旧計画とほぼ変わらない

10億円の減少のうち6.7億円がこの1事業で説明できてしまうため、
ここが確定しないと改定幅は決められません。

### ★確認事項2：鷲神高度処理設備の償却年数40年

調査票では4事業とも償却年数40年で入力されていますが、
鷲神高度処理設備（888,000千円）は機械・電気設備であり、
地方公営企業法施行規則の法定耐用年数は一般に15〜20年です。
40年は建物・構築物の年数に相当します。

20年で償却すると減価償却費は年22,200千円増え、
給水原価は 569.5円/㎥ → 587.0円/㎥ となり、建設改良費減の効果をほぼ打ち消します。

同様に、老朽管布設替（配水管）40年・水道施設耐震化（配水池）40年は妥当ですが、
江島海底送水管も40年で入力されており、こちらも確認対象です。

## 5. 調査票そのものの不備（4件）

### 【高】No.3 鷲神高度処理設備の繰入金が約3.9兆円になる

「財源構成割合 (%)」行（41行目）に、割合ではなく**金額**が入力されています。

```
D41 = 444000        ← 繰入金の「割合(%)」欄に 444,000千円 が入力されている
B49 = IFERROR(ROUNDDOWN(B45*($D$41/100), 0), 0)
    = ROUNDDOWN(353,400 × 4,440, 0) = 1,569,096,000 千円
C49 = ROUNDDOWN(534,600 × 4,440, 0) = 2,373,624,000 千円
```

集計表の「財源：繰入金」が **3,942,720,000千円（約3.9兆円）**、
「財源：その他」が同額のマイナスになります。総整備費は正しいまま（3,515,000千円）なので
気づきにくく、財源別に集計した瞬間に破綻します。

**修正**：D41 に割合 `50` を入力する（企業債 B41 も同様に `50`）。
本試算では 整備費−企業債＝444,000千円 を繰入金とみなして補正しています。

なお No.1・No.2 も「割合(%)」行に `=L14`（国費合計）等の金額参照が入っていますが、
これらは財源行が直接入力で上書きされているため、集計結果には影響していません。

### 【中】企業債の利率が全事業で未入力

「企業債償還条件」の利率(%)欄（G9・G25・G41・G57）が4事業とも空欄です。
本試算では経営戦略の加重平均借入利率 **2.1%** を仮置きしています。
実際の借入予定利率が異なると支払利息が変わります。

### 【中】No.4 江島海底送水管の属性が未入力

資産種別・更新/新規・補助/単独がいずれも空欄です（整備費170,000千円）。
資産種別が空欄のため、施設区分別に集計する際に取りこぼされます。

### 【低】入力対象期間の表記ゆれ

「入力方法」シートは「Ｒ９～Ｒ１７で行う予定の委託・工事」を対象としていますが、
調査票の様式は R8〜R17 の10年で、女川町は R8 にも計上しています（R8計 565,400千円）。
R8分が網羅されているかどうかの確認が必要です。

## 6. 試算の前提（すべて明示）

| 項目 | 設定 | 出所 |
|---|---|---|
| 借入利率 | 2.1% | 経営戦略報告書案 4-1 ⑹（加重平均借入利率） |
| 償還条件（旧計画） | 40年・元利均等・借入年度の翌年度から | 経営戦略試算シート「新規債返済スケジュール」PPMT/IPMT |
| 償還条件（新計画） | 調査票の入力値（No.1は25年、他40年／据置3年） | 建設改良費調査票 |
| 償却方法 | 定額法・残存価額0・取得年度の翌年度から満額 | 簡便法 |
| 償却年数 | 40年（調査票の入力値） | 建設改良費調査票 |
| 長期前受金の対象 | 国費のみ | 出資金・繰入金は資本金であり長期前受金の対象外として整理 |
| 有収水量 R8〜R12 | 4,316,000㎥ | 財政シミュ 水需要予測 |
| 給水収益 R8〜R12 | 590,845千円 | 財政シミュ 給水収益（現行料金） |
| 資産維持率 | 3% | 業務仕様書の正式ケース |

**長期前受金の範囲について**：新調査票の「繰入金」444,000千円・「その他」66,000千円を
長期前受金の対象に含めるかどうかで、控除項目が変わります。
一般会計出資金は資本金であり長期前受金には計上しないのが原則ですが、
補助金として整理される場合は対象になります。女川町の会計処理の確認が必要です。
