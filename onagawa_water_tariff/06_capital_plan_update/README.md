## 1. 経営戦略における償却年数の確認結果

**機械・電気設備を区分せず、新規取得資産は一律38年で償却しています。**

経営戦略試算シート `mgmt_strategy_simulation_sheet.xlsx` の「新規取得」シートを確認しました。

| 確認箇所 | 内容 |
|---|---|
| G10:G58（取得年度 R7〜R55 の49行） | **すべて 38** |
| D列 原水及び浄水施設費（浄水場・機械電気設備を含む） | 38年 |
| E列 給水及び配水施設費（管路） | 38年 |
| H3 長期前受金の収益化 | `=【成行】財政シミュ!$V$77/38` → 同じく38年 |
| J10 帳簿価額ロールフォワード | 償却開始は**取得年度の翌年度から** |

同シート B4・B8 に耐用年数への言及がありますが、これは**更新のタイミング**の前提であり、
償却年数の設定ではありません。

> ①構造物及び設備：耐用年数が20年未満の資産について、従前、大規模な修繕が1件程度しか
> 発生していないため、法定耐用年数×1.5のタイミングで、それ以外は法定用年数の1.2の
> タイミングで、試算時点の帳簿価額にデフレーターを加味した金額で試算
>
> ②管路：総務省提供資産ツールに基づき、法定耐用年数×1.2のタイミングで、基準単価×数量で試算

**つまり「耐用年数20年未満の資産（＝機械・電気設備）」の存在は認識されているものの、
償却計算には反映されず、38年に一本化されています。**
貸借対照表（`【BS】決算数値入力`）は「機械及び装置」を独立科目として持っているため、
既往資産は区分されている一方、**将来取得分だけが一律38年**という状態です。

鷲神高度処理設備（888,000千円）は機械・電気設備であり、
この一律38年の扱いが妥当かどうかが、必要改定幅を左右します（第4章）。

### 支払利息の根拠欄に古い数値が残っている

`【成行】財政シミュ` r61 の算定根拠欄は「新規債の返済スケジュール×利率の平均値（**1.79％**）」ですが、
実際の計算は「新規債返済スケジュール」C3＝**2.1％**で行われており、
経営戦略報告書案4-1⑹の記載も2.1％です。根拠欄の1.79％は更新漏れとみられます。

## 3. 影響の伝わり方

```
建設改良費（調査票）
   ├→ ① 減価償却費        取得額 ÷ 償却年数        → 総括原価 ＋
   ├→ ② 長期前受金戻入益    補助財源 ÷ 償却年数      → 総括原価 －（控除）
   ├→ ③ 支払利息          企業債残高 × 利率        → 総括原価 ＋
   └→ ④ 企業債償還金       元利均等・据置後         → 資本的支出（総括原価には入らない）
                                                    ↓
                                        総括原価 ÷ 有収水量 ＝ 給水原価
                                                    ↓
                                          必要改定率・赤字半減目標額
```

### 建設改良費・財源の新旧比較（千円）

| 　うち 企業債 | 2,956,670 | 2,434,000 | ▲522,670 |
| 　うち 国費 | 263,330 | 571,000 | +307,670 |

国費が2.2倍に増える一方、一般会計からの出資金・繰入金が
12.3億円 → 4.4億円と **7.9億円減っています**。方針転換なのか未計上なのか確認が必要です。

旧計画（利率2.1%固定）は82,772千円。利率が2.0%→3.0%に振れると、
新計画の支払利息は **+30,112千円（5年計）** 増えます。

### 読み取れること

- **利率の影響は限定的**。2.0%→3.0%でも給水原価は7円/㎥程度（1.2%）しか動きません。
  R8〜R12は借入からの経過年数が浅く、据置3年もあるため利息が本格化するのが後年度になるためです。
- **償却年数の影響のほうが大きい**。38年 → 15年で給水原価は約28円/㎥（4.9%）動きます。
- **利率3.0%かつ機械電気15年**のとき、給水原価602.6円/㎥・必要改定率4.40倍となり、
  **建設改良費が10億円減ったにもかかわらず旧計画（591.3円/㎥・4.32倍）を上回ります。**

## 6. 調査票そのものの不備（4件）

### 【高】No.3 鷲神高度処理設備の繰入金が約3.9兆円になる

「財源構成割合 (%)」行（41行目）に、割合ではなく**金額**が入力されています。

```
D41 = 444000        ← 繰入金の「割合(%)」欄に 444,000千円 が入力されている
B49 = IFERROR(ROUNDDOWN(B45*($D$41/100), 0), 0)
    = ROUNDDOWN(353,400 × 4,440, 0) = 1,569,096,000 千円
C49 = ROUNDDOWN(534,600 × 4,440, 0) = 2,373,624,000 千円
```

集計表の「財源：繰入金」が **3,942,720,000千円（約3.9兆円）**、
「財源：その他」が同額のマイナスになります。総整備費は正しいまま（3,515,000千円）なので
気づきにくく、財源別に集計した瞬間に破綻します。

**修正**：D41 に割合 `50` を入力する（企業債 B41 も同様に `50`）。
本試算では 整備費−企業債＝444,000千円 を繰入金とみなして補正しています。

No.1・No.2 も「割合(%)」行に `=L14`（国費合計）等の金額参照が入っていますが、
これらは財源行が直接入力で上書きされているため、集計結果には影響していません。

### 【中】企業債の利率が全事業で未入力

利率(%)欄（G9・G25・G41・G57）が4事業とも空欄のため、本試算では2.0〜3.0%で振っています。
実際の借入予定利率が決まれば `recalc_capital_impact.py` の `RATES` に設定できます。

### 【中】No.4 江島海底送水管の属性が未入力

資産種別・更新/新規・補助/単独がいずれも空欄です（整備費170,000千円）。
資産種別が空欄のため、施設区分別の集計で取りこぼされます。

### 【低】入力対象期間の表記ゆれ

「入力方法」シートは「Ｒ９～Ｒ１７で行う予定の委託・工事」を対象としていますが、
様式は R8〜R17 の10年で、女川町は R8 にも計上しています（R8計 565,400千円）。
R8分が網羅されているかの確認が必要です。

## 7. 試算の前提（すべて明示）

| 項目 | 設定 | 出所 |
|---|---|---|
| 借入利率（旧計画） | 2.1%（固定） | 経営戦略報告書案 4-1 ⑹／新規債返済スケジュール C3 |
| 借入利率（新計画） | **2.0〜3.0%で可変** | 調査票の利率欄が未入力のため |
| 償還条件（旧計画） | 40年・元利均等・借入年度の翌年度から | 新規債返済スケジュール PPMT/IPMT |
| 償還条件（新計画） | 調査票の入力値（No.1は25年、他40年／据置3年） | 建設改良費調査票 |
| 償却方法 | 定額法・残存価額0・取得年度の翌年度から満額 | 経営戦略「新規取得」シートと同じ扱い |
| 償却年数（旧計画） | 38年 | 経営戦略「新規取得」G10:G58 |
| 償却年数（新計画） | **38年／40年／機械電気20年／機械電気15年で可変** | 上記シナリオ |
| 長期前受金の対象 | 国費のみ | 出資金・繰入金は資本金として対象外に整理 |
| 有収水量 R8〜R12 | 4,316,000㎥ | 財政シミュ 水需要予測 |
| 給水収益 R8〜R12 | 590,845千円 | 財政シミュ 給水収益（現行料金） |
| 資産維持率 | 3% | 業務仕様書の正式ケース |

**長期前受金の範囲**：新調査票の「繰入金」444,000千円・「その他」66,000千円を
長期前受金の対象に含めるかで控除項目が変わります。
一般会計出資金は資本金であり長期前受金には計上しないのが原則ですが、
補助金として整理される場合は対象になります。女川町の会計処理の確認が必要です。

**参考：資産維持費の算定基礎の相違**
経営戦略の `【料金算定】資産維持費` シートは「対象資産（期首）1,042,625千円 × 1% × **4年**」で
算定していますが、本件成果品 `01_rate_reform_simulation_MAIN.xlsx` は
「期首期末平均 896,312千円 × 3% × **5年**」です。料金算定期間の年数と対象資産の取り方が
異なるため、経営戦略の数値と直接比較する際は注意が必要です。

