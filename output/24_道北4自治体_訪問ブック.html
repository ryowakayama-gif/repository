01いま打つ手

令和8年8月時点で、4団体すべてに同じ話ができて、なおかつ予算要求の時期に間に合うのは1つだけ。まずこれを持って行く。

4団体共通・今年度いちばん時期が合う

第3期子ども・子育て支援事業計画の中間年見直し。第3期は令和7年度から令和11年度までの5年計画で、中間年は令和9年度。令和9年度に見直しを行うなら、予算要求は今年の秋。

「子ども・子育て支援事業計画の第3期は令和7年度から令和11年度までですので、中間年が令和9年度になります。国の基本指針では、計画期間の中間年を目安に、量の見込みと実績に乖離がある場合は見直しを行うこととされております。見直しをされる場合は令和9年度当初のご発注、予算要求は今年の秋ということになるかと思いますので、ちょうど今がご検討の時期かと存じます。」

この一言のために訪問する価値がある。ここで見積の話はしない。次回訪問の許可を取って帰る。

言ってはいけない

「中間年の見直しは義務です」── 義務ではない。「求められています」「行うこととされています」までにとどめる。一字一句を決めてから訪問すること。

02越えてはいけない線

背伸びした提案は、失注より重い事故（財源の誤案内・官製談合の疑い）を招く。町村は担当者との距離が近く、つい踏み込みたくなるので、線を先に決めておく。

L1理解する

  • 話してよいのは根拠法・計画期間・所管省庁と自社の商品説明まで。
  • 役割は記録。所管課・面談者・役職・同席者／相手が前のめりになった話題／宿題と期限／現行計画の名称と計画期間。
  • 答えられない質問は「正確にお答えしたいので、確認のうえご連絡させていただいてもよろしいでしょうか」。
  • 帰社後は当日中に議事録。翌日に回すと宿題が抜ける。

L2伝える

  • 国の指針・通知・審議会資料の内容、出典付きの公表事例、計画期間からの逆算まで。
  • 最大の価値は「いつ動くべきか」を相手の代わりに計算して示すこと。
  • 未確定は「議論されています／確定は告示後です」と区別して話す。
  • 踏み込みを求められたら「上の者と一緒にお伺いしてもよろしいでしょうか」で L3 の場に切り替える。

この4団体で特に危ない

  • 広域化を勧めない。当麻町は近隣3町（東川・美瑛・東神楽）が大雪地区広域連合を組む中で単独を選んでいる。町の選択を否定する話になる。
  • 圏域を間違えない。名寄市・美深町・下川町は北・北海道中央圏域定住自立圏。当麻町はこの圏域外。
  • 未公表情報を持ち込まない。名寄・美深・下川は同一圏域で、話は必ず伝わる。一度で3団体を失う。
  • 施設の統廃合に触れない。過疎地域で担当者を最も困らせる話題。
  • 財源を断定しない。充当率・措置率・対象事業は年度で変わる。当年度資料で確認するまで口頭でも出さない。

04テーマ別ヒアリング＆スクリプト

1回の訪問で全部を聞かないこと。町村では担当が1〜2名の兼務であることが通例で、質問を並べると尋問になる。聞くのは5問までを目安に、相手が前のめりになった1テーマを深掘りし、他は次回に回す。

★ こども・子育て

根拠法＝子ども・子育て支援法第61条（事業計画）／こども基本法第10条（こども計画・努力義務）　所管＝こども家庭庁（令和5年4月発足）　第3期＝令和7年度〜令和11年度の5年計画

L1

「子ども・子育て支援事業計画は子ども・子育て支援法に基づく計画で、5年を1期として市町村が策定します。所管はこども家庭庁で、いまは第3期、令和7年度から令和11年度までの期間です。」

根拠法・周期・所管省庁・現行期を、資料を見ずに言えることがL1の到達点。所管が内閣府・厚労省から移っている点を間違えない。

L2

「第3期の計画期間は令和7年度から令和11年度までですので、中間年が令和9年度になります。中間年の見直しについて、庁内で何かお話は出ていますか。」

本命の質問。「まだ」＝情報提供のフェーズ。「そろそろ」＝上長同行のタイミング。

L2

「こども家庭センターという形には、もう整理されましたか。体制は何名でいらっしゃいますか。」

児童福祉法・母子保健法の改正（令和6年4月施行）への対応状況。「兼務で回している」が最多。当麻町町HPに子育て世代包括支援センターの記載があり、移行状況がそのまま論点になる。

L2

「いまは待機児童と定員割れでは、どちらが課題になっていますか。」

4団体すべて過疎地域。待機児童を前提にした話し方をすると、実情を知らないと思われる。

言ってはいけない

「中間年の見直しは義務です」／「こども計画の策定は義務です」── どちらも努力義務・指針上の取扱いであって法律上の義務ではない。担当者を不必要に不安にさせるうえ、誤りとして残る。

高齢者・介護保険

根拠法＝介護保険法第117条／老人福祉法第20条の8　所管＝厚生労働省　第9期＝令和6年度〜令和8年度（今年度が最終年＝第10期の策定年度）

L1

「介護保険事業計画は介護保険法に基づく計画で、3年を1期として市町村が策定するものです。所管は厚生労働省で、いまは第9期、令和6年度から令和8年度までの期間になります。」

あわせて、保険者が単独か広域連合かを記録する。発注元がどこになるかが決まる。

L2

「第10期の策定は、もう着手されていますか。庁内でお作りになりますか、それとも委託されるご予定でしょうか。」

最初に聞く一問。発注済み・未発注・庁内作成の3択を確定させる。ここを聞かずに情報提供を続けると時間を無駄にする。小規模町村では秋以降の発注や庁内作成も珍しくない。

L2

「承知いたしました。それでしたら次は令和11年度の調査、令和12年度の策定ということになりますね。それまでの間ですと、認知症施策推進計画をどう位置づけるかといったご検討が出てくるかと思いますので、そのあたりで改めてご報告にお伺いできればと思います。」

発注済みだった場合の撤退。次の周期を口に出して確定させ、その間の別テーマに接続する。引き際が良いと次の周期に呼ばれる。

L2

「下川町さんは、地域保健福祉計画の中に高齢者福祉計画と介護保険事業計画を一体で位置づけておられると拝見しました。第10期の部分は、第4期のときのように改正版という形で差し込まれるお考えでしょうか。」

下川町この質問ができるかどうかで、下川町でのL2の評価が決まる。ただし地域保健福祉計画のPDFを通読してから使うこと。

言ってはいけない

「次期の保険料は◯％くらい上がると思います」／「保険者機能強化推進交付金が取れます」／「前回の見込量の推計は甘かったですね」── 保険料の見通し・交付金の可否・前任者の否定は、いずれもL3以上の領域。

障害者・障害児

根拠法＝障害者基本法第11条第3項（障害者計画）／障害者総合支援法第88条（障害福祉計画）／児童福祉法第33条の20（障害児福祉計画）　所管＝こども家庭庁・厚生労働省　第7期・第3期＝令和6年度〜令和8年度

L1

「障がい分野は3つの計画があります。障害者基本法に基づく障害者計画、障害者総合支援法に基づく障害福祉計画、児童福祉法に基づく障害児福祉計画です。福祉計画・児童福祉計画は3年1期で、いまは第7期・第3期、令和6年度から令和8年度までです。」

3つの計画名を混同したまま話すと即座に見抜かれる。名称と根拠法をセットで暗記する。

L2

「第7期・第3期は令和8年度までですので、第8期・第4期は令和9年度からになります。策定は今年度ということになりますが、介護保険の第10期とちょうど重なる年でして、他の団体さんでもご担当の負担が集中する年になっております。」

国の周期が重なっている事実を伝え、相手の負担を言語化する。共感ではなく事実で語る。兼務体制の町村で最も効く。

L2

「障がい者計画・障がい福祉計画・障がい児福祉計画は、一体で策定されていますか。」

一体なら1本の発注、別々なら複数の受注機会。美深町「第7期美深町障がい者福祉計画」が3計画をどこまで束ねているかを、訪問前に現物で確認しておくこと。

L2

「地域生活支援拠点をすでに整備されていて、相談・緊急時の受入れ・体験の機会・専門的人材の確保養成・地域づくりの5つの機能を掲げておられると拝見しました。運用を始めてみて、いかがでしょうか。」

当麻町整備済みであることを知った上で入る。「整備されていますか」と聞いた時点で、調べていないことが露見する。

言ってはいけない

「前期の成果目標は未達ですね」／「拠点が形だけになっていませんか」／「グループホームが足りていないですよね」── 未達の指摘・機能検証・不足の断定はL3の領域。代わりに「進めにくいと感じておられる点はございますか」と相手に語ってもらう。

地域福祉

根拠法＝社会福祉法第107条　所管＝厚生労働省　福祉分野の共通事項を定め、高齢・障害・こどもの各計画に横串を通す上位計画。計画期間は5年が通例だが団体により異なる。

L1

「地域福祉計画は社会福祉法第107条に基づく計画で、福祉分野の共通事項を定めるものです。高齢・障がい・こどもの各計画に横串を通す位置づけになります。」

「福祉分野の共通事項」という言い方を覚える。個別計画との関係を図で説明できるとL2。

L2

「下川町さんの地域保健福祉計画は、社会福祉法107条の地域福祉計画を土台にして、高齢者福祉計画・介護保険事業計画・子ども子育て支援事業計画・障がいの3計画・健康しもかわ21まで一体化されていると拝見しました。第4期では改正Ⅱ版も出しておられますので、3年周期の介護の部分を改正版で差し込む運用をされているのかと理解しております。第5期の計画期間は令和6年度から令和10年度でよろしいでしょうか。」

下川町構造の理解を示しつつ、逆算の起点になる計画期間を確定させる。下川町ではこの一言が最大の武器になる。読まずに使うと次の一言で破綻する。

L2

「計画は町単独の策定でしょうか。社会福祉協議会の地域福祉活動計画と一体でしょうか。」／「併載されている計画はございますか。成年後見や再犯防止、自殺対策などです。」

一体なら発注元が2つになる。町村では社協との距離が近く、実質的に一体で動いていることが多い。併載編が増えるほど業務量が上がる。

L2

「重層的支援体制整備事業は実施されていますか。移行準備事業はいかがでしょうか。」

人口3千〜6千人規模では枠組みが過大に感じられ、未実施が多い。押し込まず、まず実情を聞く。

言ってはいけない

「重層事業はやったほうがいいですよ」／「中核機関は設置すべきです」／「圏域で共同設置すれば安く済みます」── 制度の実施を勧める・「べき」で語る・広域化を勧めるのは、いずれもL2の範囲外。

公営企業会計

根拠＝地方公営企業法　所管＝総務省（水道は令和6年4月に厚労省から国交省・環境省へ移管）　人口3万人未満の団体は簡易水道・下水道について令和6年度から公営企業会計を適用（総務省ロードマップ）。4団体すべて該当。

L1

「公営企業会計は地方公営企業法に基づく会計です。人口3万人未満の団体でも、簡易水道と下水道について令和6年度から適用することが総務省のロードマップで求められており、多くの町村が令和6年度に移行しています。」

町村の会計担当は移行の当事者。時期を間違えると即座に分かる。あわせて、どの事業を持っているか（簡易水道・上水道・下水道・農業集落排水・病院）を棚卸しする。

L2

「法適用は令和6年度からでしょうか。移行されてから、もう3期目の決算ということになりますか。」

移行時期の確認と、移行後の実務が回っているかの確認を同時に行う。移行の苦労は担当者が最も語りたい話題。聞き役に回る。

L2

「経営戦略は、法適用の前に作られたものでしょうか。作り直しのご予定はございますか。」

総務省は策定から3〜5年を目安とした改定を求めている。法適用で財務の前提が変わっており、適用前の経営戦略は実態と合わなくなっている可能性がある。

L2

「名寄市さんは病院事業もお持ちですので、公立病院経営強化ガイドラインに基づく経営強化プランを策定しておられると拝見しました。プランの点検・評価は、毎年度どちらでされていますか。」

名寄市所管は病院事務局で市役所とは別ルート。市役所側との関係を作ってから紹介をお願いする順序を守る。

言ってはいけない

「料金回収率が100％を切っていますね」／「この経営戦略は投資試算が過大です」／「公営企業会計適用債が使えます」／「値上げが必要です」── 経営比較分析表は公表資料なので見ておくこと。ただし比較して指摘するのは上長同行の場で行う。料金は住民に直結する政治的な論点。

公会計

根拠＝総務省「統一的な基準による地方公会計マニュアル」（平成27年策定・平成31年3月改訂）　所管＝総務省　所管課は財政課・会計課で福祉部門とは別ルート。補助がなく一般財源で行う業務のため、財源の話が使えないテーマ。

L1

「地方公会計は、総務省の統一的な基準による地方公会計マニュアルに基づいて、貸借対照表・行政コスト計算書などの財務書類を毎年度作成するものです。」

4表と固定資産台帳の関係を押さえる。財政担当は数字に厳しく、うろ覚えは即座に見抜かれる。

L2

「固定資産台帳の更新は、庁内でされていますか。それとも委託でしょうか。」／「財務書類は毎年度作成・公表されていますか。公表はいつ頃になりますか。」

毎年度の更新業務は継続受注の柱。小規模町村では異動の反映が滞りがちで、担当者も自覚している。最も自然に話が続く質問。

L2

「総務省が地方公会計の整備状況等に関する調査を毎年度公表しておりまして、全国と北海道内の作成・公表・活用の状況が分かります。よろしければ次回、整理してお持ちします。」

公表資料を届ける。次回訪問の口実になる。ただし「県内では御町は下位です」といった言い方はしない。

言ってはいけない

「備忘価額1円の資産が多いですね」／「公有財産台帳と突合されていないですよね」／「補助金が使えます」── 台帳精緻化の指摘はL3。公会計の整備は原則として一般財源で、補助はない。財政担当への財源の誤案内は会社ごと信用を失う。

その他計画（公共施設・過疎・総合計画・広域）

所管は企画・総務・財政部門。過疎地域の持続的発展の支援に関する特別措置法は令和3年4月1日施行・令和12年度末までの時限法。市町村計画は前期＝令和3〜7年度、後期＝令和8〜12年度。4団体すべて過疎関係市町村。

L1

「過疎地域持続的発展市町村計画は、過疎地域の持続的発展の支援に関する特別措置法に基づく計画です。この法律は令和3年4月に施行され、令和12年度末までの時限法になっています。」

「過疎法」と略さず正式名称で一度言えると印象が変わる。あわせて、公共施設等総合管理計画と個別施設計画の上下関係を説明できるようにする。

L2

「後期計画への改定はお済みでしょうか。」→ 済んでいれば →「計画の毎年度の変更、事業の追加などは、どなたが担われていますか。」

改定は令和7年度中に終えている団体が多い。改定済みを前提に「その後」を聞けるかが、L2とそれ以下の差になる。毎年度の変更が継続業務の入口。

L2

「公共施設等総合管理計画の見直しは、国の要請事項の反映まで済んでいますか。個別施設計画の反映や、保有量の数値目標、脱炭素、ユニバーサルデザインといった項目です。」

要請事項を4つ挙げられるかどうかで、準備してきたかが伝わる。

L2

「第3期のSDGs未来都市計画は2024年から2026年ということで、今年が最終年になるかと存じます。第2期が2021年から2023年でしたので3年ごとの更新かと思いますが、次期のご検討はもう始まっておられますか。」

下川町時期がぴったり合う。「SDGsで有名ですよね」だけで終えないこと。視察・取材が多く、通り一遍の褒め言葉は聞き飽きられている。

言ってはいけない

「過疎債が使えます」／「この施設は統廃合すべきです」／「広域でやれば効率的です」── 起債の充当率・措置率・対象事業は年度で変わる。当年度の地方債計画・地方債同意等基準で確認するまで口頭でも出さない。施設と広域は住民感情に直結する。
