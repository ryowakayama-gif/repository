## 2　要綱によって判明した、当方の区分表の訂正（6点）

### 2-1　【訂正・重い】人材確保・生産性向上は、市町村計画の「定めるよう努める」事項だった

当方は `build_ono_houkaisei.py` の区分表で、次のように書いていました。

> 1(6)③　人材確保・生産性向上・経営改善の取組と目標　主体＝**都道府県**　区分Ｂ
> 「**市町村計画の記載事項ではない。**」

**これは誤りです。** 要綱 第2の14(2)（第117条第3項第4号〜第5号関係）は、
**市町村介護保険事業計画に「定めるよう努める」事項**として、次の3つを挙げています。

| | 内容 | 備考 |
| --- | --- | --- |
| イ | 介護サービス提供の**生産性の向上**、**従事者の確保**、事業者の**経営基盤**の強化 | 都道府県と連携した取組 |
| ロ | **地域支援事業に従事する者**の確保・資質の向上 | 同上 |
| ハ | 地域支援事業の実施における**生産性の向上** | 同上 |

取り違えの原因は、当方が用いた「概要」p.10③が**都道府県の支援計画のことだけ**を
書いていたためです。要綱は市町村・都道府県の双方に書き分けています。

**→ 区分Ｂ（連携にとどめる）から区分Ａ（努力義務の法定記載事項）に改める必要があります。**
反映先は高齢者計画 施策4-6。「県の取組につなぐ」だけでは足りず、**町自身の取組と目標**が要ります。
とくに**ロ（地域支援事業の従事者）**は、総合事業の担い手の確保そのもので、本町の論点と直結します。

> **あわせて自己点検の規則も直す必要があります。** `build_ono_houkaisei.py` の
> 自己点検6「都道府県の事項を区分Ａに置いていない」は、この誤りをそのまま規則にしたもので、
> 正しい答えを機械が弾く状態になっています。

### 2-2　【追加】中長期推計には「地域支援事業の量」も含む

要綱 第2の14(1)イ。概要は「介護サービス量」としか書いていませんでした。
**→ 高齢者計画 第6章10の推計に、地域支援事業の量を加える必要があります。**

### 2-3　【精緻化】勘案事項は3類型、かつ「区域ごと」

要綱 第2の14(3)イ。勘案するのは次の**それぞれの入居定員の総数**で、しかも
**「当該市町村が定める区域ごと」**です。

1. 有料老人ホーム（老人福祉法第29条第1項の届出をしたもの）
2. **登録有料老人ホーム**（今回の改正で新設される登録制度によるもの）
3. **高齢者住まい法の登録住宅**（サービス付き高齢者向け住宅）

ロの医療介護連携のほうは**「当該市町村が属する都道府県が定める区域ごと」**で、区域の単位が違います。
**→ 第2章5の表と第6章2の記述を、この3類型・区域ごとに作り直す必要があります。**
町への照会Ｈ-1も、3類型に分けて聞き直します。

### 2-4　【新規・手続に効く】中長期推計は、あらかじめ都道府県の意見を聴かなければならない

要綱 第2の14(4)（第117条第14項関係）。当方の区分表にありませんでした。
**→ 策定スケジュールに直接効きます。** 県への意見照会の時期を工程に入れる必要があります。
第10期の基本指針が令和9年1月告示予定（後述）であることと合わせると、**意見聴取の時期が
計画の決定時期を縛ります。**

### 2-5　【決着】夜間対応型訪問介護の廃止

要綱 第2の4（改正前 第8条第16項）。施行期日の例外に挙がっていないため**原則の令和9年4月1日**、
すなわち**第10期計画期間の初日**です。

当方は `build_ono_review_input_kit.py:497` で「国の基本指針の確定を待つ必要がある。固定せず、
確認するまで保留にするのが安全」としていました。**要綱で廃止自体は決着です。**

ただし、**経過措置が置かれる見込み**であることが今回の調べで分かりました（下記 3-4）。
小野町の素案は 0.0人／月 で載せているため数値への影響はありませんが、
**「なぜ0なのか」の説明の根拠が「廃止」になるのか「経過措置つきの廃止」になるのかが変わります。**

### 2-6　【追加】総合事業の見直しと第1号介護予防支援事業

要綱 第2の11（第115条の45第1項第2号関係）、第2の12（第115条の47第2項・第5項関係）。
当方の一覧になく、総合事業ワークシートの確認結果とも突き合わせていません。

## 3　要綱になく、今回の調べで分かったこと（4点）

### 3-1　【小野町に直接効く】特定地域の基準の素案が示されている

社会保障審議会介護保険部会（第135回・令和8年6月29日）資料3
「特定地域（中山間・人口減少地域）の考え方について」に、**指定の指標の素案**があります。

| 項目 | 素案の内容 |
| --- | --- |
| 指標 | **75歳以上人口**と**75歳以上人口の変化率** |
| 水準 | 75歳以上人口は**1,000人未満**とすることが適当 |
| 変化率 | **75歳以上人口が減少していること** |
| 範囲 | 特別地域加算の対象地域を基本としつつ、地域の実情に応じた柔軟な対応 |
| 手続 | **市町村が指定の要否を検討し、その意向を踏まえて都道府県が定める** |
| 一部指定 | 市町村全体のほか、**旧市町村単位・行政区・日常生活圏域**など一部地域の指定も想定 |

**小野町に当てはめると（素案の基準による暫定判断）**

| | 小野町 | 基準 | 判定 |
| --- | --- | --- | --- |
| 75歳以上人口 | **1,809人**（令和7年度実績）。計画期間は1,855→1,874→**1,894人** | 1,000人未満 | **該当しない**（基準の約1.9倍） |
| 75歳以上人口の増減 | **増加**（令和9年度1,855人→令和11年度1,894人、＋39人） | 減少していること | **該当しない** |

（出典：素案 第2章1の表。高齢者人口そのものは3,443→3,418人と減りますが、
**内訳が前期から後期へ移るため75歳以上は増えます。** 特定地域の指標は75歳以上を見るため、
「人口減少地域である」ことと指標の判定は別になります。）

**→ 町全域での特定地域の指定は、現在の素案の基準では該当しない見込みです。**
ただし次の2点が残ります。

1. **基準は素案段階**であり、最終的には厚生労働省令・告示で確定します。
2. **町内の一部地域（日常生活圏域など）の指定**は、基準の作りによってはあり得ます。
   また**手続上、市町村の意向照会が入る**ため、県から照会が来たときの町の判断が要ります。

**→ 照会Ｋ-1（特定地域の対象の確認）は、「対象かどうか」ではなく
「県からの意向照会にどう答えるか」に組み替えるのが適切です。**

### 3-4　夜間対応型訪問介護には経過措置が置かれる見込み

報道ベースですが、厚生労働省は「一定の経過措置期間を設けたうえで、人員配置基準や報酬について

断定しないのが安全です。**
