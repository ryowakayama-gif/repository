作成日：令和8年10月12日

## 要旨

**どちらのブランチも作りはしっかりしている。** 高齢者側は成果品の作り（紙面の実測・復元性・自己点検の数）が強く、障害側は制度の追跡（告示後の改正・最新ガイドライン・予算の年度区分）が強い。抜けている論点は、おおむねこの強み・弱みの裏返しとして現れている。

抜けている論点は**18件**（高齢者7・障害7・両側にまたがる7・点検の型3。重複を含む）。**うち7件は、もう一方のブランチに既に答えがある**。

いちばん効くのは次の1件である。

> **両計画の整合が、互いに古い版を見て行われていた。**
> 障害側は高齢者側を `5bd79e2`（10月8日・現在から14コミット前）として、高齢者側は障害側を「10月4日が最終」（当時すでに60コミット前）として突合している。
> その結果、障害側が10月8日に書いた**照会 K-7（介護保険側に4点の記載を求めるもの）が高齢者側に届いていない。** 高齢者側が応答したのは別文書であり、4点のうち共生型サービスだけが素案に入り、介護保険優先原則・新高額障害福祉サービス等給付費・受給者証は0件のままである。
> **これは判断の相違ではなく、受け渡しの事故である。**（§5 C-7・§3 A-2）

期限があるものは2件。**目標値を支えるアンケート設問の確認**（高齢者・10月16日の回収期限まで。障害側は同じことで既に1指標が測定不能になっている）と、**認知症の人および家族等の意見聴取の方針決定**（高齢者・11月の第2回策定委員会まで。策定過程そのものに関わり、記述の追加では埋まらない）である。

## 0　この文書について

### 0-1　位置づけ

北塩原村の2本のブランチ（高齢者介護・障害）を読み、**抜けている論点**を整理したものである。

- **北塩原村の成果品ではない。** 村にお出しする文書ではなく、社内で次の一手を決めるための整理である。
- **置き場所。** 他ブランチへのプッシュは行わないため、小野町のブランチ上の `北塩原村_他ブランチ確認/` に置いた。`小野町_引継ぎ_整理済/`（小野町の成果品）の外である。
- **両ブランチには一切変更を加えていない。** 読み取りのみである。

### 0-2　この整理でできていないこと（先に書く）

| できていないこと | 理由 |
|---|---|
| 成果品（docx・xlsx）の中身の点検 | 記録MDと生成スクリプトを読んで判断している。docx を開いて1頁ずつ見てはいない |
| 計画素案の全文の通読 | 高齢者側の `18_計画素案.md` は432KB（本文139頁相当）ある。語の出現数と該当節の抜き取りによっている |
| 法令・告示の原典による確認 | 両ブランチと同じ制約（e-Gov・厚生労働省・こども家庭庁への接続が遮断）を受けている。条項番号は両ブランチの記述を前提とした |
| 他メンバーの作業範囲 | 調査票の設計・発送（高齢者）、アンケートの入力・集計（障害）は他メンバーの担当であり、ブランチに現れない作業がある可能性がある |

**したがって、下記の「抜けている」は「2本のブランチの追跡対象に現れない」という意味である。** 村とのやり取りや他メンバーの手元で既に片付いているものが含まれ得る。

## 3　高齢者介護ブランチに抜けている論点

### A-1　介護職員等処遇改善加算が計画に一度も出てこない【優先度 高】

ブランチ全体で「処遇改善」が**0件**である（素案も0件）。

| | |
|---|---|
| 根拠 | 老人福祉法第20条の8第3項第2号（従事者の確保・資質の向上、業務の効率化・質の向上のために講ずる**都道府県と連携した措置**）／基本指針の「介護人材の確保・生産性の向上」 |
| 素案の状態 | 施策4-6（介護人材の確保と生産性向上）はある。素案4-6の末尾も同項第2号への対応として施策4-6を指している。しかし**加算の取得促進に触れていない** |
| 対比 | 障害側は同じ論点（別表第一 十二）をR-1として第5章13に反映し、**福祉・介護職員等処遇改善加算の取得促進と県のワンストップ窓口の周知**を書いている |

**村は指定・指導監査の権限を持たないため、村ができるのは「県の取組みに村内・圏域の事業所をつなぐこと」である。** 障害側がこの立て方を既に確立しているので、そのまま移せる。村内の介護サービス事業所は数か所にとどまるため、分量は数行で足りる。

> 事業所数は本整理では確定していない。doc32（9月10日）は「2か所（グループホーム・通所介護）」とするが、10月10日のコミットで「村内のGHは2施設」と素案が訂正され、障害側の整合 K-5 は「介護保険側が訪問介護1・通所介護2か所」としている。**数が動いているため、ここでは引かない**（C-3・C-4で事業所名簿を揃える必要がある理由でもある）。

### A-2　障害側の照会 K-7 の4点のうち2点が未了【優先度 高】

障害側は「介護保険事業計画に、**介護保険優先原則・適用除外施設・共生型サービス・新高額障害福祉サービス等給付費**の4点を1節として置けるか」を優先度「高」で照会している（`北塩原村_障がい計画と介護保険事業計画の整合.md` K-7）。

素案の現状を語で数えた。

| 語 | 素案での件数 | 状態 |
|---|---:|---|
| 共生型サービス | 5 | **反映済**（施策3-1・指標・他計画との連携の対照表） |
| 適用除外 | 2 | **一部**（「他計画との連携」の対照表と編集注記のみ。5-1（被保険者数）の本文には節がない） |
| 介護保険優先原則 | **0** | **未** |
| 新高額障害福祉サービス等給付費 | **0** | **未** |
| 受給者証 | **0** | **未** |

障害側は、新高額障害福祉サービス等給付費の償還の対象が**訪問介護・通所介護・短期入所生活介護・地域密着型通所介護・小規模多機能型居宅介護の5種に限られ、介護予防サービスは対象外**であることまで調べている（K-6）。この5種のうち介護保険側の見込量が立つのは実質3種である。**調べた側の成果が、もう一方の計画に移っていない。**

**原因が特定できた。§5 C-7 のとおり、高齢者側はK-7を見ていない。** 障害側がK-1〜K-8を書いたのは10月8日であるのに対し、高齢者側が整合の作業（doc81）で参照した障害側ブランチは**10月4日の状態**である。高齢者側が応答したのは別文書（10月10日作成の網羅性チェック）であり、**K-7の4点の照会はそもそも届いていない。** したがってこれは判断の相違ではなく、**受け渡しの事故**である。

### A-3　法が義務とする2つの記載事項の値が、ほぼ空欄のまま急ぎの一覧に入っていない【優先度 高】

| 記載事項 | 根拠 | 性質 | 素案の状態 |
|---|---|---|---|
| 地域支援事業の**量**の見込み | 介護保険法第117条第2項第2号 | **義務** | 5-5(1)の表は20行。うち**6事業が「―」**（介護予防ケアマネジメント・総合相談支援・認知症初期集中支援・認知症カフェ・サポーター養成講座・家族介護者支援）。訪問型・通所型の従前相当も「―」 |
| 老人福祉事業の**量の目標** | 老人福祉法第20条の8第2項 | **義務** | 4-6の表は施設3事業・在宅17事業。**R7実績がほぼ全て「―」**で、目標値も弁当配達（年4回）以外は「―」 |

どちらも資料提供確認依頼書 管理番号25〜39として照会済みである。しかし：

- `72_WBSの更新と作業優先順位.md` §6「残っていること」5件に入っていない
- `86_紙面の通し確認.md` §9-2「急ぎ」7件に入っていない

**6サービスの0の扱いは1つの表を止めているが、管理番号25〜39は法が「定めるものとする」とした記載事項2つを丸ごと止めている。** 影響度の判定が逆になっているように見える。影響度1に上げるか、「実績が来なくても目標値だけは村と協議して置く」経路を作るか、どちらかを決める必要がある。

### A-4　総合事業の多様なサービスを最重点に掲げながら、量を0で立てている【優先度 中】

| | |
|---|---|
| 施策 | 施策1-2「総合事業における多様なサービスの創設」【新規】。素案は「整っていないのは通いの場と介護給付の間をつなぐサービス」「本計画の**最重点分野**として取り組みます」としている |
| 交付金の評価 | 総合事業の多様なサービスの実施状況は13点中**0点**、活用の推進は7点中1点 |
| 見込量 | 訪問型サービスA〜D・通所型サービスA〜Cは令和9〜11年度すべて**0**。編集注記は「実施を決定した場合は見込量に計上して差し替えます」 |

**最重点と掲げた施策の量が3か年すべて0であると、計画としての体裁が整わない。** 小野町では「実績のあるサービスの見込量を0と掲げることになり、計画として成り立ちません」として村に照会しているが、こちらはその裏返し（**創設すると掲げた施策の量が0**）である。第2回策定委員会で「創設するか・しないか」を決めていただき、するなら量を置く、しないなら最重点から外すかの判断が必要である。

### A-5　認知症の人および家族等の意見聴取が、期限のある未決事項として順位から落ちている【優先度 高（期限あり）】

`32_法定記載事項チェック.md` §7 は次のように書いている。

> 認知症基本法は、市町村計画の策定にあたり**認知症の人および家族等の意見を聴くこと**を求めている。……「認知症の人および家族等の意見を聴いた」ことを計画に書いていない。……**これは記述の追加では埋まらず、策定過程そのものに関わる**ため、第2回策定委員会（11月）までに方針を決める必要がある。

ところが、`72` §6 と `86` §9-2 のいずれにも挙がっていない。**11月の第2回策定委員会までという期限があり、かつ「記述の追加では埋まらない」と自ら書いているのに、作業順位の管理から外れている。**

策定委員会の委員構成に認知症の人または家族の代表が含まれるかの確認、含まれない場合の意見聴取の機会（家族会・認知症カフェ等）の設定は、**村の内部手続であり日数がかかる。** 10月中に村へお諮りする必要がある。

### A-6　第10期基本指針の告示後の再点検の仕組み【優先度 中】

`32` は第9期の基本指針（令和6年1月19日告示第18号）に対して点検しており、「第10期の基本指針は告示待ちであり、告示後にもう一度同じ確認を行う必要がある」（対応10番）としている。これ自体は正しい。

**抜けているのは、告示を待つ間の追跡である。** 障害側は同じ論点で次の教訓を得ている。

> 今回の2件は、**告示（令和8年3月31日）の後に、社会保障審議会障害者部会とこども家庭審議会障害児支援部会の資料として示されたもの**である。告示本文だけを見ていると取りこぼす。……計画確定までに、さらに改正が示される可能性がある。

高齢者側は「介護保険部会」に12ファイルで触れているが、**定期的に確認する先を明示し、確認した日を記録する形**にはなっていない。障害側が実際に取りこぼしを経験した（骨子案と素案に2件の改正が反映されていなかった）ことを踏まえると、高齢者側にも同じ型を置くのが筋である。確認先は、社会保障審議会介護保険部会の資料と、県からの市町村あて通知の2つで足りる。

### A-7　条文の原典が未確認のまま残っている【優先度 中】

`32` §1 は、介護保険法第117条第2項各号の完全な列挙と号数、基本指針の記載事項の正確な項目名が未確認であることを明記している（対応11番）。これは**既に条項番号の誤り1件を生んでいる**（第117条第3項第5号・第6号 → 第2項第3号・第4号。義務／努力義務の性質が変わる誤り）。

**同じ未了が障害側にもある**（§5 C-6参照）。両案件で同じ原典を必要としているため、村または県を通じた入手を1件の照会にまとめるのが効率的である。

### B-1　紙面が積算のみで、実測されていない【優先度 高】
