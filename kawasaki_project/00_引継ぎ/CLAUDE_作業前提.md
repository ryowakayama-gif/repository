## 技術上の必須ルール（詳細はREADME §7）
- **DOCX**: `export NODE_PATH=$(npm root -g)` 後に `node build_xxx.js` → unpack → **pBdr子要素を top,left,bottom,right,between,bar順に並替** → pack --original → validate
- **XLSX**: openpyxl編集 → **recalcは単独実行**（連鎖するとタイムアウトで破損）。MergedCellは書込前にunmerge。**ゼロエラー維持**
- チャート日本語フォント = `Noto Sans CJK JP`
