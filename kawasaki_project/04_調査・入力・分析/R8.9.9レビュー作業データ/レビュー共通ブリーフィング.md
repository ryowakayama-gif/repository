### 個票そのもの
`/home/user/repository/kawasaki_project/04_調査・入力・分析/R8調査データ/` の2つのxlsx
- `川崎町_介護予防日常生活圏域ニーズ調査_集計データ_20260807.xlsx`
- `川崎町_在宅介護実態調査_集計データ_20260807.xlsx`

「データ」シートの構造：
- 行1 = 設問グループ名（A問1 等。その設問の**先頭列にだけ**置かれる）
- 行2 = 設問文
- 行3 = 選択肢ラベル
- 行4 = `①`…（選択肢列）／`n`（有効回答フラグ列）
- 行5〜 = 個票。選択肢セルは `〇`、n列は 1
- **末尾の「計」行は必ず除くこと**
- 属性列は 性別・年齢階級・要介護状態区分（行1に見出しがあり、行3・行4が空）

python3 と openpyxl で自分で集計してよい。

> **割合は必ず `Decimal` の `ROUND_HALF_UP` で丸めること。
> Python 組込みの `round()` は偶数丸めになり 6.25→6.2 と誤るので使ってはならない。**

```python
from decimal import Decimal, ROUND_HALF_UP
def pct1(k, n):
    if not n: return None
    return float((Decimal(k*100)/Decimal(n)).quantize(Decimal('0.1'), rounding=ROUND_HALF_UP))
```

## 報告書が採っている方針（これは誤りではない。方針違反だけを指摘すること）

- 割合の分母は「設問ごとの有効回答数n（無回答を除く）」。有効票576件／142件に統一していない。
- 複数回答設問では割合の合計が100％を超える。
- 概要表には行ごとのnを付けず、表直下に一括注記を置く。
- **概要表の行は「複数の選択肢の合算値」であることが多い**
  （例：「昨年より外出回数が減っている27.5％」＝「とても減っている2.9％」＋「減っている24.5％」）。
  単一の選択肢と比べて違うと即断しないこと。
