# 旧版の図表（令和8年9月30日に 08_図表・07_ソーススクリプト から移しました）

図の数値の正本を `07_ソーススクリプト/data_zuhyo.py` の1か所にまとめたことに伴い、
**それ以前に図の数値を持っていた作図スクリプトと、その出力の画像**をここへ移しました。
記録として残すものであり、**今後の作図には用いません。**

## なぜ移したか

図の数値が次の5つのスクリプトに散らばっており、食い違いが生じていました。

| スクリプト | 持っていた図 |
|---|---|
| `create_charts.py` | 図2-2（高齢化率比較） |
| `make_chart_premium_v110.py` | 保険料の図（v1.10） |
| `make_charts_v114.py` | 図2-5・図9-1 |
| `make_charts_v115.py` | 図2-1・図2-4 |
| `make_charts_v116.py` | 図2-3・図9-1 |

このため、素案 Ver.2.3 で保険料を是正（算定Ｂ6,170→**6,143円**／
算定Ｃ5,518→**5,464円**）した際に**図9-1 が追随しておらず**、
また**画像に焼き込んだ図番号が素案 Ver.2.5 の採番と4点食い違って**いました。

## これから図を直すときは

`07_ソーススクリプト/data_zuhyo.py` の数値を直し、次を実行してください。

```bash
python3 07_ソーススクリプト/build_plan_figures.py   # 08_図表 の png を作り直す
python3 07_ソーススクリプト/build_zuhyo_daicho.py   # 台帳と自己点検
```

図表データ管理台帳は
`05_試算・管理シート/川崎町_図表データ管理台帳_R8.9.30.xlsx` です。
