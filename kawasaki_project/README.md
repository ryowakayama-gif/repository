## 技術メモ

- **Word**：Node.js `docx` ライブラリ。実行前に `export NODE_PATH=$(npm root -g)`。
  生成後は `w:pBdr` 子要素を top→left→bottom→right→between→bar 順に並べ替えてから pack（OOXMLスキーマ要件）。
- **Excel**：`openpyxl`。シート名にハイフン不可（アンダースコアで統一）。`cell.fill = None` は不可。
  **recalc は必ず単独実行**（他コマンドと連鎖するとタイムアウトでファイル破損）。
- **チャート**：matplotlib。日本語フォントは `Noto Sans CJK JP`。
- **章カラー**：1章ネイビー `1F3864` ／2章グリーン `375623` ／3章ブルー `2E75B6` ／4章オレンジ `C55A11` ／
  5章パープル `7030A0` ／6章マゼンタ `9333B0` ／7章ティール `0F4F73` ／8章チャコール `404040`
- スクリプト内の `/mnt/skills/...`・`choki/*.png`・`9ki_plan.pdf`（=`09_元資料/川崎町_第9期計画_04324.pdf`）は
  実行環境に合わせてパス調整が必要です。
