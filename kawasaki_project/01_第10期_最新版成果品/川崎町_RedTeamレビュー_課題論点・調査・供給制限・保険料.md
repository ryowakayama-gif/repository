## 1. 課題・論点整理の妥当性

### 1-1. 実データによる裏付けの検証

論点L1〜L16について、今回の調査データで裏付けが取れるかを検証した。

| 論点 | 実データによる裏付け | 判定 |
|:--|:--|:--|
| L1 移動支援 | 外出手段は自動車74.1%・路線バス5.6%。介護者の不安で「外出の付き添い・送迎」33.3%が最多タイ | **強い** |
| L2 認知症 | 物忘れの自覚41.8%。物忘れ自覚層の窓口認知度43.1%＜非自覚層51.0%。介護者の不安「認知症状への対応」33.3%が最多タイ | **強い** |
| L7 8050・老老介護 | 主な介護者の70代26.3%＋80歳以上15.8%＝**42.1%が70歳以上**。60代を含めると68.4% | **強い** |
| L3 施設の地域偏在 | 住所地特例24人。自由意見1件（「役場に近い住民は情報が早く様々なサービスを利用できている」） | **弱い**（後述） |
| L6 包括センター体制 | 自由意見1件（「必要になってからおいでくださいと門前払い」）のみ | **弱い** |
| L4 介護人材不足 | **調査に設問なし**。事業所調査は未実施 | **なし** |
| L5 広域医療連携 | **調査に設問なし** | **なし** |

**指摘1-A**：L4・L5は第9期からの継続論点として掲げているが、第10期の調査で一切検証していない。
仕様書6（1）の調査対象は一般高齢者と認定者のみで事業所が含まれないため、
介護人材の実態は把握できない構造になっている。裏付けのない論点を「重点課題」として
計画に掲げることの妥当性を再検討すべきである。

**指摘1-B**：L3（地域偏在）は本町の構造的課題として最重視しているが、
ニーズ調査576件に**日常生活圏域IDが全件未記録**のため、地区別の分析ができない。
F4で設計した7地区区分のクロス集計も実施できていない。
「中山間部住民のアクセス障壁」という主張を数値で示せない状態にある。

### 1-2. 論点として立てられていない事項

調査データから読み取れるにもかかわらず、論点化されていないものが4点ある。

1. **施設入所の待機**（最重要・第3章参照）
2. **在宅サービスの低利用率** — 在宅認定者142人のうち介護保険サービス利用ありは41.3%にとどまり、
   訪問介護の利用は推計で約14人（全体の1割）。供給不足か、ニーズ不足か、情報が届いていないかが未検証
3. **介護離職リスク** — 就労中の介護者のうち「続けていくのはやや難しい」20.5%＋「かなり難しい」5.1%
   ＝**25.6%が継続困難**。素案は介護離職防止を重点に挙げるが、この数値を根拠に使っていない
4. **経済状況と健康の連関** — 経済的に「大変苦しい」層の43.2%が健康状態不良（「ふつう」層の2.1倍）。
   保険料の所得段階設定・低所得者対策と直結する論点だが、第7章と接続されていない

### 1-3. 第1回策定委員会資料の論点整理

「⑨第10期計画に向けた検討の視点」は妥当だが、**すべて既存論点の再掲**であり、
今回の調査で新たに見えた上記2〜4が反映されていない。
「⑧分野別の課題整理」も庁内連携の視点としては有用だが、
**介護保険事業計画の中核である給付とサービス供給の論点が入っていない**。

## 2. 実態調査の内容と施策

### 2-1. 調査の構造的限界

| 限界 | 内容 | 影響 |
|:--|:--|:--|
| 属性の欠落 | ニーズ調査576件で性別・年齢階級・要介護状態区分・圏域IDが**全件空欄** | 後期高齢者層・性差・地区別の課題を数値化できない |
| 事業所調査の不在 | 仕様書の調査対象は一般高齢者と認定者のみ | 介護人材・供給側の実態が不明 |
| 自由意見欄の不在 | 全75設問に意見・要望を求める設問がない | 「アンケートでの住民意見について」の7件の出典が不明 |

**指摘2-A**：属性の欠落は分析の根幹に関わる。調査票のNO（1〜576）が町の発送台帳と対応していれば
属性を後付けできる。突合を早急に確認すべきである。

### 2-2. 施策との対応

調査で最も強い信号が出た2項目は、いずれも素案の重点と一致しており、この点は妥当である。

- 介護者の不安：**外出の付き添い・送迎33.3%**／**認知症状への対応33.3%**（同率最多）
  → 移動支援（重点）・認知症施策（第6章独立章）と整合
- 次いで入浴・洗身26.7%、食事の準備24.0%
  → 訪問介護・訪問入浴の需要を示唆するが、**実際の利用率は約1割**。ここに乖離がある

**指摘2-B**：不安として挙がる項目（入浴・食事準備）と実際のサービス利用率の乖離を
分析していない。供給の問題か、自己負担の問題か、周知の問題かで打つべき施策が変わる。

## 3. 供給制限

### 3-1. 施設需要と供給の乖離

在宅介護実態調査（n=139）の結果は看過できない。

| 施設等への入所・入居の検討状況 | 割合 | 142件換算 |
|:--|--:|--:|
| すでに入所・入居申し込みをしている | **33.8%** | 約47人 |
| 入所・入居を検討している | 14.4% | 約20人 |
| 検討していない | 51.8% | 約72人 |

要介護度の分布は要介護3が32.4%・4が19.4%・5が6.5%で、**要介護3以上が58.3%**。
特別養護老人ホームの入所要件を満たす層が厚い。

町内の施設は特別養護老人ホーム1施設・介護老人保健施設1施設のみである。
既に住所地特例24人が町外施設を利用している。

### 3-2. 素案の欠落

計画素案 v1.6 を検索した結果は以下のとおりである。

| 語 | 出現回数 |
|:--|--:|
| 待機 | **0回** |
| 施設整備 | **0回** |
| 総量 | **0回** |
| 参酌（参酌標準） | **0回** |
| 定員 | 1回 |

**指摘3-A（本レビュー最大の指摘）**：介護保険事業計画は介護保険法第117条第2項により
サービス種類ごとの量の見込みを定めるものであり、施設サービスについては
**定員の総量が都道府県の指定に係る協議の基礎**となる。
待機者・整備方針・定員の記載がない計画は、計画としての必須要素を欠く可能性がある。

さらに、素案の唯一の供給方針は次のとおりである。

> ①町内施設の供給定員のみで見込量を制約しない。町外施設利用を含めた
> 「町民の施設サービス利用ニーズ」全体を見込量とする

方針としては妥当（住所地特例24人の実態に即している）だが、
**保険料試算のStep1では施設サービスをR3実績の構成比×年1.2%で機械的に伸ばしており、
「ニーズ全体を見込量とする」方針が推計に反映されていない**。方針と推計が矛盾している。

### 3-3. 供給制限が保険料に与える影響

申込済み47人のうち要介護3以上の層が第10期中に20人入所すると仮定すると、
施設サービス受給者は134人→154人（+14.9%）となる。

この場合の保険料基準額は **7,632円 → 8,107円（+475円）** となる。
これは基金取崩3パターンの幅（495円）に匹敵する。

**指摘3-B**：供給をどこまで見込むかが、基金取崩の選択と同等以上に保険料を左右する。
にもかかわらず、第1回策定委員会資料にも素案にもこの論点が登場しない。
委員会に諮るべき最重要の政策判断が議題から欠落している。

## 4. 保険料に影響する項目の精査

### 4-1. 第9期の保険料算出表が自己矛盾している

第9期計画書p.94の算出表を検証した。

| 検証項目 | 結果 |
|:--|:--|
| 第1号被保険者負担相当額 = (標準給付費3,294,553,410＋地域支援事業費91,560,000)×23% | 778,806,084 = 778,806,084 **一致** |
| 取崩なし収納必要額 = 778,806,084＋166,005,671−129,349,000−10,800,000 | 804,662,755 = 804,662,755 **一致** |
| 取崩後収納必要額 = 804,662,755 − 78,000,000 | 726,662,755 ≠ **712,662,755（14,000,000の差）** |
| 基準額（年額）= 712,662,755 ÷ 0.96 ÷ 9,875人 | 75,175円 ≠ **78,000円（3.8%の差）** |
| 年額78,000円 ÷ 12 | 6,500円 ≠ **月額6,508円** |

**指摘4-A**：第9期の算出表は少なくとも3箇所で自己整合しない。
このため、第9期を再現するように設定した第10期の算定パラメータは、
第9期の誤差を引き継いでいる。

### 4-2. 補正係数0.97の検証 ─ 当初の指摘を撤回する

初版で「0.97は所得段階分布の補正ではなく第9期を再現するための調整値である」と指摘したが、
**この指摘は誤りであった。撤回する。**

町提供資料（実績データ確認サマリー 04シート）にR3年度末の所得段階別第1号被保険者数
（9段階・3,255人）が既に収録されており、これに第9期の段階別料率を乗じて加重平均料率を算定できる。

| 適用する料率 | 補正後被保険者数 | 補正係数 |
|:--|--:|--:|
| 第8期料率（R3当時） | 3,221.9人 | 0.9898 |
| **第9期料率・公費軽減前** | **3,168.3人** | **0.9734** |
| 第9期料率・公費軽減後 | 3,039.0人 | 0.9336 |

保険料算定では公費軽減分は公費で補填されるため軽減前料率を用いる。
その値は **0.9734** であり、ワークブックの0.97はこれとほぼ一致する。
**0.97は所得段階分布に基づく正当な値である。**

一方、**第9期計画の補正後被保険者数9,875人は同計画の人口推計9,925人に対して0.995**であり、
実際の所得段階分布から算定される0.9734と整合しない。
**不整合は当方の0.97ではなく第9期計画側にある。** 町の算定ワークシートで確認すべき事項である。

なお現在用いているのはR3年度末・9段階（第8期区分）の分布であり、4年前のものである。
第9期の13段階区分によるR7またはR8時点の分布を受領すれば確定できる。

### 4-3. 感度分析

パターンA（基金取崩なし）を基準に、単一パラメータを動かした影響を算定した。
（基準値の再現：A=7,632円／B=7,384円／C=7,137円。提示値と一致）

| 条件 | 基準額 | 差 |
|:--|--:|--:|
| 施設給付 +14.9%（申込済47人の一部が入所） | 8,107円 | **+475円** |
| 調整交付金 3.9%→5.0%（標準率） | 7,288円 | **−344円** |
| 補正係数 0.97→0.9734（R3分布から実算定） | 7,606円 | −26円 |
| 第1号被保険者数 −2.2%（R7実績の下振れを反映） | 7,804円 | +172円 |
| 給付費伸び 1.2%→0.5%/年（第9期の実績並み） | 7,529円 | −103円 |
| 収納率 96%→95% | 7,712円 | +80円 |
| 地域支援事業費 +10%（認知症基本法対応） | 7,651円 | +19円 |
| **下振れ複合**（補正0.9734＋調整交付金5%） | **7,264円** | −368円 |
| **上振れ複合**（被保険者−2.2%＋施設需要反映） | **8,289円** | +657円 |

**指摘4-C（提示方法の問題）**：
提示している3パターンの幅は **495円**（7,137〜7,632円）で、これは**基金取崩だけの幅**である。
一方、他のパラメータの不確実性を含めた幅は **1,184円**（7,105〜8,289円）に達する。

3パターンを「保険料の幅」として提示すると、実際の不確実性の4割程度しか示していないことになる。
委員会が「7,137〜7,632円の範囲で決める」と受け取ると、後に町確認データが確定した段階で
範囲外に出る可能性が高い。**基金取崩の3パターンとは別に、パラメータ確定前の
不確実性レンジを明示すべきである。**

### 4-4. 個別パラメータの検証

**調整交付金見込率3.9%（感度 −344円）**
第9期の実績（129,349,000÷3,294,553,410＝3.93%）をそのまま第10期に引き継いでいる。
しかし調整交付金は後期高齢者加入割合と所得段階分布で決まる。
川崎町は後期高齢者51.6%・非課税層30.1%であり、**本来は標準5%を超える属性**である。
3.9%という低さ自体が検証を要する異常値であり、これを無検証で3年間据え置く根拠はない。

**第1号被保険者数（感度 +172円）**
R7実績3,244人に対し、第9期計画の推計はR7=3,316人。**実績が推計を2.2%下回っている**。
にもかかわらずR8以降は第9期計画の推計値をそのまま採用している。整合していない。

**給付費の伸び率1.2%/年**
第9期計画の標準給付費の伸びはR6→R7が+0.18%、R7→R8が+0.64%である。
第10期に1.2%とする根拠が示されていない。感度自体は小さい（−103円）が、
仕様書6（5）は「要介護認定者数及び介護予防の実施を踏まえた要介護認定者数の推計」と
「サービス事業量の推計」を求めており、**認定者数×利用率×単価への分解が行われていない**。
ワークブックの10シートに認定者数の推計（R9=584人・R11=598人）はあるが、
**給付費推計に接続されていない**。仕様書要求に対する未達である。

**基金残高53,700千円**
第9期計画の「基金残高131,700千円−取崩額78,000千円」で算出している。
しかし4-1のとおり、算出表は実質92,000千円の取崩を示唆しており、その場合の残高は39,700千円となる。
また第9期期間中の積立・取崩の**実績**が未確認である。
残高が39,700千円ならパターンCは7,137円→7,266円（+129円）となる。

**地域支援事業費**
3年間すべて第9期水準（30,521千円/年）で据え置いている。
一方で素案は認知症施策としてチームオレンジ整備・本人ミーティング新設を掲げ、
地域包括支援センターの体制強化も打ち出している。
**施策として拡充を掲げながら費用を据え置くのは不整合**である（感度は小さく+19円/10%増）。

## 追記（令和8年8月20日）：本レビューを受けた対応

1. **補正係数の検証**（4-2）：R3年度末の所得段階別人数から0.9734を実算定し、
   ワークブックの0.97を裏付けた。初版の指摘は撤回した。
2. **認定者数×利用率×単価への分解**：
   `川崎町_サービス見込量・給付費推計ワークブック.xlsx` を作成し、仕様書6（5）に対応した。
   第9期計画の実績（認定者数・受給者数・サービス区分別給付費）から利用率と単価を抽出し、
   認定者数の推計に乗じて給付費を積み上げる方式に改めた。
   - 標準給付費3年計：3,286,003千円（現行の一律1.2%/年延伸に対し −3.1%）
   - 保険料基準額A：7,367円（現行7,632円に対し −265円）
   - 施設入所申込の反映度合いによる4シナリオを同ワークブック06シートに実装
     （現状維持7,367円／申込の2割7,612円／4割7,856円／6割8,100円）
3. **必要資料の特定**：同ワークブック08シートに10件を優先度付きで整理した。
   最優先は①介護保険事業状況報告年報（R5〜R7年度）と②年齢階級別・性別の認定者数である。
