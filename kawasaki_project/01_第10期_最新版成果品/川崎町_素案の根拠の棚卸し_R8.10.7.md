## 2. ⚠ 交付金の全国統計を原典から作り直し、1件の誤りを見つけました

**`05_試算・管理シート/川崎町_交付金_全国統計の再現_R8.10.7.xlsx`**（5シート）

素案 3-3 には、全国平均・規模区分別の平均・過疎地域該当別の平均・県内平均・
順位・指標群別の得点といった**全国統計が数多く書かれています。**
これらは令和8年度の全国集計（厚生労働省の公表値・1,741保険者）から
算定したものですが、**算定の過程がどの成果品にも残っていませんでした。**
町や県から「この数はどこから」と問われたときに、その場で示せない状態でした。

そこで**原典から同じ数を作り直し、素案の記述と突き合わせました。**

| | 結果 |
|---|---|
| 突き合わせた数 | **39件** |
| 一致 | **38件** |
| **不一致** | **1件** |

### 見つかった誤り

素案 3-3 は「過疎地域に該当する885保険者の平均437.4点は、
**非該当855保険者**の平均473.5点を36.1点下回ります」と書いていました。

**全国1,741保険者のうち過疎地域該当が885保険者ですので、非該当は856保険者です。**
885＋855＝1,740となり、1保険者足りません。平均473.5点の方は一致していますので、
**数え方ではなく件数の書き誤り**です。

**`01_第10期_最新版成果品/川崎町_計画書素案_v2.12_根拠整理版.docx`**（全113頁）で
856に是正しました。**他の数値は一切変えていません。**

### 再現できるようになったこと

以後は素案の版を上げるたびに実行することで、次の数の裏づけを保てます。

| | 内容 |
|---|---|
| 全国・県内 | 保険者数・平均・中央値・最小・最大・本町の順位・平均との差 |
| 規模区分別 | 5区分の保険者数・平均・中央値 |
| 過疎地域該当別 | 該当885・非該当856の保険者数・平均 |
| 指標群別 | 体制・取組／活動／成果の本町の得点・全国平均・順位・同規模順位 |
| 閾値 | 「著しく得点の低い市町村がない」の閾値（得点率の平均−標準偏差×2） |

> ⚠ **当方が新たに数値を作っているのではなく、公表値から集計しています。**
> 列の位置は年度により動きますので、**見出しの文字から列を探す**形にしました。
> 突合で一致しない数が1件でもあれば、スクリプトが止まります。

## 3. ⚠ 残る70件の原因は1つに絞れました

出所を特定できていない70件は、**9-1・9-2・9-3に集まっています。**

| 節 | 数値の件数 | うちD |
|---|---:|---:|
| 9-3　介護保険料の算定 | 252 | **34** |
| 9-1　サービス見込量 | 410 | **28** |
| 9-2　地域支援事業の量と費用 | 43 | **6** |
| その他 | 742 | 2 |

いずれも**中長期（令和17年度・令和22年度）の見込量と、保険料の内訳**です。

**算定はしていますが、算定の結果を成果品（計画見込量のxlsx）に
書き出していません。** 計画見込量のxlsxは令和11年度までしか持っておらず、
中長期の数は素案にしか残っていない状態です。

**同じ原因であった交付金の全国統計（3-3・18件）は、上記2で原典から
作り直して成果品に残しました。** 中長期と保険料の内訳についても同じことを
行います（**作業順位29**として台帳に置きました。半日を見込んでいます）。
これが済めば、素案の数の裏づけはほぼすべて揃います。
