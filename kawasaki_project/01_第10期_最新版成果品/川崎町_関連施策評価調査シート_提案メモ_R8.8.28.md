## 3．設計上、特に意図した3点

### （1）第9期計画の基本方針に紐づけて回答してもらう

02シートの「第9期計画上の位置づけ」欄は、第9期計画 第3章の**基本方針1〜5**をそのまま選択肢にしています。

| 選択肢 | 第9期計画の基本方針 |
|---|---|
| 基本方針1 | 健康づくりの推進（第2部 第1章） |
| 基本方針2 | 高齢者が安心して暮らせるまちづくりの推進（第2部 第2章） |
| 基本方針3 | 地域生活を支援する取組の充実（第2部 第3章） |
| 基本方針4 | 地域支援事業の充実（第2部 第4章） |
| 基本方針5 | 介護給付・介護予防給付サービスの充実（第2部 第5章） |
| 記載なし | 第9期計画に位置づけがないが高齢者に関連する事業 |

「記載なし」を選択肢に含めているのは、**第9期計画に載っていない高齢者関連施策を洗い出す**ためです。庁内他課の事業は計画に位置づけられていないものが相当数あると見込まれ、これを把握できれば第10期の施策体系を実態に近づけられます。

なお、第9期計画の基本理念は「**誰もが健やかに暮らせるまちづくり**」です（第9期計画 42頁）。

### （2）調査結果を提示したうえで認識を問う

03シートでは、抽象的に「課題は何か」と尋ねるのではなく、**今回の2調査で確認された事実を数値で示したうえで**、各課の認識・現在の取組・今後の方針を問う形にしています。

| 分野 | 提示する事実（抜粋） |
|---|---|
| 保健 | 物忘れ41.8％、気分の沈み34.7％、認知症相談窓口を知っている47.7％ |
| 医療 | 高血圧54.2％、経済状況「大変苦しい」層の健康不良40.5％（「ふつう」層の約2.0倍） |
| 防災 | 転倒経験33.6％、転倒不安51.9％、不安が強い層の外出控え48.1％ |
| 交通 | 自動車（自分で運転）74.1％、路線バス5.4％、外出を控える理由「交通手段がない」19.8％ |
| まちづくり | 参加していない 学習89.0％〜町内会59.4％、参加意向55.2％、担い手41.4％ |
| 分野横断 | 相談相手がいない38.8％、認知症相談窓口を知らない52.3％、支援が入っていない世帯50件 |

**回答の質が上がるうえ、聞き取りの論点も事前に絞れます。** また、各課が「自分の分野の話である」と認識しやすくなります。

### （3）「取組」と「成果」の接続を問う

04シートは、保険者機能強化推進交付金等の評価結果を提示したうえで、**実施量以外にどう成果を確認しているか**を問うものです。

| 区分 | 令和6年度 | 令和7年度 | 令和8年度 |
|---|---|---|---|
| 合計得点（800点満点） | 454点（56.8％） | 565点（70.6％） | 528点（66.0％） |
| 全国順位（1,741保険者） | 696位 | **114位** | 366位 |

一方、令和8年度のアウトカム指標は、要介護1・2の平均要介護度の伸びが**全国1,580位**、性年齢調整済み要介護2以上の認定率が**全国1,666位**です。**取組（プロセス）は全国上位だが、成果指標は全国下位**という構造が確認されています。

第10期でこの構造に手を打つには、各事業が成果をどう確認しているかを把握する必要があるため、任意回答として設けました。
