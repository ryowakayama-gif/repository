# 書体と文字の大きさを大雪広域の協議用素案に合わせました

令和8年9月30日／ビズアップ公共コンサルティング株式会社　札幌事業所

**`01_第10期_最新版成果品/川崎町_計画書素案_v2.5_書体統一版.docx`**（全101頁）

---

## 0. 「見づらい」の原因は3つありました

大雪地区広域連合の協議用素案の `styles.xml` を調べたところ、
**書体（游ゴシック）そのものは両者とも同じ**でした。
見づらさの原因は書体名ではなく、次の3点にありました。

| | 原因 | 影響 |
|---|---|---|
| **①** | **既定の段落スタイル（Normal）が定義されていなかった** | **Word が自前の「標準」を当てるため、本文が明朝体で表示されることがある** |
| ② | 同じ用途の要素に複数の大きさが混在していた | ▌小見出しが11.0ptと10.5ptの2種類、⚠注記が10.5・9.5・11.0ptの3種類 |
| ③ | 本文・表の大きさが大雪広域と揃っていなかった | 本文10.5pt（大雪10.0pt）／表9.0pt（大雪8.5pt） |

### ①がもっとも重いものです

川崎町の素案の `styles.xml` には、
`Title`・`Heading1`〜`Heading6`・`Strong`・`ListParagraph` などが
いずれも **`<w:basedOn w:val="Normal"/>`** を持っているのに、
**`Normal` スタイル自体が定義されていませんでした。**

Word は既定の段落スタイルがない文書を開くと自前の「標準」を当てます。
日本語版 Word の「標準」は環境により**游明朝・MS明朝**になることがあり、
本文だけが明朝体で表示され、
文字ごとに指定された游ゴシックの部分と混在します。
これが「見づらい」の主因と考えられます。

> 大雪広域の協議用素案には
> `<w:style w:type="paragraph" w:default="1" w:styleId="Normal">`
> （游ゴシック 10.5pt）が定義されていました。

## 2. 川崎町の素案に行ったこと

### 2-1. 既定の段落スタイル（Normal）を定義しました

大雪広域と同じ **游ゴシック 10.5pt** で定義し、
`Title`・`Heading1`〜`Heading6` ほか**16のスタイルすべてに游ゴシックを明示**しました。
これにより、Word の環境によらず游ゴシックで表示されます。

あわせて、既定の行送りを大雪広域と同じ **1.15行**（`line="276" lineRule="auto"`）に
しました。

### 2-2. 文字の大きさを用途ごとに揃え、大雪広域の水準に合わせました

| 用途 | 川崎町（Ver.2.4まで） | **Ver.2.5** | 大雪広域 |
|---|---|---|---|
| 章扉「第N章」 | 15.0pt | **14.0pt** | 14.0pt（Heading1） |
| 節見出し「1-1」 | 12.5pt | **13.0pt** | 13.0pt（Heading2） |
| ▌小見出し | **11.0pt と 10.5pt が混在** | **10.5pt** | 10.5pt（Heading3） |
| **本文・⚠注記** | **10.5・9.5・11.0pt が混在** | **10.0pt** | **10.0pt** |
| ●要点 | 10.0pt | 10.0pt | ― |
| 図のキャプション | 9.0pt | **9.0pt** | 9.0pt（Caption） |
| 出典・資料 | 8.5pt | **8.5pt** | 8.5pt |
| **表内** | **9.0pt** | **8.5pt** | **8.5pt** |
| 目次の表 | 10.0pt | 10.0pt（据置き） | ― |

**表紙・ご挨拶・目次の見出しの大きさは、体裁上の意図があるため変えていません。**

### 2-3. あわせて見つかった不具合も直しました

対比の過程で、**Ver.2.2以降に当社が加えた本文に2つの不具合**がありました。

| | 内容 | 原因 | 対応 |
|---|---|---|---|
| ① | **1-5・1-6・6-1・9-1・9-3・10-4 に加えた本文が太字になっていた**（35段落・70か所） | 本文の雛形として複製していた段落が「●要点」（太字）だった | 太字を落とした。●要点・▌小見出し・章・節の太字は残した |
| ② | **本文に強調記号「\*\*」がそのまま残っていた**（1-6） | 原稿の書き方がそのまま入った | 取り除いた |
| ③ | **ヘッダーが「計画書素案v1.0」のままだった** | Ver.1.0以降ヘッダーを更新していなかった | 「計画書素案 Ver.2.5」に改めた |

③は**Ver.1.0から約10版にわたり誤ったままでした。**
印刷・配布していれば版の取り違えの原因になるものです。

## 3. 書体の点検を機械で行えるようにしました

**`07_ソーススクリプト/check_font_R8.9.30.py`**

| 検査 | 内容 |
|---|---|
| 1 | 既定の段落スタイル（Normal）が定義されているか |
| 2 | すべてのスタイルに游ゴシックが明示されているか |
| 3 | 書体の指定がない run がないか |
| 4 | 用途ごとに文字の大きさが1つに揃っているか |
| 5 | 表内の文字の大きさが8.5pt（目次の表は10.0pt）に揃っているか |
| 6 | 本文が太字になっていないか |
| 7 | 本文に強調記号（\*\*）が残っていないか |
| 8 | ヘッダーの版表記が本文の版と一致しているか |

**Ver.2.4に当てると11件の不適合**を検出します。**Ver.2.5は13件すべて適合**です。

## 4. 頁数が3頁縮みました

| | Ver.2.4 | **Ver.2.5** |
|---|---|---|
| 本文 | 104頁 | **101頁** |
| 資料編 | 13頁 | 13頁 |
| 計 | 117頁 | **114頁** |

文字を小さくしたことにより本文が3頁縮みました。
仕様書8の「100頁程度」に対しては依然14％上回るため、
**本文の圧縮（第3章3-3の交付金の枝番分析 約4頁・第9章9-3の感度分析 約2頁・
第6章6-4の143事業の書き下ろし 約6頁を資料編又は別冊へ）**をご検討ください。
移した場合は**本文89頁・計96頁**となります。

## 6. ⚠ ご確認いただきたいこと

**当社の作業環境には游ゴシックが入っていないため、
PDF化した見え方は実際の Word とは異なります**
（LibreOffice が別の書体に置き換えます）。
docx の指定そのものは大雪広域と同じ游ゴシックに揃えていますが、
**町のパソコンで開いたときの見え方をご確認ください。**

游ゴシックが入っていない環境では、**メイリオ**又は**ＭＳ ゴシック**への
差し替えが必要になることがあります。
その場合はご指示ください（スクリプトの1か所の書き換えで全体を差し替えられます）。
