## 3. ⚠ 票の単位を2層にしました ― 同じ職員を何度も数えないために

はじめは1つの様式に「職員数」と「定員・稼働」を並べていました。**これは誤りでした。**

- **職員・採用・離職・経営は、事業所（指定の単位）でしか数えられません。**
- **定員・稼働・お受けできる量・第10期のご予定は、サービスの種類ごとです。**

1枚にすると、特別養護老人ホームに短期入所・通所介護・居宅介護支援を併設する
法人が**同じ職員の数を4回書くことになり、合計が実数を超えます。**
町内は併設が常態ですので、これは現に起きます。

そこで **様式1（事業所票・1枚）** と **様式2（サービス票・種類ごとに1枚）** に
分け、兼務の状況（兼務しているサービスと従事の割合）を併せて伺う形にしました。

## 6. ⚠ 新たに見つかった要点は5つです

### ① 中山間地域等の加算が、算定できるのに算定されていない可能性があります

川崎町は過疎地域（全部過疎）です。**訪問介護の「中山間地域等における
小規模事業所加算」は令和7年5月に取得要件が弾力化され、1か月の総訪問回数が
おおむね200回以下でよいことになりました。** 素案 2-7 にある
「登録21名に対し実働4名」という町内の状況では、**算定できる可能性があります。**

算定できれば事業所の収入が増え、**供給の維持に直結します。**
照会票では「算定しているか／算定していない理由／1か月の総訪問回数／
令和7年5月の弾力化をご存じであったか」を伺う形にしました。
ご存じなかったこと自体が、町の周知の課題として計画に書くべき事実です。

### ② 総合事業の受け手の意向を、誰も伺っていませんでした

素案 9-2 は介護予防・日常生活支援総合事業費を令和7年度 7,898千円から
令和11年度 6,226千円へ減る見込みで置いています。しかし
**事業所が撤退すれば量そのものが立ちません。** 総合事業は町の裁量で
組み立てる事業ですので、受け手の意向が前提になります。
様式2に「訪問介護相当・通所介護相当サービスの第10期の実施のお考え」を
置きました。

### ③ 素案に書いてあるのに、伺う経路がなかったものが4件ありました

| 素案の箇所 | 伺う経路がなかったもの |
|---|---|
| 5-1 災害・感染症への備え | **業務継続計画（BCP）の策定・研修・訓練・応援の相手** |
| 5-3／1-5 | **身元保証人・緊急連絡先となるご親族がおられない方の受入**（令和8年法律第51号） |
| 5-4 | **今後の医療・介護の希望の話し合いと記録の様式の有無** |
| 6-3 のKPI | **認知症介護基礎研修を受講しておられない介護職員の人数**（基礎研修は義務化されています） |

### ④ 薬局・医療機関は、介護サービス事業所の一覧に現れません

素案 9-1 の居宅療養管理指導の見込量は令和7年度実績（月8.2人）の据え置きですが、
**町内・近隣で訪問に応じていただける薬局・医療機関が何か所あるのかが
分かりません。** 様式7（薬局・医療機関の票）を設けました。

### ⑤ ⚠ 町外の事業所の宛先が、現状では作れません（回収の最大の障害）

本町の被保険者が現に利用している町外の事業所にもお送りする必要がありますが、
**国保連の給付実績（事業所別）が未受領であり（確認事項No.12）、年報では
事業所別に落ちません。**

当方の案は次の2経路による代替です。

1. **町内の居宅介護支援事業所に、給付管理の相手方の事業所の一覧をお願いする**
   （居宅介護支援事業所は給付管理のために相手方を把握しています）
   → **資料提供依頼No.39**として起票しました
2. **住所地特例者台帳の入居先施設**から入所・入居系の事業所を拾う

**確認事項No.172**としてご判断をお願いしています。

## 7. 事業所に「聞かない」ことを12件決めました

回答の負担が重いと回収できません。町内の事業所は数か所であり、
**1件の未回答が全体に効きます。** そこで次は聞かない形にしました。

| 聞かないこと | 代わりの出所 |
|---|---|
| 事業所番号・名称・所在・指定年月日・開設年月 | 町の指定台帳／県の一覧。**町が転記して票面にお示しし、お間違いの有無だけを伺います** |
| **入所率・稼働率・1人あたりの訪問回数・1人あたりの担当件数** | **町で算定します。** 事業所に割り算をさせません |
| 人員配置基準上必要な数 | 定員と利用者数から町で算定します |
| **収支の金額** | **求めません。** 黒字・おおむね均衡・赤字の別と要因だけを伺います |
| 高齢者向け住まいにご入居の方のうち川崎町の被保険者の人数 | 町の住所地特例者台帳（住まいの側では誤記が生じやすい） |
| 令和9〜11年度の利用者数の見込み | **町の推計。** 伺うのは供給の上限と継続の意向だけです |
| 加算の算定の有無／退院・退所加算等の算定状況 | 国保連の給付実績。**算定していない理由だけ**を伺います |
| 在宅の高齢者の意向・困りごと | 本年実施した3調査（重ねて伺いません） |

ほか4件は管理表の 07シートに置いています。

   載せ、1事業所のみの種類は町全体に合算します**
4. 人数が少なく個人・事業所が推測されるおそれがある欄は、**幅（「1〜4人」等）で
   ご記入いただいても結構です**
5. 収支の別・人材紹介の費用・加算を算定できない理由は、**件数又は幅のみ**を
   お示しし、事業所別には載せません

> ⚠ ［　］の4か所（文書番号・ご提出の期限・ご提出先／お問い合わせ先・
> 委託先の名称と保管の期間・廃棄の方法）は町にご記入いただく必要があります。

## 9. 回収できなかった場合の扱いを、発送の前に決めておきます

素案 2-7 は「確認が取れない数値及び特定の事業所が識別され得る数値は、
計画書（案）には掲載しません」と定めています。したがって**回収できなかった
設問を素案でどう書くかを、発送の前に決めておく必要があります。**
管理表の 09シートに当方の案を7件置きました（**確認事項No.173**）。

| 場合 | 当方の案 |
|---|---|
| 一部の事業所から返らなかった | ご回答のあった事業所の分のみで集計し、**回答のあった事業所数と全事業所数を併記**する |
| 1事業所しかない種類で、その1件が返らなかった | 素案は**【町確認】のまま残す**（推測で置かない） |
| 「記録なし」とご回答いただいた | **0件とは区別**し、「記録を取っていない事業所が○件」と書く |
| 幅でご回答いただいた | **幅のまま載せる**（中央値に丸めない） |
| 町外の事業所から返らなかった | 素案 9-1 に「**町外施設の受入余地を把握できていない**」旨を明記する |
