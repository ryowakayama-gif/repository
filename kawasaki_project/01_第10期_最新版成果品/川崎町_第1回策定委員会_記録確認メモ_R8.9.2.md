## 2．★要訂正（第2回資料・議事録で正す必要がある事項）

### 訂正1　「施設入居申し込み済みの割合が約半数」

| | |
|---|---|
| 説明された内容 | 施設入居**申し込み済み**の割合が約半数 |
| 正しい値 | **すでに申込済み 33.8％**／検討している 14.4％／**両者の計が48.2％**（n=139） |

「約半数」は**検討中を含めた48.2％**であり、申込済みは3人に1人です。
申込済みの規模は施設・居住系サービスの見込量に直結するため、
過大に伝わると整備量の議論が歪みます。**議事録及び第2回資料で明確に区別してください。**

### 訂正2　「単身世帯の施設申し込み率 約86.1％」

| | |
|---|---|
| 説明された内容 | 単身世帯の**申し込み率** 約86.1％／その他世帯 約32.9％ |
| 正しい値 | 単身世帯：**申込済み69.4％**、検討中を含めると86.1％（n=36）<br>その他世帯：検討中を含めて32.9％ |

86.1％と32.9％はいずれも「検討または申込済み」の値であり、両者の比較としては整合しています。
ただし訂正1と同じ理由で、**「申込済み」と「検討＋申込済み」を混在させない表記に統一**します。

### 訂正3　保険料の県内順位「高い方から9番目」

| | |
|---|---|
| 説明された内容 | 県内で高い方から**9番目** |
| 当社分析 | 川崎町6,500円より高い団体が**9市町村**（登米市・大郷町・名取市・七ヶ浜町・大衡村・色麻町・加美町・大和町・岩沼市）。<br>川崎町は村田町・丸森町と同額で**第10〜12位タイ** |

「川崎町より高い団体が9市町村」と「川崎町が9番目」は1つずれます。
**「県内35市町村中 第10〜12位（同額3町）」**が正確な表現です。
なお、県内最高6,950円（登米市）・最低4,000円（大河原町）は当社分析と一致しています。

### 訂正4（表記の統一）　6,508円と6,500円の混在

同一の会議で「月額6,508円（年額78,000円）」と「月額6,500円」の両方が使われました。
確認事項No.24のとおり、**算定表上の基準額が月額6,508円、第5段階の保険料月額が6,500円
（年額78,000円÷12）**です。「第8期から+120円」は6,500円ベースの比較です。
第2回資料以降は、初出時に注記を付して統一します。

## 3．★計画の前提を変える新情報（委員発言）

当日、**介護人材と事業所の運営が最大の論点**となりました。これは当社が把握していなかった
一次情報であり、第10期計画の骨格に影響します。

### 3-1　供給側の縮小が既に起きている

| 委員発言の内容 | 計画への含意 |
|---|---|
| 職員退職により**前年度に1ユニット分の人員を削減** | 供給量が既に減少している |
| 現在**利用者87名に対し職員80名** | ― |
| **今後7月に職員数が50名になる見込み**で、現在の施設運営が困難になる可能性 | 職員が▲37.5％となれば、人員配置基準上、受入定員の縮小が避けられない |
| 外国人職員2名の受け入れを予定するが、それだけでは解決しない | ― |
| 町外からの人材紹介に**1件あたり約100万円**の紹介料。運転資金を圧迫 | 事業所の経営持続性そのものが論点 |
| 配置基準が厳しくなる一方、機能訓練指導員・看護師・ケアマネジャー等の**必須資格専門職の確保が困難** | 定員があっても稼働できない構造 |
| **訪問介護は町内で登録21名に対し実働4名**。広大な地域で移動負担が大きい | 在宅サービスの供給余力が極めて乏しい |
| 入所施設から在宅復帰を希望する利用者に対し、**訪問看護等の在宅サービスの提供頻度・体制が不十分** | 「施設から在宅へ」が供給面で成立しない |

### 3-2　この情報が第1回資料の論点をどう変えるか

第1回資料及び想定問答集では、入所・居住系サービスについて
**「供給をどこまで増やすかという政策選択」**として整理しました。
しかし委員発言を踏まえると、**現状維持すら危ういというのが実態**です。論点が変わります。

| 第1回時点の整理 | 委員発言を踏まえた整理 |
|---|---|
| 施設を増やせば保険料が上がる。増やすか否かが政策選択 | 増やす以前に、**現在の供給量を維持できるかが先の問題** |
| 在宅サービスの利用勧奨で施設需要を抑える | 訪問介護の実働4名、訪問看護の体制不足により、**在宅で受け皿にならない可能性** |
| 家族介護者のいない世帯を在宅で支える | 家族介護もサービスもない世帯50件（36.2％）に、**供給できるサービスが存在しない** |

### 3-3　第9期の給付費が平坦だった理由の再解釈

標準給付費は令和6年度1,093,253千円 → 令和7年度見込1,085,203千円と**▲0.7％**で推移しました。
これまで介護予防の成果か供給制約かを判別できていませんでしたが、
**委員発言は供給制約であることを強く示唆します。**

- 給付費が伸びない＝保険料の上昇圧力は弱いが、**必要な人がサービスを受けられていない**
- 令和8年9月2日作成の保険料試算（中位＝自然増+1.5％／年）は、**供給制約がない前提**です。
  供給制約が続けば給付費は下振れし、保険料は試算より低くなり得ます
- ただしこれは「保険料が安く済んでよかった」という話ではなく、
  **計画の目的に照らせば失敗**です。第10期では、供給可能量の分析を計画に組み込む必要があります

→ 仕様書6（5）が定める**「見込量確保のための方策」**が、本町では形式的な記述ではなく
　 計画の中核になります。

### 3-4　委員から提起された対応の方向

- 行政・町からの呼びかけによる**地域内での介護人材育成・資格取得の促進**（複数委員）
- **中学・高校段階からの働きかけ**
- 地域密着型サービスの**認知向上と利用促進**

## 4．事務局から示された見解

### 4-1　基本理念は継承の方向

| | |
|---|---|
| 事務局の見解 | 現行理念「誰もが健やかに暮らせるまちづくり」は**町の長期総合計画（10年計画・継続中）の基本理念の一つ**であるため、このまま継承することが適当ではないか（確定決定ではなく意見として提示） |

**当社が把握していなかった情報です。** 素案第1章「計画の位置づけ」に
総合計画との関係を明記する必要があります。総合計画の**名称・計画期間・該当箇所**を
ご教示ください（新規確認事項No.52）。

これにより、確認事項の「確認1（基本理念を継承するか）」は事実上、継承の方向で整理されます。

### 4-2　国の動向

- 委員から、**介護報酬の前倒し見直し**及び**赤字事業者への補助**に関する報道・方針について
  情報提供を求める発言
- 事務局・当社とも、令和9年度概算要求の概計は確認しているが詳細は未把握と回答。
  情報が入り次第、委員会で共有する
- 制度的に大きく変わるものは現時点ではないとの認識（事務局）

→ **保険料試算に直結します。** 当社の試算は令和9年度に+1.5％の報酬改定を織り込んでいますが、
　 前倒し改定があれば基準年（令和8年度）の実績自体が動きます。継続して追跡します。

## 5．★策定スケジュールの変更（重要）

| | 第1回資料（案） | 当日示された内容 |
|---|---|---|
| 第2回 | 令和8年11月頃　ニーズ調査結果の詳細分析・計画骨子（素案） | 11月ごろ　**ニーズ分析報告書及び骨子案** |
| 第3回 | 令和9年1月頃　計画（案）の審議 | 1月　**素案提示・答申内容の確定** |
| 第4回 | 令和9年2月頃　答申書（案）／議会への説明 | **記録上なし** |
| その後 | パブリックコメント（1〜2月）→3月議会 | パブリックコメント→議会審議→計画策定 |

**委員会が3回構成となり、第3回（令和9年1月）で答申内容を確定する段取りです。**
これは当社の作業計画に直接影響します。

| 影響 | 内容 |
|---|---|
| 保険料 | 3パターンの提示・協議・決定を**すべて第3回（1月）で完了**させる必要がある。第4回での再協議の余地がない |
| サービス見込量 | 第3回までに確定させる必要があり、国保連データの入手が**11月中**でなければ間に合わない |
| 資料の納品 | 第2回以降の資料は**事前に委員へ郵送または手渡しで配布**する方針。11月開催なら**10月下旬までの納品**が必要 |
| パブリックコメント | 答申確定（1月）→パブコメ という順序。パブコメの結果を計画に反映する工程を別途確保する必要がある |
