## 1．原因 ― 網掛けの指定が誤っていました

ご指摘の「計画の策定にあたって」「▌ 介護保険制度の経緯と本計画の位置」
「● 本計画は、介護保険法・老人福祉法・認知症基本法の…」「区分／計画名／整合の方針」は、
いずれも**同じ1つの誤り**によるものでした。

OOXML の網掛けタグ `<w:shd>` は3つの属性を持ちます。

| 属性 | 意味 |
|---|---|
| `w:val` | 塗りつぶしのパターン |
| `w:fill` | 背景色 |
| `w:color` | 前景（パターン）の色 |

素案はすべての網掛けを **`w:val="solid"`** で指定していました。
**`solid` は「前景色でべた塗り」という意味**で、`w:color` を省略すると既定の
**auto ＝ 黒**になります。したがって `w:fill` にどの淡色を指定しても、
**必ず黒ベタで描画されます。**

- 章題・▌小見出し・●コールアウト … 淡い水色／淡い緑を指定していたが黒ベタ
- 表の見出し行 … 濃紺を指定し文字を白にしていたため、黒地に白文字

淡色を敷きたい場合の正しい指定は **`w:val="clear"`** です。

---

## 2．対応 ― 大雪地区広域連合の様式に合わせました

ご提示いただいた大雪地区広域連合の素案は、**網掛け・段落罫線・文字色を一切用いず、
文字の大きさと太字だけで階層を表す**体裁でした。印刷（1色刷り）を前提とした
自治体計画書の標準的な作りであり、仕様書8の成果品仕様（1色刷り）とも整合します。
これに合わせて素案全体の体裁を統一しました。

| 要素 | 変更前 | 変更後 |
|---|---|---|
| 章番号（第 N 章） | 24pt・濃色・中央・上下に太罫線 | **15pt・黒・左寄せ・装飾なし** |
| 章題 | 16pt・**黒ベタ**・中央・上下に太罫線 | **15pt・黒・左寄せ・装飾なし** |
| 節見出し（1-1　…） | 13pt・濃色・下罫線 | **12.5pt・黒・装飾なし** |
| ▌小見出し | 11pt・**黒ベタ**・下罫線 | **11pt・黒・装飾なし** |
| ● コールアウト | 9.5pt・**黒ベタ**・上下罫線・緑文字 | **10pt 太字・黒・字下げのみ** |
| ⚠ 注記 | 9.5pt・**黒ベタ**・上下罫線・橙文字 | **9.5pt・黒・字下げのみ** |
| 本文 | 10.5pt・**全文が太字** | **10.5pt・太字を解除** |
| ①②③ の箇条 | 10pt・太字 | **10.5pt・太字を解除** |
| 出典・注 | 8pt・灰色 | **8.5pt・黒・右寄せ** |
| 図の番号 | 9pt・濃色・中央 | **9pt・黒・太字・中央** |
| 表の見出し行 | **黒ベタに白文字** | **網掛けなし・黒文字・太字** |
| 表の本文 | 網掛けあり・全セル太字・色文字 | **網掛けなし・黒文字・太字を解除** |
| 表の罫線 | 単線（変更なし） | 単線（変更なし） |

**フォントは両文書とも游ゴシックで一致しているため、変更していません。**
本文の既定サイズも両文書とも10.5ptで一致しています。

### 全文が太字だった件

網掛けとは別に、**本文・箇条書き・表のセルを含む文書のほぼ全体に太字が指定されていました。**
黒ベタと重なって紙面が非常に重くなっていたため、
見出し・コールアウト・図番号・表の見出し行を除いて太字を解除しました。

## 5．元の配色に戻したい場合

配色そのものを残したいときは、**`w:val` を `"clear"` に改めるだけで黒ベタは解消します。**
その版が必要な場合は `restyle_soan_v113.py` の `STRIP_SHADING` を `False` にして
実行してください。網掛け・罫線・文字色を保ったまま、黒ベタだけが直ります。

また、表の見出し行に薄い網掛け（例：D9D9D9）を敷くほうが読みやすいというご判断であれば、
`restyle_tables()` に1行加えるだけで対応できます。
今回は大雪地区広域連合の様式に合わせ、網掛けなしとしています。
