## 3. タイポグラフィ

- 書体を **BIZ UDゴシック**（BIZ UDPGothic → BIZ UDGothic → Yu Gothic の順）に変更。
- 文字サイズを一律に引き上げ（12.5→18.5px、13→19px、13.5→19.5px、14→20px、16→22px、23→30px、11.5→17px）。
  1240px幅をA4本文幅160mmに縮小したとき、**本文が約8pt**になります（従来は約4.6pt）。
- 拡大により枠からはみ出す箇所は、Chromium で全 `<text>` の実測を行い（`fit.js`・`check.js`）、
  文言短縮・座標調整・レイアウト組み替えで解消しました。残る3〜7px程度の接触はセル余白の範囲内です。
- 色だけに依存しない表示：01に塗り／白抜き／ひし形の記号と凡例を追加。06は【標準】【希望者】の文字で区分。

## 4. 今回対応していない事項

以下は**未対応**です。実施する場合は別途ご指示ください。

1. **T3・T5・T8の資料編への移動**：ファイルは分離済み（T接頭辞）ですが、提案書本体と資料編のどちらに綴じるかは
   ページ構成の判断が必要なため据え置きました。
2. **表の2枚分割**：T3（9行）・T5（8行）は現状1枚に収まっており、文字も8pt相当を確保できたため分割していません。
3. **追加が必要とされた6点の図表**（現状ダッシュボード／補正前後比較／仕様書対応・役割分担表／標本設計・精度表／
   国・道・町の整合表／クリティカルパス）。このうち**補正前後比較は提案書本体の図4として既に作成済み**です。
   残り5点のうち、現状ダッシュボードは要介護認定率・介護費・保険料のデータを当方で保有しておらず、
   作成にはご提供が必要です。
4. **数値の検証**：02の手帳種別回収率（身体42.3%／療育26.8%／精神52.6%／自立支援医療69.6%）、
   03のKPI前回値（38.4%／47.8%／22.2%／21.4%）、T5の各数値は前回報告書の原本を当方で保有しておらず、
   **検算できていません**。提出前に原本との突合をお願いします。
5. **就労選択支援の開始時期**：T3は「R7.10開始の新事業」、影響欄は「R9.4〜アセスメント原則化」としています。
   社内レビューメモ13章でも開始時期の記載齟齬が未確認事項として残っており、契約後の確認事項です。

## 5. 再生成の手順

```bash
cd ashoro_proposal/figures_svg
python3 fix_svg.py          # src/ → build/（内容修正＋タイポグラフィ）
node shotall.js build preview   # 確認用PNGの書き出し（Chromium）
node fit.js build           # 枠内に収まっているかの実測チェック
node check.js build         # 図の外形からのはみ出しチェック
```
