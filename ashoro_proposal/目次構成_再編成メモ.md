# 足寄町企画提案書　目次構成の再編成

対象：`src/足寄町企画提案書_原本.docx`（19ページ・全11章）
成果物：`output/足寄町企画提案書_目次再構成版.docx`（同19ページ相当・全9章）

## 1. 再編成の方針

ご指示は「はじめに ⇒ 国の指針 ⇒ 前回計画の課題・評価 ⇒ アンケートの設計手法 ⇒ 委員会」の順に組み替え、
**評価とアンケートの設計にウェイトを置く**というものでした。これを次の3点で実装しています。

1. **順序**：1章はじめに → 2章国の指針 → 3章評価 → 4章アンケート設計 → 5章委員会 を、章間に何も挟まず一直線に並べた。
2. **統合**：評価に関する記述が旧2章（現行計画の評価）・旧3章（基礎データ）・旧5章（第8期基本指針）・旧6章（横断テーマ）の
   4か所に分散していたものを、性格に応じて2章（国の指針）・3章（評価）・5章（委員会）に振り分け、11章→9章に整理した。
3. **ウェイト**：3章（評価）と4章（アンケート設計）が本文の1位・2位の分量を占める構成にし、
   目次でもこの2章だけ小見出しまで展開して、重心が一目で分かるようにした。実測値は下記のとおり。

### ウェイトの実測値（同一条件でレンダリングして比較）

| | 原本 | 新版 |
|---|---|---|
| 評価にあたる部分 | 旧2章 約1.2ページ ＋ 旧3章 基礎データ 1.0ページ ＝ **約2.2ページ**（2章に分散） | 3章 **3.0ページ**（単一章） |
| アンケート設計 | 旧4章 **6.0ページ** | 4章 **5.0ページ**（課題領域表を3章末へ移したため1ページ分減） |
| 2領域の合計 | 約8.2ページ／本文17ページ（48%） | 8.0ページ／本文17ページ（47%） |

**正確に申し上げると、2領域の合計ページ数はほぼ変わっていません。**
総ページ数を19ページ前後に保つ制約のもとでは、構成の組み替えだけで両方を増やすことはできないためです。
今回実現したウェイトは、分量の純増ではなく次の4点です。

- **集約**：評価が旧2章（1.2ページ）と旧3章（1.0ページ）に割れて「どちらも薄い」状態だったものを、3.0ページの単一章にした。
- **位置**：国の指針の直後、アンケート設計の直前という、審査委員が最も注意して読む位置に置いた。
- **可視化**：目次24行のうち15行を3章・4章の小見出しが占め、重心が目次段階で伝わるようにした。
- **中身**：評価に「前回アンケート調査の評価」（新規）と「評価から導かれる課題領域」（旧4章から移設）を加え、
  評価が計画の評価だけでなく調査の評価まで含む二本立てになるようにした。

分量そのものを増やしたい場合は「8. さらに厚みを持たせる場合の材料」をご覧ください。

## 5. 構成変更にあわせて直した記載（要確認）

レビューメモ16-2Bで「地域福祉計画＝すべての上位計画」という断定表現を
「社会福祉法第107条に基づき福祉各分野に共通する事項を定める計画」に改める方針が決まっていましたが、
次の2か所に旧表現が残っていたため、今回あわせて修正しています。ご意向と異なる場合は元に戻してください。

- 5章（４）健康づくり計画・自殺対策との整合の冒頭
  「地域福祉計画の上位計画としての性格を踏まえると」→「地域福祉計画が福祉各分野に共通する事項を定める計画であることを踏まえると」
- 3章（７）課題領域表の「社協・関連計画との役割整理」行
  「地域福祉計画の上位計画としての位置づけ」→「地域福祉計画と関連計画の役割・位置づけの整理」

また、4章（６）の新規設問表 S-4 の設計意図欄にあった「S-8」は、提案書のどこにも定義がない
（前回調査票の既存設問番号）ため、読み手がたどれる小節参照に置き換えました（上表の最終行）。

## 6. さらに厚みを持たせる場合の材料（未反映・ご判断ください）

評価章の分量を実質的に増やす材料は、レビューメモに既にあり提案書に未反映のものが2点あります。
いずれも新しい事実の追加にはなりませんが、**書きぶり次第で関係性リスクに転じる内容**（レビューメモ9章A-1）
のため、今回は反映せず判断をお預けしています。

1. **社協事業計画の分析（メモ5-4(1)）**：第2期地域福祉計画の「指標なし・検証不能」という構造が、
   共助の実働を担う社会福祉協議会の令和7年度事業計画にも同じく存在すること。かつ社協自身が
   重点目標に「事業への外部評価の実施」を掲げていること。
   → 3章（４）に1〜2文。「町・社協の双方に共通する課題であり、社協自身が外部評価を志向している」
   という書き方にすれば批判にならず、④地域性・信頼性の証拠にもなります。
2. **空白領域の確認（メモ5-4(6)）**：重層的支援体制整備事業・CSW配置・ひきこもり・自殺対策が
   町・社協の双方の計画に記載がないこと。
   → 3章（６）または（７）に1文。第3期計画の新規論点として位置づけられます。

ご指示いただければ反映します。

## 7. 目次のページ番号について

目次のページ番号は、手打ちの数字ではなく **PAGEREF フィールド**（各章・各小節に埋めたブックマークを参照）にしてあります。
Word で開いたときに自動更新されるため、［記入］欄を埋めてページ送りが変わっても番号がずれません。
念のため、提出前に **Ctrl+A → F9**（全フィールド更新）を一度実行してください。

見た目（ドットリーダー・右揃え・書体）は原本と同じです。

## 8. 再現方法

```bash
cd ashoro_proposal/tools
python3 restructure.py ../../output/足寄町企画提案書_目次再構成版.docx   # 組み替え
python3 calibrate.py                                                     # 目次キャッシュ値の再計算（LibreOffice が必要）
```

- `plan.py` … 新しい章立てとブロックの並び順（本体）
- `newtext.py` … 新規に書き起こした本文
- `restructure.py` … 段落・表を書式ごと移設する処理
- `docxblocks.py` … `word/document.xml` を本文ブロック単位に分解・再結合する処理
- `calibrate.py` … レンダリング結果から目次のページ番号キャッシュを更新する処理

原本の段落・表は XML のブロックをそのまま移動しているため、書式・スタイルは一切変わりません。
