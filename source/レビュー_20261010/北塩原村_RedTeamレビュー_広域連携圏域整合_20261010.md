# 北塩原村 第8期障がい福祉計画・第4期障がい児福祉計画
## 広域連携・圏域整合 Red Team再レビュー
### ― 猪苗代町・磐梯町・湯川村、会津障がい保健福祉圏域、福島県との整合確認 ―

作成日：2026年10月10日  
対象：北塩原村計画素案、会津北部4町村の共同・広域機能、会津障がい保健福祉圏域、福島県の関連計画・施設・人材

---

# 1. 結論

北塩原村の計画素案は、広域連携をかなり意識して作られており、特に次の項目は、村単独で完結させず、猪苗代町・磐梯町・湯川村又は会津圏域で確保する方向が妥当です。

- 会津北部地域生活支援拠点
- 地域生活支援センターいなわしろ
- 地域生活支援拠点コーディネーター
- 強度行動障害支援
- 基幹相談支援センター
- 医療的ケア児等支援
- 医療的ケア児等コーディネーター
- 児童発達支援センター等の4つの中核機能
- 精神障害にも対応した地域包括ケア
- 長期精神科入院者の地域移行
- 会津権利擁護・成年後見センター
- 専門人材育成・研修
- 就労支援

一方、Red Teamの観点では、**「広域で行う」と北塩原村計画に記載するだけでは不十分**です。相手自治体・県・圏域側でも、同じ連携単位、同じ施設・会議体、同じKPIとして認識されているかを確認する必要があります。

計画確定前の最重要確認事項は次の7点です。

1. **会津北部地域生活支援拠点の5機能・コーディネーター・実績KPIを4町村で共通化する。**
2. **基幹相談支援センターは、前回計画の「4町村広域設置目標」に対し、現時点でも設置支援・勉強会段階である可能性が高いため、設置済みとして扱わない。**
3. **医療的ケア児等支援の協議の場を北塩原村素案では4町村共同としているが、磐梯町・湯川村の現行計画では「圏域」としているため、同一の会議体・区域を指すか確認する。**
4. **医療的ケア児等コーディネーターは、地域生活支援センターいなわしろの養成研修修了者と、磐梯町が独自に制度化したコーディネーター配置との役割を整理し、二重計上を避ける。**
5. **児童発達支援センターの4つの中核機能について、最新の県公式一覧上は会津若松市内の児童発達支援センターが圏域資源であるため、実際の接続先を明示する。**
6. **精神障害の地域移行、基盤整備量、専門医療連携は「会津北部4町村」より広い会津障がい保健福祉圏域で整合を取る。**
7. **福島県第8期障がい福祉計画・第4期障がい児福祉計画が公表された後、基盤整備量その他の県依存指標を最終調整する。**

# 2. 広域連携の「単位」を分ける

北塩原村計画では、すべてを単に「圏域」と呼ぶのではなく、少なくとも次の4層に分けるべきです。

| 層 | 構成・範囲 | 主な共同項目 |
|---|---|---|
| 会津北部4町村 | 猪苗代町、磐梯町、湯川村、北塩原村 | 地域生活支援拠点、委託相談支援、拠点コーディネーター、強度行動障害、基幹相談支援センター検討 |
| 会津障がい保健福祉圏域 | 会津若松市、喜多方市、北塩原村、西会津町、磐梯町、猪苗代町、会津坂下町、湯川村、柳津町、三島町、金山町、昭和村、会津美里町 | 精神地域包括ケア、地域移行、障がい児支援基盤、相談支援、人材、就労、専門サービス |
| 会津圏域11市町村 | 会津若松市、北塩原村、磐梯町、猪苗代町、会津坂下町、湯川村、柳津町、三島町、金山町、昭和村、会津美里町 | 会津権利擁護・成年後見センター |
| 福島県全域 | 福島県 | 第8期県計画、基盤整備量、医療的ケア児支援センター、専門人材育成、高次脳機能障害・難病等の専門支援 |

**「会津北部4町村」と「会津障がい保健福祉圏域」は同じではありません。**  
特に医療、精神科地域移行、児童発達支援センター、専門人材については、4町村だけで完結させないことが重要です。

# 3. 会津北部地域生活支援拠点

## 3-1. エビデンス

北塩原村の前計画資料では、令和3年度から猪苗代町・磐梯町・湯川村・北塩原村の4町村で「会津北部地域生活支援拠点」を整備し、地域生活支援センターいなわしろへコーディネーター業務を委託していることが確認できます。

また、社会福祉法人福島県社会福祉事業団の公式ページでも、地域生活支援センターいなわしろが、

- 猪苗代町
- 磐梯町
- 北塩原村
- 湯川村

の2町2村から、委託相談支援事業及び地域生活支援拠点事業（コーディネーター的機能）を受託していることが明示されています。

磐梯町第7期計画でも、地域生活支援拠点を猪苗代町・磐梯町・北塩原村・湯川村による広域設置としています。

### 判定

# 4. 地域生活支援拠点の5機能は4町村でKPIを共通化する

北塩原村素案は、地域生活支援拠点について次の5機能を明示しています。

1. 相談
2. 緊急時の受入れ及び対応
3. 体験の機会及び場
4. 専門的人材の確保及び養成
5. 地域の体制づくり

この方向は妥当です。

一方、北塩原村だけが詳細な実績管理を始めても、猪苗代町・磐梯町・湯川村が別の定義で記録すると、広域KPIとして比較・評価できません。

## 4-1. 4町村で統一すべきKPI

| KPI | 共通定義として決める事項 |
|---|---|
| 相談件数 | 延べ件数／実人数の別、4町村別内訳 |
| 緊急相談件数 | 「緊急」の定義 |
| 緊急受入件数 | 短期入所、GH、日中一時等の範囲 |
| 受入不可件数 | 断った件数と理由 |
| 体験利用件数 | GH体験、短期入所等の範囲 |
| 地域移行実績 | 施設・病院からの移行の定義 |
| 登録者数 | 拠点利用の事前登録者 |
| 研修受講者数 | 4町村職員／事業所職員の別 |
| 強度行動障害対象者 | 共通判定基準 |
| 検証回数 | 4町村共同の正式会議のみか、個別打合せを含むか |

### Red Team

第8期計画開始時点で、**4町村共通の「地域生活支援拠点実績様式」**を作ることを推奨します。

# 7. 医療的ケア児等支援の協議の場

## 7-1. 北塩原村素案

北塩原村素案では、

> 猪苗代町・磐梯町・湯川村と共同で協議の場を設置

としています。

## 7-2. 他自治体計画

磐梯町第7期計画は、

> 医療的ケア児支援のための関係機関の協議の場：1か所（圏域）

としています。

湯川村第7期計画も、

> 圏域において協議の場を1か所設置し、医療的ケア児等コーディネーター1名の配置を検討

としています。

### Red Team判定

方向性は一致していますが、

> **「圏域」＝会津北部4町村**

であることを示す明確な共通エビデンスは、今回確認できませんでした。

したがって、北塩原村計画で「4町村共同で設置」と確定記載する前に、猪苗代町・磐梯町・湯川村へ確認が必要です。

### 安全な暫定表現

> 猪苗代町、磐梯町、湯川村等の関係自治体及び会津圏域の関係機関と協議し、既存の協議体の活用を含め、医療的ケア児等支援のための協議の場を確保します。

4町村間で正式な合意が確認できた段階で、「会津北部4町村共同」に修正するのが安全です。

# 8. 医療的ケア児等コーディネーター

## 8-1. エビデンス

福島県の医療的ケア児等コーディネーター養成研修修了者一覧では、地域生活支援センターいなわしろ所属の研修修了者が確認できます。

また、磐梯町では令和8年4月1日から「医療的ケア児等コーディネーター配置事業実施要綱」を施行し、

- サービス情報提供
- 保健・医療・福祉・子育て・教育等の関係機関調整
- 地域資源の開拓・情報共有
- 協議の場への参画

をコーディネーター業務として明文化しています。

### Red Team論点

北塩原村素案は「コーディネーター1人継続」としていますが、次を区別しなければなりません。

- 北塩原村が配置・委託する1人
- 会津北部4町村の共同コーディネーター
- 地域生活支援センターいなわしろ所属の研修修了者
- 磐梯町独自配置のコーディネーター
- 福島県医療的ケア児支援センター

**研修修了者＝自治体の配置コーディネーター、と自動的にみなしてはいけません。**

## 8-2. 確認事項

1. 北塩原村計画の「1人」は具体的に誰を数えるか
2. 配置主体・委託主体
3. 担当区域
4. 4町村共同配置か、市町村別配置か
5. 医療的ケア児のみか、成人の医療的ケア者も含むか
6. 相談件数・調整数の報告先
7. 18歳移行時の担当継続
8. 災害・停電時支援との接続

### 推奨KPI

「配置1人」だけでなく、

- 支援ケース数
- 個別支援会議回数
- 医療機関との調整数
- 教育・保育との調整数
- 成人移行支援件数
- 災害時個別調整数

を併記することを推奨します。

# 9. 児童発達支援センター・4つの中核機能

## 9-1. 最新の県公式施設一覧

福島県の令和7年4月1日現在の障害児通所支援事業所一覧では、会津圏域の児童発達支援センターとして、

- 児童発達支援センター ゆめみっこ
- 会津通園訓練センター たんぽぽ園

が確認でき、いずれも会津若松市内です。

一方、猪苗代町には児童発達支援・放課後等デイサービス事業所がありますが、県一覧上の「児童発達支援センター」とは別の区分です。

### Red Team判定

北塩原村素案の、

> 「近隣市町村の児童発達支援センターを活用」

という表現は方向としては妥当ですが、具体的なセンターを確認しないまま記載すると、一般の児童発達支援事業所と児童発達支援センターを混同するリスクがあります。

## 9-2. 確認すべき4機能

- 高度な専門性に基づく発達支援・家族支援
- 地域の障害児通所支援事業所へのスーパーバイズ・コンサルテーション
- 地域のインクルージョン推進の中核機能
- 発達支援の入口としての相談機能

### 推奨表現

> 本村には児童発達支援センターがないため、会津障がい保健福祉圏域に設置されている児童発達支援センター等との連携により、専門的な発達支援・家族支援、地域事業所への助言、インクルージョン推進及び相談機能の確保を図ります。

### 追加確認

会津若松市内の児童発達支援センター等に対し、

- 北塩原村児への相談対応
- 村内園・学校への助言
- 村内支援者へのスーパーバイズ
- 保育所等訪問
- 医療的ケア・重症心身障がい児への対応

が圏域機能として実際に利用できるか確認します。

# 10. インクルージョン推進の協議の場

北塩原村素案では、会津北部地域生活支援拠点や既存の自立支援協議会を活用し、会津北部圏域で協議の場を設置する方向です。

これは第8期の方向性に適合しています。

一方、R6～R8の猪苗代町・磐梯町・湯川村の現行計画は、現在の第8期基本指針と同じ形の「インクルージョン推進のための協議の場」を必ずしも共通KPIとして持っていません。

### Red Team

**R9～R11の4町村次期計画で、初めて足並みを揃えるべき項目**です。

### 4町村で決める事項

- 新しい会議体を作るか
- 既存の自立支援協議会を使うか
- 医療的ケア児協議の場と兼ねるか
- 教育委員会、保育所、幼稚園、学校が参加するか
- 児童発達支援センターを構成員とするか
- 年間開催回数
- 協議結果を各自治体計画へ反映する方法

# 11. 強度行動障害支援

## 11-1. エビデンス

磐梯町計画では、会津北部地域生活支援拠点を4町村広域設置としたうえで、強度行動障害者の支援体制について検討するとしています。

湯川村計画でも、会津北部圏域の地域生活支援拠点とあわせ、強度行動障害のニーズ把握・支援体制整備を課題としています。

福島県会津圏域計画では、重点検討事項ワーキンググループやサービス調整会議を活用した支援体制の検討が示されています。

### 判定

**北塩原村素案の「4町村又は圏域で対象者数・支援ニーズを把握」は妥当です。**

## 11-2. 共通化すべき事項

- 強度行動障害の判定基準
- 現在人数
- 現サービス利用
- 未利用・未充足者
- 受入可能事業所
- 短期入所
- GH
- 生活介護
- 行動援護
- 支援者養成研修修了者
- 緊急時受入可否

# 12. 精神障害にも対応した地域包括ケア

## 12-1. エビデンス

福島県会津圏域計画では、会津障がい保健福祉圏域連絡会の「精神保健福祉に関するワーキンググループ」等を通じ、保健・医療・福祉の連携を強化し、高齢者福祉との連携も検討するとしています。

令和7年度の会津地域保健医療福祉協議会資料でも、精神障がい者地域移行・地域定着促進事業が会津圏域の関係機関により進められています。

### Red Team判定

精神科長期入院者の地域移行は、**会津北部4町村だけで完結させる項目ではありません。**

北塩原村の退院見込み1人についても、

- 精神科医療機関
- 会津保健福祉事務所

# 25. 最終Red Team評価

## A：現行方向を維持してよいもの

- 会津北部地域生活支援拠点
- 地域生活支援センターいなわしろとの連携
- 拠点コーディネーター
- 4町村による運用検証
- 強度行動障害の広域把握
- 精神障害にも対応した地域包括ケアの会津圏域連携
- 会津権利擁護・成年後見センター
- 県第8期計画の数値を待って基盤整備量を確定する考え方

## B：表現を修正・精緻化するもの

- 児童発達支援センターは「近隣市町村」より「会津障がい保健福祉圏域に設置されている児童発達支援センター等」とする
- 医療連携は4町村と会津医療圏・会津障がい保健福祉圏域を分ける
- コーディネーターは「配置人数」だけでなく担当区域と実績を示す
- 圏域利用は施設数だけでなく受入余力・送迎・冬季アクセスを確認する

## A：計画確定前に照会必須

- 会津北部基幹相談支援センターの設置状況
- 医療的ケア児等協議の場の正式な連携単位
- 医療的ケア児等コーディネーターの4町村内の役割分担
- インクルージョン協議の場の4町村共同化
- 会津圏域の医療型短期入所最新状況
- 福島県第8期計画の基盤整備量
- R9～R11の4町村次期計画間のKPI整合

# 26. 最終結論

北塩原村の第8期計画は、「村内にない施設をすべて新設する計画」ではなく、

> **会津北部4町村で持つ機能  
> ＋ 会津障がい保健福祉圏域で持つ専門機能  
> ＋ 福島県が持つ高度・専門機能**

を組み合わせる計画として設計するのが適切です。

そのためには、単に「圏域と連携」と記載するのではなく、

- どの圏域か
- どの施設・機関を使うのか
- 誰がコーディネートするのか
- 何人・何件を受け止められるのか
- 4町村で同じKPIを使うのか
- 受入不可の場合をどう記録するのか
- 県計画の数値をどこで反映するのか

まで具体化する必要があります。

最優先で、

> **会津北部4町村共同確認票を作成し、地域生活支援拠点・基幹相談・医療的ケア・インクルージョン・強度行動障害の5項目を、猪苗代町・磐梯町・湯川村と同じ表で確認する**

ことを推奨します。

これにより、北塩原村計画内では整っていても、相手自治体の計画と施設数、コーディネーター数、目標年度、会議体、KPIが食い違うリスクを大幅に減らせます。
