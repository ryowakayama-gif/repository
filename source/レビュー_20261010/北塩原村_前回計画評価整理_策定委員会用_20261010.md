# 3. 見込量の評価方法

見込量については、

> **計画値と実績が一致したか**

だけで評価しないことが重要です。

評価は、

- 予測精度
- ニーズ充足
- 潜在需要
- 供給制約
- 制度認知
- 他制度による代替
- 圏域利用

を分けて確認します。

## 3-1. 見込量評価の基本区分

| 評価区分 | 内容 |
|---|---|
| 概ね妥当 | 計画値と実績が概ね一致し、ニーズも充足 |
| 見込み超過 | 実績が計画値を上回った |
| 見込み未達 | 実績が計画値を下回った |
| 潜在需要あり | 実績は少ない・0だがニーズが存在 |
| 供給制約あり | 必要量はあるが事業所・人材・送迎等で利用できない |
| 把握不足 | ニーズの有無自体を確認できていない |

# 7. 施策評価の方法

施策評価は、

> 実施した／実施していない

の二択ではなく、次の6区分で整理します。

| 区分 | 意味 |
|---|---|
| ①障がい福祉で実施 | 障害福祉サービス・地域生活支援事業等として実施 |
| ②他制度で対応 | 介護保険、高齢者福祉、一般施策、村単独事業等で対応 |
| ③圏域で対応 | 村内に事業所がなく、圏域資源により対応 |
| ④ニーズなし | 個別確認により対象者がいないことを確認 |
| ⑤ニーズあり・供給不足 | 必要な人がいるが受入事業所・量が不足 |
| ⑥把握不足 | ニーズの有無自体を確認できていない |

# 10. KPI評価での注意点

KPIについては、

> **KPIを達成した＝政策課題が解決した**

とは評価しないことが重要です。

例えば、地域生活支援拠点等については、

- 1カ所設置
- コーディネーター1人配置
- 年1回検証

は達成しています。

しかし第8期では、

- 緊急相談件数
- 緊急受入件数
- 体験利用件数
- 地域移行支援件数
- 登録者数
- 関係機関調整数

等、**実際に機能しているかを示すKPI**へ移行する必要があります。

# 17. 最終整理

次回策定委員会での前回計画評価は、

> **KPIの達成確認**

だけではなく、

> **見込量は実態を捉えていたか**  
> **施策は実際に機能したか**  
> **ニーズがあっても使えなかったサービスはなかったか**  
> **未達の理由は何か**  
> **その結果を第8期にどう反映するか**

まで示すことが重要です。

これにより、前回計画の評価が単なる「成績表」ではなく、

> **第8期計画の見込量・施策・KPIを設定する根拠**

として機能します。
