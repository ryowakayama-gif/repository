# 北塩原村 広域連携・圏域整合 参照エビデンスパック

作成日：2026-10-10

このZIPは、北塩原村「第8期障がい福祉計画・第4期障がい児福祉計画」の広域連携・圏域整合Red Teamレビューで使用した参照元を、後から追跡できるよう整理したものです。

## 収録内容

- `00_エビデンス一覧.md`：全エビデンスの一覧、URL、確認事項、留意点
- `01_エビデンス一覧.csv`：一覧の表形式データ
- `02_根拠対応表.md`：計画論点と参照エビデンスの対応関係
- `evidence_notes/`：各参照元ごとの確認メモ
- `北塩原村_広域連携_圏域整合_RedTeamレビュー_エビデンス付.md`：レビュー本体

## 重要な留意事項

本環境では外部Webサイト上のPDF・HTML原本をそのまま一括再配布用ファイルとして取得できないため、このZIPには、**公式URL・資料名・公表主体・確認日・確認した根拠事項を整理したエビデンスメモ**を収録しています。

したがって、本ZIPは「参照元を追跡・再確認するための証跡パック」です。自治体への正式提出時に原本PDF自体も添付する場合は、各公式URLから原本を取得して同じE番号で格納すると管理しやすくなります。

特に猪苗代町の現行計画本文の個別KPIは、今回の取得では原典本文まで確認できなかったため、推測せず「要原典確認」としています。
