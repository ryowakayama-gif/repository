# 3. 見込量算定・推移分析の検証

## 3-1. 主なサービスの比較

| サービス | 参考値（現状維持） | 正本R9 | 正本R11 | 主要な論点 |
|---|---:|---:|---:|---|
| 共同生活援助（人/月） | **12** | 8 | 9 | **R9は参考値を4人下回る。退去・転出等の根拠が必要** |
| 居宅介護（人/月） | 2 | 4 | 5 | 2～3人の増加を見込む根拠が必要 |
| 生活介護（人/月） | 5 | 6 | 7 | 1～2人の増加を見込む根拠が必要 |
| 自立訓練・生活訓練（人日/月） | 約21.5（表丸め22） | 12 | 12 | 利用者数1人で利用頻度が減る根拠が必要 |
| 就労継続支援B型（人/月） | 11.3 | 11 | 12 | 大きな矛盾は限定的。R10以降の増加を確認 |
| 短期入所・福祉型（人日/月） | 1.7 | 5 | 5 | 実績から増える前提・頻度の根拠が必要 |
| 計画相談支援（人/月） | **6.8** | **23** | **24** | **参考値と正本の計数定義が異なり直接比較不可** |
| 児童発達支援（人日/月） | 3 | 8 | 8 | 利用頻度増の根拠が必要 |
| 放課後等デイサービス（人/月） | 2.7 | 2 | 2 | 利用児童の学齢移行・卒業等の確認が必要 |
| 保育所等訪問支援（人/月） | 0.8 | 0 | 1 | R9だけ0人となる理由が必要 |

**重要**：計画相談支援の参考値6.8人/月と正本23～24人は、月間利用者数と年度内実人数の違いがあるため、差の数値・比率を出して需要不足と評価してはならない。先に単位・計数定義を統一する。

参考値22行は、ZIP所収の説明メモ上、**正本との差異17行（このうち単位の相違2行を含む）・概ね整合5行**と整理されている。差異はそのまま算定誤りを意味せず、増減要因の立証が必要な項目を示すもの。

## 3-2. 算定方法の妥当性

第3版の参考値は、以下の考え方で作成されている。

```text
翌年度の必要人数 ＝ 起点人数 ＋ 確認できた増加 － 確認できた減少
必要利用量 ＝ 必要人数 × 1人当たり利用量
```

| 論点 | 評価 | 改善指示 |
|---|---|---|
| 起点：令和8年度直近3か月平均 | 比較基準として合理的 | サービスごとの最終収録月・対象月・利用者数を明示 |
| 起点：台帳にないA型を令和7年度実績で代用 | 暫定的には可 | 「需要0」と認定せず最新の支給決定・事業所情報を照会 |
| 起点：放課後等デイに令和7年度の直近3か月を使用 | データ制約上の暫定値 | 令和8年度の利用予定・就学/卒業情報で修正 |
| 増減：すべて0人 | **現状維持ケースとしてのみ妥当** | 卒業、18/22/65歳到達、転入出、退院、地域移行を個別積上げ |
| 利用量：令和8年度の総日数÷延べ利用月数 | 算式として成立 | 人数起点と利用量の対象期間を原則合わせる |
| 居宅介護時間：令和7年度の平均を利用 | 暫定的には可 | 令和8年度の時間実績を取得できるか確認 |
| 人数の整数化 | 表示処理として明示されている | 計算内部の小数値と表示丸め後の値を別列で保存 |
| 乖離基準：人数0.5人以上、量10％以上 | 一次抽出には使用可能 | 少数利用サービスは人数差1人以上を必ず個別確認 |

### 対象期間の相違

ZIPに記載された台帳収録期間は、共同生活援助3～8月、生活介護3～9月、B型3～6月、短期入所3～6月、障がい児相談支援3～7月など、サービスごとに異なる。

- 最終実績月が異なるものを一律「直近3か月」と表示するだけでは、推計の鮮度を比較できない。
- 3月～翌2月という区切りが、**サービス提供月・請求月・事業年度のいずれに対応するかは未確定**（M-136）。
- 同一の基準月が確保できないときは、サービス別に使用期間・欠測月・代替根拠を表記する。

### 現状維持ケースと正式推計の区別

今回の参考値は確認できた増減を一律0と置いており、令和9～11年度が同数になる。これは**感度分析の基準ケース**として有用だが、将来需要を裏付ける正式な予測値ではない。

正式見込量を確定する前に、サービスごとに以下を一覧化する。

1. 当年度末の利用者・支援必要者数（個人情報を公表資料に出さない形で内部管理）
2. 新規支給決定・卒業・年齢到達・転出入・退院・退所などの年度別増減要因
3. 1人当たり利用頻度（日/月、時間/月、回/月等）
4. 近隣市町村を含む実際に利用可能な供給量と未充足量
5. 令和9・10・11年度別の見込量と採用理由

# 4. 施策とKPIの再評価

## 4-1. 改善状況

KPI定義票は**32指標→38指標**に増加し、内訳は**成果16・活動16・体制6**となった。K-25～K-30の追加により、長期入院者の退院支援、就労継続、相談支援の月平均利用者数、地域生活選択肢の提示、見込量との乖離、必要量の確保率を追跡する構成ができた。

ただし「提案指標」の基準値・目標値は未確定のため、38指標すべてが正式採用・確定した状態ではない。

## 4-2. KPIごとのRed Team指摘

| KPI | 懸念点 | 推奨する修正・運用 |
|---|---|---|
| K-08 就労定着支援利用者数 | 利用量であり定着成果そのものではない | K-26の6か月・12か月就労継続率を併用 |
| K-13 健診から支援につながった割合 | 接続先が限定的 | 保健・教育・相談・福祉など必要な支援への接続を定義 |
| K-19 モニタリング実施率 | 分母となる予定件数の確定方法が不足 | 予定・実施・延期・中止の定義を明文化 |
| K-21 情報公表率 | 対象事業所0の場合に分母0 | 0件の扱いを「該当なし」と規定 |
| K-24 個別避難計画作成率 | 全対象者と優先対象者で分母が混在する可能性 | 対象別に分母・目標を分ける |
| K-29 見込量乖離の理由未記録件数 | 乖離判定の閾値未確定 | 人数差1人以上、利用量差20%以上などを**検討案**として村が確定 |
| K-30 必要量確保率 | 受入余力、移動・送迎、障害特性が未反映 | 地理的・実質的に利用できる量を分子とする |
| K-32 特定健診受診率 | 国保被保険者全体の指標であり障がい者施策の直接成果でない | 関連する地域保健指標として位置づけ |
| K-33 サービス満足度 | 集計上39.4％と61.9％が異なる分母で算出され得る | 対象者、無回答、非利用者の扱いを固定し再計算 |

※閾値や目標値は**レビュー上の提案**であり、国が北塩原村に指定した数値ではない。

## 4-3. KPI定義票の確定に必要な項目

各KPIについて、少なくとも以下を確定すること。

| 区分 | 必須確認事項 |
|---|---|
| 指標の目的 | どの施策・国の成果目標を評価するか |
| 指標種別 | 成果／活動／体制 |
| 算定式 | 分子・分母・計算単位、0件の場合の取扱い |
| 基準値・目標値 | 基準年度、R9・R10・R11の年度別目標 |
| データ | 取得元・取得時期・保有部署・データ品質 |
| 管理責任 | 担当部署、評価時期、改善判断の主体 |
| 公表 | 小人数に係る個人特定リスク、公表区分 |
| 改善方法 | 未達時に実施する協議・確保策・計画見直し |

**重要な運用原則**：「施策→指標→基準値→年度別目標→実績取得→評価→改善方策」を切れ目なく接続する。人口規模・利用者規模が小さい分野では、達成率だけでなく未充足件数・改善状況・実人数を併用する。

# 6. 新たに把握した作業管理上の論点

### 6-1. 生成器の再現性

ZIP所収の `03_生成器` には5本のPythonスクリプトがある一方、参照先の共通モジュール `kitashiobara_common` と `build_kitashiobara_shihyou_sokutei` は同梱されていない。**第3版ZIP単体では生成器の完全な独立再実行ができない**。生成器が示す自己点検の結果と、第三者が再現できることは分けて管理する。

### 6-2. 原票の検証範囲

本ZIPは機微情報なし版のため、元台帳の個人別記録からの抽出漏れ・支給決定と利用実績の突合は検証範囲外。これを「数値の正確性が確認された」とは評価しない。内部の権限者による原票検証と結果の記録が必要。

### 6-3. 正本・参考値・照会事項の版管理

参考値を作った段階では正本の正式見込量は修正されていない。村の回答があった際、次の3点を一括更新すること。

1. 正本の第5章見込量・注記
2. 再算定根拠表と照会対応履歴（M-139、M-136、M-141等）
3. KPI定義票の基準値・年度別目標値、および給付費・村負担の推計

# 8. 最終判断と推奨する作業順序

**最終判断：計画作成を継続することは妥当。ただし、正式見込量の未修正を残して最終案として確定することは推奨しない。**

1. **村からの回答・最新台帳を確定**：M-136、M-139、M-141を優先処理。
2. **22行の見込量を正式に再算定**：現状維持ケースと、確認できた増減を織り込んだ採用ケースを並記。
3. **正本に反映**：数値表、前後の説明、需給確保方策を同時に更新。
4. **正式採用するKPIを決定**：提案指標の採否、測定定義、R9～11目標値、責任部署・取得頻度を確定。
5. **財政面を接続**：確定見込量から給付費・村負担を算定。
6. **最終突合**：正本・KPI票・照会回答・算定表で数値・定義・時点・単位を相互照合。
