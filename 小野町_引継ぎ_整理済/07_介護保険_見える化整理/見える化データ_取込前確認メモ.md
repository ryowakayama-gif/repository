# 小野町 第10期介護保険事業計画 見える化データ取込前確認メモ

作成日: 2026年7月22日

## 1. 確認結果

第10期介護保険事業計画の準備として、地域包括ケア「見える化」システムから出力されたExcelデータの整理を開始した。

ただし、現時点で `C:\Users\ryowa\Downloads` 内に実在確認できたファイルは一部に限られ、利用可能な一部ファイルでは自治体名が「小野町」ではなく「金ヶ崎町」として確認された。

このため、委員会資料用の数値整理、前回計画評価、今期保険料算定に接続する基礎データとしては、現時点のファイルを確定利用しない。

## 2. 現時点での主な不整合

- 添付一覧にあるD17、D31、D49、δ1、δ2系の多くが、現在のDownloads内では未検出。
- B1等の一部ファイルは実在するが、内容確認上、小野町ではない自治体データが含まれている可能性が高い。
- この状態で集計すると、認定率、受給率、給付月額、自給率等の評価が別自治体ベースとなり、施策判断・保険料算定準備に重大な誤差が生じる。

## 3. 再取込時に必要なファイル確認

再整理の前に、以下を確認する。

1. 各Excelファイルの対象自治体が「小野町」であること。
2. 時系列データは、少なくとも第9期計画評価に使える直近年度まで入っていること。
3. 地域別データは、福島県平均・全国平均・比較対象自治体と並べて確認できる形式であること。
4. D49地域差指数、B1被保険者数、B4認定率、D1からD4受給者・受給率、D6給付月額、D17サービス別給付、D31利用日数・回数、δ系自給率データがそろっていること。

## 4. 数値整理の方針

小野町データが確認でき次第、以下の順で整理する。

1. 基礎需要: 第1号被保険者数、要介護認定率、要介護度別構成。
2. サービス利用: 在宅、居住系、施設サービスの受給率・受給者数。
3. 給付構造: 第1号被保険者1人あたり給付月額、受給者1人あたり給付月額、サービス別の増減。
4. 提供体制: 介護サービス自給率、町外利用依存、供給不足が疑われるサービス。
5. 前回計画評価: 第9期の見込量・実績差、課題の残存、施策効果の有無。
6. 今期アンケート接続: 在宅継続、家族介護、移動、認知症、介護予防、サービス不足感等のニーズと数値傾向の突合。
7. 第10期施策妥当性: 重点施策、サービス量見込み、保険料算定に影響する論点を整理。

## 5. 委員会資料での扱い

現時点では「見える化データは取込前確認中」とし、数値を断定しない。

委員会資料では、次の説明が妥当である。

- 第10期計画では、見える化データ、前回計画実績、今期アンケート結果を組み合わせて施策妥当性を確認する。
- 保険料算定に接続するため、認定率・受給率・給付月額・サービス別利用量は、自治体名と年度を確認したうえで確定値として整理する。
- 現時点では、提供ファイルの一部に自治体不一致の疑いがあるため、数値確定前にデータ再確認を行う。
