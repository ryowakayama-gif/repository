### 1-2. 基本理念と施策体系（3基本目標・14施策）

**基本理念：健康で自分らしく暮らせるまち**（第8期から踏襲）

| 基本目標 | 施策 |
|---|---|
| 1　介護予防と生きがいづくりの推進 | ① 健康づくりの推進<br>② 介護予防・日常生活支援総合事業の推進<br>③ 生きがいづくりと社会参加の推進 |
| 2　安全・安心な暮らしの確保 | ① 地域の支え合いの支援<br>② 包括的支援事業・任意事業の推進<br>③ 成年後見制度の利用促進<br>④ 認知症施策の充実<br>⑤ 高齢者虐待防止の推進<br>⑥ 災害・感染症対応等の充実<br>⑦ 多様な生活支援の充実<br>⑧ 介護人材の確保とサービスの質の向上 |
| 3　介護サービスの充実 | ① 自立支援・重度化防止に向けた取り組み<br>② 介護保険サービス等の充実<br>③ 介護サービスの見込みと保険料 |

## 2. 第3期地域福祉計画

### 2-1. 位置づけ

- 計画期間：令和8〜12年度（5年間）
- 基本理念：**ともに助け合い・支え合い、みんなが笑顔で元気に暮らせる 小野町**
- **第5章に「小野町第1期成年後見制度利用促進基本計画」を一体的に策定**（第2期からの最大の変更点）

### 2-2. 施策体系（3基本目標）

| 基本目標 | 推進施策 | 事項 |
|---|---|---|
| 1　みんなが健康でいきいきとしたまちづくり | 1 健康や生活機能の向上 | ① 地域ぐるみの健康づくり活動の向上<br>② **高齢者一人ひとりの生活機能の向上に向けたサービス提供** |
| | 2 ふれあいコミュニティの醸成 | ① **ひとり暮らしの高齢者の孤立解消**<br>② 子ども・子育て家庭の地域交流と見守り |
| | 3 生活課題の解決促進 | ① 暮らしに必要な情報提供の充実<br>② ワンストップ化の実現に向けた相談窓口の機能の充実 |
| 2　自分らしく生活を送ることができるまちづくり | 1 生活の安定と自立を促進する支援 | ① **高齢者世帯への生活自立に向けた支援**<br>② 支援が必要なこども・若者・子育て世帯への支援<br>③ 生活困窮世帯への生活自立に向けた支援 |
| | 2 総合的な支援の提供 | ① 障がいの早期発見・療養・生活支援のマネジメント<br>② **高齢者の介護マネジメント** |
| | 3 地域福祉を支える体制の整備 | ① **住民主体の福祉ネットワークづくり**<br>② 地域による福祉コミュニティの活動展開 |
| 3　安心してずっと暮らせるまちづくり | 1 見守りが必要な人たちの把握 | ① **ひとり暮らし高齢者等の見守り活動**<br>② 子育て世帯への見守り活動<br>③ 子どもたちへの見守り活動 |
| | 2 安全で安心して暮らせる社会の形成 | ① **ひとり暮らし高齢者等の緊急時への対応**<br>② **認知症の高齢者等への見守り活動**<br>③ **災害と感染症等の発生時への対応** |
| | 3 権利擁護の推進 | ① 児童虐待問題への対応<br>② **高齢者虐待問題への対応**<br>③ 障がい者虐待問題への対応<br>④ 家庭内暴力（DV）問題の対応 |

※ 太字は高齢者計画と関係する事項。

## 3. 両計画の重複と役割分担（第10期での整理）

**第9期高齢者計画の基本目標2に置かれた8施策のうち5施策が第3期地域福祉計画と重複する。**

| 第9期高齢者計画の施策 | 地域福祉計画の対応箇所 | 第10期での扱い |
|---|---|---|
| 成年後見制度の利用促進 | 第5章「第1期成年後見制度利用促進基本計画」（一体策定） | **移管**。認知症高齢者の意思決定支援の観点から連携先として記載 |
| 高齢者虐待防止の推進 | 基本目標3 推進施策3 ②高齢者虐待問題への対応 | **連携**。介護サービス事業所における虐待防止（運営基準）に絞る |
| 災害・感染症対応等の充実 | 基本目標3 推進施策2 ③災害と感染症等の発生時への対応 | **連携**。避難行動要支援者名簿・個別避難計画・福祉避難所に絞る |
| 地域の支え合いの支援 | 基本目標2 推進施策3 ①住民主体の福祉ネットワークづくり | **連携**。生活支援体制整備事業（協議体・生活支援コーディネーター）に絞る |
| 多様な生活支援の充実（生活基盤・交通） | 基本目標1 推進施策2 ①、基本目標2 推進施策1 ① | **一部連携**。移送・買物・配食は地域公共交通計画とも接続 |
| 認知症施策の充実（見守り部分） | 基本目標3 推進施策2 ②認知症の高齢者等への見守り活動 | **役割整理**。地域での見守りは地域福祉計画、初期集中支援・推進員・カフェ・医療連携は本計画 |

逆に、地域福祉計画に記載された高齢者関係事項のうち本計画で具体化すべきものは次のとおり。

| 地域福祉計画の記載 | 本計画で具体化する内容 |
|---|---|
| 基本目標1 推進施策1 ② 高齢者一人ひとりの生活機能の向上に向けたサービス提供 | 総合事業、一般介護予防事業、通いの場の立ち上げ、介護予防ケアマネジメント |
| 基本目標2 推進施策2 ② 高齢者の介護マネジメント | 地域包括支援センターの体制強化、居宅介護支援事業所の確保、認定と利用をつなぐ支援 |
| 基本目標3 推進施策2 ① ひとり暮らし高齢者等の緊急時への対応 | 緊急時の受入体制、短期入所、24時間対応の在宅サービス |
| 基本目標3 推進施策2 ② 認知症の高齢者等への見守り活動 | 認知症初期集中支援チーム、認知症地域支援推進員、認知症カフェ、医療・介護連携 |
