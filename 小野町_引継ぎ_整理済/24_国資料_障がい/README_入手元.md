# 国・県の公表資料（障がい計画）

障がい計画の論点漏れの点検（`build_ono_shogai_ronten_more.py`）で、
**原典照合に用いる国・県の公表資料**を収めたもの。

## 入手元

いずれも国（厚生労働省・こども家庭庁・法務省）又は福島県が公表した資料であり、
**特定の市町村の資料ではない。**
当社が別の団体の障がい計画の案件で入手したものを、同じ版のまま収めた。

## 扱い

- 改正案（第157回・第21回）は**告示前の案**である。成果品には「改正案」と明記し、
  告示（令和8年10月予定）の後に最終照合する。
- 当該別の団体の計画・データ・団体名は、本件の成果品に用いない。
