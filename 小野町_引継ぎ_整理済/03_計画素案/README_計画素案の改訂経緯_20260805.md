| 項目 | 値 |

| 紙面の点検 | **欠陥なし**（`check_ono_shimen.py`） |

仕様の計画書は「A4・4色刷り・**80頁程度**・50部」であり、現時点で4頁の余地がある。
ただし未確定152箇所が埋まると増える。
**なお、この76頁はLibreOfficeで組んだ値である。** 下記のとおり、Wordでは
66頁相当になる可能性がある（第9版の62頁に第10版・第11版の増分4頁を加えたもの）。

**頁数に幅がある理由。** 令和8年10月14日に `ono_style` へ Word の見出しスタイルを
当てたところ、LibreOffice の組版で62頁から70頁に増えた。両者の docx の差は
`<w:pStyle>` が76か所増えただけで、**本文・表・図は1文字も変わっていない**。
見出しの大きさ・色・太字・段落の前後の空きは段落と run に直に書いてあり、
**Word はそちらを優先するため Word の紙面は従前（62頁相当）と変わらないと
考えられるが、この環境では確かめられない。**
**町の Word で開いた頁数をいただきたい**（確認事項）。経緯は
`check_ono_shimen.py` の冒頭に記した。

なお**游ゴシックがこの環境になくIPAゴシックに置き換えて組まれる**ため、
いずれにせよ Word の紙面そのものではない。

### 紙面の点検（令和8年10月14日）

図と題の離れ・小さすぎる字を機械で洗い出す。**素案を含む6点すべて欠陥なし。**

## 障がい計画の素案について

障がい計画の素案（第1版）は引継ぎ資料のまま未改訂である。改訂には次が前提となる。

| 前提 | 状態 |
|---|---|
| 障がい者ニーズ調査の実施 | **未実施。**調査票が未確定（児童用に本文欠落） |
| 関係者団体等ヒアリング | **未着手。**委託仕様書5(3)が求める業務 |
| 現行計画（第7期障がい福祉計画・第3期障がい児福祉計画）本文 | 受領済み |
| 令和6〜8年度のサービス別実績・支給決定量 | 未受領 |

高齢者計画の骨子案・素案が先行しているのは、
「高齢者は打ち合わせから見える化で進む方針が確認済み」との町の方針によるものである。
障がい計画は、調査票の確定と発送が工程上の律速となっている。
