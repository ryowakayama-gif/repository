## 読み取った値

- 基金の明細（貸借対照表計上額。「(参考)財産に関する調書記載額」も同じ額）
  - 令和4年度末：90,000,000円
  - 令和5年度末：120,000,000円
- 令和7年度：9月補正前の積立金は1千円。9月補正で29,999千円を増やし、30,000千円になった。当初予算の繰入金（取崩し）は存目の1千円。
- 令和8年度：当初予算の積立金は30,000千円。9月補正で30,000千円を増やし、60,000千円になった。
- 令和8年度の繰入金（取崩し）は存目の1千円。

## 使う先

これらの値は `build_ono_kikin_3an.py` で使う。同スクリプトの自己点検は、この PDF の文字を読んで値を照合する。

## 未公表のもの

- 令和1〜3年度の附属明細書は画像の PDF で、文字を読み取れない。
- 令和6年度の財務書類と、令和7年度の決算書（財産に関する調書）は、サイトに掲載されていない（令和8年10月21日時点）。
