# 介護SCR

令和8年10月20日にユーザーから受領した。

- 介護SCRのデータセット3点（xlsx、各約48万行）：SCRPACKRWEL2021_2023、xSCRPACKRWEL2021_2023、xSCRPACKRMED2021_2023
- 「介護ＳＣＲの概説と利用上の留意点」（令和8年6月）

出典は、厚生労働科学研究費補助金〈長寿科学政策研究〉「2040年を見据えた地域特性に応じた介護サービス提供体制の最適化と科学的介護の推進に関する調査研究」（研究代表者：陣内裕成）である。データには、介護DBと住民基本台帳人口が使われている。

## 収めたもの

- データセットは容量が大きいため、リポジトリには収めていない。
- `小野町_介護SCR抽出_2021_2023.csv`：データセットから抜き出したもの。中身は次のとおり。
  - 全国・福島県・県中圏域・小野町の行
  - 県内59市町村の中央値と、小野町の県内順位
  - 対象は全227区分。利用者住所地ベースと、x付きの両方
- 留意点のPDF（8頁）

## 扱い

- 「x」付きは、事業所所在地ベースの集計とみられる。留意点の資料には定義がないため、提供元に確かめる。
- 県内比較では、他の市町村の名前と値を成果品に出さない。中央値と小野町の順位だけを使う。
