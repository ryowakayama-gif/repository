# 12_進捗管理 の位置づけ

**本フォルダの進捗管理表は、令和8年8月13日をもって `17_業務進捗管理` に移行しました。**

## 移行の理由

`12_進捗管理/小野町_計画策定業務_進捗管理表_20260813.xlsx` は、委託仕様書の業務項目と成果品を一覧化し、進捗の区分（完了／進行中／要対応／データ待ち／未着手）で管理するものでした。全体像の把握には有効でしたが、日々の管理には次の3点が足りませんでした。

1. **高齢者計画と障がい計画が1冊に混在していた。** 両者は別契約・別仕様書・別納期であり、担当も進み方も違います。
2. **作業の段階（フェーズ）が表現されていなかった。** 「どの段階まで来ているか」が読み取れないため、次に何をすべきかが一覧で分かりませんでした。
3. **集計がスクリプトの再実行に依存していた。** 進捗を書き換えても、スクリプトを回さないと集計が更新されません。管理表としては使えません。

## 移行先

| ファイル | 対象 |
|---|---|
| `17_業務進捗管理/小野町_業務進捗管理表_高齢者_YYYYMMDD.xlsx` | 高齢者保健福祉計画・第10期介護保険事業計画 |
| `17_業務進捗管理/小野町_業務進捗管理表_障がい_YYYYMMDD.xlsx` | おのまち障がい者計画・第4期障がい児福祉計画・第8期障がい福祉計画 |

各ブックの構成は次のとおりです。

- `00_ダッシュボード` … 全体進捗、段階別の進捗と律速、現況、警戒事項、直近のマイルストーン
- `01_WBS` … 作業を段階に分けた一覧。**「状態」「進捗率」「重み」を書き換えると、02とダッシュボードが再計算されます**
- `02_段階サマリ` … 段階ごとの件数・状態内訳・加重進捗率（数式で01を参照）
- `03_成果品管理` … 仕様書の成果品ごとの版・状態・納品仕様
- `04_工程表` … 月別の作業
- `05_資料・データ受領` … 依頼から受領までのトラッキング
- `06_会議体・意見聴取` … 協議会、パブリックコメント、ヒアリング、打合せ
- `07_課題・リスク`
- `08_変更管理・打合せ記録` … 仕様書からの変更と、その協議・記録の状態
- `09_仕様書対応表` … 委託仕様書の条項ごとに、条文の原文と対応する作業を並べたもの。対応する作業がない条項は「要確認」と表示され、業務の抜けが分かる
