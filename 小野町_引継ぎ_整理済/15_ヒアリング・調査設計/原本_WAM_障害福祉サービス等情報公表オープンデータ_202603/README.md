# 障害福祉サービス等情報公表システム オープンデータ（令和8年3月版）から県中圏域の分を抜き出したもの

- 入手元：独立行政法人福祉医療機構 WAM NET（https://www.wam.go.jp/content/wamnet/pcpub/top/sfkopendata/）
- 取得日：令和8年10月22日。サービス種別ごとのZIPファイル（29件）を取得した。
- 抜き出した範囲：事業所の住所が、県中障がい保健福祉圏域の12市町村にあるもの。
- 抜き出した列：サービス種別、事業所名、法人名、事業所番号、住所、定員、緯度経度。
- 使い方：成果品に事業所名は載せない。サービス種別ごとの事業所数と定員の集計だけを使う（build_ono_shogai_hearing_daitai.py）。
