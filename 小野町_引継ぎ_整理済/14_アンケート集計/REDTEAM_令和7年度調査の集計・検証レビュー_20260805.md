## 2. 報告書に対する指摘（3件）

### RT-09 【重大】回収数319件と集計n=366が一致しない

調査の概要（2頁）は次のとおり記載している。

| 種類 | 配布数 | 回収数 | 回収率 |
|---|---|---|---|
| 介護予防・日常生活圏域ニーズ調査 | 2,700件 | 1,835件 | 67.9％ |
| 在宅介護実態調査 | 500件 | **319件** | **63.8％** |

ところが、在宅介護実態調査の集計はすべて **n=366** である（65〜82頁）。
319÷500＝63.8％であるから、配布数・回収数・回収率の3者は内部で整合している。
**整合しないのは集計nだけである。**

考えられるのは次の2つ。

| 仮説 | 内容 |
|---|---|
| A | 回収数319が誤記で、正しくは366（366÷500＝73.2％） |
| B | 郵送以外の回収経路（認定調査時の聞き取り等）で47件が追加され、集計は合算 |

**どちらであるかで計画書第2章1(1)の記載が変わる。** 町への確認事項とした。
なお、ニーズ調査は回収数1,835＝集計nで一致しており、問題はない。

### RT-10 調査結果のまとめに転記誤りがある

まとめ（84頁）は主な介護者の勤務形態を
「フルタイムで働いている28.1％、**パートタイムで働いている24.4％**」としている。

本文（80頁・問7、n=185）は次のとおりである。

| 区分 | 割合 |
|---|---|
| フルタイムで働いている | 28.1％ |
| **パートタイムで働いている** | **18.4％** |
| 働いていない | 48.1％ |
| 主な介護者に確認しないと、わからない | 1.1％ |
| 無回答 | 4.3％ |
| 合計 | 100.0％ |

**24.4％は問9「介護休業・介護休暇等の制度の充実」の値であり、混同である。**
本文の18.4％が正しいことは、次の2点から確認できる。

- 合計が100.0％になるのは18.4％の場合のみ（24.4％だと106.0％になる）
- 就労者を対象とする問8〜10のnが86であり、(28.1＋18.4)％×185＝86.0と一致する

町に修正を依頼する。計画書には本文の18.4％を用いる。

### RT-11 通いの場の参加率が見える化システムと整合しない

本調査（35頁）の「介護予防教室・健康教室・ふれあい・共食・ミニサロンなどの
介護予防のための通いの場」への参加頻度は次のとおりである。

| 頻度 | 割合 |
|---|---|
| 週4回以上 | 0.7％ |
| 週2〜3回 | 1.4％ |
| 週1回 | 3.4％ |
| **週1回以上 小計** | **5.5％** |
| 月1〜3回 | 3.8％ |
| 年に数回 | 4.5％ |
| 参加していない | 76.2％ |
| 無回答 | 10.0％ |

**週1回以上が5.5％。** 高齢者人口3,483人に換算すると約190人規模になる。

一方、見える化システムの「週1回以上の通いの場」は
**平成28年度以降0か所・参加率0.0％**である。

これまで当方は、この0か所を根拠に「介護予防が実質的に立ち上がっていない」と
評価してきた。**その評価は保留する必要がある。**
給付費等分析結果報告書には「見える化システムに登録されていない町独自の取組がある
可能性があるため、町の事業実績で実態を確認する」と注記していたが、
**住民側の回答がその可能性を裏付けた形である。**

ただし次の留保がある。

- 調査の選択肢は「介護予防教室・健康教室・ふれあい・共食・ミニサロンなど」と幅広く、
  国が定義する通いの場（住民主体・週1回以上）より範囲が広い可能性がある
- 参加していないが76.2％であり、大多数が参加していないことに変わりはない

**町の事業実績（実施箇所・参加者数・開催回数）を確認し、
実態があれば見える化システムへの登録を依頼する。**

## 3. 先の設計に対する自己点検（懸念2件が解消、1件が的中）

### RT-02（配布経路バイアス）→ **解消**

前回のレビューで「在宅介護実態調査が介護支援専門員経由の配布であれば、
サービス未利用者が構造的に除外される」ことを最大のリスクとして挙げていた。

本調査は**郵送による配布・回収**であり、この問題は生じていない。
実際に未利用者154人（42.1％）が捕捉されている。**Z01の集計は有効である。**

### RT-06（実施時期の季節差）→ **解消**

前回は「前回調査が冬（令和4年12月〜2月）であり、今回の時期が異なると
外出頻度・閉じこもり傾向の比較ができない」と指摘していた。

今回は**令和7年11月〜12月**であり、同じ季節である。比較可能。

### RT-04（設問の存在依存）→ **一部が的中**

優先度Sの2件のうち、

- **Z01「サービスを利用していない理由」は設問が存在した。** 単純集計も掲載されている
- **N02「通いの場に参加していない理由」は設問が存在しない。** 参加していない76.2％の
  内訳を尋ねる設問がない

N02の代替として、介護予防事業への参加条件を尋ねる設問がある
（開催場所・時間63.7％、参加料金が安いこと53.4％、介護予防に効果があること43.1％、
友人・仲間が一緒に参加すること30.0％）。
**「何があれば参加するか」は分かるが「なぜ参加していないか」は分からない。**
追加調査の要否を町と協議する。

このほか、**Z08（ケアマネジャーへの相談）とN11（経済状況）も設問が存在しない。**
Z08が欠けたことにより、居宅介護支援事業所5→3の減少が利用者に与えた影響は
本調査では検証できない。事業所への聞き取りで補う。

## 4. 自らの分析に対する指摘（1件・重要）

### RT-12 「認定と利用のギャップ」の解釈を修正する必要がある

これまで当方は次のように整理してきた。

> 認定率の地域差指数1.24に対し受給率は1.07にとどまる。
> 認定を受けても利用に至っていない層が存在する。
> **利用支援が課題か供給確保が課題かを、ニーズ調査の未利用理由と突合して判別する。**

調査結果は次のとおりであった（n=154・複数回答）。

| 未利用の理由 | 割合 |
|---|---|
| 現状では、サービスを利用するほどの状態ではない | **46.8％** |
| 本人にサービス利用の希望がない | **29.2％** |
| 家族が介護をするため必要ない | **16.9％** |
| 住宅改修、福祉用具貸与・購入のみを利用するため | 5.2％ |
| サービスを受けたいが手続きや利用方法が分からない | 4.5％ |
| 利用料を支払うのが難しい | 3.9％ |
| 以前、利用していたサービスに不満があった | 0.6％ |
| **利用したいサービスが利用できない、身近にない** | **0.6％** |
| その他 | 16.2％ |
| 無回答 | 8.4％ |

**答えは「利用支援」でも「供給確保」でもなかった。**

- 供給制約（身近にない）は**0.6％**。1人相当である
- 費用（3.9％）、手続きの分かりにくさ（4.5％）もいずれも小さい
- 上位3つはすべて需要側の要因であり、合計92.9％を占める

すなわち、**認定を受けているがサービスを必要とする状態に至っていない、
あるいは本人に利用意向がない層が多数である。**
これは「認定率は県内2位だが給付月額は県内中位」という構造と整合する。

**第10期の施策方向を次のように組み替える。**

| 従前の案 | 修正後 |
|---|---|
| 「認定と利用をつなぐ支援」を新設し、未利用層への働きかけと供給確保を行う | ① **認定の運用の確認**（サービス利用の必要が生じる前の申請がどの程度あるか。認定率が県内2位である理由の説明にもなる）<br>② **本人の利用意向への働きかけ**（サービスの理解促進、体験機会の提供）<br>③ **家族介護に依存する16.9％へのレスパイト**（短期入所系の自給率は12.5ポイント低下している）<br>④ 供給確保の優先度は下げる |

**なお、この修正は「供給体制に問題がない」という意味ではない。**
未利用者154人の回答であり、現に利用している203人が
供給に不満を持っていないことを示すものではない。
居宅介護支援事業所5→3、訪問看護1事業所、短期入所系の自給率低下という
供給側の事実は依然として残る。**未利用の理由としては供給制約が主因ではない、
という限定的な結論である。**

## 6. 前回比較にあたっての留意点（2件）

### 回収率が低下している

| 調査 | 前回 | 今回 | 増減 |
|---|---|---|---|
| ニーズ調査 | 77.7％ | 67.9％ | ▲9.8ポイント |
| 在宅介護実態調査 | 68.0％ | 63.8％ | ▲4.2ポイント |

リスク該当率は10項目中8項目で改善しているが、
**回答しなかった層（32.1％）にリスク該当者が多い可能性を否定できない。**
改善傾向として記載しつつ、回収率の変化を注記する。

### 調査対象の定義が変わっている可能性がある

| 調査 | 前回の対象 | 今回の対象 |
|---|---|---|
| ニーズ調査 | 要介護1〜5の認定を受けていない65歳以上 | 65歳以上の高齢者 |

記載上は要介護1〜5を含むように読める。
ただし認定状況別の集計区分は「要支援1」「要支援2」「要介護（要支援）認定は
受けていない」の3区分のみで、**要介護1〜5の区分が存在しない。**

要介護1〜5の認定者が抽出対象に含まれていたかを町に確認する。
含まれていなければ前回と同一母集団として比較できる。
