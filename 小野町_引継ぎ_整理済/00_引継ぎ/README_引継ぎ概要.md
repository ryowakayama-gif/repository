# 小野町 高齢者・障がい計画 引継ぎ概要

作成日: 2026-07-03

## 1. 案件概要

小野町健康福祉課の計画策定案件。高齢者計画と障がい計画が同時期に動くため、共通論点である地域医療、移動、相談、防災、町外サービス利用、財源整理を横断的に扱う必要がある。

- 高齢者: 小野町高齢者保健福祉計画・第10期介護保険事業計画
- 障がい: おのまち障がい者計画・第4期障がい児福祉計画・第8期障がい福祉計画
- 計画期間: 令和9年度から令和11年度まで
- 発注課: 小野町役場 健康福祉課
- 高齢者計画の仕様上の業務期間: 契約締結日から令和9年3月31日まで
- 障がい計画の仕様上の業務期間: 契約締結日から令和9年3月25日まで

## 2. フォルダ構成

- `01_仕様書・公告`: 入札公告、仕様書。業務条件確認用。
- `02_キックオフ・業務計画`: 初回打合せ用資料。業務範囲、工程、必要書類、アンケート、見込量接続を確認する主資料。
- `03_計画素案`: 高齢者・障がいの分冊素案と、統合素案の参照版。
- `04_算定・見込量`: 介護保険料算定、障がいサービス見込量算定の考え方とExcel整理表。
- `05_参考過程`: 初稿・初版などの作業過程。最新版との差分確認用で、原則として直接提出資料にはしない。

## 3. 最初に読む資料

1. `02_キックオフ・業務計画/03_kickoff_workplan_added.docx`
   - 初回協議で確認すべき範囲、工程、役割分担、必要資料がまとまっている。
2. `04_算定・見込量/03_premium_estimation_workbook.xlsx`
   - 高齢者の保険料算定、障がいの見込量算定、必要資料、アンケート接続、Red Team/MECE点検を一体で確認できる。
3. `03_計画素案/03_combined_plan_deepened_reference.docx`
   - 統合的な論点整理が最も厚い。地域医療・関連計画・移動・防災・財源を横断確認する参照元。
4. `03_計画素案/01_elderly_plan_draft_expanded.docx`
   - 高齢者計画の分冊素案。町資料・実績反映前の作業用。
5. `03_計画素案/02_disability_plan_draft_expanded.docx`
   - 障がい計画の分冊素案。町資料・実績反映前の作業用。

## 4. 進捗状況

現時点の資料は「町資料・実績・アンケート結果を受領する前のたたき台」。本文、章立て、論点、算定フロー、必要資料一覧は整理済みだが、数値・成果目標・見込量・保険料・財源内訳は未確定。

特に未確定のもの:

- R6からR8の人口、認定者、給付費、サービス実績
- 介護予防・日常生活圏域ニーズ調査、在宅介護実態調査の結果
- 障がい者ニーズ調査の結果、クロス集計、自由回答整理
- 介護保険基金残高、基金取崩方針、所得段階別被保険者数
- 障がい福祉サービスの支給決定量、実利用量、町内外事業所別利用状況
- 医療的ケア児、特別支援学校・支援学級卒業予定者、18歳移行・65歳移行に関する個別確認
- 協議会、委員会、パブリックコメントの意見反映

## 5. 初回協議で確認すること

- 高齢者計画と障がい計画を分冊で進めるか、共通章を統合して整理するか。
- 町が保有する実績データの基準日、集計単位、提供形式。
- 高齢者の第9期評価、給付費分析、見える化システム値、保険料試算の進め方。
- 認知症施策推進基本計画を高齢者計画にどう包含するか。
- 障がい者ニーズ調査の対象、票種、発送数、回収見込み、クロス集計軸。
- 障がいサービスで実績0又は少人数のサービスを、単純に0見込にしない確認プロセス。
- 町内サービス資源が限られるサービスについて、町外利用・送迎・相談支援体制をどう記載するか。
- 地域公共交通、防災、地域福祉、こども計画、医療連携との接続範囲。
- 委員会・協議会・パブコメの回数、提出様式、庁内確認の期限。

## 6. 算定・見込量の注意点

高齢者計画:

- 見える化システムの標準ロジックを基本にする。
- 重点確認は、人口・認定者推計、サービス見込量、地域支援事業、調整交付金、基金取崩、所得段階別補正被保険者数。
- 基金取崩は第10期の抑制効果だけでなく、第11期の急騰リスクも比較する。
- 施設整備や認定率上昇がある場合は、標準ケース以外のケース試算を置く。

障がい計画:

- 実績推移だけでなく、アンケート補正、18歳移行、65歳移行、供給制約、少人数高支援度サービスの個別積上げを組み合わせる。
- 特に、就労選択支援、放課後等デイ、重度訪問介護、療養介護、地域移行・地域定着、居宅訪問型児童発達支援、医療的ケア児支援、防災は、0人見込の根拠確認が必要。
- 支給決定量と実利用量、町内外事業所別利用、セルフプラン件数を分けて確認する。

## 7. 資料の扱い

- 提出・協議のベースは `02_キックオフ・業務計画`、`03_計画素案`、`04_算定・見込量`。
- `05_参考過程` は作成経緯確認用。最新版と混ぜて使用しない。
- Word資料の多くは「案」「たたき台」であり、町資料受領後に差し替える前提。
- ファイル名はZIP由来で英数字中心。元名称は `00_引継ぎ/manifest.csv` と `00_引継ぎ/README_元資料対応表.txt` で確認する。

## 8. 次アクション

1. 初回打合せで必要資料一覧を町に提示し、受領可否と提供時期を確定する。
2. 高齢者計画は、R6からR8実績・見える化システム値・基金残高を受領後、Excelの `高齢_試算テンプレート` に入力する。
3. 障がい計画は、サービス別実績、支給決定量、町内外事業所別利用、卒業予定者、医療的ケア児等を受領後、Excelの `障がい_算定テンプレート` に入力する。
4. アンケート調査票とクロス集計軸を確定し、見込量算定に接続する設問を落とさないよう確認する。
5. 統合素案の共通章をベースに、分冊素案へ重複なく反映する。
