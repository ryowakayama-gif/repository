# 小野町水道料金改定 の位置づけ

本フォルダは **小野町水道事業料金改定支援業務委託**（業務番号 小水物等第3号）のものです。
同じ小野町ですが、`小野町_引継ぎ_整理済/` の高齢者保健福祉計画・障がい福祉計画とは
**別契約・別仕様書・別所管**（水道は地域整備課、福祉は健康福祉課）です。混ぜないでください。

## 業務の概要

| 区分 | 内容 |
|---|---|
| 発注者 | 福島県田村郡小野町 地域整備課 |

| 業務概要 | 営業費用及び資本費用等の算定、総括原価の算定、料金体系の設定、照査 |

| 前提 | 令和7年度に策定済みの経営戦略の続編にあたる |

## 受領データ（令和8年9月11日・44ファイル）

水道事業会計の予算・決算一式で、令和2年度から令和8年度までを覆います。

- **R6決算／R7決算** … 決算報告書（令和1〜7年度を1冊に収録）、損益計算書、貸借対照表、
  剰余金計算書、剰余金処分計算書・事業報告書・収益費用明細書・固定資産明細・企業債明細、
  CF計算書、補填財源明細書
- **R7当初予算／R8当初予算** … 議案、予算説明書、CF計算書、損益計算書、貸借対照表、債務償還年次表
- **R7補正（9月・12月・3月）／R8補正（9月）**
- **決算統計** … 地方公営企業決算状況調査。令和6年度決算（総務省最終・原価区分変更後）と令和7年度決算
- **消費税** … 消費税申告資料（令和3〜7年度）

**決算報告書と事業報告書は令和1年度から令和7年度までの7年度分を1冊に収録しており、
料金改定に必要な時系列はこのセットだけでそろっています。**

なお原本のファイル名は文字コードがcp932のため、展開ソフトによっては文字化けします。
`00_受領データ/原本_080911送付/` は正しい名前で展開済みのものです。

## 確認して分かったこと（詳細は `01_確認・整理` のブック）

令和7年度決算で、**料金回収率76.1％**（供給単価249.8円/㎥ 対 給水原価328.2円/㎥）。
営業損失27.8百万円を、一般会計からの他会計補助金19.5百万円と、
現金支出を伴わない長期前受金戻入27.1百万円で埋めて経常黒字14.0百万円としています。

- 給水人口は7年で11.6％減（令和1年度4,881人→令和7年度4,313人）
- 有収率69.98％（令和5年度は62.5％まで低下）。全国平均を約20ポイント下回る
- 施設利用率39.2％（配水能力4,870㎥/日に対し一日最大配水量1,908㎥/日）
- 令和8年度当初予算では営業損失が35.3百万円に拡大し、経常利益は7.4百万円に縮む

## 次にやること

総括原価の算定に入る前に、`01_確認・整理` のブックの `09_不足資料` にある
**最優先5件**（給水人口の将来推計／経営戦略の本文と試算／給水条例の料金表／
口径別・使用水量階層別の件数と水量／一般会計繰入の基準と方針）を町に依頼します。

とくに**口径別・使用水量階層別の件数と水量**は、料金体系の設定
（仕様書の工数の56.6％を占める作業）の前提です。
