## 掲載数値の出所

指標値はすべて `source/六戸町_公共_使用料改定.xlsx` / `source/六戸町_農集_使用料改定.xlsx`
の**「パターン別比較」シートの計算結果**（LibreOffice で再計算した値）。

- 経費回収率の分母は**汚水処理費（維持管理費分）＝ 経常費用 − 減価償却費 − 支払利息 − その他営業外費用**。
  資本費（＝減価償却費 − 長期前受金戻入 ＋ 支払利息）は分流式下水道等に要する経費（一般会計繰入金）で
  カバーされるため全額控除。ブック・R6決算値の双方がこの基準であることを検算済み
  （エビデンス集「汚水処理費の算定」シート）
- 人口推計は両事業とも**社人研**に統一（原本は公共＝社人研・農集＝人口ビジョン。差は0.1ポイント以内）
- 01章の本文表は**2か年改定ベース**（3か年は括弧書きで併記）。02章・03章は2か年・3か年の表を並列で掲載
- 04章の影響額は**改定完了後の最終単価**による月額（2か年改定はR9〜、3か年改定はR10〜。最終単価は共通）
- 単価表の R8 中間単価はブックの算式どおり `ROUND((現行＋最終)/2, 0)`
- モデルケース別月額は各水量区分の単価を**段階累進で積み上げ**、税込は 1.1 倍・円未満四捨五入

## 令和7年度決算との突合（完了）

令和8年8月4日に決算資料（合計残高試算表・貸借対照表／令和8年3月31日）を受領し、突合が完了しました。
詳細は `R7決算突合.md`、突合表はエビデンス集「R7決算突合」「R7実績ベース試算」シートに収録しています。

| 指標 | 公共（推計→実績） | 農集（推計→実績） |
|---|---|---|
| 汚水処理費（維持管理費分） | 168,331 → **125,145千円**（△25.7%） | 37,580 → **31,194千円**（△17.0%） |
| 使用料収入 | 57,895 → **56,752千円**（△2.0%） | 14,976 → **11,604千円**（△22.5%） |
| 一般会計繰入金 | 151,133 → **152,667千円**（＋1.0%） | 19,236 → **51,777千円**（＋169.2%／基準外繰入を含む） |
| 経費回収率 | 34.4% → **45.35%** | 39.9% → **37.20%** |
| 経常収支比率 | 98.5% → **104.06%** | 82.0% → **112.58%** |

これにより **確認事項 A・F・M・N が決着**し、**Q が一部解決**しました。

- **A**：R6→R7の維持管理費の増加は＋4.7%。推計していた＋40.9%増は生じていない
- **F**：農集の基本使用料の年間乗数は **×6**（隔月請求）が正しい（×6で算定すると実績と△1.5%）
- **M・N**：R7実績を起点にすればR6実績補正が不要となり解消
- **Q**：企業債残高（公共1,548,034千円・農集206,675千円）・現金預金・剰余金が判明

**本編（37ページ）は経営戦略の推計値ベースのまま維持**し、決算突合は別紙
（`output/六戸町_第2回審議会資料_別紙_R7決算突合.pptx`）で示す方針としました。
本編のうち事実として古くなっていた2か所（01-1 の「突合は未実施」、03-4 の「増加要因は照会中」）は
決算結果を反映する注記に差し替えています。

決算を起点に組み直した場合、公共の経費回収率はR9で56.7〜60.6%（本編46.1%）となり
目標47%はR8時点で達成、農集はR9で46.6〜49.8%（本編54.2%）と本編より低くなります。
経常収支比率は一般会計繰入金の前提で大きく変わります。農集の実績51,777千円は基準外繰入金を含むため、
別紙2の試算は経営戦略の前提（基準内繰入＝資本費相当）を採用しています。

## 引き続き検討が必要な点

- **目標水準（案）の再設定**：R9に47%以上／R10に50%以上／R12に55%以上は、公共下水道では
  今回改定のみでは達成できない。次期改定（R12検証）とあわせた目標設定が必要
- **R11以降の低下**：有収水量の減少で経費回収率は改定後もR10をピークに低下する
- **リスク管理・意思決定フロー**：レッドチーム評価で欠如と指摘された項目は未反映（第3回資料での対応を想定）
- **✅ 農集の年間乗数（確認事項F）**：R7決算により **×6（隔月請求）が正しい**ことが確定。
  ブックの×12は誤りで、農集の使用料収入を約29%過大に見積もっている
- **✅ 維持管理費の増加要因（確認事項A）**：R7決算では汚水処理費125,145千円（R6比＋4.7%）で、
  推計していた＋40.9%増は生じていない。推計が43,186千円過大だった理由（委託・工事の繰延べか
  推計過大か）と、令和8年度以降の見込みの確認が残る
- **✅ R6実績使用料収入の不一致（確認事項M・N）**：R7実績を起点にすればR6実績補正が不要となり解消
- **本編とR7決算の乖離**：本編の数値は経営戦略の推計値ベースのため、決算実績とは
  公共の経費回収率で11ポイント（34.4% vs 45.35%）の差がある。別紙で突合結果と試算を示している。
  決算ベースへの全面的な組み直しを行うかは審議会でのご判断を踏まえて対応
- **中間単価の端数処理**：算定ブックは四捨五入、第1回資料は切り捨てで5区分1円の差。
  条例上の端数処理とあわせて確定が必要（確認事項G）
- **未受領データ**：社会資本整備総合交付金の規模・対象事業費（O）、三沢市の使用料（P）、
  資金残高・企業債残高・更新投資計画（Q）、経営改善の取組状況・町内事業所の使用水量帯（R）。
  Qが揃えばSECTION 03に「事業全体の財政見通し」を1ページ追加できます

`build_talk_script.py` は pptx のノート欄を書き換えるため、**`build_deck.py`・`build_appendix.py` の後に実行**します。
