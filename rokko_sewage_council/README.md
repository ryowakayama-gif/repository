## 掲載数値の出所

指標値はすべて `source/六戸町_公共_使用料改定.xlsx` / `source/六戸町_農集_使用料改定.xlsx`
の**「パターン別比較」シートの計算結果**（LibreOffice で再計算した値）。

- 経費回収率の分母は**汚水処理費（維持管理費分）＝ 経常費用 − 減価償却費 − 支払利息 − その他営業外費用**。
  資本費（＝減価償却費 − 長期前受金戻入 ＋ 支払利息）は分流式下水道等に要する経費（一般会計繰入金）で
  カバーされるため全額控除。ブック・R6決算値の双方がこの基準であることを検算済み
  （エビデンス集「汚水処理費の算定」シート）
- 人口推計は両事業とも**社人研**に統一（原本は公共＝社人研・農集＝人口ビジョン。差は0.1ポイント以内）
- 本文表は**2か年改定ベース**、3か年改定は括弧書きで併記
- 単価表の R8 中間単価はブックの算式どおり `ROUND((現行＋最終)/2, 0)`
- モデルケース別月額は各水量区分の単価を**段階累進で積み上げ**、税込は 1.1 倍・円未満四捨五入

## ⚠ 原稿からの数値の変更点（要確認）

原稿に入っていた指標値はシミュレーションブックの計算結果と一致していなかったため、
**ブックの値に差し替えた**。審議上の意味合いが変わる箇所があるので、確認をお願いします。

| 項目 | 原稿 | 本資料（ブックの計算結果） |
|---|---|---|
| 公共 経費回収率 R7（現行） | 47% | **34.4%** ※47.11%はR6決算の実績値 |
| 公共 経費回収率 R9（②2か年） | 60%以上 | **46.1%** |
| 公共 経常収支比率 R7（現行） | 90〜95% | **98.5%** |
| 農集 経常収支比率 R9（②2か年） | 101〜103% | **85.8%**（改定後も100%未満） |
| パターン間の優劣 | ①が最も財政貢献 | **②が最大**（①76,277 < ④78,028 < ②81,531 千円／R9・公共） |

これに伴い次の記述も改めています。

- **経費回収率の目標達成**：公共下水道はどのパターンでもR9に43〜46%にとどまり、
  目標水準47%に届きません。03-4 に審議事項として明記しました。
- **農業集落排水の経常収支比率**：3案とも100%未満（R9で84〜86%）にとどまるため、
  他会計繰入等による補填が引き続き必要である旨を記載しました。
- **評価軸（01-1）の「財政健全化への貢献度」**：①◎/②○/④◎ → **①○/②◎/④○** に修正
  （使用料収入の大小に合わせた）。推奨案が②である結論は変わりません。

## 引き続き検討が必要な点

- **目標水準（案）の再設定**：R9に47%以上／R10に50%以上／R12に55%以上は、公共下水道では
  今回改定のみでは達成できない。次期改定（R12検証）とあわせた目標設定が必要
- **R11以降の低下**：有収水量の減少で経費回収率は改定後もR10をピークに低下する
- **リスク管理・意思決定フロー**：レッドチーム評価で欠如と指摘された項目は未反映（第3回資料での対応を想定）
- **農集ブックの内部不整合**：「使用料マスタ」（本資料が参照）と「使用料算定」の
  ライブ計算でパターン間の収入差が食い違う。基本使用料の年間乗数が公共は6回・農集は12回と
  異なるため、請求サイクルの確認を推奨（確認事項F）
- **維持管理費の増加要因**：汚水処理費の算定基準はR6決算・ブックとも一致することを検算で確認したが、
  維持管理費の水準がR6→R7で公共119,503→168,331千円（＋40.9%）・農集32,870→37,580千円（＋14.3%）と
  増加する。経費回収率が47.11%→34.4%に低下する主因。うち「その他（主に委託料）」が155,280千円と
  92%を占めるため、委託内容別の内訳確認が必要（確認事項A）
- **R6実績使用料収入の不一致（最優先）**：改定ブックの補正基準（公共61,104千円・農集15,802千円）が
  第1回資料の決算値（公共56,302千円・農集11,831千円）と一致しない。第1回資料の値が正であれば
  公共の経常収支比率はR9で99.8%、農集の経費回収率は40.6%となり、本資料の結論が変わる（確認事項M）
- **中間単価の端数処理**：算定ブックは四捨五入、第1回資料は切り捨てで5区分1円の差。
  条例上の端数処理とあわせて確定が必要（確認事項G）
