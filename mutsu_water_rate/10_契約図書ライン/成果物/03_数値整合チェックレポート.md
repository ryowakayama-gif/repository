## 3. 設計書（R8）の積算内訳と検証

### 3-1. 各版の比較

| 項目 | 原本 | 修正1 | 岡本修正版 |
|---|--:|--:|--:|
| 直接人件費（A） | 205,000円 | 205,000円 | 205,000円 |
| 　経営状況分析 | 90,000円 | 90,000円 | 90,000円 |
| 　現状シミュレーション | 90,000円 | 90,000円 | 90,000円 |
| 　審議会運営設計 | 25,000円 | 25,000円 | 25,000円 |
| 直接経費（B） | 207,000円 | 207,000円 | **208,000円** |
| 　機器損料 | 45,000円 | 45,000円 | **削除** |
| 　交通費 | 162,000円（3往復×54,000） | 162,000円（3往復×54,000） | **208,000円（4往復×52,000）** |
| その他原価（C） | 110,000円 | 110,000円 | 110,000円 |
| 一般管理費等（D） | 281,000円 | 281,000円 | 281,000円 |
| **小　計** | **803,000円** | **803,000円** | **804,000円** |
| 消費税 | 80,300円 | 80,300円 | 80,400円 |
| **合　計** | **883,300円** | **883,300円** | **884,400円** |

### 3-2. 積算式の検証（岡本修正版）

```
直接人件費（A）= 90,000 + 90,000 + 25,000 = 205,000円

直接経費（B）= 4往復 × 52,000円 = 208,000円

その他原価（C）= ROUNDDOWN(205,000 × 0.35 / (1-0.35), -3)
              = ROUNDDOWN(110,384.6…, -3) = 110,000円

一般管理費等（D）= ROUNDDOWN((205,000+208,000+110,000) × 0.35 / (1-0.35), -3)
                = ROUNDDOWN(523,000 × 0.538462…, -3)
                = ROUNDDOWN(281,615.4…, -3) = 281,000円

小計 = 205,000 + 208,000 + 110,000 + 281,000 = 804,000円
消費税 = ROUNDDOWN(804,000 / 10, 0) = 80,400円
合計 = 804,000 + 80,400 = 884,400円  ✅ 計算正確
```
