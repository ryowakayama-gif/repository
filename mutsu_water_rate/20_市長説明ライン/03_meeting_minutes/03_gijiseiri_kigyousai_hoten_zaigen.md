# 水道事業 経営分析・料金改定検討会議 議事整理・修正方針

## 1. 結論

本会議の修正作業で最も重要な点は、次の3点です。

1. **補填財源と現金残高を分けて整理すること**
   - 補填財源は、主として資本的収支（4条）の不足額を補うための内部留保資金等です。
   - 現金残高は、実際の支払能力を示すキャッシュ残高です。
   - 両者は関連しますが同一ではないため、「補填財源が不足すること」と「現金が枯渇すること」を同じ数値として扱わないようにします。

2. **建設改良費の修正後、企業債を再計算すること**
   - 建設改良費から国費、県費、工事負担金その他の特定財源を控除した額を企業債対象額とします。
   - 今回のシミュレーションでは、その企業債対象額に対し、**企業債充当率100％**として設定します。
   - 計算式は次のとおりです。

> 企業債発行額 ＝ 建設改良費 － 国費・県費 － 工事負担金等の特定財源

3. **企業債100％充当による将来負担を、3条・4条の双方に反映すること**
   - 借入年度は4条財源が増加し、建設改良費に必要な補填財源は減少します。
   - 一方、将来は3条の支払利息と4条の企業債元金償還が増加します。
   - 利率は、今回の試算条件として**年3.0％**を使用します。
   - 元金償還年数、据置期間、元利均等・元金均等等の償還条件が未確定であるため、最終的な利息・償還額は償還条件確定後に再計算する必要があります。

## 3. 議事内容の整理

### 3.1 経営状況の現状分析

#### 給水収益と営業損益

- 令和3年度以降、給水収益は減少傾向にあります。
- 令和7年度の営業損益は、約2.2億円の赤字となる見込みです。
- 純損益は黒字を維持していても、本業である給水収益によって営業費用を賄えていない状態です。
- 市長説明では、純利益だけではなく、営業損益、経常収支、料金回収率を併記し、事業本来の収支構造を説明する必要があります。

#### 供給単価と給水原価

- 令和7年度時点では、給水原価が供給単価を上回っています。
- 現行料金では、給水に必要な費用を料金収入で回収できていません。
- 料金改定の必要性は、次の関係で示すことが有効です。

> 料金回収率 ＝ 供給単価 ÷ 給水原価 × 100

- 100％未満の場合、給水費用を料金収入だけで回収できていないことを示します。

#### 資金残高

- 令和3年度から令和7年度末までに、資金残高は約8.5億円減少しています。
- 大規模な建設改良事業に充当できる余剰資金が限定的になっています。
- 一般会計繰入金に依存している構造を明示し、繰入金がない場合の資金推移も併記する必要があります。

---

### 3.2 令和8年度以降の将来推計

#### 補填財源不足

- 現行料金、現行投資計画、現行の一般会計繰入条件を前提とすると、令和9年度から令和10年度頃に補填財源が不足する見通しです。
- ただし、建設改良費の純額を企業債で100％調達する前提へ変更すると、建設改良費に対する当年度の補填財源使用額は減少します。
- そのため、企業債修正前の補填財源不足額をそのまま使用せず、次の順番で再計算する必要があります。

1. 建設改良費を年度別に修正する。
2. 国費・県費・負担金等を年度別に控除する。
3. 控除後の純建設改良費に企業債を100％充当する。
4. 4条収支不足額を再計算する。
5. 企業債元金償還額を加え、補填財源使用額を再計算する。
6. 支払利息を3条費用に加え、純損益と資金残高を再計算する。

#### 「予算が組めない」という表現

市長説明では危機感を示す必要がありますが、資料上は次のように表現する方が正確です。

> 現行料金及び現行の財源条件を継続した場合、令和9年度から令和10年度頃に資本的収支の財源不足が発生し、追加の企業債、一般会計繰入、事業延期又は料金改定を行わなければ、現行投資計画を維持できない見込みです。

「補填財源がマイナスになるため直ちに事業継続不能」と断定するのではなく、どの財源対策を行わなければ不足するのかを明示します。

## 4. 補填財源の整理

### 4.1 補填財源と現金残高の違い

| 区分 | 内容 | 主な用途 |
|---|---|---|
| 補填財源 | 減価償却費等により生じる損益勘定留保資金、利益剰余金処分額、過年度留保資金等 | 4条収支不足額の補填 |
| 現金残高 | 預金、現金等の実際の資金残高 | 工事代金、償還金、運転資金等の支払 |
| 4条収支不足額 | 資本的支出から企業債、補助金、負担金等の資本的収入を差し引いた額 | 補填財源で補う対象額 |

補填財源残高がある場合でも、未収金や未払金の状況によっては現金が不足する可能性があります。反対に、現金が存在していても、予算上の補填財源として整理できない部分があります。

### 4.2 基本計算式

#### 資本的収支不足額

> 資本的収支不足額  
> ＝ 資本的支出  
> － 企業債  
> － 国県補助金  
> － 工事負担金  
> － その他の資本的収入

#### 補填財源年度末残高

> 年度末補填財源残高  
> ＝ 年度当初補填財源残高  
> ＋ 当年度発生補填財源  
> － 当年度補填財源使用額

#### 当年度発生補填財源の主な構成

- 当年度分損益勘定留保資金
- 過年度分損益勘定留保資金
- 利益剰余金処分額
- 消費税及び地方消費税資本的収支調整額
- その他、制度上補填財源として使用可能な財源

### 4.3 補填財源表の推奨様式

| 年度 | 当初残高 | 当年度発生額 | 建設改良費への使用 | 元金償還への使用 | 消費税調整額等 | 年度末残高 |
|---|---:|---:|---:|---:|---:|---:|
| R8 |  |  |  |  |  |  |
| R9 |  |  |  |  |  |  |
| R10 |  |  |  |  |  |  |
| R11 |  |  |  |  |  |  |

企業債を純建設改良費へ100％充当する場合、「建設改良費への使用」は原則として縮小しますが、「元金償還への使用」は将来増加します。

## 5. 建設改良費修正に伴う企業債の取扱い

### 5.1 今回の設定条件

| 項目 | 設定 |
|---|---|
| 企業債対象額 | 建設改良費から国費、県費、工事負担金等を控除した額 |
| 企業債充当率 | 100％ |
| 想定利率 | 年3.0％ |
| 対象期間 | 令和8年度以降の将来推計期間 |
| 元金償還条件 | 別途設定が必要 |
| 利息計上区分 | 3条・支払利息 |
| 元金償還区分 | 4条・企業債償還金 |

### 5.2 企業債発行額

> 年度別企業債発行額  
> ＝ 年度別建設改良費  
> － 年度別国県補助金  
> － 年度別工事負担金  
> － 年度別その他特定財源

企業債発行額がマイナスになる場合は0円とします。

### 5.3 利息計算

簡易シミュレーションでは、次の方法が考えられます。

> 年間支払利息  
> ＝ 期中平均企業債残高 × 3.0％

> 期中平均企業債残高  
> ＝（期首企業債残高 ＋ 期末企業債残高）÷ 2

ただし、実際の支払利息は、借入月、据置期間、償還方法、借入期間により異なります。市長説明用の概算値として使用する場合は、「平均残高に年3％を乗じた概算」と注記します。

より精緻な試算では、借入年度別に償還表を作成し、各企業債の期首残高に3％を乗じます。

### 5.4 元金償還

元金償還額を算定するには、少なくとも次の条件が必要です。

- 償還期間
- 据置期間
- 元金均等又は元利均等
- 年1回又は年2回償還
- 借入時期
- 既発債の償還予定

これらが未設定のままでは、企業債100％充当後の補填財源残高を正確に算出できません。

### 5.5 企業債100％充当の財政影響

| 時点 | 影響 |
|---|---|
| 借入年度 | 4条収入が増加し、建設改良費に必要な補填財源が減少 |
| 借入年度 | 現金流出が抑制され、資金残高の低下が緩和 |
| 翌年度以降 | 3条の支払利息が増加 |
| 翌年度以降 | 4条の元金償還額が増加 |
| 中長期 | 補填財源が元金償還に使用される |
| 中長期 | 将来世代の料金負担又は一般会計負担が増加 |
| 中長期 | 企業債残高、債務償還負担、支払利息が増加 |

企業債は補填財源不足を解消する恒久財源ではなく、支払時期を将来へ移す財源です。

## 6. 大湊バイパス事業等の建設仮勘定の取扱い

### 6.1 減価償却開始時期

- 建設仮勘定に計上されている間は、原則として減価償却を行いません。
- 供用開始後、固定資産へ振り替えた時点から、所定の会計処理に基づいて減価償却を開始します。
- 令和10年度以降に供用開始する想定であれば、供用開始年度、供用開始月、資産区分、耐用年数を確認し、減価償却費を再計算します。

### 6.2 推計への影響

- 減価償却費の増加により、3条費用は増加します。
- 純利益及び経常収支比率は低下する可能性があります。
- 一方、減価償却費は非現金支出であるため、損益勘定留保資金の発生額にも影響します。
- 補助金等で取得した資産が含まれる場合は、長期前受金戻入も併せて確認します。
- 減価償却費だけを追加し、長期前受金戻入や補填財源発生額を反映しないと、3条・4条の整合が崩れます。

## 7. 料金改定シミュレーション

### 7.1 資産維持費

資産維持費は、将来の更新財源を料金原価に織り込む考え方です。資料では「保有資産の3％」と単純化せず、次の計算根拠を明示する必要があります。

> 資産維持費 ＝ 対象資産額 × 資産維持率

確認が必要な項目は次のとおりです。

- 対象資産の範囲
- 帳簿価額又は取得価額等、計算基礎となる資産額
- 資産維持率0％、1％、2％、3％の設定根拠
- 算定期間
- 料金算定上の控除収益
- 料金収入増加額と改定率の関係

### 7.2 シナリオ

| シナリオ | 資産維持率 | 説明 |
|---|---:|---|
| A | 0％ | 収支均衡に必要な最低限の料金水準 |
| B | 1％ | 更新財源を一部確保する案 |
| C | 2％ | 更新財源の確保を強める案 |
| D | 3％ | 理論上の資産維持費を最大限反映する案 |

3％の場合に改定率が50％を超える場合は、次の数値を併記します。

- 資産維持費を除く収支改善分
- 資産維持費相当分
- 企業債利息増加分
- 大湊バイパス事業等の減価償却増加分
- 料金改定後の料金回収率
- 料金改定後の現金残高
- 料金改定後の補填財源残高

### 7.3 段階改定

現実的な選択肢として、次の比較が必要です。

- 一度に必要改定率を反映する案
- 当初は資産維持率1％相当を反映し、5年後に再改定する案
- 当初は資産維持率2％相当を反映し、投資実績に応じて再検証する案
- 基本料金と従量料金の配分を見直す案
- 一般会計繰入と料金改定を組み合わせる案

## 10. Red Teamチェック

### 10.1 企業債100％充当でも補填財源不足が残るか

企業債を純建設改良費へ100％充当する場合、建設改良費に対する補填財源使用額は大きく減少します。したがって、企業債修正後も令和9年度から令和10年度に補填財源が不足するという結論を示すには、次の要因を数値で説明する必要があります。

- 既発債の元金償還
- 新規債の元金償還開始
- 企業債対象外経費
- 消費税資本的収支調整
- 3条赤字による内部留保資金の減少
- 一般会計繰入金の減少又は終了
- 補助金・負担金の入金時期のずれ

### 10.2 資金ショートの年度

「令和9年度・令和10年度に資金ショート」とする場合、少なくとも次の3指標を区分して示します。

1. 補填財源残高が0円未満となる年度
2. 現金・預金残高が必要運転資金を下回る年度
3. 4条収支の財源不足により予定事業を実施できなくなる年度

3つの年度が一致しない場合があります。

### 10.3 企業債の過大計上

次の経費は、企業債対象外又は別途整理となる可能性があるため、純建設改良費の全額を機械的に企業債計上しないよう確認が必要です。

- 企業債対象外の事務費
- 維持修繕費
- 補助対象外かつ起債対象外の経費
- 消費税相当額
- 既に他財源が充当されている経費
- 建設改良費以外の支出

今回の「100％」は、**起債可能額に対する充当率100％**として整理する必要があります。

### 10.4 利率3％の取扱い

3％は将来推計上の設定値であり、実際の借入利率ではありません。資料では次の注記が必要です。

> 将来の金利上昇リスクを考慮し、新規企業債の想定利率を年3.0％として試算しています。実際の借入条件により支払利息は変動します。

### 10.5 資産維持費3％

「3％を盛り込むと改定率50％超」と説明する場合は、3％の計算対象資産と料金算定期間を明示します。資産額の定義が不明確なままでは、改定率の再現性がありません。
