## 3. 算定方法

投資財政計画Excel `SIM_R8予算置換_0%` シートにおいて、**料金改定率 `B6` を 0 とした場合**の値です。

```
B6（必要改定率）= 0        ※納品版は 0.0726393943654804（＝7.3%）

r10 給水収益  = '02_R8予算_年次計画置換'!給水収益 × IF(年度>=11, 1+B6, 1)
r57 補てん可能財源相当 = 純損益 + 減価償却費 + 資産減耗費 − 長期前受金戻入
r72 補填財源残高（期末）= 前年度末残高 + r57 + 資本的収支不足額
      起点：R7末 183,463千円（0708修正版 補てん財源経過表）
r59 年度末現預金残高   = 前年度末残高 + r57 + 資本的収支不足額
      起点：R7末 242,588千円（R7決算）
```

投資計画・企業債条件は両ケース共通のため、**資本的収支不足額は改定の有無で変わりません**。
差が生じるのは給水収益経由の純損益、すなわち `r57` のみです。

**妥当性の担保**として、同スクリプトで納品版の条件（B6=7.26%）を計算し、

確認済みです。

さらに、算定した「改定なし」の経常収支比率・料金回収率は、

## 5. ★あわせて発見した重要な不具合（要判断）

本作業でモデルを精査した結果、**営業収益の集計に二重計上**があることが判明しました。

### 内容

`SIM_*` シートの `r9 営業収益 = SUM(r10:r12)` ですが、構成行は次のとおりです。

| 行 | 項目 | 性質 |
|---|---|---|
| r10 | 給水収益（改定反映後） | 改定後の金額**そのもの** |
| r11 | **うち**料金改定増収 | r10 の**内数**（差分の再掲） |
| r12 | その他営業収益 | 独立項目 |

`r11` は `r10` の内数であるため、`SUM(r10:r12)` は**増収額を二重に算入**しています。
`r11 = r10 −（改定前給水収益）` なので、R10以前は0となり影響しませんが、
**R11以降のみ**発生します。**12あるSIMシート全てで同一**です。

### 影響を受けない項目

- **必要改定率（7.3％／21.5％／35.7％／49.8％）** … `B6` は `02_R8予算_年次計画置換` シートのみを
  参照して算定しており、`r9` を経由しません。**変わりません。**
- **料金回収率** … `r10 ÷ 給水原価対象費用` で算定。`r9` を経由しません。**変わりません。**
- **資本的収支不足額・累計4条不足△4,887百万円** … 4条側のため影響なし。
- **本メモの「改定なし」の全数値** … 改定率0のとき `r11 = 0` となり二重計上が発生しないため、
  **是正の有無にかかわらず同値**です。

### 判断が必要な事項

是正すると「7.3％の改定を行っても、R11の補填財源はなお△40百万円、経常収支比率はR14以降
再び100％を下回る」という**結論の重みが変わります**。影響範囲は P.7・P.9・P.10・P.11 と
Excel全12SIMシートに及び、「1ページ追加」の範囲を超えるため、本対応では**是正を反映していません**。

本ファイルのP.9・P.10の「改定あり」は、**市が保持する現行資料と同じ数値**で作成しています。
