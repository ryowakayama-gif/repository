## 1. 結論（先に3行）

1. `SIM_*` シートの **`営業収益 = SUM(給水収益, うち料金改定増収, その他営業収益)`** は、
   第2項が第1項の**内数**であるため二重計上である。
2. 影響は **R11以降のみ**。補填財源残高・現預金はR16末で**502,733千円（資産維持費0％ケース）過大**。
   **経常収支比率は影響あり**（R11で+5.34ポイント過大）、**料金回収率は全年度で影響なし（差0.00）**。
3. **必要改定率（7.3／21.5／35.7／49.8％）は影響を受けない**。算定経路が独立しているため。

## 2. 問題の所在

対象セル：`SIM_R8予算置換_0%` シート（他11シートも同一構造）

| 行 | 項目 | 数式（C列＝R8の例） |
|---|---|---|
| r9 | 営業収益 | `=SUM(C10:C12)` |
| r10 | 　給水収益（改定反映後） | `='02_R8予算_年次計画置換'!C7*IF(8>=11,1+$B$6,1)` |
| r11 | 　**うち**料金改定増収 | `=C10-'02_R8予算_年次計画置換'!C7` |
| r12 | 　その他営業収益 | `='02_R8予算_年次計画置換'!C8` |

`r10` は改定率を乗じた**改定後の給水収益そのもの**、`r11` は `r10` から改定前給水収益を
差し引いた**増収分の再掲（内数）**である。したがって

```
r9 = r10 + r11 + r12
   = 改定後給水収益 + （改定後給水収益 − 改定前給水収益） + その他営業収益
```

となり、増収分が二重に算入される。正しくは `r9 = r10 + r12` である。

---

## 3. 二重計上と断定する4つの根拠

### 根拠1：ラベルが「うち」である

`r11` の項目名は「**うち**料金改定増収」。会計・統計上「うち」は上位項目の内数を示す慣用表記であり、
加算項目ではない。

### 根拠2：数式が差分そのものである

`r11 = r10 − '02'!C7`。`r10` から改定前給水収益を引いた差分＝`r10` の構成要素。
独立した収益源ではない。

### 根拠3：改定のない年度では正しい定義になっている

R7〜R10は `IF(年度>=11,…)` により改定率が乗じられず `r11 = 0` となる。このとき

```
r9 = r10 + 0 + r12 = 給水収益 + その他営業収益
```

これは営業収益の正しい定義である。実際、R7の値は

```
r9(R7) = 1,246,225 = 給水収益 1,217,101 + その他営業収益 29,124
```

でR7決算と整合する。**つまり数式の意図は `給水収益 + その他営業収益` であり、
`r11` を含めたのは範囲指定の誤り**と考えられる。

### 根拠4：是正後の方が内部整合する

資産維持費0％ケースは「収支均衡に必要な最低限の料金水準」と定義されている。

| | R11〜R15平均 経常収支比率 |
|---|---:|
| 現行（二重計上あり） | **105.61%** |
| 是正後 | **100.38%** |
| 改定なし | 95.16% |

「収支均衡の最低ライン」で経常収支比率が平均105.6％になるのは定義と矛盾する。
是正後の100.4％は定義と整合する。

さらに、`総括原価回収率`（r36。`r9` を経由しない独立算定）のR11〜R15平均は **100.013%** であり、
必要改定率が総括原価をちょうど回収する水準に較正されていることを示す。
是正後の経常収支比率平均100.38％はこれと整合するが、現行の105.61％は整合しない。

## 8. 想定される反論と検討

| 反論 | 検討 |
|---|---|
| **「`r11` は増収を明示するための独立行で、加算が意図どおりでは」** | 成立しない。`r11 = r10 − 改定前給水収益` であり `r10` の部分集合。加算すると改定後給水収益が `r10 + r11 = 改定前給水収益 + 増収×2` となり、いかなる会計定義とも一致しない |
| **「R7〜R10は正しいのだから数式全体が正しいのでは」** | R7〜R10で正しいのは `r11=0` だからにすぎない。数式の欠陥は改定が発生するR11以降にのみ顕在化する |
| **「必要改定率も過大なのでは」** | 該当しない。`B6` は `02_R8予算_年次計画置換` シートのみを参照し、SIMシートの `r9` を経由しない。総括原価回収率のR11〜R15平均が100.013％であることも、較正が正しいことを裏付ける |
| **「料金回収率も過大なのでは」** | 該当しない。`r32 = r10/r34×100` で `r9` を経由しない。再計算でも全年度で差0.00を確認 |
| **「是正すると7.3％では足りないことになり、改定率の再算定が必要では」** | 必要改定率の定義は「R11〜R15の5か年で総括原価を回収する水準」であり、その意味では7.3％で正しい。ただし是正後は経常収支比率がR14以降100％を下回るため、**年度単位での均衡は達成されない**。これは二重計上とは別の論点（算定期間を通期で均す方式の性質）であり、審議会で論点化する価値がある |

## 9. 是正の是非（判断が必要な事項）

### 是正した場合に生じる説明上の変化

- 「7.3％の改定を行っても、**R11の補填財源はなお△40百万円**」となり、R12でようやくプラス転換
- 経常収支比率が **R14以降ふたたび100％を下回る**（99.24％→98.36％→97.22％）
- 純損益が **R14以降ふたたび赤字**（△12→△26→△45百万円）

これは「7.3％では不十分であり、資産維持費を織り込んだ1〜2％帯の改定が必要」という
既存の方針（議事録2回目③「1〜2％を現実的検討帯」）を**むしろ補強する**方向に働く。

### 影響する成果物

- 市長説明資料：P.9・P.10・P.11（P.7は影響なし）
- Excel：`SIM_*` 全12シート（`r9` の数式を `=SUM(r10,r12)` へ）

### 現状の対応

**本件は未是正**。市が保持する現行資料との整合を優先し、直近の修正（P.9への改定なしケース追加）は
現行モデルの数値で作成している。
