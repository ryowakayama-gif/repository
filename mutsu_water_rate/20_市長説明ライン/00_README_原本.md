## 現在の未対応事項・今後の課題

1. **R7→R8繰越工事182百万円**：R8建設改良費888百万円に未反映。実行時はR8建改が最大1,070百万円規模となり得る。市の執行見込確定後に別途反映要。
2. **40年元利均等の表現統一**：v8で市が「40年元利均等」に変更。Excelモデル（Δモデル）は元金均等で実装されているため、表現とモデルの整合を審議会資料化までに要確認。
3. **段階改定・5年後見直し**：議事録v2③の「段階改定・5年後見直しも選択肢」の具体設計は未実装。R10料金審議までに要検討。
4. **需要の価格弾力性**：料金改定に伴う節水行動を未反映。実測値ベースの補正を審議会資料化前に検討。
5. **企業債起債対象範囲**：営業設備費（量水器・機械器具購入費）は起債対象外の可能性。100%充当計算で若干過大となる可能性。要精査。

## 現在対応中の質問

**自治体からの質問（2026/8/9頃受領）**：
> P9の補填財源残高はR11から料金改定済みの残高となっているのでしょうか？

**回答**：はい。SIM_R8予算置換_0%シートr10（給水収益・改定反映後）で `= '02_R8予算_年次計画置換'!F7 * IF(11>=11, 1+$B$6, 1)` によりR11以降給水収益を7.3%増額し、純損益経由で補填財源残高r72に反映しています。R11末46百万円はR10末△83百万円からの改定効果（+約86百万円/年）による回復を表現しています。
