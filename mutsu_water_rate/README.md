# むつ市 水道料金改定業務　作業アーカイブ

チャット（2スレッド）からクラウドコードへ移行した、むつ市水道事業の料金改定検討業務一式です。
移行日：令和8年8月31日

## 1. 業務の全体像

むつ市上下水道局の**令和11年度（R11）料金改定施行**を最終ゴールとする3か年業務です。

| 年度 | 業務区分 | 契約 | 状態 |
|---|---|---|---|
| R8 | 水道事業経営分析及び予測シミュレーション策定業務 | 単年度・880,000円（税込） | **進行中** |
| R9 | 水道ビジョン改定業務委託 | 単年度・5,500,000円（税込）予定 | 未契約 |
| R10 | 料金改定検討支援業務 | 単年度・2,970,000円（税込）予定 | 未契約 |
| R11 | 料金改定施行（市側対応） | — | — |

受託者：ビズアップ公共コンサルティング株式会社

## 2. 2つの作業ラインの関係

チャットは2スレッドに分かれていましたが、**同一案件の別レイヤー**です。

```
                むつ市 適正水道料金検討業務（R8〜R10）
                              │
        ┌─────────────────────┴─────────────────────┐
        │                                           │
  10_契約図書ライン                          20_市長説明ライン
  「契約をどう組むか」                        「中身をどう作るか」
        │                                           │
  仕様書・設計書・見積書・工程表               投資財政SIM・市長説明PPT
  （R8〜R10の3か年を規定）                    （R8業務の実際の成果物）
        │                                           │
  レビュー・数値整合チェック済               v1→v8まで反復・市に納品済
```

- **10_契約図書ライン**＝業務そのものを成立させる契約図書のレビュー。仕様書の誤記・履行期間・設計書の積算検証。
- **20_市長説明ライン**＝R8業務の実作業。R7決算〜R16の投資財政シミュレーションと市長説明資料の作成。

2ラインは独立ではなく、**R9業務の呼称**（改定／策定）や**償還方法の表現**（元金均等／元利均等）で相互に矛盾があります。詳細は `00_引継ぎ/03_課題管理表.md` を参照。
