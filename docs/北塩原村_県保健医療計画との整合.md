# 0. 結論から

**この計画は、国の基本指針が名指しで「調和を保つ相手」として挙げているものでした。それが当方の計画素案から落ちていました。**

令和8年10月15日に数えたところ、計画素案に「保健医療計画」**0回**、「医療圏」**0回**、「へき地」**0回**、「無医地区」**0回**。第7章（他計画との連携）は村の4計画のみで、県の医療計画が入っていませんでした。

根拠は2つあり、いずれも国の基本指針の告示本文（令和8年3月31日）で確かめました。

| | 条項 | 内容 |
|---|---|---|
| ① | **第三の一の７**（他の計画等との関係） | 障害福祉計画等を「**医療計画**（医療法（昭和二十三年法律第二百五号）第三十条の四第一項に規定する医療計画をいう。）…その他の法律の規定による計画等であって障害者等の福祉に関する事項を定めるものと**調和が保たれたものとすることが必要である**」 |
| ② | **第二の二**（精神障害にも対応した地域包括ケアシステムの構築） | 「当該目標の達成に当たっては、地域の医療サービスに係る体制の整備が重要であることから、**特に医療計画…との関係に留意すること**」 |

**計画素案に9件の反映を行いました**（うち1件は確かめた結果「直す必要なし」と判定）。照会を2件（Ｍ-129・Ｓ-38）起こしました。

# 1. いちばん重い発見

## ① 計画期間の終期が本計画と同じで、中間見直しが「いま」です

| | 期間 |
|---|---|
| 第8次福島県医療計画 | **令和6年度～令和11年度（6年間）** |
| 本計画（第8期障がい福祉計画・第4期障がい児福祉計画） | 令和9年度～令和11年度 |

**本計画の期間は、県医療計画の後半3年にそのまま収まります。**

さらに同計画は「在宅医療、外来医療、医師の確保に関する事項…については、**3年ごとに**調査、分析及び評価を行い、必要な場合には計画の見直しを行います」としており、**これに当たるのが令和8年度＝いまです。**本計画の策定と県医療計画の中間見直しが同じ年度に進んでいます。

| 地域平均生活日数 | 319.3日以上（令和11年度） | 325.3日以上 | **334日以上（令和11年）**<br>現況321.3日（令和元年） |

# 3. 確かめた結果「直す必要なし」としたもの

**医療的ケア児支援センターの名称です。**県医療計画は「福島県医療的ケア児支援センター」と書いています。当方の正本 第5章2（15）を見ると、

> 医療的ケアを必要とする方については**福島県医療的ケア児支援センター**が相談と地域支援を担い…なお、医療的ケア児及びその家族に対する支援に関する法律の改正（令和８年法律第77号。令和９年４月１日施行）により、このセンターの名称は「**医療的ケア児等支援センター**」に改められます。施行の日は本計画の期間の初日に当たるため、**本計画期間においては改称後の名称で扱います。**

**既に正式名称を用い、本計画期間中の改称まで書いていました。**直す必要はありません。ＫＩ-4 として立てた項目を取り下げ、経緯を生成器に記録しています。
