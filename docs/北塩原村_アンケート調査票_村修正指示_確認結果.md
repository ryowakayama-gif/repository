### ①について — 手帳所持者数との関係

朱書きの区分別人数の合計は15人。これは**障害支援区分の認定を受けている者の数**であり、手帳所持者数（第2章で扱う）とは母集団が異なる。区分認定は介護給付（居宅介護・生活介護・短期入所・施設入所支援等）の支給決定に必要な手続きであるため、**15人＝介護給付を利用しているか、利用申請をした者の実数**とみてよい。

第5章のサービス見込量のうち、介護給付系の推計は現在「実績の伸び率＋年齢到達移行」で組んでいるが、区分別人数が判明したことで**区分ごとの標準的な支給量から積み上げる検証**が可能になった。区分4以上が8人（区分4=5、区分5=1、区分6=2）であることは、重度者の割合が相応にあることを示す。

### ②について — 第4章の成果目標に直結

基本指針は医療的ケア児等について、**①関係機関の協議の場の設置**と**②医療的ケア児等コーディネーターの配置**を成果目標としている。「対象者1名だから設問不要」という村の判断は調査票としては合理的だが、**計画上は1名でも対象者がいる以上、協議の場と コーディネーターの確保は必要**である。経管栄養が毎日必要という状態像も判明したため、第4章に具体的に書ける。

## 4. 再考をお願いしたい削除指示（2件）

### (1) 障がい者版 問36「就労選択支援について、必要だと思うこと」の削除

**村の理由**：会津管内に就労選択支援事業所がないため設問不要。

**当方の見解**：**事業所がないからこそ、ニーズ把握が必要**と考える。

- 就労選択支援は令和7年10月に施行された新サービスで、基本指針は令和11年度末までに**各市町村又は各圏域に1事業所以上**の設置を目指すとしている（全国目標は令和11年度に年間82,000人の利用）
- 会津管内に事業所がないことは「設問を削る理由」ではなく、**計画に書くべき課題**である
- 村が単独で事業所を確保することは現実的でないため、**圏域（会津若松地方）での共同確保**を第5章に位置づける必要がある。その根拠として村民のニーズデータがあると説得力が増す
- 問36の選択肢6には「制度を知らない」がある。**認知度そのものが有用なデータ**であり、事業所の有無とは独立して意味がある

削除する場合でも、第5章に「圏域内に事業所がないため、会津若松地方の広域調整により確保を図る」旨の記載は必要になる。その場合、根拠は村の窓口相談実績等に求めることになる。

### (2) 障がい者版 問7「障害支援区分の認定」の削除

**村の理由**：役場で人数を把握しているので設問不要。

**当方の見解**：総数の把握という意味では村のとおりだが、**回答者の区分別クロス集計ができなくなる**点はご承知おきいただきたい。

- 問7を残せば「区分4以上の人が外出で何に困っているか」「区分別のサービス利用意向」といった分析ができる
- 削除すると、アンケート結果は障がい種別（問6）でしか層別できない
- ただし対象者15人という規模では区分別クロス集計の統計的意味は乏しく、**個人が特定されるおそれ**もある。**削除に合理性はある**と考える

上記を踏まえ、**削除に異議はない**。第5章の推計では、朱書きでいただいた区分別人数（①）を役場データとして用いる。

## 7. 区分別人数15人と給付実績の突合

朱書きの区分別人数を、現行計画（第7期）の令和8年度見込利用者数と突き合わせた。

| 観点 | 内容 | 判定 |
|---|---|---|
| 区分4以上（8人）と施設入所支援（4人） | 施設入所支援は原則区分4以上（50歳以上は区分3以上）が要件。区分4以上8人のうち4人が施設入所支援を利用している計算で矛盾しない。残る4人は在宅で生活介護等を利用しているとみられる | 整合 |
| 区分3以上（10人）と生活介護（6人） | 生活介護は原則区分3以上（50歳以上は区分2以上）が要件。区分3以上10人のうち6人が生活介護を利用している計算で矛盾しない | 整合 |
| 区分認定者（15人）と共同生活援助（8人） | 共同生活援助は障害支援区分の認定を必ずしも要しない。施設入所4人＋生活介護6人＋居宅介護4人＝14人（重複を含む）に対し区分認定者が15人であることから、**共同生活援助8人の相当部分は区分認定を受けていない**と推定される | 要確認 |
| 区分認定者（15人）と計画相談支援（22人） | 計画相談支援は訓練等給付（就労継続支援B型11人等）の利用者も対象で、これらは区分認定を要しない。15人＋11人＝26人の範囲内にあり矛盾しない | 整合 |
| 区分1が0人であること | 認定を受ける者が一定以上の支援を要する層に限られていることを示す。「非該当」となった者の有無は本データからは分からない | 要確認 |

**この突合から、既存の見込量を変更すべき箇所は見つからなかった。**区分別人数は現在の見込量と矛盾せず、むしろ算定根拠を補強する。第5章の推計方法の節に「障害支援区分別人数による検証」として追記できる。

一方、**重度訪問介護（区分4以上が要件）と行動援護（区分3以上かつ行動関連項目10点以上）は実績0だが、対象要件を満たす者が在籍する**ことが判明した。本計画の「実績ゼロをニーズゼロと判断しない」という方針に、具体的な裏づけが得られた。
