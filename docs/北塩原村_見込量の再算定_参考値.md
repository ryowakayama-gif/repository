# 1. 作り方

レビューが示した式に従いました。

- 翌年度の人数 ＝ 起点の人数 ＋ 確認できた増加 － 確認できた減少
- 利用量 ＝ 人数 × 1人当たりの利用量

| 要素 | 取り方 |
|---|---|
| 起点 | 村の給付の台帳の令和8年度の直近3か月の利用者数の平均。利用が数か月おきのサービスは月平均。台帳の無いもの（就労継続支援Ａ型）は資料２－３の令和7年度 |
| 増減 | 卒業・年齢到達・地域移行・退院・退去は、村の回答が無く1人も確認できていないため **0** |
| 1人当たりの利用量 | 台帳の令和8年度の利用日数 ÷ 利用者の延べ月数。居宅介護の時間は台帳に無いため、資料２－３の令和7年度（30.25時間÷2.6人＝11.6時間） |
| 計画相談支援 | 国の基本指針の数え方（月間の利用者数）。参考に年度の実人数も示した |
| 表に置く場合 | 0を超え1に満たないものは1に切り上げ、それ以外は四捨五入 |

増減を0としたため、**参考値は「いまの利用が続いた場合」の値**で、令和9〜11年度は同じ値になります。
