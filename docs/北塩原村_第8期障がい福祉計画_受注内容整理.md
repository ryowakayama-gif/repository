- 本業務の改定対象は **障がい福祉計画（第8期）と障がい児福祉計画（第4期）の2本** です。

## 2. 業務の目的（仕様書2）

1. 障がい者・障がい児とその家族のニーズを把握する。
2. 現行計画（令和6〜8年度）における障がい福祉サービス及び障がい者福祉施策の実績を評価する。
3. 上記を通じて次期計画（令和9〜11年度）における課題を明らかにし、「第8期北塩原村障がい福祉計画・第4期北塩原村障がい児福祉計画（案）」を策定する。

## 3. 受注範囲の全体像（仕様書4）

業務は次の3本柱で構成されます。

- **Ⅰ　策定のためのニーズ調査**（アンケート調査票の設計・封筒印刷・発送・回収・データ入力・集計分析・調査結果報告書の取りまとめまでの作業一式）
- **Ⅱ　計画策定業務**（基礎調査・現行計画評価・見込量検討・施策検討・計画案検討・計画書作成・委員会支援）
- **Ⅲ　打合せ等業務**（電話・面談（オンライン・対面））
