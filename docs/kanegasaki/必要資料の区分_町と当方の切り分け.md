## 1. 区分の基準

| 区分 | 基準 | 先 |
|---|---|---|
| **Ａ** | **町の帳票・実績・事業の実施状況・庁内の体制でなければ分からないもの** | **町** |
| **Ｂ** | **国または県が公表している資料で確認できるもの** | **当方** |
| **Ｃ** | **町のアカウント・回線・権限がないと取得できないもの**（見える化システム・国保データベース・国保連合会・県経由の調査） | **町**（取得の操作のみ） |
| **Ｄ** | **資料ではなく、町のご判断** | **町** |

**Ｃを分けた理由**　資料そのものは町が保有していない。国または県のシステムからの出力、または回線の制約により当方では取得できないものである。「町にある資料をください」とは性質が異なる。

## 7. 当方の確認に要する前提

**作業環境から `www.mhlw.go.jp`・`www.pref.iwate.jp`・`www.sangiin.go.jp` に接続できない。**
**Ｂの32件を当方で進めるには、次のいずれかを要する。**

| | 方法 |
|---|---|
| **①** | **作業環境のネットワークの設定で上記ホストを許可していただく**（クラウド環境のメニュー →「Edit」→ Network access。手順は https://code.claude.com/docs/en/cloud-environments#network-access ） |
| **②** | **該当する資料をファイルでお送りいただく**（これまでと同じ方法） |

**①であれば以後の資料の確認で町のお手数を要しない。**
**なお、本区分の根拠としたURLは検索により所在を確かめたものであり、ページを開いて中身を照合したものではない。**
