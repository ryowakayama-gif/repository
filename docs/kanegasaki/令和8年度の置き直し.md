# 令和8年度の見込量を「令和7年度実績×伸び」で置き直す様式

成果品：`out/令和8年度の置き直し_第10期見込量.xlsx`（7シート・34サービス）

---

## 1. 置き直しの式

```
令和8年度 ＝ 令和7年度実績 ×（1＋採用伸び率）

採用伸び率 ＝ MEDIAN( 一律の伸び率 − 乖離の上限,
                      一律の伸び率 ＋ 反映割合 ×（サービス別の趨勢 − 一律の伸び率）,
                      一律の伸び率 ＋ 乖離の上限 )

サービス別の趨勢 ＝ 令和7年度実績 ÷ 令和6年度実績 − 1
```

### パラメータ（初期値・シートで変更可）

| 項目 | 初期値 | 根拠 |
|---|---|---|
| **一律の伸び率** | **▲2.214%** | 第1号認定者数 令和7年度813人→令和8年度795人（第10期ワークシート） |
| **趨勢の反映割合** | **50%** | 趨勢をそのまま延ばすと外れやすいため半分だけ織り込む |
| **乖離の上限** | **20.0ポイント** | 一律の伸び率からの乖離の上限 |

**基準年度を令和7年度とする理由**：見込量は基準年度の実績から出発する。基準年度は完結した年度のうち最も新しいもの。令和8年度は年度の途中で基準年度にできない。令和7年度は12か月完結し、総給付費1,238,432千円が月報積上げと5千円差（千円丸めの累積）で一致する。

## 6. シート構成

| シート | 内容 |
|---|---|
| 00_この様式について | 目的・基準年度の考え方・置き直しの式・留意 |

| **02_置き直し（給付費）** | **34サービス。Ｆ〜Ｋ列は数式、Ｍ・Ｎ列は初期パラメータでの計算結果（値）。★印12件が令和7年度実績との連続性を欠く箇所** |

## 8. 留意

- 本様式が示すのは「令和7年度実績を基準に置き直すとどうなるか」であり、**令和8年度の実績見込みそのものではない**。令和8年度の月報（令和8年5月審査分以降）が揃えば実績で置き換える。
- Ｆ〜Ｋ列は数式である。Excelで開くと再計算される。Ｍ・Ｎ列は初期パラメータでの計算結果を値で示したもので、数式の結果と一致する（合計1,256,595.5千円）。

## 9. 保険料への効きの計算（令和8年9月11日 訂正）

当初、月額への効きを一律に「金額×1.076227×0.23488÷166,144」で計算していたが、次のとおり改めた。

| 項目の性質 | 係数 | 例 |
|---|---|---|
| **総給付費**の増減 | ×1.076227（標準給付費への換算）×**0.211278** | 総給付費1%＝40,476千円 → **55円** |
| **標準給付費**の増減 | ×**0.211278** | その他給付費308,537千円 → **391円** |
| **地域支援事業費**の増減 | ×**0.23**（第1号被保険者負担分にのみ入る） | 195,630千円 → **270円** |
| **保険料収納必要額**を直接動かすもの | ×**1** | 準備基金9,000万円 → **▲540円** |

分母＝14,252人×0.9769×12×0.9977＝**166,689人・月**

0.211278 ＝ 第1号被保険者負担割合23% ＋ 調整交付金相当5% － 調整交付金見込交付割合6.8722%

**準備基金と第1号被保険者負担割合の2行は、当初の式では余分に0.23を掛けていたため、それぞれ125円・315円と過小に表示されていた。正しくは540円・251円（1ポイント）である。**
