## 2. 指標数の記載が表と合っていなかった

本文は「**38指標（成果6・活動16・体制16）**」としていたが、**表の行を数えると34項目（成果8・活動16・体制10）**であった。

原因は、**1行で2つの数値を併せて持つ項目が4つある**ことにある（全体の重度化率と軽度化率／老人クラブの団体数と会員数／地域ケア会議の開催回数と検討件数／介護職員就職支援助成金の交付人数と定着率）。**34行＋4＝38** で、「38」という数字自体は誤りではなかったが、**行数と数値の数を区別せずに書いていたため、表を数えた人には合わない。**

**上記1で3項目を加えたため、現在は次のとおり。**

| | |
|---|---|
| **項目（表の行）** | **37**（成果9・活動18・体制10） |
| うち2つの数値を併せて持つ項目 | 5 |
| **数値の数** | **42** |
| **目標値を置いたもの** | **23** |
| **「監視」としたもの**（数値が下がることが望ましいとは限らない） | **7** |
| **置かないもの（現状値未把握）** | **7** |

**9-3に上記の内訳表を置き、「上表は指標の一部である」という記載を「上表が指標の全体である」に改めた。**

あわせて、**照会文書《要確定10》・第2回策定委員会資料の判断事項Ⅲ・資料編の別表6**の記載をすべて同じ数字に揃えた。
