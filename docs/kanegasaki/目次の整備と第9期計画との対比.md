## 2. 目次の実装

### 仕組み

| 要素 | 実装 |
|---|---|
| **本文へのリンク** | 見出しに `w:bookmarkStart/End`（`_Toc10_001`〜`_Toc10_077`）を置き、目次の各行を `w:hyperlink` で包む。**フィールドではないため更新しなくてもクリックで移動できる** |
| **ページ番号** | `PAGEREF <bookmark> \h` フィールド。**Wordで開いた時点で `w:updateFields` により更新される** |
| **更新前の表示値** | `out/_toc_pages.json`。`mk_toc.py` が組版結果から求める |
| **ドットリーダー** | 右端17.0cmに右揃えタブ（`WD_TAB_LEADER.DOTS`） |
| **フッターのページ番号** | 本文セクションに `PAGE` フィールド。**表紙・目次にはページ番号を付さず、本文を1ページから数える**（`w:pgNumType w:start="1"`） |

### ページ番号の求め方（`mk_toc.py`）

```
mkf_soan.py で組版 → LibreOffice で PDF 化 → PyMuPDF でページごとの本文を取得
→ フッターの「- n -」から印刷ページ番号を読む
→ 見出しの位置を突き合わせ → out/_toc_pages.json に書く
→ 目次の行数が変わると本文の開始ページも動くため、値が安定するまで繰り返す
```

**突き合わせで2つの工夫を要した。**

1. **見出しは13pt以上の文字だけを対象に探す。** 本文に章名を引用した表（0-4 章立て・0-5 目次対比）があるため、文字列の一致だけでは最初の引用を拾ってしまう。見出しは16pt（章）・14pt（節）、本文12pt・表11pt と大きさが違うため、これで分離できる。
2. **突き合わせの鍵はダッシュより前を採り、先頭の番号を落とす。** PDFの文字抽出では「２-３　認知症高齢者の状況　―　増えているのはⅡbだけである」が `２-\n　\n　―　\nⅡ\n３\n認知症高齢者の状況\n増えているのはb だけである` のように並びが入れ替わる。

**この2つを入れるまで、第1章のページが5（正しくは7）と出ていた。** 0-5の対比表に「第1章　計画策定にあたって」という文字列があるためである。

### 環境の整備

本コンテナには `libreoffice-core` / `libreoffice-common` しか入っておらず、**Writer の入出力フィルタ（`writer.xcd`）がないため .docx も .txt も「source file could not be loaded」で読めなかった。** `libreoffice-writer` を導入して解決した。

**BIZ UDPゴシックは導入されていないためIPAゴシックで代替される。** Wordでの組版と多少ずれる可能性があるが、ページ番号はフィールドであり**Wordで開いた時点で正しい値に更新される。**
