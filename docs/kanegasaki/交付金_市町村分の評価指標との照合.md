## 4. 矛盾を1件見つけた ―《要回答52》として照会

**交付金では「認知症の人の声を聞く機会（本人ミーティング、活動場所への訪問など）を設けている」として4点満点を得ている。**一方、計画素案は「第9期の策定過程に認知症の人およびご家族から意見を聴く機会は存在しない」としている。**両者は矛盾する。**

**既にそうした機会があるのであれば、《要確定8》のＡは新たに設けるものではなく、既存の取組を計画に位置づけるものになる。**判断の性質が変わるため、第2回策定委員会の前に確認を要する。
