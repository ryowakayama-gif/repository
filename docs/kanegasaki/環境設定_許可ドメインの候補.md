## 1. 北塩原村のブランチで分かったこと

`claude/kitashiobara-elderly-care-plan-i6bgzm` の `a37182c9`（令和8年10月20日）

**村にネットワークの設定を改めていただき、厚生労働省・総務省統計局・e-Stat・介護サービス情報公表システムに接続できるようになった、という記録である。**
その結果、Ｃ区分（公表資料で先行し不足分のみ照会する）が3件決着・2件が絞り込まれ、確認事項は186件→185件になった。

**その回で効いたのは次の3つで、いずれも金ケ崎町にも当てはまる。**

| | 北塩原村での結果 | 金ケ崎町への当てはまり |
|---|---|---|
| **1** | **介護報酬の地域区分を原典で確定した**（一覧に県名の記載がないこと自体が答えであった） | 本町の地域区分も同様に原典で確定できる。**「無いことの確認」は尋ねるより原典が確か** |

## 3. ★許可の効き方　―　ホスト名の完全一致である

**同じドメインでも、サブドメインと `www.` の有無で別物として扱われる。**実測で確かめた。

| 試したホスト | 結果 |
|---|---|
| `www.mhlw.go.jp` | **通る** |
| `mhlw.go.jp`（www なし） | **403** |
| `kaigokensaku.mhlw.go.jp`（www なし） | **403** |
| `www.kaigokensaku.mhlw.go.jp` | **通る** |
| `mieruka.mhlw.go.jp` | **403** |
| `zzz.pref.fukushima.lg.jp`（存在しない名） | **403**（許可されていれば名前解決の失敗になるはずで、403 は政策による遮断を示す） |

**したがって、ご依頼の際は次の形でお願いする必要がある。**

- **`www.` のあり／なしを両方挙げる。**どちらで公開されているか外からは分からず、片方だけだとリダイレクトで落ちる
- **使うサブドメインを1つずつ挙げる。**「`mhlw.go.jp` 配下」といった書き方では広がらない
- 併せて **「パッケージマネージャを許可する」の設定は外さない**（Python・フォント等の取得に要る）

## 5. 設定の変更の場所

**セッションのタイトルバーのクラウド環境のメニュー →「Edit」→「Network access」。**
**「Allowed domains」にホストを1行ずつ加える。**「Allow package managers」のチェックは外さない。
手順は `https://code.claude.com/docs/en/cloud-environments#network-access` にある。
