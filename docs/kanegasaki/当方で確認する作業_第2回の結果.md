## 1. 最も重い発見　―　№6 の記述が、本文の用法と別の事項を指していた

**計画素案の本文は11か所で《要回答6》を参照しており、いずれも「高齢者向け住まい（有料老人ホーム・サービス付き高齢者向け住宅等）の入居定員総数および要介護者等の入居状況」である。**
**ところが附の一覧・照会文書・区分文書は、いずれも№6を「認知症高齢者数の定義と実数（480人／726人）」と記していた。**

| | 状況 |
|---|---|
| **本文（11か所）** | **高齢者向け住まいの入居定員総数・要介護者等の入居状況** |
| **一覧の記述** | 認知症高齢者数の定義と実数（480人／726人） |
| **作業管理メモ §5** | **高齢者向け住まいの整備状況・入居実態**（本文と一致していた） |
| **区分** | **Ｂ（当方で一次資料を確認する。ご回答は不要です）** |

**実害があった。** 高齢者向け住まいの入居定員総数は、**改正後の介護保険法第117条第5項が中長期的な推計を定めるにあたり勘案することを求めている事項**であり（令和9年4月1日施行＝本計画の期間の初日）、本素案の11か所がこれに依存している。
**それにもかかわらず、照会文書では「Ｂ＝ご回答は不要です」の側に置かれており、町にお願いしていなかった。**

**「480人」は本文のどこにも現れない。** また認知症高齢者数の定義そのものは№1（Ｂ7の認定者数の定義）・№48（Ｂ7と事業状況報告の233人差）・№51（どの系列を用いるか）が扱っており、重複していた。

**したがって№6の記述を本文の用法に合わせ、区分をＢからＣ（公表資料で先行し、不足分のみ照会）に改めた。**
**定員は有料老人ホームの一覧およびサービス付き高齢者向け住宅情報提供システムで確かめられるが、要介護者等の入居状況は公表されていないためである。**

## 2. 当方の判断で決着したもの

### (1) №51　認知症高齢者等（自立度Ⅱ以上）はＢ7による　【第2章3・第8章4-3・0-6⑥】

**現状分析レポートは岩手県の自立度調査により令和5年度61.8％（令和7年度で約488人）、本素案は見える化Ｂ7により令和6年10月末69.3％（同565人）を用いていた。77人の差である。**

**Ｂ7（見える化システム）を本計画の系列と定めた。理由は3つある。**

| | 理由 |
|---|---|
| **①** | **国の第10期基本指針（案）別表1は、要介護者等の状況の把握方法を「見える化システム」としている**（№23で確認済み） |
| **②** | **Ｂ7は各年4月末・10月末の2時点で更新されるため、計画期間中の進捗管理を同じ系列で続けられる** |
| **③** | **自立度別の内訳（Ⅱa・Ⅱb・Ⅲ以上）はＢ7にしか存在せず、割合と内訳を別の系列に置くと内訳の合計が総数と合わなくなる** |

**ただし人数はＢ7の構成比に本計画の認定者数を乗じて求め、Ｂ7の認定者数の実数は用いない**（№48の233人の差があるため）。
**岩手県の自立度調査による61.8％は、系列の違いを示すために併記する。**

**これは№15（認知症相談窓口の認知度の母数を全体32.1％に統一）と同じ性格の判断である。どの資料を用いるかは当方が決めるべき事項であり、町のご確認に委ねるものではない。**

### (2) №44　費用負担の見直しに伴う調整に係る係数は、国が示していない　【第8章1】

**利用者負担の見直し等・特定入所者介護サービス費等の2つの財政影響補正係数は、第10期の係数シートで「（未定）」として1（影響なし）のまま置かれている。**
**令和8年7月15日の全国介護保険担当課長会議資料に記載がなく、当方で確認した範囲では国の公表資料にも示されていない。**

**第8章1の「国が示した第10期の諸係数」の表に行を加え、暫定係数1を用いた旨と、国が係数を示した場合は給付費の水準そのものが動く旨を注記した。**

### (3) №17　サービス種類別の実利用者数（人／月）は、公表資料では得られない　【別表1・第8章3】

**国民健康保険団体連合会の介護給付適正化システムが保険者に配信する実績帳票は「事業所別サービス状況一覧表」「受給者別給付状況一覧表」等であり、サービス種類別の実利用者数（人／月）に直接対応する帳票は、公表資料では確認できなかった。**
**介護保険事業状況報告は受給件数（件／月）であり、人数ではない。**第9期の対計画比が11.5％から967.4％まで開いた原因がこの単位の違いである（第3章2）。

**したがって町から国保連合会へご照会いただく必要がある。**第3の№35（令和8年度の月報のご提供）とあわせてお願いする。

## 4. 胆江圏域の地域リハビリテーション広域支援センターを特定した　【《要確定12》・№58】

**岩手県は地域リハビリテーション連携指針（令和4年3月改定）に基づき圏域ごとに地域リハビリテーション広域支援センターを指定しており、胆江圏域は美希病院である。**
**県のリハビリテーション支援センターはいわてリハビリテーションセンターであり、圏域ごとの広域支援センターの運営上の課題について保健所・県と連絡協議を行う。**
**県の指針は9圏域10箇所において広域支援センターによる支援体制が維持されてきたとしている。**

**出所は2つあり、いずれも一致する。**岩手県「地域リハビリテーションの推進」および いわてリハビリテーションセンター「地域支援」。

**これが効くのは《要確定12》である。**
本町の地域リハビリテーション活動支援事業は「実施無」であり、その理由が「リハビリテーション専門職の人手不足」と「関連団体との定期的な協議の場がない」ことである（第3章3）。
**交付金 推進 目標Ⅱ（ⅰ）2エ・オ（計16点）はリハビリテーション専門職等の関与を前提とするが、評価指標の留意点は「関係団体や県・近隣市町村による広域団体等と連携して関与する仕組み」でも対象とする。**

**すなわち接続先を新たに作る必要はない。既にある県の枠組みに接続すればよい。**
**計画素案 第6章 基本方針1(4)（協議の場の設置）と第7章5⑨（専門職の関与の枠組み）に反映し、《要確定12》の当方の案にも接続先として明記した。**

**ただし、現在の指定状況と協力を求められる範囲は確認を要する**《要回答58》**。**県のページの更新はおおむね1年以上前である。

## 6. 見える化システムのＢ7について　―　町のアカウントでの出力をお願いする（№1・48）

**指標の定義書はシステム内にあり、公表資料では確認できなかった。**
**あわせて、同システムは令和8年10月にＢ7（認知症高齢者自立度の状況）・Ｂ8（障害高齢者自立度の状況）の閲覧可能な期間を追加している。本素案が用いる令和6年10月末より新しい時点が利用できる見込みである。**

**お願いするのは2つである。①Ｂ7の指標解説　②Ｂ7の直近の時点における認定者数合計と自立度別の内訳。**

**なお、№48（Ｂ7の認定者数合計1,048人と事業状況報告815人の233人差の理由）は、分からないままでも計画の数値を動かさない。**
**本計画はＢ7の構成比のみを用い、Ｂ7の認定者数の実数を用いていないためである（第2章3・第8章4-3）。**
