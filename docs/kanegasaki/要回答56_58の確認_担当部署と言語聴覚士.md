## 2. 《要回答56》　補装具費（補聴器）の支給件数　―　当方では取れない

| | 当たった先 | 結果 |
|---|---|---|
| **1** | **福祉行政報告例**（厚生労働省） | **補装具費の支給は「都道府県・指定都市・中核市」単位。市町村別の公表がない。**本町は一般町村であり対象外 |
| **2** | **主要な施策の成果に関する説明書**（一般会計） | **町のウェブサイトに公表されていない** |
| **3** | **第7期金ケ崎町障がい福祉計画**（42頁） | **「補装具」「補聴器」の語が1か所もない** |

**したがって、支給件数は町のご回答によるほかない。**

### ★代替となる実測値を得た　―　聴覚・平衡機能障がいの手帳所持者

**出所：第7期金ケ崎町障がい福祉計画 第2章Ⅱ（保健福祉センター調べ・各年度3月末現在）**

| | 平成28年度 | 令和元年度 | 令和4年度 |
|---|---|---|---|
| **聴覚・平衡機能障がいの身体障害者手帳所持者** | **77人** | **64人** | **60人** |
| 身体障害者手帳所持者に占める割合 | 12.5％ | 10.9％ | **12.0％** |

**令和4年度の内訳**　18歳未満0人・18〜64歳27人・**65歳以上33人**

### これが効くこと

**手帳の対象になる水準（おおむね両耳70デシベル以上）に達する方は60人、うち65歳以上は33人である。**
**これに対し、聞こえにくさを自覚する方の見当は約1,880人である**（75歳以上2,688人の約7割。素案 第6章 基本方針3(3)）。

**すなわち、加齢性難聴の大多数は身体障害者手帳の制度の外側にいる。**
**補装具費の支給では届かないため、早期発見と受診勧奨を介護予防の側から行う必要がある。これが施策を置く理由そのものである。**

**なお手帳所持者は77人→60人へ17人（22.1％）減っているが、身体障害者手帳所持者の全体も617人→501人へ減っており、聴覚・平衡の割合（12.5％→12.0％）はほぼ変わらない。手帳の所持者数の減少は、難聴の方が減ったことを意味しない。**

## 4. 《要回答58》　★協議の場と派遣調整の仕組みは既にある

**胆江地域リハビリテーション広域支援センター**
**社団医療法人 啓愛会 美希病院**（奥州市前沢字古城丑沢上野100）

| 区分 | 同指針が掲げる取組 |
|---|---|
| **連携促進** | **地域リハビリテーション連絡協議会の開催**／地域の協力医療機関・施設および**三療法士会（理学療法士会・作業療法士会・言語療法士会）と情報共有**／**リハビリテーション専門職派遣調整ガイドラインの運用** |
| **人材育成** | 地域の在宅介護サービス事業所の介護職員等を対象とした研修会・実技指導・助言／要請に応じたリハビリテーション専門職の派遣 |
| **市町村支援** | **地域包括支援センターと共同した住民主体の通いの場および地域ケア会議へのリハビリテーション専門職の派遣調整** |

**同指針が挙げる胆江圏域の課題は2点である。**
- 協力施設のリハビリテーション専門職が、地域リハビリテーションの支援活動に参加できるような、圏域内での体制整備が必要
- 三療法士会の協力を得ながら、地域の抱える課題に対しリハビリテーション専門職が支援する体制づくりの強化が必要

**本町の地域リハビリテーション活動支援事業が「実施無」である理由の一つは「関連団体との定期的な協議の場がない」ことであった。**
**しかし圏域には既に連絡協議会があり、派遣調整ガイドラインが運用され、地域包括支援センターと共同した派遣調整の実績もある。**
**「協議の場がない」ことは、新たに場を作らなければ解消できないものではない。**

**本計画では、既存の連絡協議会および派遣調整ガイドラインに、本町の地域ケア会議・介護予防事業・聴こえの確認を乗せることから始める。**
