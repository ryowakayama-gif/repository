## 3. 成果品に内部の作業の語が入っていないかの確認

**他団体の作業の前提に「発注者へ提供する文章に、受託者の内部の仕組み・作業経過を書かない」という指示がある。**
**本町の制約（業務仕様に記載のある分析の語のみを用いる。手法名や内部の作業名は提示用資料に含めない）と同じ趣旨であるため、成果品12点を機械的に走査した。**

| 走査した語の種類 | 結果 |
|---|---|
| **スクリプト名・ファイル名**（`.py`・図の生成の名称ほか） | **0件** |
| **作業環境の語**（リポジトリ・作業領域・版の管理の語ほか） | **0件** |
| **手法名** | **0件** |
| **他団体の名**（大雪・東川・美瑛・東神楽ほか） | **0件** |

**「復元」「検算」「突き合わせ」は現れるが、いずれも計画の内容を述べたものである。**

- 「**第9期にあった3つの節を復元する**」　…　計画の構成の話
- 「**第9期のワークシートで検算し、公表値と一致することを確かめた**」　…　算定の検証
- 「**メッシュの座標では機械的に分割できない**」　…　データの性質

**いずれも分析の記述であり、当方の作業の経過ではない。**
