## 1. やり方　―　画面はスクリプトで動くが、中身は3つのリクエストで取れる

**医療情報ネット（ナビイ）の検索はJavaScriptで動くため、画面をそのまま取っても結果は出ない。**
**ページのスクリプト（`S2300.jsx`）を読み、次の3つのリクエストで同じ結果が得られることを確かめた。**

| | リクエスト | 内容 |
|---|---|---|
| **1** | `GET /znk-web/juminkanja/S2300/initialize` | セッションを張る（Cookieを受け取る） |
| **2** | `GET /znk-web/juminkanja/S2300/iryoSearch?XCHARSET=utf-8&XPARAM=keyword&iyakuKbn=1&keywordType=<種別>&keyword=<語>` | **検索IDがJSONで返る。**2つ目以降のキーワードは `&id=<検索ID>` を付けて同じ先へ送る |
| **3** | `GET /znk-web/juminkanja/S2400/initialize?id=<検索ID>` | 結果の一覧（HTML） |

**キーワード種別**　1＝フリーワード／2＝施設名称／**3＝診療科目**／**4＝所在地**

**再現用に `build/navii.py` を置いた。**`python3 -I navii.py <診療科目> <所在地>` で件数と施設の一覧が出る。

## 4. 分かったこと

**第一に、診療科名は法令の表記で引く。**「耳鼻咽喉科」は通称であり、医療法施行令の診療科名は「耳鼻いんこう科」である。
**0件という結果が出たときは、対照の検索を1つ行って手順の正しさを確かめる。**本件では「内科×金ケ崎町」で9件が返ることを確かめてから語を替えた。

**第二に、画面がスクリプトで動くことは、中身が取れないことを意味しない。**
ページのスクリプトを読めば、どのURLにどのパラメータを送るかは書いてある。本件は3つのリクエストで足りた。

**第三に、医療情報ネットは診療科目だけでなく検査項目まで持っている。**
「純音聴力検査」は「耳鼻咽喉領域の一次診療」の項目であり、前年度実施件数とともに登録されている。
**診療科目の有無よりも、検査を実際に行っているかのほうが、受診勧奨先としては重要である。**
