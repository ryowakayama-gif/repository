# 計画素案 第8章の張り替え（第10期ワークシート 令和8年9月28日出力）

令和8年9月28日

町のご指示により、**第10期ワークシート総括表の令和8年9月28日出力（推計パターン0908）を正とし、計画素案の第8章および関連箇所を張り替えた。**

## 4. 8-6「所得段階の設定」の書き改め

**町が所得段階別第1号被保険者数を登録されるため、様式のみであった8-6を実体のある節に改めた。**

- **(1) 基準額に対する割合　―　標準段階区分**：13段階の割合と基準所得金額、第9期の本町の割合との対照。**第2段階のみ本町0.65が標準0.685を下回ること、第10期も0.65とする場合は弾力化による登録を要すること（影響は3か年計45人・保険料月額約18円）を明記した。**
- **(2) 所得段階別第1号被保険者数**：第9期の構成比を第10期の第1号被保険者数に乗せた登録案（13段階×3年度＋3か年計＋補正後被保険者数）。
- **検算**：ワークシート係数シートの全国値により `1 －Σ（1－割合）×（本町の加入割合－全国値）` で算定した補正係数は令和9年度0.9770・令和10年度0.9767・令和11年度0.9770。**第9期の0.9767〜0.9780および本章で用いた0.9769と整合する（分母の差27人・月＝0.016％、保険料月額への影響は1円未満）。**

登録用のデータは `所得段階別第1号被保険者数_登録用.xlsx` として別途お渡しした。

## 5. 張り替えていない箇所

| 箇所 | 理由 |
|---|---|
| **長期推計（令和15年度6,850円・令和30年度7,500円ほか）** | 第10期ワークシートの計画期間の推計とは別系統（1人あたり給付費の伸びと第1号被保険者負担割合の仮定による参考値）であり、9月28日出力の影響を受けない |
| **地域支援事業費 199,237千円** | 第9期実績を基礎に上限まで積んだ値であり、ワークシートの地域支援事業費シートは全項目0のまま |
| **8サービスの復元（3か年19,248千円・月額26円）** | 令和7年度実績から第1号認定者数の伸びで復元したものであり、ワークシートの令和9〜11年度に依存しない |
| **第1回・第2回策定委員会資料** | 別途の張り替えを要する（第2回資料の保険料の記述が5,536円・4,996円のままである） |

## 6. 残る前提

**本章の数値は、次の登録が行われた時点でさらに動く。**

1. **所得段階別第1号被保険者数**（登録すればワークシート側でも保険料が算定される）
2. **地域支援事業費**（ワークシートは全項目0）
3. **その他給付費**（ワークシートは全項目0）
4. **予定保険料収納率・準備基金残高・取崩額**（ワークシートは空欄または0）
5. **令和8年度の月報（202605以降）**《要回答35》。受領できれば令和8年度の置き直しは実績に置き換わり、ワークシートとの差▲161,565千円のほぼ全部が解消する

**1〜4が登録されたワークシートが再出力される場合は、その出力に合わせて再度張り替える。**
