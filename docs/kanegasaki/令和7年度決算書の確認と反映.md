## 1. 至急2件のうち1件が、ほぼ解けた　―　介護給付費準備基金

**基金の運用状況に関する調書により、残高が確定した。**

| | 額 |
|---|---|
| **令和6年度末現在高** | **281,511,103円** |
| 令和7年度中　増（積立金3,322,679円＋基金利子419,850円） | **3,742,529円** |
| 令和7年度中　減（繰入金13,092,000円＋利子相当の繰出419,850円） | **13,511,850円** |
| **令和7年度末現在高** | **271,741,782円** |

**純減は9,769,321円である**（積立金3,322,679円−繰入金13,092,000円。利子は基金に生じて特別会計の財産収入に繰り入れられるため、増減に同額が立つ）。
**決算書の歳入「基金繰入金13,092,000円」・歳出「基金積立金3,322,679円」・歳入「財産収入（介護給付費準備基金利子）419,850円」と1円まで整合する。**

**最も重いのはここである。** 計画素案が引いていた令和5年度末の残高見込は約2億7,046万円であり、**令和7年度末271,741,782円はこれとほぼ同水準である。**
**第9期は「3年で9,000万円を取り崩して基準額を5,450円から4,900円に引き下げる」前提であったが、2年を経ても基金はほとんど減っていない。**
**したがって第10期で9,000万円を取り崩す余力はある。**令和7年度の当初予算は28,420,000円の繰入れを予定していたが、補正で15,328,000円を減額し、決算は13,092,000円であった。

**残るのは令和8年度の取崩予定額と積立予定額のみである。**令和8年度当初予算（介護保険特別会計）の該当欄、または町でお持ちの令和8年度末の残高見込額で確定する。

## 3. ★包括的支援事業・任意事業費について、3つの額が一致しない

**令和7年度の地域支援事業費の決算額（確定）**

| 区分 | 決算額 |
|---|---|
| **介護予防・日常生活支援総合事業** | **35,740,816円**（介護予防・生活支援サービス事業費29,206,514円＋一般介護予防事業費6,534,302円） |
| **包括的支援事業・任意事業** | **42,154,304円**（総合相談16,971,066／包括的・継続的ケアマネジメント15,656,797／認知症総合支援4,037,019／任意事業2,908,163／生活支援体制整備2,545,532／在宅医療・介護連携19,987／権利擁護15,740） |
| 審査支払手数料 | 73,255円 |
| **計** | **77,968,375円** |

**ここで問題が見つかった。包括的支援事業・任意事業費について、次の3つの額が一致しない。**

| | 額 | 出所 |
|---|---|---|
| **①第9期計画額** | **20,106千円**／年 | 計画素案 第8章4（ワークシートからの復元値） |
| **②交付対象と逆算される事業費** | **約2,600万円〜2,732万円** | 国庫支出金10,518,200円÷38.5％＝27,320千円／県支出金5,004,658円÷19.25％＝25,998千円／一般会計繰入金5,244,000円÷19.25％＝27,242千円。**3経路が整合する** |
| **③決算額** | **42,154,304円** | 令和7年度決算書 |

**②と③の差（約1,500万円）は交付金の対象外であり、一般会計からの繰入で負担されているものとみられる**（事務費繰入金33,083,000円のうち、総務費14,875,242円を超える部分）。
**①は②をも下回る。すなわち計画素案 第8章4の包括的支援事業・任意事業費の見込みは過小である可能性がある。**

**仮に年27,000千円に置き直すと3か年で約20,700千円の増となり、第1号被保険者負担分23％を通じて保険料月額に約29円効く。**
**置き直すには上限額の実額が要る。《要回答47》の残りはこの1点に絞られた。**

**なお総合事業費は、当初予算44,164千円に対し決算35,741千円（80.9％）にとどまる。**令和6年度の逆算値45,264千円との差は、執行の差と、交付決定額からの逆算が概算交付と精算の関係を含むことの両方による。

## 5. 老人福祉事業の量の目標を置けるようになった　【第7章9を新設】

**これまで「第9期計画書の再提供が前提」として置けていなかったが、令和7年度決算の老人福祉費（支出済額48,058,148円）により対象事業を特定できた。**
