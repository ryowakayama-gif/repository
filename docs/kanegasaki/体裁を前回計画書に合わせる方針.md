## 4. 実測で見つかった、計画書としての体裁の問題　―　7件

**第9期計画書の受領を待たずに判断できるものである。**

### (1) ★太字が本文の76.2％を占めている

| | 太字 | 計 | 割合 |
|---|---|---|---|
| **協議用　本文** | **71,226字** | 93,479字 | **76.2％** |
| **協議用　表の中** | **70,810字** | 107,254字 | **66.0％** |
| **公表用　本文** | **16,168字** | 22,356字 | **72.3％** |
| **公表用　表の中** | **9,988字** | 16,122字 | **62.0％** |

**デザインルールは「強調は『読み手が判断に使う数値と結論』に限る」としているが、守られていない。**
**4分の3が太字であれば、太字は強調として機能しない。**公表用の計画書としては、ここが最も目につく差になる。

**協議用については、太字の多用に理由がある。**協議用は「どこを見て判断するか」を示す作業文書であり、読み手は町の担当者と策定委員である。
**しかし公表用は住民が読むものであり、同じ使い方はできない。**

### (2) 表紙の日付が「令和8年9月」のまま

**協議用・公表用のいずれも、表紙の5行目が「令和8年9月」である。**令和8年10月19日現在、2か月前の日付が入っている。
**成果品として出す段階の日付に直す必要がある。**第3回策定委員会（令和8年12月16日）に出すのであれば「令和8年12月」である。

### (3) 表紙にヘッダ（文書名）が出ている

**計画書の表紙にヘッダを出さない。**セクションを分けて表紙だけヘッダなしにする。

### (4) 表紙が文字5行のみである

**現在は「金ケ崎町」「計画名」「素　案」「計画期間」「令和8年9月」の5行である。**
**計画書の表紙に通常あるもの（町章・発行者名・発行年月の体裁・写真または図案）がない。**
**「素　案」は、公表の段階では外す。**

### (5) 章扉がない

**第1章が本文の流れの中で始まる。**自治体の計画書は章の区切りに扉を置くことが多い。前回計画書を見て判断する。

### (6) 目次に作業用の注記が入っている

**「各行をクリックすると本文へ移動します。ページ番号はWordで開いた時点で自動的に更新されます」**。
**協議用には要るが、公表用には載せない。**

### (7) 末尾が「本素案の限界」「以　上」で終わっている

**報告書の体裁である。計画書は資料編で終わり、必要なら奥付（発行年月・発行者・連絡先）を置く。**
**「本素案の限界」は協議用に残し、公表用からは外す。**

**(1)(2)は協議用でも直すべきもの。(3)〜(7)は公表用で直すものである。**

## 5. 直す順序　―　逆順にやると手戻りする

| 段 | 直すもの | 直す場所 | 波及 |
|---|---|---|---|
| **①** | **用紙・余白・本文の書体・文字サイズ・行間・ページ番号** | **`fmt.py` の定数とセクション設定（1か所）** | **全ページのページ割りが動く。**目次のページ番号・図の配置・表の改ページがすべて変わる |
| **②** | **見出しの階層と書式（色・サイズ・章扉）** | **`fmt.py` の `H1`／`H2`／`H3`** | **目次の形・`check_docx.py` の見出し規則に波及** |
| **③** | **表・図の体裁（罫線・網掛け・キャプション・出典）** | **`fmt.py` の `TBL`／`SRC`／`FIG`、`figs.py` の配色** | **220表・26図に一度に効く。**図は再出力を要する |
| **④** | **個別の記載（表紙・はしがき・目次の注記・章扉の文言・資料編の構成・奥付）** | **`ch_kohyo.py`（公表用）／`ch_soan.py`（協議用）** | その文書のみ |
| **⑤** | **太字の整理・表記の統一** | **`ch_*.py` の本文** | その文書のみ。**ただし量が多い**（太字は7万字） |

**①を最後に回すと、④⑤で直した後にページ割りが全部動き、目次の再生成と図の配置の点検（`check_docx.py` の図の規則）をやり直すことになる。**
**①②③は `fmt.py` の1ファイルで足りる。④⑤は本文を触る。先に共通の器を決める。**

**各段の後に必ず3種の点検を通す。**`check_docx.py`（体裁・図の配置・表の合計・記号の件数）／`chk_kakunin.py`（確認事項70件の突合せ）／`chk_kohyo.py`（公表用の数値が協議用と一致するか）。

## 6. 差分の洗い出しの手順　―　表紙から7ブロック

**前回計画書と本計画を、表紙から順に7つのブロックに分けて突き合わせる。**

| | ブロック | 見るもの |
|---|---|---|
| **1** | **表紙** | 町章・計画名の割り方・計画期間の書き方・発行者・発行年月・図案 |
| **2** | **はしがき** | 町長挨拶の有無・署名の形・ページ番号の有無 |
| **3** | **目次** | 階層の深さ・リーダーの有無・図表目次の有無・資料編の掲げ方 |
| **4** | **章扉** | 有無・扉の体裁・章名の書き方 |
| **5** | **本文** | 節の体系・見出しの書式・表と図の体裁・出典の書き方・柱・ページ番号 |
| **6** | **資料編** | 構成（策定経過・委員名簿・用語解説・アンケート結果・条例要綱など）・資料の番号の付け方 |
| **7** | **奥付・裏表紙** | 発行年月・発行者・連絡先・裏表紙の体裁 |

**各ブロックで3列に分ける。**

| 列 | 内容 |
|---|---|
| **Ⅰ** | **前回にあって本計画にないもの** |
| **Ⅱ** | **本計画にあって前回にないもの** |
| **Ⅲ** | **両方にあるが体裁が違うもの** |

**判定は3つに限る。**

| 判定 | 意味 |
|---|---|
| **合わせる** | 前回計画書の体裁に寄せる |
| **合わせない** | **理由を書く。**国の第10期基本指針が新たに求める記載（中長期的な推計・地域の分類に基づく確保・認知症施策推進計画の一体化・老人福祉事業の量の目標）は前回計画書にない。**これらは体裁だけ揃えて内容は本計画のものを残す** |
| **町のご判断** | 表紙の図案・章扉の有無・はしがきの扱いなど、町のご意向によるもの |

**節の対応は既に `0-5`（第9期計画との目次対比）で取ってある。**これを体裁込みに拡張する。

## 7. 機械で担保する　―　目視に頼らない

| | 仕組み | 状況 |
|---|---|---|
| **1** | **`chk_taisai.py`　docxの体裁の実測値を一覧にする** | **今回作成した。**用紙・余白・Normal・本文と表の書体／サイズ／太字／色の分布・ヘッダ・フッタ・ページ番号を出す。上記3・4の数値はこれによる |
| **2** | **第9期計画書のPDFから体裁の値を取る** | **PDFを受領したら走らせる。**PyMuPDFでフォント名・サイズ・余白・ページ番号の位置・見出しの色を取り、上記3の右の欄を機械で埋める |
| **3** | **`check_docx.py` に体裁の規則を追加する** | **基準が決まってから。**現在は図の配置・表の合計・記号の件数・参照を見ている。ここに「本文の書体」「見出しの色」「太字の割合の上限」を加える |
| **4** | **`chk_kohyo.py`** | **既にある。**公表用の数値が協議用に現れるかを見る。体裁を変えても数値の整合は崩さない |

**太字の割合は、上限を決めて機械で見るのがよい。**たとえば公表用の本文は10％以下、表の中は25％以下とする。
**7万字を目視で直すのは現実的でない。**割合を測りながら、数値と結論に限って残す形で落としていく。

**受領を待たずに進められること　―　4件**

| | 作業 | 基準がどこに決まっても要るか |
|---|---|---|
| **1** | **表紙の日付を直す**（令和8年9月　→　提示の時点） | **要る** |
| **2** | **太字の整理**（公表用の本文を数値と結論に限る） | **要る**（前回計画書がどうであれ、76％は強調として機能しない） |

| **4** | **表記・用語の内部不統一の洗い出し**（算用数字・和暦・カッコ・単位・「障がい」の使い分け） | **要る** |

**この4件は、第9期計画書の体裁がどう決まっても捨てにならない。**
**逆に、用紙・書体・見出しの色・表の体裁（上記5の①②③）は、前回計画書を見るまで手を付けない。推測で `fmt.py` を書き換えると、受領後にもう一度やり直すことになる。**

## 9. やらないこと
