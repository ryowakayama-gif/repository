**検算：**目標別の得点を合計すると、令和6年度 189＋204＝393点、令和7年度 245＋218＝463点、令和8年度 227＋207＝434点となり、一覧表の合計欄と一致した。**目標Ⅳは2つの交付金で同一の指標であり、同じ得点が両方に計上される。**

### 3つの指標群は性格が違う

| 指標群 | 問われること | 得点の動かし方 |
|---|---|---|
| **（ⅰ）体制・取組** | 仕組みがあるか（計画に記載・要綱・会議体） | **計画に書けば翌年度に得点になる** |

**評価年度と交付年度は1年ずれる。**令和8年度交付金は令和7年度の取組に対する評価であり、**本計画に書いたことが最初に得点に現れるのは令和10年度交付金である。**

## 3. 県内の他市町村の取組状況 ― 確認できたこと・できなかったこと

### 確認できたこと

| | | 出所 |
|---|---|---|
| ① | **本町の県内順位は17位→8位→14位（33保険者中）** | 全国一覧表に記載 |
| ② | **令和7年度交付金の全国平均は435.0点。**当方の算定値434.99点と一致する | 公表情報および全国一覧表 |
| ③ | **市町村別の評価結果は厚生労働省が公表している**（「保険者機能強化推進交付金等の集計結果について」）。**したがって県内33保険者の得点は、原本さえ入手すれば算出できる** | 厚生労働省の公表 |
| ④ | **評価結果を自ら公表している市町村は全国に多数ある**（山形市・厚木市・笠間市・大田原市・上板町・四万十町ほか） | 各市町村の公表資料 |

### 確認できなかったこと

| | | 理由 |
|---|---|---|
| ① | **岩手県内33保険者の個別の得点・平均・分布** | **当方が保有しているのは全国一覧表から抽出した金ケ崎町の行のみで、他団体の行は保持していない** |
| ② | **岩手県の県平均と、県内での本町の相対的な位置（順位以外）** | 同上。**県平均が全国平均より高いか低いかが分からないため、「県内14位」が何を意味するかを説明できない** |
| ③ | **岩手県内で評価結果を独自に公表している市町村の有無** | **検索した範囲では確認できなかった。**他県には多数あるが県内の例は見つからなかった |
| ④ | **岩手県による市町村支援の取組状況**（都道府県分の評価指標） | 県の公表資料を確認できなかった |

**なお、厚生労働省のサイトは当方の作業環境のネットワークポリシーにより接続できないため、原本を自ら取得することはできない。**

### どうするか（2案）

| | 案 | 内容 |
|---|---|---|
| **Ａ** | **原本を入手して県内比較を行う**【当方の案】 | **全国一覧表の原本をご提供いただければ、県内33保険者の得点分布・県平均・本町の位置を算出し、第3回策定委員会にお示しする。他団体の個別名は用いず、分布（四分位・平均）と本町の位置のみを用いる** |
| Ｂ | 順位のみで報告する | 全国平均・全国順位・県内順位の3つで報告する。いずれも一覧表に記載があり確認済 |

**Ａを案とする理由は、「県内14位」という順位だけでは委員会でのご説明が成り立たないためである。**県平均が全国平均を下回っていれば県内14位は「県内では中位だが全国では下位」を意味し、県平均が全国並みであれば素直に中位を意味する。**どちらであるかによって、委員会に示すべき課題の重さが変わる。**

→ **《要回答52》として照会文書に追加した。**確認事項は51件→52件。

## 6. 交付金と計画の接続

**交付金の評価指標と、本計画の施策・成果指標は同じものを指している。**別冊の8に、交付金の目標ごとに対応する施策と成果指標を並べた。

| 交付金の目標 | 本計画の施策 |
|---|---|
| 推進 Ⅱ 公正・公平な給付 | **基本方針5(4) 介護給付適正化の推進**【法定記載事項】 |
| 推進 Ⅳ 成果指標群 | **基本方針1(3) 要介護1・2層の重度化防止**【重点課題1】 |
| 支援 Ⅰ 介護予防／日常生活支援 | **基本方針1(2)(4)**【重点課題3】 |
| 支援 Ⅱ 認知症総合支援 | **基本方針3（認知症施策推進計画）**【重点課題5】 |
| 支援 Ⅲ 在宅医療・在宅介護連携 | **基本方針4(1) 多職種の連携** |
| 推進 Ⅲ 介護人材の確保 | **第7章5 介護人材の確保**【重点課題4】 |

**すなわち、計画の進捗管理と交付金の自己評価を1つの表で行える。毎年度の評価を二重に行う必要はない。**

## 7. 留意点

- **他団体の個別データは扱っていない。**全国一覧表を用いた箇所は金ケ崎町（保険者番号033811）の行のみを抽出したものであり、比較の相手方は全国平均・全国順位・岩手県内順位に限っている。県内比較を行う場合も、他団体の個別名は用いず分布と平均のみを用いる。
- **交付金の充当先（どの事業に充てているか）は未確認である。**使途は地域支援事業等に限られるため、第6章で新設する5施策の財源を検討するうえで把握が必要。別冊の確認事項5に掲げた。
- **令和8年度に新設された「成果指向型配分枠」（配点100点）は、ご提供いただいた一覧表に含まれていない別枠の評価であり、本町の得点は不明である**《要回答8》。
