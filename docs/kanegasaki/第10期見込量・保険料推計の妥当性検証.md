## 4.【Ⅴ】対計画比がサービス別に開いている

全体はR6 99.2%・R7 104.1%。しかしサービス別には**11.5%〜967.4%**。

計画を大きく上回る：定期巡回617.7→**967.4%**／認知症対応型通所介護190.1→**237.4%**／福祉用具貸与118.8→**134.9%**／訪問リハ106.0→**133.1%**／短期入所生活介護119.4→**124.3%**／訪問看護94.1→**123.8%**／居宅介護支援114.5→**122.0%**

計画を大きく下回る：介護予防居宅療養管理指導59.3→**11.5%**／介護予防訪問リハ28.2→**32.1%**／短期入所療養介護（老健）25.3→**40.8%**／介護予防訪問看護57.3→**42.0%**／介護予防小多機95.1→**46.9%**／特定福祉用具購入費88.8→**52.8%**／地域密着型通所介護73.6→**66.5%**／小多機79.0→**83.0%**／GH87.3→**87.4%**

**総額が計画どおりでも内訳は大きく外れている。第10期はR8を基準にほぼ横ばい（R8→R11 +3.1%）で置いているため、この偏りが持ち越される。**

## 5. 正しい推計方法（手引きの手順を本町に当てはめる）

| | 手順 | 本町での適用 |
|---|---|---|
| ① | 基準年度は完結した最新年度 | **令和7年度**。R8は年度途中で基準年度にできない。R8は「R7実績×伸び」で置き、個別に手入力しない |
| ② | 出所の内的整合を点検 | **確認済**。利用者数×1人あたり給付費＝給付費が成立し、R6総給付費が年報と1円まで一致 |
| ③ | 対計画比を計画期をまたいで求める | **実施済**（第4章） |
| ④ | 一律の伸びにサービス別趨勢を一定割合だけ加える | R6→R7の伸びを反映割合50%程度・上限±20%程度で反映することを提案 |
| ⑤ | 0のサービスは実績を置く | **8サービス（6,367千円）を復元** |
| ⑥ | 趨勢に現れない要因を別に積む | GH定員・老健受入体制・小多機の職員半減・R9報酬改定 |
| ⑦ | 保険料まで通して比べる | その他給付費・地域支援事業費・調整交付金・所得段階別補正・収納率・準備基金をすべて入れる |
| ⑧ | 給付費1%が月額に何円効くかを先に求める | **本町は月額61.6円** |
