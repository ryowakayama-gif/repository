## 2. 評価

### (1) 9件の設計は妥当である

**9件はいずれも「町でなければ出せないもの」（当方の区分でいうＤ）に絞られている。**
44件の資料提供依頼一覧から、優先度が高く、かつ町の手でなければ出ないものを抜き出した形になっている。
**町にお願いする束としては、この粒度が実務的である。**

### (2) ★No.4は有用な新規の依頼である

**要介護認定の更新前後の状態変化（改善・維持・悪化）は、資料提供依頼一覧44件にも当方の照会文書70件にもない。**
これが得られると、次の3つが同時に裏づけられる。

| | 効く箇所 |
|---|---|
| **1** | **第2章4 要介護1の重度化**（更新時の移行率24.1％→57.0％）。本計画の中心となる事実の検証 |
| **2** | **第3章 介護予防ケアマネジメントの状態の維持・改善の割合**（令和6年度76.5％→令和7年度78.7％）。この上昇が事業の効果か対象者構成の変化かの判別 |
| **3** | **第9章3 成果指標**（重度・軽度に分けた調整済み認定率の監視） |

**当方の《要回答14》（要介護1から要介護2へ移行した人が移行前に利用していたサービス）より範囲が広い。No.4に統合してよい。**

### (3) この9件では足りないもの

| | 事項 |
|---|---|
| **1** | **《要確定》17件のご判断が1件も入っていない。**資料ではないため当然であるが、**別便で要る**（基金の取崩額・人口推計の基礎・成果指標の目標値ほか） |
| **2** | **至急2件のうち、基金の令和8年度末残高見込がNo.1の「残高見込表」に含まれるかが読み取れない。**年度と、積立額を含むかを明示したい |
| **3** | **資料提供依頼一覧44件のうち35件が入っていない。**うち**資-01（認知症高齢者の日常生活自立度別人数・県調査）**は《要回答51》に対応し、第2章3の系列の確定に効くため、9件に加えることをお勧めする |
| **4** | **第5（計画書の仕上げ）6件が入っていない**（はじめに・用語解説・老人福祉事業4件の実績ほか）。**ただし用語解説・事業所一覧・パブリックコメントの結果は他メンバー素案の資料編にあり、そちらで足りる見込み** |

**9件とも資料名のみであり、何年度分か、どの時点か、どの定義かが書かれていない。**
**このまま受け取ると、使えない粒度で届く可能性がある。**次の補足を付けることをお勧めする。
