## 2. ★至急《要回答4・39》　―　介護給付費準備基金

**出所：令和8年度介護保険特別会計予算書（町サイト `articles/2026022000048`／42頁）**
**一般会計は＜骨格予算＞と明示されているが、介護保険特別会計にその記載はない。**

| | 款項目 | 令和8年度 | 令和7年度 | 比較 |
|---|---|---|---|---|
| **取崩** | 7款2項1目 **介護給付費準備基金繰入金** | **21,581千円** | 28,420千円 | **▲6,839千円** |
| **積立** | 4款1項1目 **介護給付費準備基金積立金** | **460千円** | 320千円 | ＋140千円 |

### 令和8年度末の残高見込

| | 計算 | 額 |
|---|---|---|
| 令和7年度末残高（決算により確定） | — | **271,741,782円** |
| 令和8年度 取崩（当初予算） | ▲21,581,000円 | |
| 令和8年度 積立（当初予算） | ＋460,000円 | |
| **令和8年度末残高見込** | | **250,620,782円** |

### ★ただし、当初予算は実績と大きく離れる

**令和7年度で確かめられる。**

| | 当初予算 | 決算 | 差 |
|---|---|---|---|
| 取崩 | 28,420千円 | **13,092千円** | **▲15,328千円** |
| 積立 | 320千円 | **3,323千円** | ＋3,003千円 |
| **純減** | **28,100千円** | **9,769千円** | **▲18,331千円** |

**令和7年度は、当初予算の見込みより18,331千円多く基金が残った。**
**令和8年度も同じ方向に振れるとすれば、残高は250,620,782円を上回る公算が大きい。**
**したがって250,620,782円は下限に近い値として扱うのが妥当である。**

### 資料提供依頼一覧（確-11・指-56〜58）との差

| | 一覧 | 当方（当初予算による） | 差 |
|---|---|---|---|
| 令和8年度 取崩 | 23,650,000円 | **21,581,000円** | **2,069,000円** |
| 令和8年度 積立 | （含めていない） | **460,000円** | 460,000円 |
| **令和8年度末残高見込** | 248,091,782円 | **250,620,782円** | **2,529,000円** |

**一覧の23,650,000円は当初予算の額ではない。**出所の確認を要する（補正後の額か、別の見込みか）。
**保険料への影響は、取崩額1,000万円が月額約60円であるから、2,529,000円の差は月額約15円である。**

**いずれにせよ、第10期で9,000万円を取り崩す余力はある。**250,620,782円から9,000万円を取り崩しても**160,620,782円**が残る。

### 第9期3か年の取崩し

| | 令和6年度 | 令和7年度 | 令和8年度 | 計 |
|---|---|---|---|---|
| 取崩 | 2,799千円 | 13,092千円 | **21,581千円（当初予算）** | **37,472千円** |

**計画は3年で9,000万円であった。当初予算ベースでも41.6％にとどまる。**
**「第9期の取崩しが進んでいない」という素案 第8章5の見立ては、この数字でも裏づけられる。**

**なお、これは当初予算であって決算見込ではない。**
**至急《要回答4・39》は「積立額を含めた令和8年度末の残高見込」をお尋ねするものであり、取り下げない。**
**ただし、町のご回答を待たずに第8章の試算を進められる状態にはなった。**
