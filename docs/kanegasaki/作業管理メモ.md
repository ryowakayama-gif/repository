## 3　年度・時点の表記の原則

### 3.1　資料には5つの時点系列がある

| 資料 | 基準日 | 「令和7年度」が指す期間 |
|---|---|---|
| 住民基本台帳 | **各年3月31日現在** | 令和7年3月31日 |
| 介護保険事業状況報告　様式1（被保険者数・認定者数） | **各月末現在** | 令和8年3月31日 |
| 介護保険事業状況報告　様式2（給付費・受給件数） | **審査月** | 令和7年5月〜令和8年4月審査分 |
| 社人研　将来推計人口 | **各年10月1日現在** | 令和7年10月1日 |
| 第9期計画書の認定率 | **各年9月末** | 令和7年9月30日 |

最も早い時点と最も遅い時点で **13か月の開き** がある。

### 3.2　表記の原則

| | 原則 | 例 |
|---|---|---|
| ① | **人口（住民基本台帳）は日付で書く。「令和7年」「令和7年度」は使わない** | 令和7年3月31日現在 |
| ② | **被保険者数・認定者数は年度末と日付を併記する** | 令和7年度末（令和8年3月31日） |
| ③ | **給付費・受給件数は年度と集計期間を併記する** | 令和6年度（令和6年5月〜令和7年4月審査分） |
| ④ | **将来推計は年度と西暦を併記し、社人研の基準日を注記する** | 令和22年度（2040年） |
| ⑤ | **第9期計画書から引く値は、計画書の時点をそのまま書く** | 令和5年9月末　16.4％ |
| ⑥ | **時点の異なる値を同じ列に並べない。** やむを得ず並べるときは列見出しに時点を書く | — |

### 3.3　あわせて留意する3点

1. **給付費の集計期間**
   介護保険事業状況報告の年度は **審査月の5月から翌年4月まで**。
   4月〜翌年3月で集計すると年報と一致しない（令和6年度で2,333千円の差）。
   検証：令和6年度の年報 様式2の総計 **1,185,811,534円** ＝ 月報の令和6年5月〜令和7年4月審査分の合計（1円まで一致）。

2. **月報の様式変更（令和7年5月審査分から）**
   - 居宅介護支援・介護予防支援が「居宅（介護予防）サービス」の内数から**別掲**に
   - 短期利用の有無による細分が追加（小規模多機能型居宅介護（短期利用以外）等）
   - 名称変更：福祉用具購入費→特定福祉用具販売、住宅改修費→住宅改修
   - **総計は前後で比較できるが、居宅サービスの小計はそのままでは比較できない**

3. **第1号被保険者数の2系列**
   月報には同じ月末の値が2か所に出る。
   - 当月分月報の「当月末現在」欄　… 令和8年3月31日 **4,683人**
   - 翌月分月報の「前月末現在」欄　… 令和8年3月31日 **4,681人**
   令和6年度の年報 様式1「当年度末現在」は **4,678人** で、**後者の系列が年報と接続する**。

### 3.4　分析の性格の切り分け

- 各章の冒頭で「本章は**現状**（○年○月○日時点）を扱う」「本章は**推移**（○年〜○年）を扱う」と宣言する
- 推移を示す表には、**期間の両端の年月日を列見出しに書く**
- 同じ節の中で現状と推移を混ぜない
