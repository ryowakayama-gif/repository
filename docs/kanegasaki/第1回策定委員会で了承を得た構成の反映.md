## 1. 基本理念　―　確定した

**別葉の基本理念（案）は次の3行である。**

> **自分らしくいきいきと健やかに**
> **住み慣れた場所で　つながり　支えあい暮らせるまちづくり**
> **〜　一人ひとりの生きがいと幸せを　地域共生の力で支える　〜**

### (1) 従前との違い

| | 文言 |
|---|---|
| **第8期** | 地域で支え合い、いきいきと健やかに暮らし続けられるまちづくり　〜地域包括ケアシステムの更なる深化をめざして〜 |
| **第9期** | 同上　〜多様な人との連携で地域包括ケアシステムの更なる深化をめざして〜 |
| **当方の案**（従前の素案5-2） | 同上　〜認知症になっても、介護が必要になっても、住み慣れた地域で暮らし続けられる町へ〜 |
| **確定（別葉）** | **自分らしくいきいきと健やかに／住み慣れた場所で　つながり　支えあい暮らせるまちづくり／〜　一人ひとりの生きがいと幸せを　地域共生の力で支える　〜** |

**当方の案は「本文は継承し副題のみを改める」ものであった。確定した案は本文そのものを組み替えている。**
継承されたのは「いきいきと健やかに」「支え合い」「住み慣れた」の3つであり、**冒頭に「自分らしく」が置かれた。**

### (2) 計画の構成との対応　―　素案に書いた

| 理念の語 | 対応する章・方針 |
|---|---|
| **自分らしく** | **認知症基本法が掲げる「新しい認知症観」**（第6章 基本方針3） |
| **つながり　支えあい** | **基本方針4（地域共生社会に向けた地域包括ケアシステムの深化）** |
| **住み慣れた場所で** | **介護保険法第5条第3項および基本方針2（在宅生活の支援）** |
| **地域共生**（副題） | **基本方針4。**あわせて**認知症基本法第1条の共生社会**（別冊2の第2層） |

### (3) 不整合3件が解消した

**従前、基本理念の文言が成果品のあいだで3通りあった。**

| 成果品 | 従前の文言 |
|---|---|
| 計画素案 5-2・第2回策定委員会資料 | **〜認知症になっても、介護が必要になっても、住み慣れた地域で暮らし続けられる町へ〜** |
| **別表2（大目標）・概要版の図** | **「支え合い　健やかに　自分らしく暮らせるまち　かねがさき」** |
| **別冊2（共生社会の実現の欄）** | **同上** |

**確定した文言に揃えたため、3通りが1つになった。**
**別冊2については、副題の「地域共生」が共生社会の実現を直接に掲げている旨を加えた。**

### (4) 第2回策定委員会の判断事項Ⅴを書き替えた

**従前は「副題（案）でよいか」であった。**基本理念が町長・副町長の協議を経て確定したため、
**「第1回策定委員会にお示しした案のとおり確定してよいか」に改めた。**
