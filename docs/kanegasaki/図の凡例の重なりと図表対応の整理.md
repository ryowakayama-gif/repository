# 図の凡例の重なりと、図と表の対応の整理

令和8年9月25日

**ご指摘2件（図5で金ケ崎町の点数と凡例が重なっている／図があるものに対して表があったり文章だけだったりばらばら）は、いずれもそのとおりであった。**規則を決め直し、機械点検を加えた。

---

## 1. 凡例と値ラベルの重なり

### 何が起きていたか

**凡例をプロット領域の中（右上・右下など）に置いていた。**棒の長さや値ラベルの位置はデータによって変わるため、**置く場所を決め打ちにすると、いずれ重なる。**図5では推進Ⅰの「70」が凡例の裏に隠れていた。

### どう直したか

**凡例はプロット領域の外（軸の下）に中央揃えで置くことにした。**

| 助数 | 用途 |
|---|---|
| **`LEG(ax, ncol, gap)`** | 1つの軸の図。**軸の下に置く** |
| **`LEGF(fig, ax, ncol)`** | **2段組みの図。図全体の下に置く** |

**凡例のある図10点すべてを置き換えた。**軸の中に凡例を置いている図はなくなった。

### 再発しないようにした

**`figs.py` に重なりの自動検出を入れた。**図を保存する直前に、凡例の位置と、値ラベル・棒・線の位置を突き合わせる。**重なりがあれば `python3 figs.py` が終了コード1で止まる。**

### あわせて直したもの

**図23（介護職員の採用・離職と昨年比）で、1つの図の中に赤が2つの意味で出ていた。**左の段は「離職＝赤」、右の段は「前年を下回る＝赤」であった。**右の段を淡い青1色に改め、下回る系統には `▲` を付し、その意味を図の中に書いた。**

## 2. 図と表の対応

### 何が起きていたか

**図の数値が表にあるものと、図だけのものが混ざっていた。**

| 文書 | 図 | 状況 |
|---|---|---|
| **計画素案** | 図15（県内33保険者の分布） | **分布の数値が表になく、本文に「中央値390.0点」とあるだけ** |
| | 図21（難聴20点の内訳） | **ア〜エの配点・全国平均が表になく、本文に書かれているだけ** |
| | 図2・図5・図16・図25 | **本文段落の直後に置かれ、表から離れていた** |
| **第2回策定委員会資料** | 図2（認定率の推移） | **認定率の推移の表がない** |
| | 図4（県内の分布） | **分布の表がない** |
| | 図5（目標別の得点） | **目標別の表がない**（5(3)の表は交付金別で、県平均の列がない） |
| | 図6（認知症総合支援の内訳） | **内訳の表がない** |

### 規則を決めた

**数値は表で示し、図はその表を読みやすくするために添える。**

1. **図は、表・その出典行・他の図の直後に置く。本文段落の直後に図を置かない。**
2. **図の数値は、直前の表に載っていること。**表にない数値を図だけで示さない。
3. **表があっても図を置かないことはある**（図は本文5ページに1点程度）。**逆は許さない。**

### 直した内容

**表を6つ新たに置いた。**

| 文書 | 新たに置いた表 |
|---|---|
| **計画素案 3-5** | **岩手県内33保険者の分布**（最大・第3四分位・中央値・平均・第1四分位・最小） |
| **計画素案 基本方針3(1)** | **難聴20点の内訳**（ア〜エ／配点／全国平均／本町／県内で得点している保険者数） |
| **第2回策定委員会資料 4** | **要支援・要介護認定率の推移**（本町・岩手県・全国／Ｒ4〜Ｒ8） |
| **同 5(3)** | **岩手県内33保険者の分布** |
| **同 5(4)** | **目標別の得点**（本町／岩手県平均／全国平均／町−県平均／県内順位） |
| **同 5(5)** | **認知症総合支援100点の内訳**（6項目／配点／本町／全国平均／差） |

**あわせて図4点（素案 図2・図5・図16・図25）を、本文段落の直後から、対応する表の直後へ移した。**

**新しい表も他団体の扱いは従前どおりである。**県内については**分布（最大・四分位・中央値・平均・最小）、県平均、県内順位、得点している保険者数のみ**を用い、**個別の保険者名と個別の得点は用いていない。各表の出典行にその旨を明記した。**

## 5. 留意点

- **重なりの自動検出は、凡例と「値ラベル・棒・線」の重なりを見るものである。**軸ラベルどうしの重なりや、図の外の文字の重なりは見ない。
- **「図の数値が直前の表にあるか」は機械では確かめていない。**図はPNGであり、数値を読み取れないためである。**配置の規則（図は表の直後）で担保し、数値の一致は目視で確かめる。**
