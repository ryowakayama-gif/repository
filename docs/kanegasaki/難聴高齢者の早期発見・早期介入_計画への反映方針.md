# 難聴高齢者の早期発見・早期介入　―　計画への反映

令和8年9月25日

交付金（介護保険保険者努力支援交付金 目標Ⅱ（ⅰ）3）の**難聴高齢者の早期発見・早期介入20点が3年連続で全項目0点**であり、全国平均との差（▲6.9点）が本町の最大の弱点であることを受けて検討し、**町のご決定により計画素案・委員会資料・別冊・照会文書に反映した。**

## 2. なぜア・イの10点にとどめるか

| 根拠 | 内容 |
|---|---|
| **県内の実勢** | **岩手県内33保険者のうち12保険者がア・イの10点を取得。ウ・エの取得は県内で0である** |
| **全国の実勢** | **ウ0.73点・エ0.24点。**ア3.44点（全国の69％が得点）・イ2.44点（同49％）。**20点満点は全国1,741保険者中83団体（4.8％）** |
| **効果** | **認知症総合支援は44点→54点となり、岩手県平均49.3点を上回る。本町が県平均を下回る唯一の目標がこれである**（県内25位／33） |
| **実行可能性** | **ア・イは新たな予算を要さない。ウは言語聴覚士、エは記録の仕組みを要する** |

**この10点は、別冊で整理した「計画に書くことで取れる51点」とは性質が異なる。51点は記載のみで足りるが、10点は令和9年度からの実施を伴う。**計画素案3-5・別冊5・委員会資料5(4)のいずれでも、**分けて示した。**両方を得れば434点→495点となる。

## 3. 3つのモデルと本町の受け皿

| **②サービスC型**（竹田市・新潟県） | **町独自の短期集中型通所サービスが既にある**（基本方針1(3)） | **地域リハビリテーション活動支援事業が「実施無」**。理由が**支援体制がない・リハ専門職の人手不足** | **中期の本命。第10期は協議の場に言語聴覚士会・耳鼻咽喉科医を加えるまで** |

## 10. 留意点

- **ア・イは計画への記載だけでは足りない。**令和9年度の取組が令和10年度交付金で評価されるため、**令和9年度の当初から実施しなければ計画期間の最初の評価に間に合わない。**
- **参照した有病率と他団体の実績値は、公表資料の本文を確認できていない**（《要回答54》）。環境のネットワーク設定を広げていただければ直接確認できる。
- **ウ・エを置かないことは、残り10点を取らないという判断である。**県内で取得例がなく全国平均も0.73点・0.24点であることによる。**第11期の検討事項として9-2に残すことは可能である。**
