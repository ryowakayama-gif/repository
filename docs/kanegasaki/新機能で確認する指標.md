## 3　レーダーチャート18指標

**地域の概況（需要）**：65歳以上高齢者割合／2040年に向けた将来推計人口増加率／高齢独居及び高齢夫婦のみ世帯率／**調整済み認定率**／介護サービス受給率／第1号被保険者1人あたり保険給付月額

**サービス提供体制（供給）**：**介護サービス自給率**／要支援・要介護者1人あたり施設サービス入所定員／同 居住系サービス入所定員／人口10万人あたり居宅（福祉系）事業所数／同（医療系）／同 居宅介護支援事業所数

**医療介護連携**：在宅死亡者数（自宅）／入院時情報連携加算・退院退所加算算定率（居宅介護支援＝入退院支援）／**協力医療機関連携加算算定率**（施設・居住系＝日常の療養支援）／看取り介護加算・ターミナルケア加算算定率（看取り）／緊急時訪問看護加算算定率（急変時の対応）／認知症（専門ケア）加算算定率

留意：**分子となる利用者・事業所が存在しない場合、データは0として偏差値に含まれる。**
事業所数が僅少な本町では偏差値が実態より低く出るため、**バックデータ（実数値）を必ず併読する。**
医療介護連携は2025年のデータのみ。

## 4　事業所別指標は事業者アンケートを一部代替できる

取得できるもの：**事業所別の従事者数・利用者数・回転率（通所系）・定員充足率（施設居住系）の5か年推移**と
**「5年間連続減少アラート」**（5年連続で減少が続く事業所に○）。

| アンケートで把握予定 | 代替 |
|---|---|
| ①受入可能量 | **不可** |
| ②稼働率 | **可**（回転率・定員充足率） |
| ③従事者数と充足状況 | **従事者数は可**、充足感は不可 |
| ④テクノロジー導入状況 | **不可** |

→ **先に事業所別指標を取得し、アンケートの設問を①③④の3点に絞る。**回収率が上がり町の負担も減る。

## 5　将来推計機能で判明したこと（操作説明より）

- **被保険者数のデータソースは3択**：①「日本の地域別将来推計人口」　②同を補正したデータ
  （性年齢階級別／前期・後期高齢者別の2種）　③独自データ。**《要確定1》の選択肢を3択に改めた。**
  「推計人口と第1号被保険者数との比較結果」と補正内容のExcelをダウンロードできる。
  社人研R7.10.1の4,766人に対し実績4,681人（R8.3.31）で85人差があり、**②を選ぶ余地がある。**
- **自然体推計の認定率の扱い**：計画期間（R9〜11）は**近年の変化の傾向が継続すると仮定**、
  **令和12年度以降はR11の認定率・サービス利用率が変化しないと仮定**。素案の補正Ｄの記述を合わせた。
- 将来推計機能は**令和6〜8年度の介護保険事業状況報告**に基づく。
