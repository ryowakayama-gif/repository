# 外部レビュー（重点再レビュー・令和8年10月24日）の指摘への対応

金ケ崎町　高齢者福祉計画・第10期介護保険事業計画・認知症施策推進計画

**令和8年10月24日**

対象：成果物とエビデンスの一式（令和8年10月24日）に対する重点再レビュー（S10件・A17件・B6件）。
主題は、**要支援・要介護の区分の取り違え**と、**データの母集団を超えた原因の断定**である。

---

## 0. 結論

**S10件のうち、当方の記述で直せるもの9件を直した**（S-10は既に試算表示を維持しており確認のみ）。
**原因の断定は、町の帳票（帳票3-7の全区分、認定者の出入りの集計、見える化の抽出条件）がそろうまで書かない形に改め、確認事項に№71・72を加えた**（72件・Ｄ32件）。
修正した文書は、計画素案（協議用・公表用）、第2回策定委員会資料・想定問答集、確認事項（素案の附・照会文書・区分）、WBS（作業管理メモ・工程表）、交付金の別冊1、別表2・別表6。

**レビューが「15.9％と13.2％の2.7ポイント差」とした点は、素案の出典行で原因が分かった。**合計（Ｂ5-a）は**町の人口構成**を基準とした系列、重度・軽度（Ｂ6-a・Ｂ6-b）は**全国の人口構成**を基準とした系列であり、足し合わせるものではない。指標名にその旨を明記し、抽出条件そのものは№71で確かめる。

## 1. 優先度Ｓの対応

| ID | 指摘 | 対応 |
|---|---|---|
| **S-01** | 「軽度から中度」 | **「要支援層」「要介護1・2層」「要介護3〜5層」に統一し、区分の定義表（見える化の軽度＝要支援1〜要介護2、交付金の軽度＝要介護1・2など）を協議用0-3・公表用2-4・第2回資料4に置いた。**要介護1→2は、いずれの定義でも軽度の区分の中での移行であり、それ自体は認定率を上げないと明記 |
| **S-02** | 57.0％の確定扱い | **53.5〜57.0％の幅で表示**（表は「要介護2・3へ移った割合」と「その他を含めた場合」の2列に、図は要介護2・要介護3・その他（区分確認中）の積上げに作り直した）。**成果指標№1の名称を「要介護1の更新時に要介護2以上へ移った割合」とし、目標は区分の確認後に設定（暫定45％以下）** |
| **S-03** | 要介護2の増加の原因の断定 | **「要介護2の増加が要介護1からの移行によるものであることが実測で確認できた」を削除。**帳票は更新申請に限った集計であり、断面の人数の増加（148人→184人）をこの移行だけで説明できない、出入りの集計（№72）で確かめる、とした |
| **S-04** | 認定率の上昇の寄与の分解 | **「0.8ポイントのうち0.6ポイント（4分の3）」の分解を削除。**要介護1→2は認定率を変えないことを明記 |
| **S-05** | 4.4＋8.8≠15.9 | 上記0のとおり。**指標名に基準人口を明記**（協議用・公表用・別表6・問答集） |
| **S-06** | 別表2で要介護1・2の施策に予防通所リハ | **要介護1・2は介護給付（通所・訪問リハ、訪問看護、居宅介護支援、地域ケア会議）、要支援1・2は予防給付・総合事業と分けた。**協議用8-7の予防通所リハの根拠も、運動器の該当率ではなく実績の推移に改めた |
| **S-07** | 別表2の「通いの場（週1回以上）41か所」 | **オレンジカフェの令和5年度の数の混入であった。**「通いの場13か所・152人（週1回以上6か所・65人）／オレンジカフェ41→53か所（別の事業）」と書き分けた |
| **S-08** | 交付金の長期を「3年」・町の割合と同じ方向 | **4年間（令和3年1月→令和7年1月）に訂正。**国の評価は介護保険総合データベースで性・年齢・要介護度を調整したもので、町の更新時の割合とは母集団・期間・算定方法が異なる関連観察であり、同じ傾向・原因とは断定しない、とした（別冊1・協議用・公表用） |
| **S-09** | 「取組の後退ではない」等 | **評価の結果と原因の解釈を分けた。**「配点の改定による増減」は事実として残し、「取組の後退ではない」「低下は本町側の要因」は、順位は施策の良し悪しを単独で示さない（国の注意書き）に改めた |
| **S-10** | 保険料を確定扱いしない | 既に試算表示を維持（確認のみ） |
