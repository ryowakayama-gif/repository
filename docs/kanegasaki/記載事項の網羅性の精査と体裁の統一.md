## 2. 構成の対比から加えた3事項

**他団体の協議用素案の目次と本町の素案の目次を節の単位で突き合わせ、本町にない節を洗い出した。そのうえで、原典に照らして本町にも必要と判断したものだけを加えた。**

| 加えたもの | 必要と判断した理由 | 箇所 |
|---|---|---|
| **公費による低所得者の保険料軽減** | **素案の第1段階0.455・第2段階0.685・第3段階0.690は公費軽減後の値であるのに、軽減の説明がなかった。**軽減前は0.50・0.75・0.75である。**本町では3か年延べ4,159人（第1号被保険者の29.2％）が対象になる** | **第8章6** |
| **24時間対応の在宅サービスの確保** | **国の基本指針が求めている。**本町の定期巡回・随時対応型訪問介護看護は第9期に給付費で対計画比967.4％と、計画を最も大きく上回っている。**24時間対応の需要が実在する** | **第7章2** |
| **介護保険法第117条が定める記載事項との対照表** | **法定記載事項の網羅性を計画書の中で示せる。**第5章1は基本指針との対応を示しているが、法との対応を示していなかった | **第5章1** |

**加えなかったもの**

| 他団体にあるが本町に置かないもの | 理由 |
|---|---|
| **サービスの通常の事業実施地域** | **他団体は3町からなる広域連合であり、町をまたぐサービス提供の範囲が論点になる。**本町は1町1圏域であるため同じ論点は生じない。**ただし訪問系の自給率は55.93％まで下がっており（第7章2）、町外事業所の所在地の把握は課題として残る**《要回答19》 |
| **施設・居住系の入退所の状況** | **在宅生活改善調査・居所変更実態調査を本計画では実施していない（第9章2で第11期に向けて位置づけ済）。**データがないまま節だけを置かない |
| **管内保険者の保険料の比較** | **《制約》県内の個別の保険者名および個別の得点・保険料は用いない。**分布のみで示す方針を継続する |
| **施策の採否・見直し基準** | **本町は別表2（施策体系表）でSTEP1〜5の形により同じことを行っている**（令和8年9月28日作成） |
