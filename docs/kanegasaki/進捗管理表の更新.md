### 律速が変わったこと

前版で最長の制約経路にあった**《要回答1》（見える化Ｂ7の認定者数の定義）は、Ｂ7の解説により出典・集計時点・対象が判明し、《要回答46》の整理に吸収された。** その《要回答46》も、将来推計の推計方法を再現した検証（`将来推計の推計方法の再現と検証.md`）により解決している。

**残る律速2件の性質は異なる。**

- **《要回答35》** ― **資料のご提供だけで解決する。** 令和8年度の月報（令和8年5月月報以降）をいただければ、当方が行っている令和8年度の置き直しが実績に置き換わり、**保険料月額245円の論点がそのまま消える。** 費用も判断も要しない。
- **《要回答3》** ― **別表2（施策体系表）の唯一の着手条件。** 4項目のうち稼働率は事業所別指標、従事者数は介護人材実態調査で把握済であり、残るのは受入可能量とテクノロジーの導入状況の2項目。短時間のヒアリングで足りる。

## 4. シート構成

| シート | 内容 |
|---|---|
| **00_サマリ** | 大分類別の進捗（工数加重）／状態別のタスク数／この版で変わったこと／読み方 |
| **01_WBS** | **60タスク。**大分類・WBS番号・仕様書の項・作業名・成果物・段階・進捗率・状態・前提制約・工数・備考。オートフィルタとデータバーつき |
| **02_確認事項** | **12件（《要確定》《要回答》の主要なもの）。**優先・止まっている作業・関係WBS・状態。**解決したものは緑で示す** |
| **03_次の優先順位** | 10件。順位・工数・理由・着手条件 |
| **04_成果物一覧** | 18件。規模・段階・備考 |

集計はすべて数式（COUNTIF／SUMIF／SUMPRODUCT）で01_WBSを参照しており、**01_WBSの進捗率を書き換えればサマリが追随する。** `fullCalcOnLoad` を立ててあるため、開いた時点で再計算される。

## 5. 留意点

- **工数（人日）は当方の想定であり、契約上の工数を示すものではない。**
- **進捗率は工数で加重した加重平均。**単純平均ではない。
- **「着手不可」は作業速度の問題ではなく、確認事項が解けるまで論理的に進められないもの。**現在2件・8人日（別表2と意見聴取）。
- **他団体のデータは一切含まない。**全国一覧表を用いた箇所は金ケ崎町（保険者番号033811）の行のみを抽出している。
