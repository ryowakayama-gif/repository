## 2. この7指標から読み取れること

### 第一に、高齢者の就業・社会参加の受け皿が縮小している

- **④シルバー人材センターの受託件数 750件 → 726件（▲24件・▲3.2%）**
  8指標の中で**唯一、現状値を下回った**指標。目標950件に対し進捗率はマイナス12.0%。
- ③老人クラブは第8期に29団体の目標に対し21団体（▲8団体）となり、第9期はその21団体を維持することを目標に置き直したもの。会員数は令和3年度1,064人→令和5年度802人（3年で262人・24.6%減）。

→ **どちらも「支援の枠組みはあり、目標も掲げていて、それでも減っている」。支援の額や方法ではなく、参加の形そのものを見直す必要がある。**

### 第二に、認知症サポーターは量的拡大の余地が小さい

累計3,946人は町の人口15,085人の**26.2%**。人口の4人に1人が受講済み。
目標4,426人には3年で700人（年233人）が必要だったが、実績は2年で220人（年110人）。
一方で**ステップアップ講座の修了者は0人**（交付金でも3年連続0点）。

→ **第10期は受講者数を増やすことより、受講者が実際に活動につながる仕組み（チームオレンジ等）に重点を移す。**

### 第三に、成果が出た2指標には共通点がある

| 達成した指標 | 町が直接はたらきかける相手 |
|---|---|
| ⑤配食サービス 0→3事業者 | 民間事業者（明確） |
| ⑦生活支援サポーター 84→109人 | 研修受講者（明確） |

| 未達の指標 | 町の取組と結果の間に介在するもの |
|---|---|
| ④シルバー人材センター受託件数 | 発注者（企業・個人）の判断 |
| ③老人クラブ団体数 | 住民の参加意思 |
| ⑥認知症サポーター | （量的飽和） |

→ **第10期の目標設定では「町が動かせる指標」と「結果として現れる指標」を分けて置く。** シルバー人材センターなら、会員数・就業延人員・受託件数の3つを併記し、どこで詰まっているかが分かるようにする。

### 第四に、⑧は目標を達成する見込みだが、それは交付人数の目標である

121人に12,460,000円（1人あたり102,975円）を交付し、R8末には137人で目標134人を上回る見込み。
**しかし同じ期間に、町内の介護職員数は昨年比97.1%と減っている**（介護人材実態調査）。

→ **交付人数だけでなく定着率を併せて把握しなければ、事業の効果は判断できない。** 第9章3の指標を「交付人数（累計）と定着率」に改めた。

### 参考：⑤配食サービスの意味

令和元年に1事業者が撤退し**0から出発**して3事業者まで回復。目標を50%上回る。第9期で最も成果が出た指標。
第10期は箇所数ではなく、**利用者数と提供体制の安定**を目標に置く。
