## 2. 図の規則

**第1回資料の図1〜16から読み取った規則である。**図はmatplotlibで生成したPNGを貼る（Excelの貼り付けではなく、データから再生成できる形にする）。

### 配色　―　1つの図の中で、色は1つの意味しか持たない

**比較図**（本町・県・全国などの系列がある図）**では、系列の色を条件で変えない。**

| 系列 | 色 |
|---|---|
| **金ケ崎町** | **#C00000（赤）** |
| **岩手県平均** | **#ED7D31（オレンジ）** |
| **全国平均** | **#A6A6A6（グレー）** |
| **配点・満点などの背景の帯** | **#F2F2F2**（枠 #D9D9D9） |

**「県平均を下回る項目だけ赤にする」は禁止**である。凡例と棒の色が食い違う。**下回っていることは色ではなく `▲` と注記で示し、その意味を図の中に書く。多系列の図では、値ラベルを系列の色にする。**

**内訳図・順位図**（本町のデータだけの図）**では、赤が何を指すかを図中か出典行に1文で書く。**

| 用途 | 色 |
|---|---|
| **注目させたい項目** | **#C00000（赤）** |
| **主** | **#2E75B6（青）** |
| **背景的な項目・参考** | **#BDD7EE（淡い青）** |
| **減少・対象外** | **#A6A6A6（グレー）** |
| **値ラベル** | **#1F3864（濃紺・太字）** |
| **基準線・参照値** | **#ED7D31（オレンジ・破線）** |

**閾値で塗り分ける場合は2段階までとし、オレンジは使わない**（オレンジは基準線と県平均に予約している）。

### 形

| 用途 | 形 |
|---|---|
| **順位・項目間の比較** | **横棒**（`barh`・`invert_yaxis()`で上から並べる） |
| **推移（3〜5時点）** | **折れ線**（系列が3つまで）または**縦棒**（単一系列） |
| **満点に対する到達度** | **薄い帯（配点）の上に実績の棒を重ねる** |
| **等間隔でない年の推移** | **横軸を数値にする**（Ｒ12・Ｒ15・Ｒ17…をカテゴリにすると形が歪む） |

### 規則

1. **値ラベルを必ず付す。**軸目盛りを読ませない。
2. **軸ラベルに単位を（）で入れる。**「得点（800点満点）」「認定率（％）」
3. **基準値・参照値は破線＋文字ラベル**で示す。
4. **凡例は系列が2つ以上のときのみ。**棒や線に重なる位置には置かない。重なるときは凡例を消し、図中に直接文字を置く。
5. **背景は白、枠線あり、目盛線は用いない**（横棒のみ縦の目盛線を #E6E6E6 で薄く）。
6. **縦軸を0から始めない場合は、出典行にその旨を書く。**
7. 書体は **IPAGothic**（本文のBIZ UDPゴシックに近いゴシック体）。出力は **dpi200**。

### 置き方

- **キャプションは図の上に【図N】として置く**（11pt太字 #1F4D78）。番号は文書内の連番で、`FIG()` が自動で付す。
- **出典は図の下に8ptで置く。**出典には**その図から読み取ってほしいことを1文添える。**
- **幅は12〜15cm。**本文幅（17.0cm）いっぱいにはしない。
- **キャプション・図・出典が別ページに分かれないようにする。**`FIG()` がキャプションと図の段落に `keepNext`、図の段落に `keepTogether` を付す。改ページを手で入れる必要はない。
- **図は、その図が説明する表または段落の直後に置く。**出典は「資料：上表に同じ。」で足りる場合が多い。
- **数の目安は本文5ページに1点程度。**計画素案（120ページ）は25点、策定委員会資料（29ページ）は8点。

## 3. 文章の規則

| | 規則 |
|---|---|
| **変更履歴** | **書かない。**「第○版からの変更」「本文素案への修正履歴」は成果品に載せない |
| **分析の語** | **業務仕様に記載のある分析の語のみを用いる。**手法名や内部の作業名は載せない |
| **他団体のデータ** | **全国一覧表は金ケ崎町（保険者番号033811）の行のみを抽出する。**県内比較を行う場合も、**個別の団体名と個別の得点は出さず、分布（最大・四分位・中央値・平均・最小）と本町の順位のみ**を用いる。図の出典にもその旨を明記する |
| **他団体のデータの混入** | **大雪地区広域連合のデータが混ざっている場合は金ケ崎町では用いない** |
| **未確定の箇所** | **推測で埋めない。**`【　】`（数値未確定）・`【案】`（当方の案）・`《要確定》`（町の判断）・`《要回答》`（照会中）で示し、件数を0-1で集計する |
| **断定** | **確認していないことは確認していないと書く。**出所を確認できていない値は《要回答》を立てる |

## 4. 委員会資料の構成

**第2回の構成（第1回を踏襲したもの）。**

| 節 | 内容 |
|---|---|
| **1** | 本日の次第（議題・参照先・所要時間） |
| **2** | 前回からの経過 |
| **3** | 計画素案の全体像（章立て・前期計画からの変更） |
| **4** | **現状と住民ニーズ　―　計画の土台となる「事実」**（番号を振った一覧＋図） |
| **5** | 前期計画の評価（成果指標・財政・**交付金による外部評価・県内の状況**） |
| **6** | 基本理念・重点課題・施策の体系 |
| **7** | 計画期間中の施策（新設施策・施策と指標の対応・財源の制約） |
| **8** | 認知症施策推進計画としての位置づけ |
| **9** | （参考）見込量・給付費・保険料の途中経過 |
| **10** | **本日ご判断・ご意見をいただきたい事項**（1件ごとに　ご判断いただく内容／当方の案／根拠・事実／影響　の4行の表） |
| **11** | 今後のスケジュールと次回にお諮りする事項 |

**原則。**
- **節の見出しは「何章の何を扱うか」と「その節の結論」を「―」でつなぐ**（例：「交付金による外部評価　―　体系と本町の位置」）。
- **判断を求める事項は必ず最後の節に集め、本文中では「本日の判断事項Ⅰ」のように参照する。**
- **ページ区切りは節の単位で入れる**（`doc.add_page_break()`）。

## 5. 実装

| ファイル | 内容 |
|---|---|
| **`fmt.py`** | 体裁のヘルパー。`P` `H1` `H2` `H3` `BUL` `TBL` `SRC` `FIG` と、目次（`TOC_HERE` `BODY_HERE` `BUILD_TOC`）・ページ番号 |
| **`figs.py`** | 図の生成。配色・書体・保存の規則を定数と `_save` `_lab` に集約し、図ごとに関数を1つ置く |
| **`figs_soan.py`** | 計画素案の図。配色・書体・保存の規則は `figs.py` から取り込み、図の中身だけを書く |
| **ビルド** | `{ cat fmt.py; echo; cat ch_XXX.py; } > mkf_XXX.py && python3 mkf_XXX.py`（`ch_XXX.py` は `fmt.py` の関数を前提に書く） |
| **点検** | **`.claude/skills/docx-design/check_docx.py` を実行する**（図・表・検算・記号・参照・文言・図の素）。指摘が残ったまま提示しない |
| **目視** | PDF化して、**①図の凡例と棒の色が合っているか　②図の文言が直前の表・段落と合っているか　③表の数値と本文の数値が一致しているか　④図と出典が別ページに分かれていないか**を見る |
