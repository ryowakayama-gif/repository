## 4. 将来推計の方法　―　見える化システムとの整合

### (1) 線形補間そのものは妥当。当方も同じ方法

**社人研「日本の地域別将来推計人口」は5年刻み（2025・2030・2035・2040・2045・2050年）でしか公表されない。**このため**令和15年度（2033年）・令和30年度（2048年）は補間が避けられない。**当方の素案2-7(2)も「前後の年度から年齢階級別に線形補間」としており、**方法は本編と同じ。ずれは補間によるものではない。**

### (2) ずれているのは補間する前の人口フレーム　―　貴側の「一致しない」の原因

### (3) 認定率・認定者数　―　長期の方法は妥当。計画期間の値が合っていない

**見える化システムの将来推計機能の式**（当方が計算過程確認シートから再現。素案8-1）

```
認定率(n年後) = MEDIAN( MEDIAN(令和8年度実績率 + n×変化, 0, 100),
                        令和8年度実績率×0.9, 令和8年度実績率×1.1 )
```

- **上下10％のキャップが掛かる。**
- **令和12年度以降は令和11年度の値で固定される。すなわち見える化システムは計画期間（令和9〜11年度）しか推計しない。長期推計は機能の外である。**

**本編の「年齢階級別認定率を令和7年度末で固定」は、上式で変化＝0とした場合に相当し、±10％のキャップの内側にある。長期推計の方法としては妥当。**
