### 《要回答7》生活支援コーディネーターの「0点」の出所　―　交付金7点の起点が1つに絞れた

**手元の令和9年度 介護保険保険者努力支援交付金 該当状況調査票（本町分）から特定した。**

| 枝 | 内容 | 配点 | 本町 |
|---|---|---|---|
| **ア** | データとして整理している | 1点 | **○** |
| **イ** | データを地域住民や関係団体等に提供・説明している | 1点 | **○** |
| **ウ** | **データを踏まえ、生活支援コーディネーターとともに、協議体を活用しながら、地域の課題を分析・評価している** | 1点 | **×** |
| **エ** | ウの分析・評価を踏まえ、推進方策を策定し関係者に周知している | 2点 | **×** |
| **オ** | 推進方策の策定時に、庁内の高齢者施策以外の部門と連携し、多様な主体との連携を含めて検討している | 2点 | **×** |
| **カ** | 推進方策を定期的に見直し、関係者に周知する仕組みがある | 2点 | **×** |
| **計** | | **9点** | **2点** |

**国は「ア→イ・ウ→エ→オ・カの順で該当していることが望ましい」としている。本町はア・イが該当しており、連鎖が切れているのはウの1か所である。**
**未得点7点の起点は1つであり、既存の協議体で分析・評価を行って記録を残せばウは該当する。新たな体制を設ける必要はない。**
**オは第9章1の推進体制（住宅部門・国民健康保険の担当課・障害福祉担当との連携）がそのまま当たる。**

### 《要回答54》加齢性難聴の有病率　―　素案の数値が過小であった

**原典を特定した結果、素案が用いていた数値は出典を確認できないものであり、かつ実態より小さかった。**

| 年齢 | 男性 | 女性 |
|---|---|---|
| 65〜69歳 | 43.7％ | 27.7％ |
| 70〜74歳 | 51.1％ | 41.8％ |
| **75〜79歳** | **71.4％** | **67.3％** |
| **80歳以上** | **84.3％** | **73.3％** |

**出典：国立長寿医療研究センター「老化に関する長期縦断疫学研究（ＮＩＬＳ−ＬＳＡ）」（日本老年医学会雑誌49巻2号）。厚生労働省 広報誌「厚生労働」2024年10月号 特別企画1が同じ数値を掲げている。**

**素案は「聴力検査ベースで65〜74歳3人に1人、75歳以上約半数」としていたが、原典では75歳以上の約7割である。**
**あわせて、難聴を自覚している割合は75歳以上で34.4％（日本補聴器工業会 ＪａｐａｎＴｒａｋ2022）であり、有病率の約7割に対し自覚は約3割にとどまる。**

**この開きが施策の設計を決める。対象は「聞こえにくいと感じて相談に来る人」ではなく「聞こえていないことに気づいていない人」であり、待っていては届かない。**
**従前の推計人数（約920人〜約2,030人）は取り下げ、規模の見当として「75歳以上2,688人の約7割」を用いる。**

### 《要回答12》通いの場の定義　―　本町の13か所は国の定義に当てはまる

**国の調査は通いの場を「市町村が把握しているもののうち、体操や趣味活動などを行い、市町村が介護予防に資すると判断するもの」とし、住民が主体的に取り組んでいることを要件としている（運営主体は住民に限らない）。市町村の財政支援の有無は要件としていない。**
**本町の13か所はすべて運営主体が住民団体であり、定義に当てはまる。**

| | 本町（令和6年度） | 全国（令和6年度実施分） |
|---|---|---|
| **月1回以上開催の参加者** | **152人（高齢者人口比3.2％）** | **約248万人（同6.9％）** |
| **うち週1回以上開催の参加者** | **65人（同1.4％）** | **約95万人（同2.7％）** |
| **週1回以上開催の箇所の割合** | **46.2％** | **39.0％** |
| **主な運営主体** | 住民団体（13か所すべて） | 住民団体 69.1％ |

**参加率は全国の半分にとどまる一方、開催の頻度と運営主体の構成では全国を上回る。「場の質ではなく、場の数と参加者の数が足りない」形である。**

### 《要回答25》人口メッシュの出典　―　版の取り違えに注意を要する

**国土数値情報「500mメッシュ別将来推計人口データ（Ｈ30国政局推計）」は、平成27年国勢調査を基準に、社人研「日本の地域別将来推計人口（平成30年3月推計）」の推計値・仮定値を用い、メッシュ別の合計が同推計の市区町村別人口と一致するよう調整したものである。**
**値が社人研推計と一致するのはそのためであり、別の推計ではない。**
**ただし本計画の人口推計は社人研の令和5年推計によっており、基礎となる版が異なる。見える化システムが搭載するメッシュは2020年を起点とするため、Ｈ30国政局推計ともさらに別の版である可能性がある。**
**→ メッシュの値と第2章7の推計値を足し合わせない旨を第7章8に記した。**
