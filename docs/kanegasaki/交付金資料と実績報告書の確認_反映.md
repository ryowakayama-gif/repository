## 2. 《要確定8》の性質が変わった

**町は令和9年度の該当状況調査票において、支援 目標Ⅱ（ⅰ）1カを「該当」として申告している。**

| | 内容 |
|---|---|
| **評価指標** | **「認知症の人及び家族等の意見を踏まえた市町村認知症施策推進計画の策定に着手している」**（配点5点・昨年度×） |
| **町の記載** | **「カ：施策推進計画策定に係りアンケートを実施している。」** |
| **当方の整理** | **第4章6のアンケート（介護予防・日常生活圏域ニーズ調査）は要介護認定者を除く65歳以上の方を対象としており、認知症の人ご本人の意見ではない** |

**したがって、ご判断いただきたいのはＡ（実施する）／Ｂ（実施しない）の選択ではない。**
**Ａ　アンケートをもって足りるとするか、Ｂ　認知症の人およびご家族から直接ご意見をうかがう機会を加えるか　である。**
**第2回策定委員会の判断事項Ⅰを、この形に書き替えた。**

**あわせて《要回答52》が解決した。**支援 目標Ⅱ（ⅰ）1ア（認知症の人の声を聞く機会・4点満点）の根拠は
**「認知症の方も参加している通いの場への訪問を実施している」**であり、**計画の策定のための意見聴取ではない。**
**計画素案の「第9期の策定過程に意見を聴く機会は存在しない」という記述と矛盾しない。**

## 3. 実績報告書による反映

### (1) 高齢者虐待　―　記載事項の不足が実績つきで埋まった

**令和8年10月14日の洗い出しで「素案に『虐待』の語が1度も出てこない」としていた不足である。**

| 相談内容 | 令和4年度 | 令和5年度 | 令和6年度 |
|---|---|---|---|
| 認知症・精神障害等 | 286件 | 320件 | 306件 |
| **家族介護** | **1,421件** | **1,102件** | **1,432件** |
| **高齢者虐待（疑いを含む）** | **14件** | **20件** | **62件** |
| 成年後見制度・権利擁護 | 44件 | 82件 | 50件 |
| 見守り・独居 | 346件 | 393件 | 416件 |
| 介護予防事業他 | 499件 | 651件 | 449件 |
| **計** | **2,610件** | **2,568件** | **2,715件** |

**相談の総数は3年間で105件（4.0％）増えるにとどまる一方、高齢者虐待（疑いを含む）は14件から62件へ4.4倍になっている。**
**あわせて、やむを得ない事由による措置（養護者による虐待を受けている高齢者の緊急一時保護）が令和6年度に1件発生している**
（令和4・5年度はいずれも0件。緊急一時保護事業委託料87,100円）。

**素案 第6章 基本方針2(3)に、虐待の防止を施策として新設した。**取組は5つ（通報の受理と事実確認／居室の確保／養護者への支援／研修体制の整備／身体的拘束等の適正化）。
**成果指標には件数を置かない。**件数の増加は通報の仕組みが働いていることの表れでもあり、減ることが望ましいとは限らないためである。
