## 0. なぜ2本に分けるか

**1本では、相反する2つの要請を同時に満たせない。**

| | 協議用に要るもの | 公表用に要るもの |
|---|---|---|
| **未確定箇所** | **どこが未確定かを明示する**（【　】【案】《要確定》《要回答》・件数の集計） | **計画書に記号は載せられない** |
| **分析の過程** | **どう導いたかを示す**（交付金の枝ごとの突合せ、感応度の11論点、現状分析レポートとの整合） | **結論を示す。過程は別冊に送る** |
| **他の版との関係** | **第9期計画との目次対比、第1回策定委員会資料との数値の関係** | **載せない** |
| **文体** | **である調**（分析の文書） | **です・ます調**（住民の方が読む文書） |
| **分量** | **制約を置かない。**根拠を残すことが優先 | **第9期計画書と同程度**（第9期は全7章＋資料編） |

**協議用を削って公表用にすると、協議の過程で確認した根拠が失われる。**
**公表用に協議用の記載を残すと、計画書に未確定の記号と内部の作業の語が載る。**
**したがって2本立てとし、公表用は協議用から内容を採って書き直す。**

## 3. 数値の照合　―　`chk_kohyo.py`

**公表用は協議用から内容を採って書き直したものである。書き直しの際に数値を取り違えると、2本の成果品で数が食い違う。**
**これを機械で防ぐため、`chk_kohyo.py` を置いた。**

**公表用のdocxに現れる数値を1つずつ取り出し、協議用のdocxに現れるかを照合する。**
年・年度・章節の番号は体系の番号であるため対象から外している。

```
協議用の数値 1114 種　公表用の数値 123 種

公表用だけに現れる数値　なし
```

**現に1件を捕らえている。**公表用の第1章に「85歳以上は令和7年度の1,026人から令和30年度には1,242人へ、21.1％増える」と書いたところ、
**協議用は社人研推計（令和7年度1,074人→令和11年度1,010人→令和22年度1,257人→令和30年度1,242人）に統一しており、
「21.1％増える」は第1回策定委員会資料の系列であって協議用の系列ではなかった。**
**「本計画の期間中は1,042人から1,010人へと減り、令和22年度に1,257人でピークを迎える」に改めた。**

**あわせて、他案件の数値の混入を1件捕らえている。**
公表用の第2章に「第2号被保険者の認定者が各年度2人から3人である」と書いたところ、
**この数は協議用に現れない。他案件（北塩原村）の記録にある数であった。**当該の記述を落とした。

## 5. 2本をどう保つか

**協議用と公表用は、同じ事実を扱う2つの文書である。片方だけを直すと食い違う。**

| | 規則 |
|---|---|
| **１** | **事実と数値は協議用を正とする。**公表用は協議用から採る。**`chk_kohyo.py` が毎回これを確かめる** |
| **２** | **町のご判断・ご回答が届いたら、まず協議用に入れる。**そのうえで公表用に反映する |
| **３** | **章立て・基本理念・基本方針・施策の名称は、策定委員会で了承を得たものを正とする。**両方に同じものを置く |
| **４** | **公表用にだけ置く記述**（です・ます調の言い換え、住民向けの説明）**は、協議用に戻さない** |
| **５** | **点検は2本とも行う。**`check_docx.py` は体裁、`chk_kohyo.py` は数値の一致を見る |

**`mk_toc.py` は、目次のページ番号の対応表を第3引数で受けられるようにした。**
2つの文書が同じ対応表を使うと、あとからビルドしたほうが先のページ番号を壊すためである。
