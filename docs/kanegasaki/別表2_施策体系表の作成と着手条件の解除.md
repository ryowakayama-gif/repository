## 2. 着手条件を解除した理由

**手引きを読んだ結果、《要回答3》を待つ必要がないことが分かった。**

### (1) 手引きが求めているのは「調査が揃うこと」ではない

> 「ビジョンを達成するための『サービス提供体制の構築方針（STEP４）』も明確に示すことができず、その結果として『自然体推計に基づく見込み量の修正（施策反映）』を行う**明確な根拠**を持つことができなかった、関係者間での合意形成をはかることができなかった、ということはないでしょうか。」
> （『介護保険事業計画における施策反映のための手引き』p.7）

**求められているのは、見込量を修正する明確な根拠を持つことである。**

### (2) 根拠は既に取れている

**当初、事業所ヒアリングは4項目を予定していた。そのうち2項目は他の資料で把握できた。**

| 項目 | 状況 |
|---|---|
| ②稼働率 | **見える化システムの事業所別指標で把握済**（グループホーム94〜100％、地域密着型特養100％→88.3％ほか） |
| ③従事者数 | **介護人材実態調査で把握済**（18事業所・職員個票260人。訪問系77人・通所系33人・施設居住系155人、勤務時間・資格・提供時間の内訳まで） |
| **①サービス種類別の受入可能量** | **未把握。**ただし**施設・居住系は定員と稼働率で代替でき、訪問系は勤務時間（1人あたり週29.2時間）で代替できる** |
| **④テクノロジーの導入状況** | **未把握。**ただし**基本方針5の生産性向上の体制整備に関わるのみで、見込量には効かない** |

**残る2項目はいずれも見込量を動かさない。したがって別表2の完成を待たせる理由がない。**

## 4. 別表2で明らかになったこと

### (1) 指標のない施策が4つある

**基本方針2(2) 高齢者の住まいかたの支援、2(3) 高齢者の権利擁護の支援、5(2) 情報提供体制の充実、5(3) 災害や感染症対策**の4施策には参照指標がない。**うち2(2)は《要回答6》（高齢者向け住まいの整備状況）の受領後に置ける。残る3つは、体制整備のみの施策であり指標を置きにくい。**第9章3の整理（20施策のうち7施策に指標がなく、うち重点課題に直結する3施策に新たに指標を置いた）と整合する。

### (2) 新設7施策のうち5施策の財源が地域支援事業費に集中している

**通いの場の拡充、訪問型サービスAの検討、通いの場への送迎、多様な生活支援サービス、家族介護者への支援の5つは、いずれも地域支援事業費で担うものである。**しかし総合事業費の上限の伸びは3年で4.13％しかなく、**上限まで積んでも第9期からの増は3か年3,607千円・月額5円にとどまる。**

**新設する施策の財源を上限の伸びだけで賄うことはできない。既存事業費の組替えまたは一般財源によることになる。この点は、施策を並べる前に第2回策定委員会でご議論いただく必要がある。**

### (3) 確保方策に使える制度が整理できた

**手引き第5章が挙げる5つの制度のうち、本町で使えるのは3つである。**

| 制度 | 本町での使い道 |
|---|---|
| **公募制** | **永岡生活圏（令和32年までに65歳以上が35.0％減）で事業所を残す手段。**エリアを設定した公募により採算を確保する |
| **条件付加** | **三ケ尻生活圏（85歳以上が30.1％増える唯一の生活圏）への立地誘導** |
| **総量規制** | **施設・居住系の定員を計画に明記することが前提。**《要確定5》の判断後 |
| 市町村協議制 | **本町は訪問系の自給率が55.93％まで下がっており、抑制ではなく確保が課題。現時点では用いない** |
| 市町村独自報酬 | 一般財源を要する。本計画では置かない |

**これまで第7章2の確保方策は「見込量の上限をどう置くか」に寄っていたが、計画作成後に町が主体的に取れる手段が整理できた。第7章2に反映することを次の作業とする。**
