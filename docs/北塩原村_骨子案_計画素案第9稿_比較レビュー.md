## 6. 構成上の論点：施策体系をどこまで書くか

A は第4次障がい者計画（改定対象外）を第3章で「参考」として扱い、本計画自身の基本理念・基本目標・施策体系を設けていません。B は第5章・第6章でこれを本計画の内容として構築しています。

- 仕様書4-Ⅱ(5)は①基本理念及び基本目標、②施策体系及び各施策の方向性を**計画案の必須記載事項**としているため、「参考」扱いのままでは要件を満たしません。
- 一方、第4次障がい者計画が継続中である以上、理念・目標を新たに設定し直すのは適切ではありません。
- また B 第6章の9分野は、施策の分量として障がい者計画の領域に踏み込みすぎている面があります。

**推奨する折衷案**：A 第3章を「第4次北塩原村障がい者計画の推進状況と本計画における施策の方向性」に拡張し、第4次計画の理念・基本目標を**継承する旨を明記したうえで**、B 5-3の重点施策体系（8本）と B 第6章各節の「具体的な取組み」を圧縮して統合します。B 第6章の各節末にある「目標値：次期アンケート調査の結果を踏まえて設定」という書式は、アンケート実施前の現時点では適切なため維持します。

**別ブックでの管理**（村からの実績受領後にそのまま入力できる形で構築）

- `output/北塩原村_将来推計.xlsx` — 人口推計・手帳実績・手帳将来推計・推計方法・村確認事項の6シート。トレンド延長法の回帰対象年数を `COUNT()` で可変にしてあるため、R6〜R8実績を入力すると5か年回帰から8か年回帰へ自動的に切り替わります。
- `output/北塩原村_財源構成案.xlsx` — 負担区分マスタ・給付実績（介護／障害児）・財源構成試算・サービス別財源構成・地域生活支援事業・村単独事業・R9〜R11推計・村確認事項の10シート。負担割合を1か所で持たせているため、割合を変えれば全年度・全サービスが再計算されます。

いずれもビルド時に自己検証を実行します。将来推計ブックは推計値（3区分×3手法＋合計＋人口補間）をPythonで再計算して表示値と突合し、財源構成案ブックはサービス別内訳の合計が受領原票の年度合計と一致することを2区分×6年度で確認します。

## 8. 総括

| 観点 | 優れている方 |
|---|---|
| 計画書としての体裁・章立て | **A** |
| 見込量表の完成度（④⑤⑥） | **A** |
| 成果目標の具体性（⑦） | **A** |
| 基本指針改正の網羅性・制度動向の最新性 | **A** |
| 改定対象外計画との範囲整理 | **A** |
| 手帳所持者数の将来推計（③） | **B**（A は欠落） |
| 基礎データの新しさ（人口・推計） | **B** |
| 基本理念・基本目標・施策体系（①②） | **B** |
| 財源評価・少数母数分析・関連計画接続 | **B** |
| 進行管理の設計（⑧） | **B** |

A は「計画書として完成度が高いが、分析の裏付けと仕様書必須事項の一部を欠く」、B は「分析は充実しているが計画書の形になっていない」という関係です。**A を器として採用し、B の分析成果を移植する**のが、仕様書要件と村との合意事項の双方を満たす最短経路です。
