### 実際の賦課（隔月検針）

調定は**奇数月（5・7・9・11・1・3月）の年6回**。1回の請求は2か月分で、

```
2か月分請求額（税込） = floor( 税抜額 × 1.1 )
　税抜額 = 2,016 + 37×(V−10)[10<V≤20] + 174×(V−20)[20<V≤100] + 200×(V−100)[V>100]
　V = 2か月分の使用水量（㎥）／ 区分境界は月額表の2倍（10・20・100㎥）
```

- 例）2か月20㎥＝2,624円、40㎥＝6,452円、100㎥＝17,936円、378㎥＝79,096円
- **検証**：R7年度3月調定 1,519件のうち 1,428件（94%）がこの式と完全一致。残りは基本料金未満の72件（日割・休止等）と19件（月中異動の日割等）で、体系の理解に相違なし。
- **注意**：この式は「金額 → 水量」の向きには一意に使えません。2か月1〜10㎥はいずれも基本料金2,217円になるためです（§2-2）。

### 現行体系の特徴（改定検討上の論点）

1. **6〜10㎥の40.7円と11㎥〜の191.4円で単価が4.7倍に跳ねる。** 月10㎥→11㎥で負担が急増する不連続な構造で、実質「基本料金＋2段階」に近い。
2. **月10㎥（2か月20㎥）まではほぼ横ばい**（2,217〜2,624円）。少量使用者の負担が極めて軽い一方、基本料金への依存度が高い。
3. 八戸圏域8市町村との比較（経営戦略 表2.9）では**階上町の区分数が3と最も少ない**（八戸市は9区分）。経営戦略は「他市町村の多くが累進制を採用し大口需要が多いため、条例上はほぼ同等でも実収入で300〜450円/20㎥の差がついている」と分析している。

### 2-4 データ上の注意点（要確認事項）

1. **偶数月の調定が集計から漏れている。** 漁集では6・8・10・12・2月にも計7件・43,091円の調定があるが、集計ブックは奇数月6回分のみを対象としている。
2. **毎月検針の大口分が過小評価。** 集計ブックは1か月検針分の㎥数を2倍して2か月表に載せている（シート注記「※赤字は1カ月ごと検針、㎥数注意」）が、年12回の請求のうち奇数月6回しか拾えていない。**大口ほど51㎥超の従量料金が効くため、改定後の増収額も過小評価になっている可能性がある。**
3. **特殊算定492件の扱い。** 日割・異動等で料金式に一致しない調定（公共487件・漁集5件、計3,045,941円＝全体の7.1%）。増収試算では現行調定額×改定率で扱っており、実際の改定影響とは差が生じうる。
4. **漁集2ブックの差異。** 1月分で、オリジナル側に使用者番号 8090026-000-01（3,800円）が1件多い（236件 vs 237件）。集計ブックは236件側を採用。毎月検針分の扱いによる意図的な除外と思われるが、要確認。
5. **公共の月別明細は3月分のみ。** 改定影響を精緻に試算するには、**公共下水道の年間調定明細（使用水量付き）**が必要。

|---|---|---|

### 3-4 ⚠ 検討にあたって留意すべき点

1. **改定時期が既に到来している。** 経営戦略は**R8＝令和8年度＝今年度**の10%改定を前提に収支を組んでいる。年度途中の現在まだ未改定であり、遅れはそのまま計画との乖離になる。
2. **経営戦略の使用料収入と今回の調定額は、現時点では単純比較できない（v1から修正）。**
   今回取得した調定データベースでは、経営戦略のR7使用料収入計画値を下回っています。ただし次の3点が未整理のため、乖離率を数値で示すことは保留します。
   - **税込／税抜の別** — 今回の35,613千円は明確に税込調定額。経営戦略の38,724千円が同じ基準かは未確認。
   - **調定と決算上の収入の別** — 収納率・過年度調定・不納欠損等により、調定額と決算上の使用料収入は一致しない。
   - **集計範囲の欠落** — 偶数月調定・毎月検針者の一部が未収録（§2-4）。
   → 比較する場合は、この3点を揃えたうえで行う必要があります。
3. **10%改定でも経費回収率は公共47.7%・漁集26.4%（R16）にとどまる。** 100%には遠く、一般会計繰入金（R7見込 公共約222百万円、漁集約37百万円）への依存は継続する。「どこまで回収率を上げるか」の政策判断が改定率を決める。

## 5. 現段階で言えること／言えないこと

**言えること**
> 現行料金表を約10%引き上げた場合、現在集計できているR7調定データに対して**年間約443万円の増収効果**が見込まれ、改定の方向は経営戦略（ケース①「5年毎に10%」）と整合する。

**まだ言えないこと**
- 「10%改定すれば経営上十分」とは言えません。改定後の経費回収率を最新値で再計算していないためです。
- 増収額の確定値とも言えません。年間調定の欠落分（偶数月・毎月検針大口）の補正が必要です。

## 6. 次のステップ

1. **公共下水道の年間調定明細（使用水量付き）の入手** — 水量推計の幅と欠落分をなくすため、最優先。
2. **欠落分の補正** — 偶数月調定・毎月検針者の年12回分を反映し、増収額を確定。
3. **経費回収率の再計算** — R7決算または最新見込／R8予算／最新有収水量／最新汚水処理費／基準内・基準外繰入金を用い、**「今10%改定すると経費回収率が何%になるか」**まで示す。
4. **改定率の目標設定** — 経営戦略表5.19の目標（公共40%／漁集26%）か、本文が示す当面目標（公共50%／漁集37%）か。目標が決まれば必要改定率が逆算できる。
5. **料金体系の2案併記**
   - **案A**：経営戦略準拠で単純約10%改定（体系は現行のまま）
   - **案B**：同等の増収額を確保しつつ体系も見直し（基本料金を厚めに／6〜10㎥区分の引上げ／11㎥の4.7倍ジャンプの緩和）
   公共で2か月20㎥以下が件数の51.6%を占めるため、基本料金・少量区分の設定で負担の公平性が大きく変わる。
6. **改定時期と激変緩和** — 経営戦略はR8改定を前提。一度に10%か、段階実施か。
