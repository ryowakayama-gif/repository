# 再現手順

本ZIPは単体で追試できます。外部の絶対パスは参照しません。

## 必要なもの

- Python 3.9 以上、`openpyxl`（`pip install openpyxl`）
- Word文書を作り直す場合のみ Node.js と `docx`（`npm install docx`）

## 1. 確定モデルの自己診断

```
cd 04_スクリプト
python3 recompute.py
```

次の値が表示されれば入力データとモデルが一致しています。

```
調定件数         : 9,220 件
調定額（税込）   : 44,567,510 円
区分別収入の合計 : 44,567,510 円（実額との差 0 円）
従量収入         : 23,070,442 円
従量課金対象水量 : 161,984 ㎥
6〜10㎥ 従量収入比 10.0% / 水量比 34.9%
B案 平年度増収  : 4,478,920 円（+10.05%）
```

## 2. 成果物のチェック（410項目）

```
cd 04_スクリプト
python3 check.py
```

`01_成果物/` のWord・Excelを読み、記載値が確定モデル（`recompute.py`）と一致するかを突合します。
結果は標準出力と `01_成果物/check_results.json` に出ます。`05_ログ/check_results.json` は
本ZIPを作成した時点の同じ実行結果の控えで、内容は一致します。

**このチェックは確定モデルと成果物の整合を確認するもの**で、`check.py` は `recompute.py` の
関数を共有しているため**モデルそのものの独立検算ではありません**。次のものは検出されません。

- **モデルそのものの妥当性**：集計ブックの水量欄の解釈（隔月検針／毎月検針／水量欄＝月あたり・
  2か月請求）は3通りの算定式との照合による推定を含みます。
- **表・図の意味上の矛盾**：数値が一致していても、表の名称や区分のくくり方が本文のロジックと
  食い違っている場合は検出されません。
- **図の描画内容**：図が4点埋め込まれていることは確認しますが、PNG画像の中身までは検証して
  いません（図の数値は `mkfigs.py` が `recompute.py` から直接算定）。
- **制度解釈**：繰出基準など制度の解釈の妥当性は対象外です。
- **補助資料の旧版値**：チェック対象はWord・Excelで、補助的なMD・CSVは対象外です。

## 3. 設計レバー（基本使用料・料金区分）の試算

```
cd 04_スクリプト
python3 structure.py              # 一般化モデルの自己診断
python3 mk_structure_csv.py       # 03_根拠データ/35〜37 を再生成
```

`structure.py` は料金表を (基本使用料, 基本水量, ((上限, 単価), ...)) の形で一般化し、
基本使用料・基本水量・区分境界を自由に動かせるようにしたものです。算定規定は
`recompute.py` と同一で、現行料金表を与えると `recompute.py` と1円まで一致します。

```
現行料金表が recompute と一致 : 一致
現行料金表での再現           : 44,567,510 円（差 +0 円）
B案の再現                    : 増収 4,478,920 円（+10.05%）・経費回収率 54.5%
```

## 4. エビデンスExcelの再生成（任意）

```
cd 04_スクリプト
python3 build_xlsx.py
```

`03_根拠データ/` のCSVから `01_成果物/階上町下水道使用料改定_試算エビデンス.xlsx` を作り直します。

## 5. 図とWord文書の再生成（任意）

```
cd 04_スクリプト
python3 mkfigs.py                 # figs.html を出力
# figs.html をブラウザで開き、#fig1〜#fig4 を 02_図/ にPNGで保存
npm install docx && node build.js # 01_成果物/ にWordを出力
```

図を作り直さない場合は `02_図/` の既存PNGがそのまま使われます。

## パスの上書き

既定ではスクリプトからの相対で解決します。別配置で動かす場合は環境変数で指定します。

| 変数 | 対象 | 既定 |
|---|---|---|
| `KAMIKAMI_DATA` | 入力データ | `../00_入力データ` |
| `KAMIKAMI_OUT` | Word・Excel | `../01_成果物` |
| `KAMIKAMI_EVIDENCE` | 根拠CSV | `../03_根拠データ` |
| `KAMIKAMI_XLSX` | Excel出力先 | `../01_成果物/…xlsx` |
| `KAMIKAMI_FIGDIR` | 図の読み込み元 | `./figures` → `.` → `../02_図` |
| `KAMIKAMI_DOCOUT` | Word出力先 | `../01_成果物` → スクリプトと同じ場所 |

## 入力データについて

`00_入力データ/` の3ファイルは、いずれも**集計値のみで個人情報を含みません**。

| ファイル | 内容 |
|---|---|
| `R7_使用料集計ブック_公共.csv` | 令和7年度 公共下水道の金額別度数分布（水量欄・請求金額・月別件数） |
| `R7_使用料集計ブック_漁集.csv` | 同 漁業集落排水 |
| `R7_日割実額.csv` | 基本水量未満の日割額の実測（件数・合計額のみ） |

原本である調定簿明細表には氏名・使用者番号が含まれるため同梱していません。
原本から本CSVを作り直す場合は、集計ブックの該当列をそのまま書き出し、
日割額は明細から件数と合計額を集計してください。

## 本ZIPの作り直し（リポジトリで作業する場合）

配布物とリポジトリではディレクトリ配置が異なります。対応づけは `mkbundle.py` に定義してあり、
リポジトリ側で次を実行すると同じ構成のZIPが得られます。

```
python3 mkbundle.py [出力先.zip]
```
