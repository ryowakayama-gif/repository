## v3での追加

令和6年度決算統計の提供を受け、**32表・40表に基づく経費回収率**を算定し、**案A（体系維持）／案B（体系見直し）の比較表**を追加しました。

**経費回収率 ＝ 使用料収入 ÷ 汚水処理費（32表）。** 汚水処理費は維持管理費（汚水分）のみです。資本費（減価償却費 − 長期前受金戻入 ＋ 支払利息）は全額が「分流式下水道等に要する経費」として基準内繰入金で措置されるため、汚水処理費に含まれません。32表の数値でこの関係を検証しています（`data/14`）。

| | 汚水処理費 | 使用料収入 | 経費回収率 |
|---|---:|---:|---:|
| 公共下水道 | 67,464千円 | 33,652千円 | **49.9%** |
| 漁業集落排水 | 19,614千円 | 7,229千円 | **36.9%** |

繰出基準の使用料対象資本費（＝使用料収入 − 汚水維持管理費、負なら0）が現在ゼロで、+20%改定でもゼロのままのため、**基準内繰入金は改定によって変わりません**。水洗便所等普及費330千円（漁集は不明水処理費2,318千円）は現行額が継続する前提で計算しています。

## 試算方法

### 現行使用料の算定式

隔月検針のため1請求＝2か月分。2か月分の使用水量 V に対し、区分境界を2倍（10・20・100㎥）にして単価を適用します。

```
2か月分請求額（税込） = floor( 税抜額 × 1.1 )

税抜額 = 2,016
       + 37  × (V − 10)    …  10 < V ≤ 20
       + 174 × (V − 20)    …  20 < V ≤ 100
       + 200 × (V − 100)   … 100 < V
```

この式が調定実額を再現することを、R8.3月調定1,519件で検証しています（`data/06`）。

### 調定の3区分

| 区分 | 定義 | 水量推計 |
|---|---|---|
| 通常算定 | 金額が料金式と一致し、水量が一意に定まる（2か月11㎥以上） | 確定値 |
| 基本料金帯 | 金額が基本料金2,217円。2か月1〜10㎥のいずれでも同額 | **不詳**（下限1㎥／上限10㎥） |
| 特殊算定 | 日割・月中異動等で料金式に一致しない | **対象外** |

### 増収試算

通常算定・基本料金帯は水量から新料金を再計算し、件数を乗じます。特殊算定は本来の水量が不明なため、**現行調定額×改定率**で扱います。

### 案1の端数処理についての注記

集計ブックの案1集計値は **8,218,319円（+11.45%）** ですが、これは奇数㎥を2㎥ブロックに切り上げて計算しているためです。現行と同じ算定方法で再計算すると **8,136,688円（+10.35%）** となり、差は約82千円です。本一式では後者を採用しています。

## 既知の限界（引き継ぎ事項）

1. 集計ブックは**奇数月6回分のみ**を対象としており、偶数月の調定（漁集で7件・43,091円）が含まれていません。
2. **毎月検針の大口分**は、年12回の請求のうち奇数月6回しか捕捉できていません。大口ほど51㎥超の従量料金が効くため、**改定後の増収額も過小評価**となっている可能性があります。
3. **公共下水道の月別明細は3月分のみ**入手済みで、他は金額からの逆算です。年間明細（使用水量付き）が入手できれば、水量推計の幅も欠落分も解消します。
4. 漁集の2ブック間で1月分に1件差異があります。本試算は集計ブックが採用している236件側に準拠しています。
5. 特殊算定492件（調定額3,045,941円＝全体の7.1%）は、増収試算で現行×改定率の簡便法によっています。
6. **経営戦略の経費回収率（公共35.0%・漁集25.8%、R4）と32表ベース（49.9%・36.9%、R6）は分母が異なり連続しません。** 経営戦略は資本費を含むベース（汚水処理原価496.84・662.35円/㎥）です。目標水準はこの不連続を整理してから設定する必要があります。
7. **分流式経費の算定方法**（使用料対象資本費の考え方）が階上町でどう運用されているかは未確認です。「資本費全額を機械的に基準額とする」運用であれば、使用料水準と連動しません。
8. 経費回収率の試算は**汚水処理費をR6水準で据置**いています。実際には維持管理費の変動があります。
