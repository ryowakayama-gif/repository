## v10での更新（税抜＝損益ベースへの統一）

「経常収支比率・経費回収率は損益（税抜）ベースであり、3条予算（税込）と混在させると不整合になる」とのご指摘を受け、令和6年度 地方公営企業決算状況調査表作成要領で税区分を確認したうえで、分析をすべて税抜＝損益ベースに統一しました。

- **作成要領による税区分**：20表 損益計算書・21表 費用構成表・32表 経営分析(一) は**税抜**、23表 資本的収支・26表 歳入歳出決算・33表 経営分析(二) は**税込**。
- **32表 26．「（02行）列24「（再掲）下水道使用料」は、20表列3（法非適用企業にあっては26表列3）と同額を記入する」** → 決算統計上の下水道使用料は**法適用＝税抜／法非適用＝税込**。階上町はR6から法適用のため、R1〜R5は税込・R6以降は税抜という断絶があります。
- **【判明】経営戦略の使用料収入は税区分が不整合です。** 採用単価173.9円/㎥はR1〜R4（法非適用＝税込）の実績平均ですが、収支シミュレーションは減価償却費・経常収支比率を扱う損益ベース＝税抜の枠組みです。税抜ベースとして約9.1%（R8で4,752千円）過大です。
- **差の内訳（税抜）**：①単価の税区分による過大 4,752千円／②改定10%の未実施 4,305千円／③漁集の水洗化率80%分 272千円／④有収水量前提の過大 3,047千円／⑤単価差 −690千円／⑥予算の保守的計上 2,490千円。合計14,177千円。
- **平年度増収額は約4,024千円（税抜）／約4,427千円（税込）**。基礎はR7年間全件調定（税抜40,526千円）を推奨。
- **経営指標への反映（R7決算基礎・静態試算）**：経費回収率 49.5%→54.4%、経常収支比率 87.5%→89.0%。使用料を税込のまま算定すると経費回収率は5.0ポイント過大になります。
- **参考**：経営戦略 表2.8の近隣比較も税区分が混在しています（①実績使用料単価は法適用の八戸市のみ税抜、③条例上の料金は全団体税込）。
- データ追加：`31_決算統計作成要領の税区分.csv`。`26`を税抜ベースに全面差し替え。

## v3での追加

令和6年度決算統計の提供を受け、**32表・40表に基づく経費回収率**を算定し、**案A（体系維持）／案B（体系見直し）の比較表**を追加しました。

**経費回収率 ＝ 使用料収入 ÷ 汚水処理費（32表）。** 汚水処理費は維持管理費（汚水分）のみです。資本費（減価償却費 − 長期前受金戻入 ＋ 支払利息）は全額が「分流式下水道等に要する経費」として基準内繰入金で措置されるため、汚水処理費に含まれません。32表の数値でこの関係を検証しています（`data/14`）。

| | 汚水処理費 | 使用料収入 | 経費回収率 |
|---|---:|---:|---:|

## 試算方法

### 現行使用料の算定式

隔月検針のため1請求＝2か月分。2か月分の使用水量 V に対し、区分境界を2倍（10・20・100㎥）にして単価を適用します。

```
2か月分請求額（税込） = floor( 税抜額 × 1.1 )

税抜額 = 2,016
       + 37  × (V − 10)    …  10 < V ≤ 20
       + 174 × (V − 20)    …  20 < V ≤ 100
       + 200 × (V − 100)   … 100 < V
```

この式が調定実額を再現することを、R8.3月調定1,519件で検証しています（`data/06`）。

### 調定の3区分

| 区分 | 定義 | 水量推計 |
|---|---|---|
| 通常算定 | 金額が料金式と一致し、水量が一意に定まる（2か月11㎥以上） | 確定値 |
| 基本料金帯 | 金額が基本料金2,217円。2か月1〜10㎥のいずれでも同額 | **不詳**（下限1㎥／上限10㎥） |
| 特殊算定 | 日割・月中異動等で料金式に一致しない | **対象外** |

### 増収試算

通常算定・基本料金帯は水量から新料金を再計算し、件数を乗じます。特殊算定は本来の水量が不明なため、**現行調定額×改定率**で扱います。

### 案1の端数処理についての注記

集計ブックの案1集計値は **8,218,319円（+11.45%）** ですが、これは奇数㎥を2㎥ブロックに切り上げて計算しているためです。現行と同じ算定方法で再計算すると **8,136,688円（+10.35%）** となり、差は約82千円です。本一式では後者を採用しています。

## 既知の限界（引き継ぎ事項）

0. **（v7で定量化）** 集計ブックの「〜2,216」行は1件あたり2,216円（上限額）で評価されていますが、R7年度3月分の調定明細で実額を確認したところ**71件で64,144円（平均903円）**でした。年間全件で集計すると**9,220件・44,578,708円**（公表値は主検針6か月・9,070件・42,987,132円）。改定率および税抜単価には影響しません。
1. 集計ブックは**主検針月6回分のみ**を対象としており、偶数月の調定（漁集で7件・43,091円）が含まれていません。
2. **毎月検針の大口分**は、年12回の請求のうち奇数月6回しか捕捉できていません。大口ほど51㎥超の従量料金が効くため、**改定後の増収額も過小評価**となっている可能性があります。
3. **公共下水道の月別明細は3月分のみ**入手済みで、他は金額からの逆算です。年間明細（使用水量付き）が入手できれば、水量推計の幅も欠落分も解消します。
4. 漁集の2ブック間で1月分に1件差異があります。本試算は集計ブックが採用している236件側に準拠しています。
5. 特殊算定492件（調定額3,045,941円＝全体の7.1%）は、増収試算で現行×改定率の簡便法によっています。
6. **経営戦略の経費回収率（公共35.0%・漁集25.8%、R4）と32表ベース（49.9%・36.9%、R6）は分母が異なり連続しません。** 経営戦略は資本費を含むベース（汚水処理原価496.84・662.35円/㎥）です。目標水準はこの不連続を整理してから設定する必要があります。
7. **分流式経費の算定方法**（使用料対象資本費の考え方）が階上町でどう運用されているかは未確認です。「資本費全額を機械的に基準額とする」運用であれば、使用料水準と連動しません。
8. 経費回収率の試算は**汚水処理費をR6水準で据置**いています。実際には維持管理費の変動があります。
9. **R8予算41,906千円は令和8年度当初予算書で確定しました**（公共34,356千円＋漁集7,550千円の合算・税込、税抜換算38,096千円）。残る論点は、予算が有収水量をどう置いたのか（R7決算比−6.1%の根拠）です。
10. **経営戦略の目標値は税抜へ読み替える必要があります。** 経費回収率目標（公共40%・漁集26%）は**資本費を含む分母**であり、決算書公表値（R7 49.5%）とは連続しません。分子も税込・税抜のいずれで置くかで数ポイント動きます。現況継続R8は税抜42,944千円、採用ケースR8は税抜47,521千円が正しい読み替えです。
