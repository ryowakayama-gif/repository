唯一の例外として、`doc/01_現状確認メモ.md` に、漁集2ブック間の差異を照会いただくため使用者番号1件のみ記載しています。取扱いにご留意ください。

## 試算方法（要旨）

### 現行使用料の算定式

隔月検針のため1請求＝2か月分。2か月分の使用水量 V に対し、区分境界を2倍（10・20・100㎥）にして単価を適用します。

```
2か月分請求額（税込） = floor( 税抜額 × 1.1 )

税抜額 = 2,016
       + 37  × (V − 10)    …  10 < V ≤ 20
       + 174 × (V − 20)    …  20 < V ≤ 100
       + 200 × (V − 100)   … 100 < V
```

この式が調定実額を再現することを、R8.3月調定1,519件で検証しています（`data/06`）。

### 水量の推計

調定明細に使用水量の記載がないため、**請求金額から上式を逆引きして水量を推計**しています。
基本料金未満（日割・休止等）は10㎥として扱っており、この分は水量が過大／単価が過小に出ます。

### 増収試算

`data/03` `data/04` の金額別度数分布に各料金案を当てはめ、件数を乗じて年額を再計算しています。
公共の「〜2,216円」区分（392件）のみ、水量が特定できないため一律で改定率を乗じています。

### 案1の端数処理についての注記

集計ブックの案1集計値は **8,218,319円（+11.45%）** ですが、これは奇数㎥を2㎥ブロックに切り上げて計算しているためです。
現行と同じ算定方法（2か月分の水量にそのまま単価を適用）で再計算すると **8,136,229円（+10.34%）** となり、差は約82千円です。本エビデンスでは後者を採用しています。

## 既知の限界（引き継ぎ事項）

1. 集計ブックは**奇数月6回分のみ**を対象としており、偶数月の調定（漁集で年7件・43,091円）が含まれていません。
2. **1か月検針の大口分**は、年12回の請求のうち奇数月6回しか捕捉できていません。大口の年間収入・水量は実態より小さく出ています。
3. **公共下水道の月別明細は3月分のみ**入手済みで、他は金額からの逆算です。年間明細（できれば使用水量付き）が入手できれば精度が上がります。
4. 漁集の2ブック間で1月分に1件差異があります（オリジナル側に3,800円の1件が多い）。本試算は集計ブックが採用している236件側に準拠しています。
