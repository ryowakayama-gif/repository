### チェックの方法

2. 同じ数値を令和7年度調定データ（9,070件）から独立に再計算し、記載値と一致することを確認
3. Excelエビデンスのシート20〜24を読み込み、説明資料の各表と同値であることを確認

単に「Excelの値をWordに転記できているか」ではなく、**両方が元データから正しく導かれているか**を確認している。

## 4. 検証の限界（申し送り）

チェックで担保できているのは「記載値が元データから正しく導かれていること」であり、次の点は担保していない。

1. **調定データの範囲** — 令和7年度の奇数月6回調定（9,070件）に基づく。偶数月調定および毎月検針者の一部を含まないため、増収額はやや過小に出ている可能性がある。説明資料の第8章に留意事項として明記済み。
2. **使用水量の推計** — 調定明細に使用水量がないため、請求金額から逆引きしている。基本料金帯（2,217円）は1〜10㎥のいずれでも同額のため水量を特定できず、推計の対象外としている。ただし改定後の金額には影響しない（2か月10㎥以下は基本使用料のみで決まるため）。
3. **汚水処理費の前提** — 経費回収率は汚水処理費を令和6年度水準で据え置いた試算。維持管理費の変動は織り込んでいない。
4. **経費回収率の定義** — 決算統計32表ベース（維持管理費の汚水分のみ）。経営戦略が用いる経費回収率（資本費込み）とは連続しない。この不連続の原因は未確認。
5. **レンダリング環境** — 本チェックはLibreOffice WriterでPDFに変換して目視確認した。Microsoft Wordでの表示は微差が生じる可能性がある。日本語フォントは「MS Pゴシック」を指定しているため、環境によって行送りが変わりうる。
