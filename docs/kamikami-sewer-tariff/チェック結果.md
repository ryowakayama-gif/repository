## 2. レビュー指摘への対応

| # | 指摘 | 対応 |
|---|---|---|
| 1 | P1の「経営戦略の目標は既に達成」は削除すべき。定義の異なる49.9%と40%を比較して達成と判定しており論理的に成立しない | **削除**。「令和6年度決算統計32表から算定した参考値は公共49.9%・漁集36.9%である。ただし、経営戦略が用いる経費回収率とは算定範囲が異なるため直接比較はできない」に差し替え。目的も「経営戦略が見込む使用料収入の水準を確保しつつ、現行料金体系の負担配分を見直す」に改めた |
| 2 | 「+10%」だけでは6〜10㎥の+96.6%が見えない | 表題を「**調定額ベースの平均増収率 約10%**」に統一。表5の下に「平均増収率と区分単価の改定率は別物」の注記を置き、**基本±0%／6〜10㎥ +97.3%／11〜50㎥ +9.2%／51㎥〜 +10.0%** を明示。第2段階の**+194.6%**も併記した（税抜設計に変更したため数値が96.6%→97.3%、194.8%→194.6%に変わっている） |
| 3 | 「完全是正」は6〜10㎥が11〜50㎥より高い逆転体系であり名称が不正確。「是正率100%」も危険 | 「**参考：174円まで引上げ**」に改称し、**実施案ではなく比較の端点**である旨を注記。「是正率」は「**単価差縮小率（現行11〜50㎥単価174円への到達率）**」に改称した |
| 4 | 条例別表は税抜。80円（税込）を「単価の差替えのみ」とするのは不正確。条例も2本ある | **料金案を税抜の整数単価で設計し直した**（中心案：基本1,008円据置／6〜10㎥ 73円／11〜50㎥ 190円／51㎥〜 220円）。税込は条例どおり税抜額に消費税を加算し1円未満を切り捨てて導出。**第8章「条例改正に向けた整理」を新設**し、税抜別表（表11）・2条例である旨・端数処理を記載した |
| 5 | 公衆浴場汚水が抜けている | R7調定データを照合し、**公衆浴場汚水でしか成立しない調定金額は0件**であることを確認。「適用者を確認できないため試算対象外」とし、据置か同率改定かを決める必要がある旨を第8章に記載した |
| 6 | 「なぜ80円か」の理由があると強くなる。「推奨案」より「たたき台」が妥当 | 「推奨案」→「**中心案（事務局たたき台）**」に改称。5-2節「中心案を中心に置いた理由」を新設し、**①平均増収率 約9.9% ②月5㎥以下は据置 ③主要利用帯（月8〜50㎥）の増加率が+9.7〜+15.1%（幅5.4ポイント）で、弱い縮小の10.0ポイント・強い縮小の23.5ポイントより均等 ④単価の開きを4.70倍→2.60倍** の4条件を数値で提示した |
| 7 | 429.5万円はR8年度効果ではなく平年度効果 | 表8を「**平年度増収額（参考）**」に変更。施行日・検針周期・施行日をまたぐ2か月請求の扱いが未定であり、初年度影響額は別途算定が必要である旨を第1章と第9章に記載した |
| 8 | データ不足は増収額だけでなく料金単価にも影響する | 第9章の冒頭に「**料金表は暫定である**」を新設。11〜50㎥の190円は平均増収率から逆算した値であり、大口データの不足が51㎥〜からの増収を過小評価し、その不足分を11〜50㎥で余分に回収する設計になっている可能性がある旨を明記。**最終料金表の確定は年間調定データ補完後**とした |
| 9 | 「従量水量の4割」は分母の説明が必要 | 「**従量課金対象水量**（基本使用料に含まれる水量＝2か月10㎥を除いた水量）」に統一し、図2にも「全汚水量ではない」の注記を追加。本文も「基本水量を除く従量課金対象水量の37.9%に6〜10㎥単価が適用されている一方、同区分に対応する従量収入は5.3%」に改めた |
| 10 | 「本来この区分が負担すべき分」は証明できない | **削除**。「この区分の相対的に低い負担が維持される場合、必要な増収分は他の区分に配分することになる」に差し替えた |
| 11 | 経費回収率・繰入金は静態試算と明示すべき | 「**参考経費回収率**」に改称し、「令和6年度決算の使用料・汚水処理費を固定し使用料改定のみを反映した**静態試算**」と明記。繰入金も「令和6年度決算の費用構成を固定した静態試算では、平均増収率+15%程度までは…影響しない」と限定し、**令和13年度まで見通す場合は年度別の再計算が必要**である旨を追記した |
| 12 | 経営戦略との関係は収入水準の整合に限定すべき。R8予算41,906千円との差も要突合 | 「経営戦略が見込む約10%の増収水準を確保しつつ、現行料金体系の単価差を縮小する案」と位置づけ、「経営戦略が検証しているのは使用料収入の増加であり、**区分間の負担配分までを事前に決定しているわけではない**」と注記。R8予算41,906千円と経営戦略のR8見込52,273千円の差について、**打合せ前に突合が必要**である旨を第9章に記載した |

## 4. 検証の限界（申し送り）

1. **料金表は暫定**。11〜50㎥の税抜190円は平均増収率から逆算した値であり、毎月検針の大口データが補完されると変わりうる。政策方向（6〜10㎥の単価差縮小）は議論できるが、料金表の確定は年間調定データ補完後とすべき。
2. **増収額は平年度ベース**。施行日未定のため初年度影響額は含まない。
3. **参考経費回収率は静態試算**。令和6年度決算の使用料・汚水処理費を固定し、使用料改定のみを反映している。令和13年度までの見通しとする場合は年度別の再計算が必要。
4. **経費回収率の定義**。決算統計32表ベース（維持管理費の汚水分のみ）であり、経営戦略が用いる経費回収率とは算定範囲が異なる。直接比較はできない。
5. **公衆浴場汚水**。R7調定データ上は適用者を確認できないが、「適用者がいない」ことの確認は台帳側で別途必要。
6. **令和8年度予算との差（解決済み）**。差10,367千円の内訳は、①改定10%の未実施 4,736千円、②漁集の水洗化率80%分 299千円、③**消費税相当（経営戦略は税込・予算は税抜）4,294千円**、④残差1,038千円である。詳細は第9章および `04_R8予算と経営戦略の差異分析.md`。**41,906千円が「公共＋漁集の合算・税抜・当初予算」であることの一次資料確認は残っている。**
7. **調定データの集計範囲**。説明資料の公表値42,987,132円は主検針月6か月分であり、かつ集計ブックの「〜2,216」行を1件2,216円（上限額）で評価している。年間全件では9,220件・44,578,708円、平年度増収額は約4,427千円（税込）・約4,024千円（税抜）となる。改定率および税抜単価には影響しない。
8. **レンダリング環境**。LibreOffice WriterでPDFに変換して目視確認した。Microsoft Wordでの表示は微差が生じうる。
