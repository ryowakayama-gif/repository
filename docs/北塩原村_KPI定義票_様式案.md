# 0. 何を作ったか

1指標を1枚にまとめる様式です。何を・どう数え・いつ・誰が取り・達しなかったら何をするかを、1枚で決めます。欄は16で、レビューが推奨した13項目をすべて含みます（生成のたびに照合しています）。

| シート | 中身 |
|---|---|
| 00_使い方 | 16欄の書き方、公表区分（甲・乙・丙）の案、値の置き方、年次の点検評価との関係 |
| 01_定義票 | 1指標1枚の様式（空欄）と、記入例（Ｋ-08 就労定着支援事業の利用者数） |
| 02_ＫＰＩ一覧 | 32指標の定義の案（一覧の形） |
| 03_国の8分野 | 国の成果目標8分野ごとの指標（成果・活動・体制の別） |
| 04_村が決めること | 使い始める前に村に決めていただく6点 |

# 1. 32指標の内訳

| 種類 | 数 | 値の扱い |
|---|---|---|
| 国の成果目標・活動指標（正本 第4章の表） | 15 | 基準値・目標値を正本の表から写した。表の行が正本に実在することを毎回確かめる |
| レビューの提案から足したもの（【提案】、黄色） | 9 | **算定方法とデータの出所だけを置き、基準値・目標値は「村が決定」として空けた** |
| 第4次障がい者計画の8指標 | 8 | 第3章の基準値・目標値。中間見直しで改める場合はここも改める |

提案の9指標は次のとおりです。

- Ｋ-03 地域移行の意向確認の実施率
- Ｋ-10 就労選択支援を経た方の進路決定率
- Ｋ-13 健診から支援につながった割合
- Ｋ-14 中核機能の確保数
- Ｋ-16 緊急時に受け入れられなかった件数
- Ｋ-19 モニタリングの実施率
- Ｋ-22 重度の障がいのある方の受入れ確保率
- Ｋ-23 移動の希望に対し利用できなかった件数
- Ｋ-24 個別避難計画の作成率

体制（あるかないか）と活動（行った回数）だけでは、本人の暮らしが変わったかが見えません。そのため、成果を見る指標を主に足しました。

# 2. 公表区分（案）

村の人口は約2,300人で、対象となる方が1人・2人の指標が多いため、指標ごとに公表の扱いを分ける案を置きました。

| 区分 | 扱い | 例 |
|---|---|---|
| 甲 | 実数を公表する | 協議の場の回数、研修の人数、拠点の設置 |
| 乙 | 実数を公表し、属性（障がいの種別・年齢・利用先）は書かない | 地域移行者数、一般就労移行者数、就労定着支援の利用者数 |
| 丙 | 村の内部の記録にとどめ、計画と公表には達成の有無だけを書く | 健診から支援につながった割合、重度の方の受入れ確保率、進路決定率 |

丙は、正本 第4章の障がい児の注記（Ｍ-76・Ｍ-77）と同じ考え方です。

# 3. 村に決めていただくこと

1. 提案の9指標を採るか。採る場合は基準値と目標値（見込量の置き直し（Ｍ-139）とあわせて決めるのがよい）
2. 就労定着支援の目標値2人を据え置くか（Ｍ-140）
3. 数を取りまとめる課（Ｍ-134）。健康づくり・母子保健・防災の担当と分ける指標がある
4. 公表区分の案、とくに丙の範囲
5. 把握の時期（前年度の実績を5月に取りまとめ、自立支援協議会に報告する案）
6. 第4次計画の目標値を中間見直しで改めるか

# 4. 自己点検

| 検査 | 内容 |
|---|---|
| ① | レビューの推奨項目（13項目）がすべて定義票の欄になっている |
| ② | 正本から写した値（16点）が、正本 第4章の表の行に実在する |
| ③ | 提案の指標に目標値を置いていない。提案でない指標には正本の出所がある |
| ④ | 番号が連番で、区分・公表区分が定義どおり |
| ⑤ | 国の8分野すべてに1指標以上ある |
| 否定試験67・68 | 正本と違う値を写すと②が、提案の指標に目標値を置くと③が不合格になる |
