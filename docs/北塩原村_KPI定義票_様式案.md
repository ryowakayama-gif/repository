# 0. 何を作ったか

1指標を1枚にまとめる様式です。何を・どう数え・いつ・誰が取り・達しなかったら何をするかを、1枚で決めます。欄は16で、レビューが推奨した13項目をすべて含みます（生成のたびに照合しています）。

| シート | 中身 |
|---|---|
| 00_使い方 | 16欄の書き方、公表区分（甲・乙・丙）の案、値の置き方、年次の点検評価との関係 |
| 01_定義票 | 1指標1枚の様式（空欄）と、記入例（Ｋ-08 就労定着支援事業の利用者数） |
| 02_ＫＰＩ一覧 | 38指標の定義の案（一覧の形）。右端に第2回レビューの目標案を「参考」として置く |
| 03_国の8分野 | 国の成果目標8分野ごとの指標（成果・活動・体制の別） |
| 04_村が決めること | 使い始める前に村に決めていただく6点 |

**区分の見直し（第2回レビュー）：** 第4次計画の8指標を一律に「成果」としていたのを改め、個別に区分しました（成果3・活動3・体制2）。全体では成果16・活動16・体制6です。

**参考の目標案：** 第2回レビューが示した管理目標（意向確認率100％、重度者の受入れ確保率80→90→100％など）は、目標値の欄には入れていません。一覧の右端に「参考」として置きました。レビュー自身が「国が北塩原村に指定した数値ではなく、村が採否を決める」としているためです。

体制（あるかないか）と活動（行った回数）だけでは、本人の暮らしが変わったかが見えません。そのため、成果を見る指標を主に足しました。

# 2. 公表区分（案）

村の人口は約2,300人で、対象となる方が1人・2人の指標が多いため、指標ごとに公表の扱いを分ける案を置きました。

| 区分 | 扱い | 例 |
|---|---|---|
| 甲 | 実数を公表する | 協議の場の回数、研修の人数、拠点の設置 |
| 乙 | 実数を公表し、属性（障がいの種別・年齢・利用先）は書かない | 地域移行者数、一般就労移行者数、就労定着支援の利用者数 |
| 丙 | 村の内部の記録にとどめ、計画と公表には達成の有無だけを書く | 健診から支援につながった割合、重度の方の受入れ確保率、進路決定率 |

丙は、正本 第4章の障がい児の注記（Ｍ-76・Ｍ-77）と同じ考え方です。

# 3. 村に決めていただくこと

1. 提案の15指標を採るか（参考の目標案を使うかを含む）。採る場合は基準値と目標値（見込量の置き直し（Ｍ-139）とあわせて決めるのがよい）
2. 就労定着支援の目標値2人を据え置くか（Ｍ-140）
3. 数を取りまとめる課（Ｍ-134）。健康づくり・母子保健・防災の担当と分ける指標がある
4. 公表区分の案、とくに丙の範囲
5. 把握の時期（前年度の実績を5月に取りまとめ、自立支援協議会に報告する案）
6. 第4次計画の目標値を中間見直しで改めるか

# 5. 第3回レビュー（令和8年10月24日）による改め

- **欄を1つ足した（16→17欄）：** 「0件・該当なしの扱い」。率の指標は、分母が0の年度を「該当なし」とし、達成・未達を判定しません。人数・件数の指標は、対象の方がいない年度も0として記録します。
- **9指標の定義を直した：**

| 指標 | 直したこと |
|---|---|
| Ｋ-08 就労定着支援の利用者数 | 利用者数は定着の成果そのものではないため、Ｋ-26（6か月・12か月後の就労継続率）と併せて見る |
| Ｋ-13 健診から支援につながった割合 | つながった先を、保健師の継続支援・保育所・幼稚園・学校での配慮・医療機関の受診まで広げ、内訳を取る |
| Ｋ-19 モニタリングの実施率 | 予定・実施・延期・中止を定義し、中止は分母から除く |
| Ｋ-21 情報公表の公表率 | 対象事業所が0の年度は「該当なし」 |
| Ｋ-24 個別避難計画の作成率 | 全対象と優先対象で分母と目標を分ける |
| Ｋ-29 乖離の理由の未記録件数 | 乖離の幅の検討案（人数差1人以上又は量の差2割以上）を参考に置いた |
| Ｋ-30 必要量の確保率 | 分子を「地理的・実質的に利用できる量」（送迎の範囲・冬季・障がいの特性）とした |
| Ｋ-32 特定健診の受診率 | 障がいのある方の施策の直接の成果ではなく、関連する地域保健の指標と位置づけた |
| Ｋ-33 サービスの満足度 | 分母と無回答・非利用者の扱いを固定してから再計算する |
