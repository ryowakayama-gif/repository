### アンケートで測る3指標はすべて問題があります

**K-1（差別・偏見）— 比較不可**

| | 前回（問36） | 今回（問34／障がい児 問33） |

| 選択肢 | ある／少しある／ない の**3択** | 週に1回／月に1回／年に1回／ない／**わからない** |

## 4. 見込量・地域生活支援事業

### 見込量 — 比較可。ただし区分の異動が3点

同一サービスで比較できますが、次の3点で区分が動いています。比較表を作る際は注記が必要です。

1. **医療型児童発達支援**が令和6年度に児童発達支援へ一元化された
2. **就労選択支援**が令和7年10月に創設された（前回計画に見込量なし）
3. **宿泊型自立訓練**は令和2年度に実績があるが今回の見込量区分にない

前回の判定（現行計画評価ブック 01）は、見込どおり3・見込を上回る5・見込を下回る7・過大計上3・計上漏れ2・実績と見込とも0が5でした。**第8期はこの判定を踏まえた設計になっています**（実績のあるサービスを0としない歯止め、居宅介護の時間数を40時間に是正）。

### 地域生活支援事業 — 比較可。論点2件

1. **成年後見制度利用支援事業**は実績1人に対し令和6年度以降5人を見込んでおり、増加の根拠が不明
2. **地域活動支援センター機能強化事業**は実績3人が見込2人を上回るが、令和6年度以降も2人で据え置かれている

### T-1 — 前回計画本編の転記誤り
