# 素案4-6の是正（令和8年10月13日）― 高齢者サービスの手引きとの食い違い

村の「高齢者サービスの手引き（令和8年度版）」により、素案4-6（高齢者福祉サービスの量の目標）の
記述が実態と違っていることが分かっていた（doc76 §1-3〜§1-5）。
**村のご回答を待たずに素案を直した。** 理由は次の2つである。

1. **すでにある仕組みを「創設を検討」と書いた計画書は、委員から見て村の実態を
   把握していない資料に見える。** 第2回策定委員会（11月）の前に直す必要がある
2. **老人福祉法第20条の8第2項は確保すべき老人福祉事業の量の目標を定めることを
   求めている。** 村が現に実施している事業を落とすと法定記載事項を欠く

| | 改訂前 | 改訂後 |
|---|---|---|
| 4-6(2) 在宅福祉サービスの事業数 | 9事業 | **17事業** |
| 移動支援の記述 | 「移動支援の創設を検討する」 | **「既存の路線バスICカード・コミュニティバスの活用と周知、届かない範囲の補い方の検討」** |
| 配食の記述 | 「村の委託により現在の体制を維持する」 | **「ひとり暮らし高齢者弁当配達サービス（赤十字奉仕団・年4回）」** |
| 計画書の頁数 | 本文116頁＋前付4頁＝120頁 | **本文116頁＋前付4頁＝120頁**（変わらず） |

## 1　移動支援 ― すでに無料の仕組みがある

素案は施策2-1と4-6(2)の両方で
**「介護予防・生活支援サービス事業による移動支援の創設を検討する」**と書いていた。

手引きによれば、村は次をすでに行っている。

- **村民向けの路線バスICカードを発行**し、喜多方⇔裏磐梯・猪苗代⇔裏磐梯の路線バスが**無料**
- 路線バスの運行区域以外でも**無料のコミュニティバスが運行**
- いずれも公共交通の担当部局（総務企画課防災係）が所管

### 1-1　書き改めた内容

施策2-1の**現状と課題**に、既存の仕組みを書き加えた。そのうえで課題の立て方を変えた。

> 第10期の課題は、新たな仕組みを作ることではなく、この仕組みが必要な方に届いているかを
> 確かめることです。移動に関する課題の把握が0点にとどまっているのは、既存の仕組みの
> 利用の状況と、届いていない範囲を把握できていないことによります。

**取組を3項目から4項目に改めた。**

| | 改訂前 | 改訂後 |
|---|---|---|
| 1 | 移動に関する課題を体系的に把握します | 同じ。**ICカードとコミュニティバスの利用の状況、地区別の運行の状況から、支援が届いていない範囲を明らかにします**を加えた |
| 2 | **介護予防・生活支援サービス事業による移動支援の創設を検討します** | **ICカードとコミュニティバスの周知を図り、交付・利用の手続の分かりやすさを高めます** |
| 3 | 公共交通担当部局との連携を継続します | **既存の仕組みでは届かない範囲について、介護予防・生活支援サービス事業による補い方を検討します** |
| 4 | ― | 公共交通担当部局との連携を継続します |

**「創設を検討」を捨てたのではなく、位置を変えた。** 既存の仕組みが前に来て、
創設の検討は「届かない範囲について」の後詰めになる。これが実態に合う順序である。

指標は「路線バスICカード・コミュニティバスの利用の状況の把握（未把握→把握）」とした。

> はじめは「路線バスICカードの交付を受けた方の人数」に【要設定】の目標値を置いた。
> **しかしこれでは「交付を増やすこと」が目標に見える。**
> 施策が約束しているのは利用の状況の把握であり、
> それが国の評価指標で0点にとどまっている項目である。指標を取組に揃えた。

### 1-2　第2回策定委員会資料も直した

**第2回資料（資料4 施策体系）にも同じ記述があった。**

> 改訂前：「令和4年度に評価が改善。生活支援サービス事業による移動支援の創設を検討」
> 改訂後：「令和4年度に評価が改善。既存の路線バスICカード・コミュニティバスの活用と周知、届かない範囲の補い方の検討」

**同じ数値・同じ記述を2つの成果品に別々に書いているところは、片方を直して終わりにできない。**
素案を直したときは委員会資料も走査した。

あわせて doc14（令和8年8月31日の検討の記録）の施策一覧にも同じ記述があるため、
**記録はそのまま残し、下に是正の注を置いた。**

## 2　配食 ― 年4回の弁当配達である

素案は「村の委託により現在の体制を維持する」と書いていた。
手引きによれば**ひとり暮らし高齢者弁当配達サービス**であり、
**赤十字奉仕団**が実施し、**年4回を予定**するものである。「委託」ではない。

| 項目 | 改訂後 |
|---|---|
| 事業名 | ひとり暮らし高齢者弁当配達サービス |
| 単位 | 回／年 |
| 目標（R9・R10・R11） | **4・4・4** |
| 確保の方策 | 赤十字奉仕団による弁当の配達（年4回）を継続する。毎日の食事の確保という課題に対しては年4回では足りないため、介護予防・生活支援サービス事業による配食の創設を検討する（施策1-2） |

### 2-1　総合事業の配食とは別の事業である

**素案には「配食」が2か所に出てくる。**

| | 事業 | 状況 |
|---|---|---|
| 4-6(2) | ひとり暮らし高齢者弁当配達サービス（村単独・赤十字奉仕団） | 年4回を予定 |
| 2-6・施策1-2 | 介護予防・日常生活支援総合事業の配食（多様なサービス） | 令和5年度の決算で実施の実績なし |

改訂前は4-6(2)の「配食サービス」がどちらを指すのか読み取れなかった。
**両者が別の事業であることを注記し、量の目標は前者について掲げた。**

あわせて**施策1-2（総合事業における多様なサービスの創設）の取組に配食を明記**し、
4-6(2)との往復を閉じた。

> 毎日の食事の確保が課題となる世帯への配食について、総合事業による実施を検討します。
> 村単独の弁当配達は年4回であり、量の目標は4-6(2)に掲げています

## 3　素案が落としていた8事業を量の目標に加えた

手引きには素案に載っていない村単独事業が9件あった（doc76 §1-4）。
**うち8件を4-6(2)の量の目標に加え、在宅福祉サービスを9事業から17事業にした。**

| 加えた事業 | 内容 |
|---|---|
| 寝具洗濯サービス | 在宅介護高齢者等寝具洗濯サービス（社会福祉協議会に委託） |
| 訪問理美容サービス | 在宅介護高齢者等訪問理美容サービス（同） |
| なりすまし詐欺抑止装置の貸与 | 65歳以上の高齢者世帯等で固定電話をお持ちの方に無償貸与 |
| 火災警報器の配布 | 65歳以上の高齢者世帯等で未設置の場合に無償 |
| 防犯カメラ等の設置助成 | 高齢者のみで居住する世帯に上限10万円・補助率10/10 |
| 長寿を祝う会 | 75歳以上・9月 |
| 健康長寿祝金 | 75歳から100歳までと101歳以上。住所地特例の方を含む |
| 地域・健康づくり活動活性化助成金 | 高齢者が参画する自主活動団体への活動費の助成 |

**帯状疱疹予防接種は加えなかった。** 予防接種による健康の保持の事業であり、
老人福祉事業の量の目標として掲げる性格のものではないと判断した。
この区分でよいかは村にご確認いただく。

あわせて、既にあった事業の記述も手引きの要件に合わせた。

| 事業 | 加えた要件 |
|---|---|
| 緊急通報システム | 65歳以上のひとり暮らし高齢者世帯等で**固定電話をお持ちの方**。「お元気コール」による安否確認つき |
| 介護用品の支給 | **要介護4以上**で常時紙おむつ等を必要とする在宅の方。月額**4,000円**（非課税世帯は**5,000円**） |
| 高齢者教室 | **シニア元気アップ教室**（月2回程度・北山地区と裏磐梯地区の2会場） |

### 3-1　施策のない5事業の扱い

17事業のうち**5事業（寝具洗濯・訪問理美容・長寿を祝う会・健康長寿祝金・活動活性化助成金）は、
第4章の施策体系に対応する施策がない。**

無理に既存の施策に当てはめることはしなかった。
施策2-3は「住まいの安定的な確保と生活困難者支援」であり、寝具洗濯・訪問理美容は住まいではない。
施策2-5は住民の支え合いの活動であり、祝金は村の金銭給付である。

**量の目標のみ掲げ、確保の方策の欄に「施策体系上の位置づけは村と協議する」と書いた。**
4-6の導入文も「対応する施策がある事業については」に改め、注記で5事業を名指しした。
施策を新設するか、既存の施策に含めるか、量の目標のみとするかは村のご判断である。

## 4　固定電話の要件と緊急連絡カード

手引きにより、**緊急通報システムとなりすまし詐欺抑止装置が
いずれも「固定電話をお持ちの方」を要件としている**ことが分かった（doc76 §1-5）。
**固定電話のない高齢者世帯は、村の見守りの2つの手立てのいずれからも外れる。**

施策2-4（日常生活の安全確保）を次のとおり改めた。

- **現状と課題**に、村が緊急通報システムのほかにも3事業（なりすまし詐欺抑止装置・
  火災警報器・防犯カメラ）を実施していること、および固定電話の要件が課題であることを書いた
- **取組**に3事業の継続と、固定電話のない世帯の把握を加えた
- **緊急連絡カード**（持病・お薬・かかりつけ医・緊急連絡先を記入し電話機や冷蔵庫の近くに
  備え付けるもの）を加えた。**固定電話がなく緊急通報装置を設置できない世帯にも届く手段**であり、
  要件の穴を補う位置にある（doc76 §2 の提案）
- **指標**に「緊急通報システムの設置台数」と「固定電話のない高齢者世帯の把握（未把握→把握）」を加えた

> 素案は施策2-4を緊急通報システムだけで組み立てていた。
> **村はもっと広く手当しているのに、計画が狭く書いていた。**
> 手引きを読まなければ分からないことだった。

## 5　頁数は増えなかった ― 列幅の誤りを見つけた

8事業を加えたことで、**計画書の頁数は本文116頁から118頁（＋前付4頁＝122頁）に増えた。**
点検49（頁数が仕様書の目安100頁から±20頁を超えて離れていないか）が不適合になった。

原因を追ったところ、**4-6(2)の表の列幅の合計が90%しかなかった。**

| 列 | 改訂前 | 改訂後 |
|---|---:|---:|
| 事業 | 32 | 22 |
| 単位 | 11 | 7 |
| R7実績 | 11 | 8 |
| R9・R10・R11 | 8・8・8 | 5・5・5 |
| **確保の方策** | **12** | **48** |
| 合計 | **90** | **100** |

**確保の方策の欄は文を書く列であるのに12%しかなく、表全体も紙幅の90%しか使っていなかった。**
文が細い列で折り返すため行が高くなり、17行の表が3頁に膨らんでいた。
列幅を直したところ、**本文は116頁に戻った**（＋前付4頁＝120頁）。
8事業を加えたのに頁数が増えないのは、この無駄が消えたためである。

### 5-1　素案・委員会資料に11＋8件の同じ誤りがあった

全部の表を数えたところ、**合計が100%でない表が素案に11件・委員会資料に8件**あった。
下は86%、上は114%である。

**100%を下回ると表が紙幅より狭くなり、長い文の列が折り返して行が高くなる。
上回ると本文の領域からはみ出す。**
**紙面の目視確認ができない環境では、この食い違いは機械でしか見つからない。**

19件すべてを直した。比率を保って100%に合わせ、4-6(2)だけは
確保の方策の列を広く取り直した。
**うち2件は当方が本日作った表である**（第3回資料の2-2が81%、6-1の3案の表が110%）。

### 5-2　点検66を新設した

**表の列幅の合計が100%であること**と、**列数と見出しの数が合っていること**を見る点検を
素案・第2回資料・第3回資料の295表に当てた。
欠陥を戻すと不適合になることを確かめている。

> この誤りは、素案を組み立てはじめてから**2か月近く残っていた**。
> 組立てが `cols = TBLW * w / 100` と割り付けていることを読んで初めて
> 「合計が100でなければならない」と分かった。
> **組立ての側の決まりを、点検の側に写していなかった。**
