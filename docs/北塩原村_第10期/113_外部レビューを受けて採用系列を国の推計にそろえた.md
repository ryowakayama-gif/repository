# 外部レビューを受けて、採用系列を国の推計にそろえた（令和8年10月23日）

計画素案（成果品18・本文121頁）と策定委員会参考資料（成果品19・11頁）に対し、外部レビュー（176項目の点検）の結果を受け取った。
結論は「公表用確定稿としての承認は推奨しない」。指摘を原典で1件ずつ確かめ、手元のデータで直せるものを直した。

## 2. 採用系列をそろえた

国の推計ワークシートを採用値とし、当方がワークシート受領前に立てた系列（案B）は「参考」として分けた。

| 箇所 | 前 | 後 |
|---|---|---|
| 5-7 当方の算定の表群 | 採用値と並んでいた（末尾の注記で断るのみ） | 「参考　当方の検算（国の推計ワークシートの受領前の算定）」の見出しの下に移し、冒頭で採用値でないことと系列の違いを断る |
| 5-7 算定上の月額と条例上の基準額 | 当方の6,756円・6,054円・12パターンの上下限 | 国の3案（A 6,610.55円→6,600円、B 5,952.45円→5,900円、C 5,513.72円→5,500円）。当方の値は注記へ |
| 図「保険料と条例基準額」 | 本計画の算定として掲出 | 「参考　当方の検算による12パターン」に改題し、参考の表の直後へ |
| 5-11 中長期 | 当方の系列（認定者220→193人）が本表 | 国の系列（第1号被保険者994→845人、85歳以上198→286人、認定者210→228人）を本表に。当方の系列は「参考　感度分析」 |
| 5-5(1) 延ばす基礎 | 「5-3の見込み（214→214→217→220人）」と誤って帰属 | 国の系列（206→208→211→210人、1,009→1,004→1,000→994人）。通いの場の参加者数は276人へ |
| 5-5(2) 事業費 | 系列の断りなし | 令和5年度末を基準に延ばすため当方の系列によることを明記。令和7年度決算で基準を置き直す時点で国の系列へ |
| 5-4(12) 担い手の枠 | 需要に208・220・212・193人が混在 | 国の系列（estimate_jinzai.py がワークシートから引く）。要支援の充足率は100.0→61.1→21.0→0.0%、令和22年は要介護1以上にも約7人分届かない |
| 5-8 表の保険料行・資料6-5 | 当方の値が先 | 国の値を先に置き、当方の値は検算と明記 |
