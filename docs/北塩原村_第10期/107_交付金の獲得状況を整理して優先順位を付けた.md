## 1　いちばん危なかったところ　―　小計の列を明細と数えた

全国集計表（市町村分）の見出しは、**明細（指標の枝番）と小計（指標群計・目標計）が
同じ行に並ぶ。** 配点のある列を機械的に拾うと、小計が混ざる。

混ざったまま数えると、こうなった。

| | |
|---|---|
| 目標Ⅰ〜Ⅲの項目の配点計 | 200点（本当は100点） |
| 本村の素点合計（推進Ⅰ） | 152点。合計列は76点 |
| **読み取った規則** | **「項目の素点合計の2分の1が得点になる」** |

**しかもこの比は、全国1,741市町村すべてでぴったり2.000だった。**
最小2.000・最大2.000。検算はきれいに通った。

この規則が正しければ、**素案5-9の「61点を取得すると447点は508点になります」は
2倍の誤りで、正しくは447点が477点程度**ということになる。
村にお示しする数値の根幹が崩れる。

**崩れていなかった。** 比が常にちょうど2.000だったのは、
**小計の配点が明細の配点とまったく同じだから**である。
明細68点＋32点＝100点の横に、小計68点・32点が並んでいる。両方足せば200点。

| 列 | 中身 | 配点 |
|---|---|---|
| 57〜67 | 推進Ⅱ（ⅰ）体制・取組指標群の明細 | 計68点 |
| 68〜75 | 推進Ⅱ（ⅱ）活動指標群の明細 | 計32点 |
| **76** | **Ⅱ（ⅰ）計** | **68点** |
| **77** | **Ⅱ（ⅱ）計** | **32点** |
| 78 | Ⅱ 合計 | 100点 |

**「全団体で比が一定」は、規則を見つけた証拠ではなく、同じものを二度数えた証拠だった。**

明細の列を「枝番（ア・イ…）か孫番（①②…）が**生の値として**入っている列」に
限ると、配点計は目標ごとに100点になり、**明細の合計は目標の合計列に等しくなった**
（全国1,741団体で確認）。**項目の配点はそのまま得点になる。素案は正しかった。**

### なぜ生の値で見分けられるか

見出しの1行目から6行目までは横に結合されているため前方補完が要る。
**7行目（孫番）は列ごとの値で、補完してはいけない。**
補完すると「2 / 給付費適正化事業の取組状況 / ア」が
「… / ア / ③」になり、判定表と照合できなくなる。
現に最初の実装では、判定表32件のうち**6件しか照合できなかった。**
補完をやめたら32件すべてが照合できた。

## 6　素案を直した

5-9の文に算術の食い違いがあった。

> 計画に書くだけで取得できるのは56点、本業務の実施で取得できるのが4点で、
> **あわせて60点です。これに認知症施策推進計画の5点を加えた61点**が……

**60＋5は65であって61ではない。** 上表の61点は「記載の56点＋認知症計画の5点」である。
本業務の残り4点は上表に入っていない。文を組み直した。

### 直したら紙面が1頁増えた　―　戻すまでに3往復した

書き替えたあと測り直したら、**推定は111頁のまま動かないのに実測が112頁に増えた。**
A〜Nをすべて行っても116頁となり、**許容115頁を1頁超えた。**

文を詰めた。**戻らなかった。** さらに詰めた。**やはり112頁だった。**

| 5-9の書き方 | 推定 | 実測 |
|---|---|---|
| 直す前 | 111 | **111** |
| 書き替え（順位・推進Ⅲ2/エの説明を含む） | 111 | **112** |
| 詰めた | 111 | **112** |
| さらに詰めた | 111 | **112** |
| 算術の訂正だけにとどめた | 111 | **111** |

**字数の問題ではなく、改頁の位置が送られたことによるものだった。**
5-9に何かを足せば、字数にかかわらず1頁増える位置にあった。

そこで**素案5-9は算術の訂正だけにとどめ、新たに分かったことは成果品15に置いた。**
到達点は従前どおり551点（32項目の範囲）とし、
推進Ⅲ2/エの6点を含む557点は成果品15が示す。

## 8　この回で分かったこと

**検算がきれいに通ることは、正しさの証拠にならない。**
「全国1,741団体すべてで比がちょうど2.000」は、強い証拠に見えた。
**同じものを二度数えていれば、比は必ずぴったり2になる。**
きれいすぎる一致は、規則ではなく重複を疑う。

**「2倍の誤り」を村にお示しするところだった。**
素案の508点を477点に「訂正」する寸前だった。
正しいものを誤りだと言うほうが、誤りを見逃すより害が大きい。
**原典の構造（どの列が明細でどの列が小計か）を見るまで、訂正に手をつけない。**

**見出しの前方補完は、行によって可否が違う。**
横に結合されている行（1〜6行目）は補完が要り、
列ごとの値である行（7行目の孫番）は補完してはいけない。
**一律に補完したため、判定表32件のうち26件が照合できずに落ちていた。**
落ちたことは「判定なし」として静かに通り、優先順位の表が1項目だけになって初めて気づいた。
**数が思ったより少ないときは、絞り込みではなく照合の失敗を疑う。**

**紙面は字数ではなく改頁の位置で動く。**
5-9を詰めても詰めても112頁のままで、算術の訂正だけに戻したら111頁になった。
**「増えたから削る」は効かない場所がある。**
許容に余裕が0頁のいま、本文に1行足すかどうかは分量の判断ではなく、
**その位置に足せるかどうかの判断**である。測らずに足さない。
