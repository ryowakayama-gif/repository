# 新旧対照条文による条文の確定と、2つの訂正（令和8年10月15日）

法律案新旧対照条文（令和8年法律第51号）を受領し、介護保険法第117条の
号の並びを確かめた（PDF 91〜95頁）。号の番号を素案の本文に書き入れた。

**確かめて分かった訂正が2つある。いずれも、本計画の不足を「改正への未対応」と
見ていたのが誤りで、実際は「現行法の求めを書いていなかった」というものである。**

| | 直す前（doc91・doc92の理解） | 原典で確かめた事実 |
|---|---|---|
| 都道府県と連携した取組 | 令和8年法律第51号による**新設** | **現行法（第3項第4号・第5号）に既にある。** 改正は文言の整理 |
| 都道府県への意見聴取 | 同じく**新設** | **現行第13項に既にある。** 改正は対象の拡大（第2項第1号・第2号 → 第1号から第3号まで） |
| 中長期的な推計（量） | 新設の義務 | **現行は第3項第3号の努力義務。** 改正で量だけが第2項第3号の義務へ格上げ。費用と保険料は努力義務のまま |
| 項番号 | 見ていなかった | 新第5項の挿入により**現行の第5項から第7項が第6項から第8項へ**、現行第8項が第9項へ、現行第13項が第14項へ繰り下がる |

## 1　確定した号の並び（介護保険法第117条）

### 第2項（定めるものとする＝義務）

| 号 | 事項 | 改正 |
|---|---|---|
| 一・二 | サービスの種類ごとの量の見込み／地域支援事業の量の見込み | 現行のまま |
| **三** | サービスの種類ごとの量**及び地域支援事業の量**に関する中長期的な推計 | **新設** |
| **四** | 提供体制の確保および地域支援事業の実施に関し、中長期的な観点から市町村が取り組むべき施策 | **新設** |
| 五・六 | 自立支援等施策／その目標 | 現行の三・四が**繰り下がり** |

### 第3項（定めるよう努める）

| 号 | 事項 | 改正 |
|---|---|---|
| 三 | **費用の額および保険料の水準**に関する中長期的な推計 | 現行から「量」が抜け、第2項第3号（義務）へ移る |
| **四** | 生産性の向上・従事者の確保および資質の向上・経営基盤の確立の**双方**の実現を図る取組に資する都道府県と連携した取組 | 新設 |
| **四の二** | **地域支援事業に**従事する者の確保および資質の向上に資する都道府県と連携した取組 | 現行四から範囲が縮み、号が移る |
| **五** | **地域支援事業の実施における**業務の効率化・質の向上その他の生産性の向上に資する都道府県と連携した取組 | 現行五から範囲が縮む |

### 第5項（新設・勘案）

第2項**第1号から第3号まで**を定めるに当たり、次を勘案しなければならない。

- 一　区域ごとの、有料老人ホーム・登録有料老人ホーム・登録住宅の**入居定員総数**
- 二　都道府県が定める区域ごとの、**医療に関する専門的知識を有する者と介護サービス事業者・居宅における医療を提供する医療機関その他の関係者との連携の状況**

### 第14項（現行第13項・手続）

第2項**第1号から第3号まで**を定め、または変更しようとするときは、あらかじめ
都道府県の意見を聴かなければならない（現行は第1号・第2号）。

### 第120条の3（新設）

都道府県は、市町村・公共職業安定所・都道府県福祉人材センター・介護労働安定
センター・介護サービス事業者を構成員とする団体・教育機関等により構成される
**協議会**を置く。施策4-6に書いた「県が設置する協議会」はこれである。

## 2　2つの訂正の意味

### 2-1　「都道府県と連携した取組」は現行法にも既にあった

doc91・doc92では、この3件を「令和8年法律第51号により加わった努力義務」と
整理していた。原典を見ると**現行の第3項第4号・第5号に既にある**。
改正は、対象を「サービス及び地域支援事業に従事する者」から
「地域支援事業に従事する者」へ絞り、新たに「サービスの提供における…
経営基盤の確立の双方」を第4号として立てる、という**文言の整理**である。

したがって、本計画に「都道府県と連携した取組」が0件だったのは
**改正への未対応ではなく、現行法の努力義務を書いていなかった**ということである。
**見立てとしては、より重い。**

### 2-2　都道府県への意見聴取も現行法にある

同じく、現行第13項が**量の見込み（第2項第1号・第2号）について**意見聴取を
求めている。改正はここに中長期的な推計（第3号）を加えるものである。
第9期の計画でも意見聴取が必要だったことになるため、
**第9期ではどのように行ったか**を村に確認する事項に加えた。

### 2-3　項番号の繰り下がりに注意が要る

本計画の1-4と資9は、医療計画との整合を「介護保険法第117条第5項」として
引いている。新第5項（勘案）の挿入により**現行の第5項から第7項は
第6項から第8項へ繰り下がる**（新旧対照条文 PDF 93頁。第120条の2が
「第117条第6項」←「第五項」と改まることでも確かめられる）。

この規定が現行の第何項かは、手元の新旧対照条文では確かめられない
（改正のない項は「（略）」のため）。5-12に掲げ、条文で確かめて
**施行後（令和9年4月1日）の番号に揃える**。
