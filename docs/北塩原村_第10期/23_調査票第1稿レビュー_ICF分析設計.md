## 3. ICFを用いた分析の設計 — ご提案への回答

### 3-1 ご提案の評価

> 「元気な高齢者は高血圧や糖尿、転倒、物忘れなど認知リスクがない場合に健康と定義する」

**発想の方向は正しく、そのまま使える部分があります。**とりわけ、**判定に用いる設問がすべて標準設問で揃う**点は大きな利点です（問8(7) 現在治療中の病気／問2(4) 転倒経験／問4(1) 物忘れ）。独自設問を追加せずに実装できます。

ただし、この定義をそのまま採ると次の3つの問題が生じます。

**(1) 該当者が少なくなりすぎます。**
問8(7)で「1．ない」を選ぶ高齢者は多くありません。高血圧・脂質異常症を含めると、65歳以上の大半が何らかの治療中の疾病を持ちます。回収を450〜500件と見込んでも、「疾病ゼロ」に該当するのは数十件規模になる可能性が高く、**地区別（4地区）・年齢別のクロス集計に耐えません**。

**(2) ICFの考え方とは逆向きになります。**
ICF（国際生活機能分類）は、疾病の有無ではなく「**心身機能・活動・参加**」で生活機能をとらえ、疾病があっても活動・参加ができていれば生活機能は保たれていると考える枠組みです。疾病の有無で「健康」を定義すると、ICF以前の医学モデル（ICIDH）に戻ることになります。

**(3) 村の政策目的から外れます。**
議事録では「**本来元気な軽度者が総合事業等を利用している割合が高い**」という問題意識が示されています。この層は「疾病を持ちながら生活機能は保たれている人」である可能性が高く、疾病ゼロ基準では**取りこぼします**。

### 3-2 代替案

**案B（推奨・主軸）：疾病 × 生活機能の2軸マトリクス**

ご提案の「疾病を基準にする」という発想を残しつつ、母数の問題を回避します。

| | 生活機能リスク 0領域 | 1〜2領域 | 3領域以上 |
|---|---|---|---|
| **疾病 0（治療中の病気なし）** | 完全健康層 | | |
| **疾病 1〜2** | **← 村が言う「元気な軽度者」はここ** | | |
| **疾病 3以上** | 疾病はあるが機能は保たれる層 | | 重複リスク層 |

- 横軸＝問8(7)の疾病数（「1．ない」を0とカウント）
- 縦軸＝リスク判定の該当領域数（運動器・転倒・閉じこもり・低栄養・口腔・認知・うつ・IADL）

**この形式の利点**

1. 母数の問題が起きません。全回答者が9象限のどこかに入ります。
2. 村が求める「前向きな分析」になります。「**高血圧や糖尿病があっても、○割の方は生活機能が保たれています**」という示し方ができ、共助・互助の担い手が「特別に健康な人」ではなく「ふつうに疾病を持つ多数派」であることを示せます。
3. 「疾病あり×機能低下なし」の象限に**要支援認定者や総合事業利用者がどれだけいるか**を、管理番号による認定データとの紐付けで特定できます。**議事録の問題意識をそのまま検証できます。**

**案A（併用）：生活機能ベースの4層区分**

施策の対象者を切り出すための区分です。

| 層 | 定義 | 施策上の位置づけ |
|---|---|---|
| 第1層 元気・活躍層 | リスク判定 全非該当 かつ 問5(1)のいずれかに月1回以上参加 | 現在の担い手 |
| **第2層 元気・未参加層** | リスク判定 全非該当 だが 社会参加なし | **共助・互助の担い手候補。最重要ターゲット** |
| 第3層 リスク層 | リスク判定1つ以上該当・認定なし | 介護予防の対象 |
| 第4層 要支援・要介護層 | 認定あり（名簿から） | 給付・総合事業の対象 |

第2層のうち、問5(2)(3)で「是非参加したい」「参加してもよい」と答えた人数が、**有償ボランティア等の担い手の推計値**になります。これは議事録の「共助・互助への転換」を数字で裏づける材料です。

**案C（委員会資料の見せ方）：ICF 5領域のプロフィール**

第2回策定委員会（11月）の説明用に、ICFの5領域をレーダーチャートで地区別に示します。ただし領域スコアの合成には恣意性が伴うため、**本文の根拠は案B・案Aの実数で示し、案Cは説明の補助**に留めるのが安全です。

### 3-4 結論：ICF分析のために独自設問を追加する必要はありません

上表のとおり、**ICFの5領域はすべて標準設問（必須＋オプション）で埋まります**。むしろ、標準のオプション項目を採用しない判断のほうが分析の幅を狭めます。

**ICF分析のために推奨する対応は1つだけです。**
→ **§1-2の問7(7)（この1か月間に会った友人・知人の人数）を採用すること。** 番号ずれの解消と分析軸の確保を同時に達成できます。

## 4. 村独自設問の採否判断

第1稿のニーズ調査には**14問の村独自設問**が含まれています。標準（必須＋オプション）が約66問ですので、**全体で約79問**になります。

### 4-1 判断

| 村独自設問 | 判断 | 理由 |
|---|---|---|
| 問3(9) 定期的に歯科医院を受診していますか | **残す** | 第9期の課題。交付金の口腔関連指標に対応 |
| **問3(10) 1日に何回食事をとりますか** | **削除を提案** | 低栄養は問3(1)BMI・(7)体重減少・(8)共食の3問で把握できます。**唯一、他の設問と役割が重複しています** |
| 問7(8) 現在利用している公的サービス以外の支援・サービス | **残す** | 共助・互助の実態把握の核心 |
| 問7(9) 利用先（無償／有償／その他＋自由記入） | **残すが簡素化を提案** | 有償ボランティアの実態は村の最重点。ただし**自由記入3欄は入力コストが高い**ため、選択式＋自由記入1欄への簡素化を提案します |
| 問7(10) 今後必要と感じる支援・サービス | **残す** | 除雪を含む。第9期の住民ニーズ第1位 |
| 問8(8) 定期的な通院・服薬 | **残す** | 保健事業との一体的実施の指標。ポリファーマシー対策の基礎 |
| 問10(1)〜(5) 在宅医療・介護・終末期医療 | **残す** | 交付金の支援目標Ⅲ「人生の最終段階における支援」4項目が0点。**ACPの実態を把握する唯一の手段** |
| 問11(1)〜(3) 成年後見制度 | **残す** | 議事録の重点論点。見える化に該当データがありません |

**削除を提案するのは問3(10)の1問のみです。**他の13問はいずれも第10期の施策・交付金の指標と結びついており、削るべきではありません。

### 4-2 頁数への影響

仕様書の目安は「ニーズ調査 A4約12頁」です。標準の必須＋オプション調査票が12頁程度であるため、**14問の追加で12頁を超える可能性が高い**と見込まれます。

**対応の優先順位**

1. 問3(10)を削除（1問）
2. 問7(9)の自由記入欄を簡素化（レイアウト圧縮）
3. 上記で足りない場合は、**設問を削るのではなくレイアウト（段組み・級数・行間）で吸収**する

**標準のオプション項目を落として頁数を稼ぐことは推奨しません。**とくに問4(10)〜(18)（知的能動性・社会的役割）と問7(5)〜(8)（環境因子）は、ICF分析の「参加」「環境因子」の軸そのものであり、これを落とすと村が求める分析ができなくなります。
