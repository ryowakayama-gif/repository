# 確認事項の鮮度の点検と、居住系サービスの受給者数の算出（令和8年10月8日）

作業順位1（Ⅱ-117 確認事項の鮮度）を行った。
その過程で、**見込量推計の停止要因としていたものの一部が、受領済みのデータで解けている**
ことが分かり、居住系サービスの受給者数を按分の参考値から算出に切り替えた。

## 1　確認事項の鮮度を機械で見るようにした（順位1）

### 1-1　点検59　参照先の実在

確認事項は照会票として村に渡る。素案の節を書き替えたり図を足し引きすると、
確認事項に書いた参照先だけが残り、**村に存在しない節を示す**ことになる。

**点検59「確認事項が指す素案の節・図が実在すること」**を新設した。
確認事項が指す節・図の69件を突き合わせ、実在しないものがないことを確かめる。
「資料3の3-3」のような委員会資料の節番号、docNN、図NN-M は対象外とする。

走査で1か所、**委員会資料の節番号を素案の節と読み違える書き方**が見つかった。
「資料3の3-3・3-4・3-6は…」に続く文で「3-6は第10期に…」と書いており、
村が読むと素案の3-6と取れる。「資料3の3-6」と書き改めた。

### 1-2　「ない」と述べている30件を1件ずつ当たった

確認事項のうち「がない」「未作成」「未実施」と述べているものを機械で洗い出し、
30件を1件ずつ確かめた。**2件が現に古くなっていた。**

| 確認事項 | 書かれていたこと | 現在 |
|---|---|---|
| 介護保険事業状況報告 月報 第2表・第3表 | 施設・居住系はサービス種類別の受給者数の系列がない | **居住系2種は算出できる**（下記2） |
| 医療介護連携に関する加算の算定状況 | 加算の算定状況が未把握 | **算定率は見える化で把握済み**（10月6日に図にした）。残るのは実数。優先度をBからCへ |

残る28件は、現時点では正しい記述である。

## 2　居住系サービスの受給者数を算出に切り替えた

### 2-1　2つの系列を割れば出せる

「見える化」システムにサービス種類別の受給者数の系列はない。
しかし次の2つはサービスごとに収録されている。

- **D13系列** 第1号被保険者1人あたり給付月額（サービス種類別）
- **D17系列** 受給者1人あたり給付月額（サービス種類別）

したがって

> **受給者数 ＝ 第1号被保険者1人あたり給付月額 × 第1号被保険者数 ÷ 受給者1人あたり給付月額**

### 2-2　2通りで検算した

**検算1　受給者数の系列があるサービスで一致するか**

通所介護（受給率の系列があり、素案は別の経路で算出している）で試したところ、
**令和5年度37.2・令和6年度42.2・令和7年度38.9人／月**となり、素案の値と一致した。

**検算2　居住系の和が見える化の居住系受給者数と合うか**

| | 算出の和 | 見える化 D1 |
|---|---|---|
| 令和5年度 | 24.4人／月 | **24.4人／月** |
| 令和6年度 | 24.9人／月 | **24.9人／月** |
| 令和7年度 | 27.1人／月 | 27.4人／月（差0.3人） |

令和5・6年度は完全に一致した。令和7年度の0.3人は、
地域密着型特定施設入居者生活介護の給付費が0で残差を割り振れないことによる。

### 2-3　D17系列があるのは15サービス

| | サービス |
|---|---|
| **算出できる（15）** | 訪問介護・訪問入浴介護・訪問看護・訪問リハビリテーション・居宅療養管理指導・通所介護・通所リハビリテーション・地域密着型通所介護・認知症対応型通所介護・短期入所生活介護・短期入所療養介護・福祉用具貸与・介護予防支援／居宅介護支援・**特定施設入居者生活介護**・**認知症対応型共同生活介護** |
| **算出できない（按分のまま）** | 介護老人福祉施設・介護老人保健施設・介護医療院・介護療養型医療施設・地域密着型特定施設入居者生活介護・地域密着型介護老人福祉施設・小規模多機能型居宅介護・看護小規模多機能型居宅介護・定期巡回・夜間対応型訪問介護・特定福祉用具販売・住宅改修 |

**停止しているのは施設サービス3種（特養・老健・介護医療院）だけ**になった。
この3種は月報 第2表・第3表の実数を待つ。

### 2-4　改まった数値

| | 改訂前（按分） | 改訂後（算出） |
|---|---|---|
| 認知症対応型共同生活介護（令和7年度） | 25.0人／月 | **23.8人／月** |
| 　同　村内定員27人に対する到達率 | 92.6% | **88.1%** |
| 特定施設入居者生活介護（令和7年度） | 2.4人／月 | **3.3人／月** |

**見込量は給付費（千円／年）で算定しているため、保険料には影響しません。**
人／月は表示と到達率に用いる値です。

改めた箇所は、素案2-5・5-4(5)・5-4(8)・資6の事項七と事項八、確認事項3件です。

### 2-5　稼働率が下がったことの意味

認知症対応型共同生活介護の稼働率は92.6%ではなく88.1%でした。
ただし**令和5年度74.8%→令和6年度77.8%→令和7年度88.1%と上がり続けている**ことは変わりません。
「村内に受け皿の余地がほとんどない」という水準の表現は88%に合わせて改める必要があり、
施策3-2と2-11の課題1の書きぶりの見直しを翌営業日の順位4に置きました。

### 2-6　点検72として固定した

**点検72「居住系の受給者数の算出が見える化と合うこと」**を新設した。

- サービス別に、表の値が算出の値と一致すること（6件）
- 3か年とも、居住系の和が見える化の居住系受給者数と0.5人以内で一致すること

按分に戻すと不適合になることを自己試験で確かめた。
