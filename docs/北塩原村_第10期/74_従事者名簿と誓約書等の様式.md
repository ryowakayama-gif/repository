# 従事者名簿・誓約書・持出簿・廃棄記録簿の様式（令和8年10月9日）

doc16（個人情報取扱管理ルール）§3・§4 が求めている様式のうち、未作成であった4件を作った。
根拠：仕様書6(1)「業務上知り得た個人情報を第三者に開示・漏洩しない」（WBS Ⅴ-97）／
北塩原村個人情報保護条例／個人情報の保護に関する法律。

**調査票の回収期限は令和8年10月16日（金）である。** 回収が始まると、
調査票の原本・管理番号対応表という個人情報を取り扱うことになるため、
その前に従事者を確定し、誓約書を取得しておく必要がある。

---

## 0　4件の様式と、いつ使うか

| 様式 | doc16の根拠 | 作成・取得の時期 | 保管 |
|---|---|---|---|
| 様式1　従事者名簿 | §3 | 契約締結後ただちに作成し村へ提出。変更時は事前に届出 | 当方で保管し、村へ写しを提出 |
| 様式2　誓約書 | §3 | 業務開始前に全従事者から取得 | **業務完了後5年間**当方で保管 |
| 様式3　個人情報 持出簿 | §4-1 | 紙媒体を持ち出すとき（原則禁止。やむを得ない場合のみ） | 業務完了後5年間 |
| 様式4　廃棄記録簿 | §4-2 | 紙媒体を廃棄したとき | 業務完了報告に添付 |

**記入後の様式は版管理に置かない。** 様式1・2・3には従事者の氏名が入るため、
doc16 §5-3（職員の氏名・連絡先は版管理に置かない）により、
記入後のものはリポジトリに置かず、当方の施錠可能な保管場所と
アクセスを限定した電子領域で管理する。本書に載せるのは**空の様式だけ**である。

## 1　様式1　従事者名簿

```
                                              令和  年  月  日

  北塩原村長 様

                        ビズアップ公共コンサルティング株式会社
                        業務責任者                      印

        個人情報取扱従事者名簿

  第10期北塩原村高齢者福祉計画・第10期北塩原村介護保険事業計画策定業務
  （委託第27号）において個人情報を取り扱う従事者を、下記のとおり届け出ます。

                        記

  1 従事者
  ┌──┬──────────┬────────┬──────────────┬──────┬──────┐
  │ # │ 氏名               │ 所属           │ 本業務における役割           │ 誓約書     │ 研修       │
  │    │                    │                │                              │ 取得日     │ 受講日     │
  ├──┼──────────┼────────┼──────────────┼──────┼──────┤
  │ 1  │                    │                │ 業務責任者                   │            │            │
  ├──┼──────────┼────────┼──────────────┼──────┼──────┤
  │ 2  │                    │                │                              │            │            │
  ├──┼──────────┼────────┼──────────────┼──────┼──────┤
  │ 3  │                    │                │                              │            │            │
  └──┴──────────┴────────┴──────────────┴──────┴──────┘

  2 取り扱う個人情報の範囲（従事者ごとに該当するものに○）
  ┌──┬──────┬──────┬──────┬──────┬──────┐
  │ # │ 宛名ラベル │ 調査票原本 │ 管理番号   │ 回答データ │ 要介護認定 │
  │    │            │            │ 対応表     │            │ データ     │
  ├──┼──────┼──────┼──────┼──────┼──────┤
  │ 1  │            │            │            │            │            │
  └──┴──────┴──────┴──────┴──────┴──────┘

  3 鍵および権限の管理
    (1) 施錠可能な保管場所の鍵は業務責任者が管理します（doc16 §4-1）。
    (2) 電子データ専用領域へのアクセス権限は、本名簿に記載の者に限り付与します。
    (3) 個人所有の端末および記録媒体への保存は行いません。

  4 変更の届出
    従事者の追加・削除が生じた場合は、**事前に**本名簿を更新して届け出ます。
    削除する場合は、当該者のアクセス権限を削除した日を併記します。

  5 添付
    本名簿に記載の全従事者の誓約書（様式2）の写し
```

**「本業務における役割」の書き方。** 調査票の設計・印刷・発送は他メンバーの担当であり、
計画策定と集計・分析は当方の担当である。役割の欄は、
その者が実際に行う工程（宛名ラベルの取扱い／封入・封緘／開封・データ入力／
集計・分析／計画の執筆）で書き、取り扱う個人情報の範囲（2）と対応させる。
**役割がないのに名簿に載せると、アクセス権限を絞る意味がなくなる。**

## 2　様式2　誓約書

```
                                              令和  年  月  日

  ビズアップ公共コンサルティング株式会社
  業務責任者 様

                        所属
                        氏名                            印

        個人情報の取扱いに関する誓約書

  第10期北塩原村高齢者福祉計画・第10期北塩原村介護保険事業計画策定業務
  （委託第27号）に従事するにあたり、個人情報の取扱いについて
  下記の事項を遵守することを誓約します。

                        記

  1 守秘
    業務上知り得た個人情報を、第三者に開示または漏洩しません。
    この義務は、本業務の従事を離れた後および契約期間の終了後も変わりません。

  2 目的外利用の禁止
    個人情報を、本業務の目的以外に利用しません。
    複写・複製は業務上必要最小限にとどめ、複写物も原本と同一に管理します。

  3 持出しの禁止
    個人情報を含む資料を、承諾なく作業場所の外に持ち出しません。
    やむを得ず持ち出す場合は、村の事前承諾を得たうえで持出簿（様式3）に記録します。

  4 個人所有の端末等への保存の禁止
    個人所有の端末・記録媒体・クラウドサービスに個人情報を保存しません。
    電子データは、アクセス権限を限定した指定の領域でのみ取り扱います。

  5 事故の報告
    個人情報の漏洩・紛失・毀損またはそのおそれを認めたときは、
    ただちに業務責任者に報告します。報告を遅らせたり、自ら処理しようとしません。

  6 返還・消去
    業務の完了または従事を離れるときは、保有する個人情報を
    業務責任者の指示に従って返還または消去します。

  7 法令等の遵守
    個人情報の保護に関する法律、北塩原村個人情報保護条例および
    個人情報取扱管理ルール（doc16）の定めに従います。

  8 違反した場合
    本誓約に違反した場合は、法令および就業規則に基づく措置を受けることに
    異議を申し立てません。

  （本誓約書は、業務完了後5年間、受託者において保管します。）
```

**条例の名称は村にご確認のうえ確定する。** 本様式は「北塩原村個人情報保護条例」と
置いているが、令和5年4月の個人情報保護法の改正により地方公共団体の条例が
整理されているため、**現に効力を有する条例の名称と条番号を村にご確認いただく**
必要がある（doc16 §10-1）。確認前に従事者から誓約書を取得する場合は、
「個人情報の保護に関する法律及び北塩原村の定める規程」として取得し、
名称が確定した時点で差し替える。

## 3　様式3　個人情報 持出簿

doc16 §4-1 は紙媒体の持出しを**原則禁止**とし、やむを得ない場合は
村の事前承諾を得たうえで記録することとしている。
**承諾のない持出しは、記録があっても違反である。**

| # | 持出日時 | 対象（媒体・件数） | 持出先 | 目的 | 村の事前承諾（日・方法） | 返却日時 | 実施者 | 確認者 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**記入の約束ごと**

1. 1件の持出しを1行とする。まとめて記入しない。
2. 「村の事前承諾」が空のまま持ち出してはならない。
3. 返却日時は、返却を確認した者（確認者）が記入する。持出者が自分で書かない。
4. 持出し中に複写した場合は、複写物の件数と廃棄の日を備考に記す。

## 4　様式4　廃棄記録簿

doc16 §4-2 は、調査票原本・宛名ラベル・対応表および誤印刷・試し刷りを
**溶解処理または細断（クロスカット）**により廃棄し、
日時・対象・方法・実施者を記録して**業務完了報告に添付**することとしている。

| # | 廃棄日時 | 対象 | 媒体 | 数量 | 方法 | 実施者 | 立会者 | 証明書の有無 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**記入の約束ごと**

1. 方法は「溶解処理」「細断（クロスカット）」のいずれかを書く。
   「廃棄」「処分」とだけ書かない。何をしたかが残らない。
2. 溶解処理を委託した場合は、溶解処理証明書の有無と番号を記す。
3. 誤印刷・試し刷りも対象である。一般ごみとして廃棄しない（doc16 §4-2）。
4. 電子データの消去は本簿ではなく、doc64 §3-2「消去の実施記録」に記録する。
   **媒体が違うと確かめ方が違う**ため、簿を分けている。

## 5-2　レッドチーム走査の対象に加えた

**本書は村へ渡すものであり、かつ個人情報の取扱いそのものを定めた文書である。**
記入後の様式を誤って本書に貼ってしまうと、個人情報が版管理に入る。
これを機械で防ぐため、レッドチーム走査（`scripts/redteam_soan.py`）の対象に加えた。

| 走査 | 本書に当てるか | 理由 |
|---|---|---|
| a 日本語でない文字 | 当てない | 罫線（┌─┬┐）が当然に出る |
| b 受託者を主語とする語 | 当てない | 様式の性質上「受託者」が主語になる（名簿は受託者が村へ提出し、誓約書は受託者において保管する） |
| **c 禁止表現** | **当てる** | 様式の説明文に断定の言い回しが混じらないようにする |
| **d 個人情報の形** | **当てる** | **記入後の様式を貼ったことを検出する** |
| f 半角・全角のゆれ | 当てない | 表の体裁で出る |

**自己試験で確かめた。** 様式1の氏名の欄に電話番号を入れた状態にすると、
d が「電話番号の形」として検出する。戻すと要確認0件に戻る。

## 6　残っていること

| 事項 | 状況 |
|---|---|
| 従事者名簿の提出 | **様式はできた。記入と提出は契約締結の確認後**（Ⅴ-97・０-02） |
| 誓約書の取得 | 同上。**調査票の回収期限（10月16日）の前に取得する** |
| 従事者研修の実施 | doc16 §9 #4。本ルールと村条例の内容について業務開始前に実施する。条例の名称の確認が前提 |
| 村指定の様式の有無 | 村にご確認いただく（doc16 §10-2）。村指定のものがあればそれに従う |
| 条例の名称と条番号 | 村にご確認いただく（doc16 §10-1）。確認前は法律名と「村の定める規程」で取得する |
| 溶解処理の委託先と費用の扱い | doc64 に残っていることとして挙げている |
