# 委員会資料の書体をそろえ、素案をカラー版と単色版の2つで管理する（令和8年10月23日）

村より「委員会資料も同じ書体にそろえること」「障がい計画と同様に仕様書に合わせて、単色版と2つの運用で素案管理すること」とのご指示を受けた。

## 1. 委員会資料の書体

第2回・第3回の委員会資料（成果品08・12）と参考資料（成果品19）を、計画書と同じ BIZ UDPゴシック に改めた（build_shiryo_docx.js）。あわせて計画書と同じ見切れの対策を入れた。

- 11ptを超える字（表紙の題・資料名）の行送りを最小値指定にした
- 図の高さの上限を9.3inから8.4inに下げた（見出しと同じ頁で頁の下からはみ出さない高さ）
- 表紙から頁番号を外した

## 2. 単色版と2つの運用

### 根拠

仕様書5①は、計画書を「A4判・両面約100頁・モノクロ」で作成するとしている（spec_data 仕様書5①-a、WBS Ⅳ-89）。障がい福祉計画も、図はカラーで作りつつ、仕様書のモノクロ（コピー）印刷に耐えることを管理している。

### 運用

| | カラー版 | 単色版 |
|---|---|---|
| ファイル | 06_…計画素案.docx／17_…計画素案_公表用.docx／18_…計画書_公表用.docx | それぞれ末尾に「_単色」 |
| 用途 | 画面での閲覧・委員会での投影・電子媒体 | 印刷・製本（仕様書5①） |
| 組み方 | build_soan_docx.js | build_soan_docx.js --tanshoku |
| 中身 | 同じ素案（soan.json／kouhyou_soan.json）から組む。本文・割付・頁数は同じ | |

- 単色版は、見出しの帯・表の見出し行・節の色文字・注記の罫を灰の濃淡に置き換える（濃紺→262626、青→595959、淡青→EDEDED、注記の赤→7F7F7F）。地と字の明度差は大きく取り、白黒コピーでも潰れない
- 図は28点のうち27点がもとから灰の濃淡で描かれている。色を持つ図3-1（施策の体系）だけ単色の図（fig3-1_施策体系図_単色.png）を別に描いた。施策の区分（継続・強化・改称・新規）はもとから塗りの濃淡と罫の太さ・破線で分けている
- Word が持つ見出し・リンクの既定の色（青）も単色にした（宣言しないと目次のリンク等に色が残る）

### 管理の仕組み

- 点検84（verify_soan）：06・17・18の3組について、①両版の本文の文字が同じこと（片方だけ組み直していないこと）、②単色版の文字・塗りに色がないこと、③単色版の図に色がないことを毎回確かめる
- 納品物の台帳（nohin_data）に単色版3点を成果品として登録した
- 頁数は割付が同じためカラー版の実測をそのまま用いる（18の単色版を変換して118頁＝カラー版と同じことを確かめた）

## 3. 委員会資料の単色版

同日、村より「委員会資料も単色で作成すること」とのご指示を受け、委員会資料にも単色版を設けた。

| カラー版 | 単色版 |
|---|---|
| 08_…第2回策定委員会資料.docx | 08_…第2回策定委員会資料_単色.docx |
| 12_…第3回策定委員会資料.docx | 12_…第3回策定委員会資料_単色.docx |
| 19_…策定委員会参考資料_交付金の評価と第10期の目標.docx | 同 _単色.docx |

- 組み方は `node scripts/build_shiryo_docx.js [3|kofukin] --tanshoku`（回の指定と順不同）
- 置き換えは計画書と同じ（濃紺→262626、青→595959、淡青→EDEDED、注記の地→F2F2F2・罫→7F7F7F）。要点の囲みは黄の地（FFF2CC）→F2F2F2、黄土の罫（BF8F00）→404040 とした。図3-1は単色の図を用いる
- 確かめ方は計画書と同じで、共通の部品 scripts/tanshoku_check.py にまとめ、verify_soan 点検84（06・17・18）と verify_shiryo 点検26（08・12・19）から使う
- 印刷して配る資料は単色版を、投影・電子での送付はカラー版を用いる
