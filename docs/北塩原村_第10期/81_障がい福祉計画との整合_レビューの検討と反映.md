介護保険事業計画）の側の修正を行った（WBS Ⅱ-72）。

| | 確認した結果 |
|---|---|
| 障がい計画のブランチ | `claude/kitashiobara-disability-plan-order-36oyd1`（令和8年10月4日が最終）。当方の別業務として同時に策定中 |
| 本計画の修正 | 1-4に節を新設／施策3-1・施策4-1に取組を追加／資9（関連計画との対照）を新設／人口の系列の断りを追加 |

## 1　レビューの中心的な指摘は正しい ― ただし診断は逆だった

レビューは次のとおり述べている。

> 障がい計画に「高齢者福祉計画・介護保険事業計画との連携」の章があるのに対し、
> 第10期介護保険事業計画素案では「障がい福祉計画」「障害福祉」「共生型サービス」の
> 明示的な相互参照を現時点で確認できない。したがって整合は片方向である。

### 1-1　本計画の側に参照がないことは、そのとおりだった

素案を走査した結果である。

| 語 | 素案での件数 |
|---|---:|
| 障がい福祉計画 | 0 |
| 障害福祉 | 0 |
| 共生型 | 0 |
| 障がい者 | 0 |
| 適用除外 | 0 |
| 障害支援区分 | 0 |

「成年後見制度」の用語解説に「知的障害、精神障害などにより判断能力が十分でない方」と
あるだけで、**計画間の整合としては皆無**であった。レビューの指摘は当たっている。

### 1-2　しかし障がい計画の側にも、本計画との連携の節は無かった

**ブランチの素案を確認したところ、障がい計画の第7章「他計画との連携」は次の3計画を
扱っており、高齢者福祉計画・介護保険事業計画との連携の節は置かれていなかった。**

1. 第3次健康21・北塩原村グッドヘルスプラン
2. 北塩原村第五次総合振興計画
3. 北塩原村こども・子育て計画

同章の冒頭は「村からの依頼を踏まえ、本計画と『第3次健康21』及び『北塩原村第五次
総合振興計画』との連携について、以下に整理します」と書かれており、**村の依頼により
扱う計画を定めた章**である。

したがって**整合は片方向ではなく、双方に無い状態であった。**
レビューの「障がい計画から介護計画を参照するだけでなく、介護計画側にも明記する」という
処方は、前提が片方向であることに拠っている。実際には**双方に置く必要がある。**

## 2　レビューが指す記述が原典に見当たらないものが3件ある

レビューの優先Aのうち3件は、**ブランチの素案では確認できなかった。**

| 【優先A】「65歳に達すると介護保険法の給付が優先します」が一律に読める → 表現の修正 | **すでに修正後の表現で書かれている。** 「一律に適用するものではなく、市町村が本人の意向を聴取し、介護保険サービスで必要な支援が受けられるかを個別に確認したうえで支給決定を行います」 |

## 3　本計画に加えたもの

### 3-1　1-4（計画の位置づけ）に「障がい福祉計画との関係」を新設

介護保険優先原則の書き方は、障がい計画の素案と同じ水準に揃えた。

> 障害者総合支援法第7条により、65歳以上となって介護保険の被保険者となった方については、
> 給付の内容が重なる部分について原則として介護保険制度が優先されます。ただしサービスの種類、
> 本人の心身の状況、利用の意向、介護保険で確保できる支援の量を個別に確認するものであり、
> **年齢に達したことのみを理由として一律に介護保険へ移るものではありません。**

あわせて、本村の規模では1人の移行が両計画の見込量を動かすことと、
**実際に移る分だけを両計画の見込量へ同じ年度に反映する**ことを書いた。

### 3-2　施策4-1（地域包括支援センターの機能強化）に取組を3つ追加

| 追加した取組 | レビューの該当箇所 |
|---|---|
| 40歳・65歳到達時に障がい福祉担当・相談支援専門員と情報を共有し、制度間の移行・併用を調整する。介護支援専門員と相談支援専門員が引継ぎを行う | §8 連携節の案 |
| 高齢の方が障がいのある家族の主たる介護者となっている世帯は、世帯全体の生活の継続という観点から連携して支援する | §16 8050型世帯 |
| 福祉用具・補装具・住宅改修について、制度が移ることで現に使っている用具が使えなくなることがないよう移行の前に確かめる | §18 福祉用具 |

指標に「65歳に達する障がい福祉サービス利用者の移行の確認（未実施→到達者全員）」を加えた。

### 3-3　施策3-1（居宅サービスの確保）に共生型サービスを追加

障がい計画の側は「村内及び圏域の介護保険事業所に対し、指定取得の意向を確認する」
「圏域4町村と協調して制度周知を行い、指定の意向がある事業所を把握する」としている。
本計画の側は、その相手方としての取組を書いた。

**レビューの注意（「働きかける」ことと「指定を受ける」ことは別）を指標に反映した。**

| 指標 | 現状値 | 目標値 |
|---|---|---|
| 共生型サービスについて協議した事業所数 | 0か所 | **村内3か所** |
| 共生型サービスの指定を受けた事業所数 | 0か所 | **―（協議の結果による）** |

指定を受けるかどうかは事業者の判断であるため、**村が約束できるのは協議までである。**
指定の数を目標値に置くと、村が達成できない目標を計画に書くことになる。

生涯学習推進計画については、**計画期間が令和9年度で満了する**ため

### 3-5　人口の系列の断りを追加（2-1）

素案の令和7年の値（総人口2,315人・高齢化率40.5%）は**国立社会保障・人口問題研究所の
推計**である。表の出典には明記していたが、**本文は「40.5%となり」「2,315人へと減少しました」
と実績のように書いていた。**

- 序の「40.5%となり」→「**40.5%と推計され**」
- 2-1に段落を追加。推計であること、住民基本台帳とは基準日も値も異なること、
  障がい福祉計画は住民基本台帳の実績を用いているため同じ年の高齢化率が異なる値で
  現れること（資9）

### 3-6　若年性認知症と障がい福祉の接続（4-7(2)）

素案は「本村の該当者の状況は把握できていません」で止まっていた。
第2号被保険者の認定者が各年度2人から3人である（5-3）ことと結びつけ、
その方々に若年性認知症の方が含まれるか、障がい福祉サービス・精神保健の支援を
受けているかを障がい福祉担当との間で確かめる旨を加えた。
就労の継続は障害者総合支援法の就労系サービスが受け皿となる場合がある。

| **A** | 障がい福祉計画との連携の節を双方の計画に置くこと（現在はどちらにも無い） | 本計画の記載はこのままお示しする。障がい福祉計画の側は別業務のため提案にとどめる |
| **A** | 数を揃える3つの対象（第2号被保険者・65歳到達者・適用除外施設入所者） | 第2号被保険者は各年度2〜3人を据え置き、65歳到達による移行は0、適用除外の該当者はなしとして算定し、資9と5-12に明記する |
| B | 成年後見の指標名を両計画で揃えること | 現在の指標名のまま、障がい福祉計画の事業量とは別の指標であることを注記する |

### 4-1　適用除外施設入所者は保険料の分母を動かす

**指定障害者支援施設に生活介護および施設入所支援の支給決定を受けて入所している方は、
介護保険の被保険者とならない。**
障がい計画は施設入所支援の利用者を扱っており、同一の名簿で確かめる必要がある。

**該当者がいる場合、本計画の第1号被保険者数が減り、保険料の分母が動く。**
本村の第1号被保険者は約1,000人であるため、数人でも保険料基準額に効く。
これが3つの対象のうち唯一、本計画の数値に直接効くものである。

### 4-2　個人情報の扱い

突合に**氏名は要らない。** 匿名の整理番号・生年月・区分・利用しているサービス・
月の利用量で足りる（doc16 §5-2）。計画書には人数のみを載せる。
レビューが提案する「65歳移行台帳」も、この形であれば内部資料として扱える。

## 5　頁数 ― 削減案の余裕が1頁に減った

| | 削減前 | 削減案をすべて行った場合 |
|---|---:|---:|
| 改訂前 | 120頁 | 107頁 |
| **改訂後** | **122頁** | **109頁** |
| 村が許容する頁数 | ― | **110頁** |

**余裕は3頁から1頁に減った。** これ以上の加筆は、削減案の組み合わせでは許容に収まらなくなる。
以降は加えるときに同じだけ削る前提で進める。

**許容に収まる組み合わせも変わった。**

| 組み合わせ | 改訂前 | 改訂後 |
|---|---:|---:|
| 案A・B・E・F・H（5案） | 110頁 | **112頁（許容を超える）** |
| 案A・B・E・F・H・J（6案） | 108頁 | **110頁** |
| 案A・B・C・E・F・H・J（7案・最小） | 107頁 | **109頁** |

改訂前は5案で許容に収まったが、**改訂後は6案を行わないと収まらない。**
Ⅱ-113（削減案の組み合わせの対応表）の記述を組み直した。

### 5-1　点検49の判定の対象を改めた

点検49は「計画書全体が仕様書の目安100頁から±20頁を超えて離れていないか」も見ていた。
**改訂により122頁となり、この判定で不適合になった。**

分量の判定は点検52が持っている（削減案をすべて行って村が許容する110頁に収まるか）。
村が10頁程度の超過を許容すると判断し（10月10日）、削減案で届くことを点検52が
確かめている以上、**削減前の素案を別の目安で二重に判定すると、村の判断と食い違う
警告が出る。** 点検49の第3の判定を外し、2つの推定が互いに矛盾しないことだけを見る形にした。

> **検査を緩めたのではない。** 削減前が膨らみすぎる危険は点検52が受け持っている
> （すべて行っても許容に収まらなければ不適合になる）。現に余裕は1頁しかなく、
> 点検52はこれを見ている。

### 5-2　第2回資料1の別冊の頁数も直した

第2回策定委員会資料の配付資料一覧は、別冊（計画素案）を「約127頁」としていた。
積算が131頁になったため、点検10（資料1の別冊の頁数と積算の整合・許容±3頁）が落ちた。
**約131頁に直した。**
