# 確認事項の区分　―　村に尋ねるもの／当方で進めるもの／先行して縮小するもの（令和8年10月15日）

確認事項は209件ある（うち解決済34件・未解決208件）。**すべてを村にお尋ねすると、
村の手が足りずに答えが返らない。**答えが返らなければ計画が止まる。

そこで未解決の208件を3つに分けた。**基準は一つである。当方で解消すべき計算上・
資料解釈上の疑問を、村の確認責任に転嫁しない。**

| 区分 | 意味 | 件数 |
|---|---|---|
| **Ｂ　当方で進める** | 国・県の原典、公表資料、当方が受領済みの資料、当方の算定だけで片がつく。**村には尋ねない** | **21件** |
| **Ｃ　先行して縮小** | 他の計画・公表資料で大半が書ける。**当方が先行して整理し、村固有の事実だけを尋ねる** | **45件** |
| **Ｄ　村のご回答が必要** | 村の決算・実績・内部データ・意向・判断でなければ分からない | **142件** |

**村にお尋ねするのはＣ・Ｄの187件。**うち調査工程（束7・他メンバー担当）34件と社内1件を除き、
照会票に載るのは152件（Ｃ44件・Ｄ108件）である。

**Ａ（解決済み）は `wbs_kakunin.SOLVED` が34件を持つ。本台帳は未解決分のみを扱う。**

---

## 1　台帳　`scripts/wbs_kubun.py`

```
KUBUN[題] = (区分, 当方が先行して行うこと)
```

**Ｄは既定であり書かない。Ｂ・Ｃだけを掲げる。**66件である。
鍵は確認事項の題そのものであり、`wbs_pending.IMPACT` と同じ持ち方にした。

**鍵が外れると黙ってＤに落ちる。**落ちると、当方で片をつけるはずのものを村に尋ねてしまう。
これを防ぐため、**点検22**（`verify_wbs.py`）が、台帳の鍵がすべて確認事項に実在すること、
当方が先行して行うことが空でないこと、解決済みのものに区分がないことを毎回確かめる。
**台帳の鍵を1字ずらすと落ちることを確かめてある。**
