## 1. 資料B'（ニーズ調査）の突合結果

### 1-1. 標準様式の構成（令和7年8月版）

必須35問／オプション30問。第9期（令和4年8月版）からの変更は**就労の追加のみ**（手引きQ1）。

| 問 | 内容 | 必須 |
|---|---|---|
| 問1 | あなたのご家族や生活状況について | 3 |
| 問2 | からだを動かすことについて | 7 |
| 問3 | 食べることについて | 4 |
| 問4 | 毎日の生活について | 6 |
| 問5 | 地域での活動について | 3 |
| **問6** | **就労について**（第10期新設・**全てオプション**） | 0 |
| 問7 | たすけあいについて | 4 |
| 問8 | 健康について | 6 |
| 問9 | 認知症にかかる相談窓口の把握について | 2 |
| | **計** | **35** |

### 1-2. 一致状況

**問1・問2・問3(1)〜(8)・問4・問5 は、設問文・選択肢・順序とも標準様式と完全一致**しています。

**必須35問はすべて資料B'に含まれています。**

村独自設問は15問（問3(9)歯科受診、問3(10)食事回数、問6(8)(9)(10)保険外サービス、問7(8)服薬、問9在宅医療・終末期、問10成年後見、問11自由意見）。手引きは「保険者における調査結果の活用目的に照らして、独自の調査項目を設定しても構いません」としており、**問題ありません**。

### 1-3. 相違点（4件）

**① 標準の「問6 就労について」が不採用 → 問6以降の番号が1つズレている**

| 資料B' | 標準様式 |
|---|---|
| （不採用） | 問6 就労について |
| 問6 たすけあいについて | **問7** たすけあいについて |
| 問7 健康について | **問8** 健康について |
| 問8 認知症にかかる相談窓口 | **問9** 認知症にかかる相談窓口 |

オプション項目のため不採用は差し支えありません。ただし手引きQ12に次の注意があります。

> 調査項目の順番は、変更しないことが望ましいですが、入れ替えても調査結果に影響せず比較可能と考えます。なお、**「見える化」システムに掲載するための入力の際には、提示している調査票の調査項目順に入れ替え直す必要がある**のでご注意ください。

→ **集計・入力工程に「標準様式の項目順への並べ替え」作業を織り込む必要があります。**

**採用を検討する価値はあります。** 手引きQ1は追加理由を「高齢期における就労等が要介護状態となるリスクの低減に効果があるとの研究成果が繰り返し報告されていることから」としています。設問は(1)現在の就労状態＋①いつ引退したか の2問のみで負担は小さく、中山間・人口減少地域である本村では就労が論点になります。オプション項目も見える化システムへの登録対象です。

**② 標準の問7(7)「この1か月間、何人の友人・知人と会いましたか」が欠落**

資料B'問6(7)＝標準問7(8)「よく会う友人・知人はどんな関係の人ですか」となり、番号が繰り上がっています。オプション項目で第9期にもなかったため方針とは整合しますが、見える化登録時の対応付けに注意が必要です。

**③ フェイス項目（地区・性別・年齢）は標準様式にない**

手引きQ9：

> 標本名簿と回答を照合できる前提で、一般高齢者、介護予防・日常生活支援総合事業対象者、要支援者の区分をはじめとする**基本属性は標本名簿から取得することとして調査票を設計**しています。もし市町村事情で照合できない場合は、分析に必要な基本属性についての調査項目を加えてください。

→ 資料B'が置いているのは**許容範囲**です。第9期同様に地区別集計を行うため実務上も妥当。ただし管理番号で標本名簿と照合できるなら重複するため、村と整理しておくとよいです。

**④【新規要件】被保険者番号と照合可能な形式での配布**

手引き5.：

> **今回の調査から、被保険者番号と照合可能な形式で配布することに変更**しています。

手引きQ1：

> 標本となった高齢者が後に要介護認定を受けたかどうか等、介護予防の取組の効果を調査後に検証するためには、調査結果と個人が照合できるように**調査票と被保険者番号を含む標本名簿を照合可能としたものを作成・保存**しておく必要があります。

→ 資料B'の管理番号欄が、**被保険者番号を含む標本名簿と照合できる運用**になっているかの確認が必要です。単なる連番では要件を満たしません。**村のラベルシール作成仕様と一体で設計**してください。

### 1-4. 実施時期

手引き4.：

> 10 期計画策定に向けては**令和７年度中に実施**いただくことを想定しています。

北塩原村は令和8年9月実施＝**令和8年度**で、国の想定より1年度遅くなります。ただし「前回調査と比較する場合は実施時期を揃えることが望ましい」とされており、第9期が令和5年9月実施のため**季節は揃っています**。見える化システムへの登録タイミングと他自治体との比較可能性について、村と確認しておくべきです。

### 1-5. 「市役所」表記の修正について（前回指摘の補強）

標準様式（参考資料1）にも「右にある番号は、**市役所**の中でのみ…」とあり、**厚労省テンプレートの原文ママ**です。ただし、

- Q12の改変禁止は「**設問文や選択肢**」についての指示であり、管理番号の説明文は該当しません
- 別のQ&Aで、地域包括支援センターを地域の通称に置き換えて調査した場合も「登録してよいです」と、地域実情に合わせた語の置換を明示的に許容しています

→ **「村（役場）」への修正は問題ありません。前回指摘を維持します。**

**資料C'の設計は手法ⅡとⅢが混在しています。**

- 問5で**要介護度を直接聞いている** → 手法Ⅲ（非接続）の設計
- 一方で**管理番号欄を追加** → 手法Ⅲでは不要。手引きP.19：「事後的に認定データとの関連付けを行いませんので、**被保険者番号が判別できるような通し番号等を調査票に付する必要もありません**」

**さらに仕様書との齟齬があります。**

仕様書Ⅰ(5)：「厚生労働省提供の認定データ関連付け自動プログラムの活用を可能とした入力」
手引きP.19：「**手法Ⅲについては、自動集計ソフトはありませんのでご留意ください**」

→ **仕様書の要件を満たすには手法Ⅱ以上が必要です。** 手法Ⅲを選ぶ場合は、仕様書との齟齬を村と整理する必要があります。

**推奨順は Ⅰ → Ⅳ → Ⅱ／Ⅲ です。**
手引きP.6：「手法Ⅰでの実施が困難な場合は**手法Ⅳでの実施可能性を**、手法Ⅳでの実施が困難な場合は手法Ⅱや手法Ⅲでの実施方法を検討してください」
手引きP.19：「手法Ⅲは、手法Ⅰ〜Ⅱ及び手法Ⅳでは実施が困難な場合の手法として設定している点に留意してください」

**手法Ⅳは本村の状況に適合します。** 第9期の回収率45.8%（33/72）、対象約150人、村内の居宅介護支援事業所数がごく少数という条件は、手引きが手法Ⅳの想定とする「人口規模の小さい市町村におけるサンプル確保の困難」にそのまま当てはまります。ただし手引きP.20は「ケアマネジャーが回答者であるため、**過去の調査結果と単純に比較することが出来ません**」「ケアマネジャーが本人・家族等の意向を的確に把握できていることが前提」とし、「これらの特徴について**関係者間であらかじめ議論・確認を行い、共通認識を図った上で進めることが必要**」としています。

### 2-4.【重要】調査対象者の定義が仕様書と異なる可能性

手引きP.9・P.10（手法Ⅰ〜Ⅲ）：

- 対象は「在宅で生活をしている**要支援・要介護**認定を受けている方のうち、**更新申請・区分変更申請に伴う認定調査を受ける（受けた）方**」
- **新規申請者は対象外**（介護保険サービスの利用実績がないため）
- 「在宅」の定義：医療機関入院者、特別養護老人ホーム・介護老人保健施設・介護医療院・特定施設・認知症高齢者グループホーム・地域密着型特定施設・地域密着型特別養護老人ホームの入所入居者を除く
- **サービス付き高齢者向け住宅・住宅型有料老人ホーム・ケアハウス等の入居者は「在宅」に含む**
- 市町村内に住民票を残したまま市町村外にいる方は対象外

仕様書は「在宅の**要介護**認定者　**約150人**」。次の3点で定義が異なる可能性があります。

1. **要支援を含むか**（国の定義は要支援・要介護の両方）
2. **更新・区分変更の認定調査を受ける方に限るか**（国の定義は限定。約150人は在宅認定者の全数に近く、国の定義より広いと推測される）
3. **サ高住等の入居者を含むか**

→ 前回の確認事項（第9期72人→約150人と約2倍）の背景がここにある可能性が高く、**抽出条件の確認が必須**です。
