## 4. 村のご判断で加えられた変更（確認事項5件）

いずれも読みやすさや村の表記ルールへの配慮と理解しています。ただし**手引きは「必須項目及びオプション項目の設問文や選択肢を独自に改変すると、見える化システムへの登録による他保険者との比較ができなくなる」と定めています**ので、念のため整理します。

一方で、手引きのQ&Aは「地域包括支援センターを『○○介護相談センター』と通称に置き換える程度であれば登録してよい」としています。**意味が変わらない範囲の言い換えは許容される**というのが線引きです。

| # | 変更 | 当方の見解 |
|---|---|---|
| 1 | **「障害」→「障がい」**（問2(8)①、問1(2)①、問11(1)ほか） | 村の表記ルールによるものと理解します。意味は変わらず、**許容される可能性が高い**と考えます |
| 2 | **「是非参加したい」→「ぜひ参加したい」**（問5(2)(3)） | 同上。**許容される可能性が高い**と考えます |
| 3 | **「地域包括支援センター・役所・役場」→「地域包括支援センター・役場」**（問7(5)） | 村に「役所」がないための配慮と理解します。手引きQ&Aの通称の例に最も近く、**許容されると考えます** |
| 4 | **「買い物（宅配は含まない）」→「買い物（移動販売等※宅配は含まない）」**（問7(9)(11)、在宅 問11・問12） | 村内の移動販売への配慮と理解します。ただし**「移動販売を含む」という趣旨の追加は、回答の範囲を広げる方向の変更**です。第9期・他保険者との比較に影響し得ます |
| 5 | **「常勤（フルタイム）」「非常勤（パート・アルバイト等）」**（問6(1)） | 第1稿から維持。回答しやすさへの配慮として妥当と考えます |

**4のみ、比較可能性への影響が他より大きい**と考えます。移動販売の利用実態を把握したいのであれば、標準の選択肢は変えず、**村独自設問として別に1問立てる**方法もあります。ご判断ください。

## 5. 個人情報に関する説明文について（ご相談）

### 5-1 送付状の変更

| | 第1稿 | 第2稿 |
|---|---|---|
| 送付状 | お名前を書かずにご回答いただきますので、**回答された方が特定されたり、個人の回答内容が明らかにされたりすることはありません。** | **管理番号等は統計分析上において利用するものです。** |

**この変更は正しい方向です。** 管理番号により被保険者番号と紐付ける以上、「特定されることはありません」とは書けません。第1稿の記述は事実と異なっていたため、修正されたものと理解しました。

ただし、**新しい文は説明として短すぎます**。キックオフ議事録では次のように整理されていました。

> 住民からの問い合わせ（特定されるのではないか等）に備え、「回答内容は統計・調査目的のみに使用する」旨を説明文に明記し、クレーム対策を行う。

**次のような書き方を提案します。**

> この調査では、お名前をご記入いただく必要はありません。調査票には管理番号を印刷していますが、これは統計上の集計・分析のためにのみ用いるもので、**個人を特定して回答内容を取り扱うことはありません**。回答内容は介護保険事業計画の策定以外の目的には使用しません。

### 5-2 個人情報の取扱い欄から「市町村外の」が削除されています

| | 第1稿（標準様式どおり） | 第2稿 |
|---|---|---|
| | 厚生労働省の管理する**市町村外の**データベース内に情報を登録し | 厚生労働省の管理するデータベース内に情報を登録し |

**「市町村外の」を削ると、データが村の外に出ることが読み取れなくなります。** これは説明が不足する方向の変更です。この欄は**手引きが図表10として文例を示している箇所**でもありますので、**標準様式どおりに戻すことを提案します**。

### 5-3 在宅B票の案内文が1行削除されています

| | 第1稿（標準様式どおり） | 第2稿 |
|---|---|---|
| | A票の問14で「2．」〜「5．」を選択された場合は、「主な介護者」の方にB票へのご回答・ご記入をお願いします。**「主な介護者」の方のご回答・ご記入が難しい場合は、ご本人様（調査対象者様）にご回答・ご記入をお願いします（ご本人様のご回答・ご記入が難しい場合は、無回答で結構です）。** | 前段のみ |

**削除された1文は、主な介護者が記入できない場合の取扱いを示すものです。** これがないと「介護者が書けないときはどうすればよいか」が分からず、**B票が丸ごと無回答になる可能性**があります。B票は仕事と介護の両立に関する分析（集計仕様書のX-16・X-17）の全データ源ですので、**復活を提案します**。
