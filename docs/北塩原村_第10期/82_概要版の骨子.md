# 概要版の骨子（令和8年10月13日）― A3両面

議事録により、概要版を**A3両面程度**で作り、**理念・体系図・推移データ**を載せることが
決まっている。第2回策定委員会 資料8-3は「村と受託者で内容を調整（委員会での確認は不要）」
としており、**令和9年2月末頃の議会全員協議会**で用いる想定である（WBS Ⅳ-92）。

| 作ったもの | 置き場所 |
|---|---|

| 収まりの見込み（面積の積み上げ） | `scripts/estimate_gaiyou.py` |
| 点検（verify_soan 点検67） | `scripts/verify_soan.py` |

| | 結果 |
|---|---|
| 要素 | **25件**（表面14・裏面11） |
| 収まり | **表面73%・裏面76%**（A3縦・余白15mm・本文9pt・行送り1.5倍） |
| 余り | 表面 約1,842字分・裏面 約1,625字分 |
| 決まっていないもの | **6件**（保険料・成果目標の目標値・基本理念の継承・所管課・配布の範囲・仕様の範囲内か） |

## 1　第9期の構成を踏襲する

第9期の概要版（令和6年3月発行・北塩原村住民課）は2ページであった（doc08）。

| 面 | 内容 |
|---|---|
| 表面 | 基本的な考え方、基本理念、基本目標、数値①〜⑦ |
| 裏面 | 施策体系図 |

**踏襲する理由は2つある。**

1. **村民と議会が見慣れた形である。** 概要版は計画書を読まない方に向けたものであり、
   前回と形が変わると読み手が探す場所を見失う
2. **第9期との比較ができる。** doc08 は第9期概要版の数値をすべて見える化データ・
   特別会計決算と突き合わせており、同じ様式で書けば第10期の値を同じ軸で並べられる

### 2-1　数値①〜⑤に時点の断りを入れる

第9期概要版の数値は**令和◯年10月1日・住民基本台帳**であった（doc08 §0）。
一方、本計画の素案は**国勢調査と社人研推計**の系列を用いている（2-1）。

**同じ様式で推移を見せると、系列が変わる。**
概要版では「実績は住民基本台帳・各年10月1日、推計は社人研による」ことを明記する。
これは本日あわせて素案2-1に加えた断りと同じ趣旨である（doc81 §3-5）。

### 2-2　④地域支援事業費は定義を確かめてから載せる

doc08 §4 のとおり、第9期概要版④の地域支援事業費は決算と**6,300〜10,100千円**ずれている。
誤差ではなく集計範囲の違いであり、**任意事業を除いているという仮説は立つが断定できない。**

**第10期で同じ様式で書くなら、どの範囲を計上するかを確かめないと第9期と比較不能になる。**
確認事項として既に起票されている（優先度B）。

### 3-1　施策体系図はA3のために作り直すのが望ましい

**計画書の図3-1はA4に合わせた縦長である**（5.52×8.90インチ＝140×226mm・縦横比1.61）。

| 幅 | 高さ | 裏面の高さ（390mm）に占める割合 |
|---:|---:|---:|
| 125mm | 202mm | **52%** |
| 180mm | 290mm | **74%** |

**A3の幅を活かすには横長に作り直すのが望ましい。**
縦長のまま幅を180mmに広げると高さ290mmとなり、裏面の高さの74%を占めて他が入らない。
骨子では幅125mmに縮めているが、**この幅では図の中の文字が7pt相当まで小さくなる。**
横長に作り直すかどうかを村のご判断の対象とした。

### 3-2　保険料は枠のまま残す

概要版には保険料の基準額を載せる。
**基金の取崩しの3案（A案 条例6,600円／B案 5,900円／C案 5,500円）のうち
いずれを採るかが決まってからでないと作れない。**

議会全員協議会（令和9年2月末頃）の時点では条例案が定まっている必要があるため、
**第3回策定委員会（令和9年1月下旬〜2月上旬）のご決定を受けて作成する工程**となる。
骨子では枠を置き、決定後に記入する。

## 4　収まりは面積で積んだ

頁数ではなく**面積**で見た。概要版は1面のなかで段を組むため、
行送りを追う推定（estimate_layout）より面積の積み上げが実際に近い。

| | 表面 | 裏面 |
|---|---:|---:|
| 使える面積（A3縦・余白15mm） | 104,130mm² | 104,130mm² |
| 要素 | 53,280 | 56,566 |
| 要素の間の空き（22%として見込む） | 22,909 | 22,909 |
| **合計** | **76,189（73%）** | **79,474（76%）** |
| 余り | 27,941（本文で約1,842字分） | 24,656（本文で約1,625字分） |

**表と枠は字数から出した面積の1.6倍で見込んだ。**
ます目の余白・罫線・埋まらないます目があるため、字数だけで積むと
6行の表が6行分より狭く出てしまう。

### 4-1　この推定でできないこと

**段の割り方・図の置き方・折りの位置は紙面を見ないと決まらない。**
本環境では docx を PDF に変換できないため、**紙面の確認はつねに未実施**である。
**面積が収まることは、収まる見込みが立つことを意味するにとどまる。**

余りを約1,600〜1,800字分残したのは、この推定が概算であることと、
保険料の欄が決定後に膨らむことを見込んだためである。

## 5　点検67を新設した

概要版は計画書とは別の成果品である。**別々に書くと数も言い方も食い違う。**
骨子の要素がすべて素案の節または図を出どころに持ち、それが実在することを機械で確かめる。

| 見るもの | 内容 |
|---|---|
| 出どころの実在 | 要素25件の出どころ（節番号・図番号）が素案に実在すること |
| 図の実在 | 図のファイルが `output/figures/` にあること |
| 字数 | 図以外の要素が字数を持つこと（0字の要素は骨子として意味がない） |
| 収まり | A3両面に収まる見込みが立つこと |
| 未決の明示 | 決まっていないものが4件以上挙がっていること（骨子は未決を隠さない） |

**逆試験で確かめた。** 出どころを存在しない節（3-99）にすると不適合になり、
字数を10倍にすると「表面が63,799mm²あふれる」で落ちる。

## 6　確認事項を3件から1件に集約した

**概要版について、同じ問いが3件起票されていた。**

| # | 見出し | 優先度 |
|---|---|---|
| 57 | 概要版の要否（仕様書に記載なし。第9期は概要版を作成している） | C |
| 103 | 概要版の位置づけ（仕様の範囲内か追加対応か） | B |
| 122 | ★概要版（A3両面程度）が仕様の範囲内か追加対応か | A |

いずれも「仕様の範囲内か追加対応か」という同じ問いである。
**優先度Aの1件に集約し、残る5つの判断事項を書き足した。**

- 仕様の範囲内か追加対応か（本来の問い）
- 基本理念を第9期から継承するか（素案3-1も村との協議事項としている）
- 配布の範囲と部数（議会全員協議会で用いる想定。村民への配布は未定）
- 所管課と問い合わせ先の表記（氏名・直通番号は載せない。doc16 §5-3）
- 施策体系図を横長に作り直すか

### 6-1　同じ型の重複がもう1件あった

確認事項の台帳を「同じ関連WBS＋5文字以上の共通語」で機械的に突き合わせたところ、
17組の候補が出た。読んだ結果、**ほとんどは別の問いが語を共有しているだけ**であったが、
1件は本当の重複であった。

| # | 見出し | 優先度 |
|---|---|---|
| 30 | 北塩原村第六次総合振興計画の策定状況 | B |
| 112 | 第六次総合振興計画（2027年度〜）の策定状況 | A |

**優先度Aの1件に集約した。**

> **この突き合わせは点検にしなかった。** 17組のうち本当の重複は1件で、
> 残りは「第2回策定委員会の開催日」と「第2回策定委員会の資料の事前送付」のように
> **別の問いが語を共有しているだけ**である。
> 合否の点検にすると誤りの警告ばかりが出る。
> **一度走らせて目で読むことに意味があり、機械の判定には向かない。**

本日は当方も同じ誤りをしている（doc80 §6 の6番）。
**確認事項を起こす前に台帳を語で探す**手順を守る。
