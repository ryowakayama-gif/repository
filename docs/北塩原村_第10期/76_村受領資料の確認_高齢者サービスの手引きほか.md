## 1　高齢者サービスの手引き ― 素案の誤りを1件見つけた

### 1-1　村内のグループホームは2施設である（素案の誤り）

素案1-8の2は、協力医療機関の要件について
**「村内の入所施設は認知症対応型共同生活介護1施設のみです」**と書いていた。
手引きの「サービス事業者一覧（村内）」は**グループホームを2施設**挙げている。

| | 村内の事業所 |
|---|---|
| 居宅介護支援 | 北塩原村社会福祉協議会 居宅介護支援事業所 |
| 介護予防支援 | 北塩原村地域包括支援センター |
| 訪問介護 | 北塩原村社会福祉協議会 訪問介護事業所 |
| 通所介護 | 北塩原村デイサービスセンター／小野デイサービスセンター（**2か所**） |
| 認知症対応型共同生活介護 | グループホームラポール／グループホームさくら（**2施設**） |

**素案2-5の事業所数の表は、令和3年度から一貫して「認知症対応型共同生活介護 2」と
している。** 節をまたいで食い違っていた。1-8の2を「2施設」に直した。

**村内で提供されているサービスが3種類（訪問介護・通所介護・認知症対応型共同生活
介護）であることは変わらない。** 居宅介護支援と介護予防支援はケアマネジメントで
あり、給付のサービスの種類には数えていない。

### 1-2　点検を加えた（同じ型の誤りを機械で見つける）

点検57は「村内で提供されているサービスはN**種類**」は数えていたが、
**個々のサービスの事業所の数は見ていなかった。**
2-5の事業所数の表（令和6年度）と、本文で述べる「○○はN施設／N か所／N事業所」を
突き合わせる形に広げた。

**自己試験で確かめた。** 1-8の2を「1施設のみ」に戻すと検出し、戻すと0件になる。

## 2　緊急連絡カード ― 素案に記載がない

文字がすべてアウトライン化されており、テキストが取り出せなかった。
**画像に起こして読んだ。**

| 区分 | 記入欄 |
|---|---|
| 共通情報 | 住所・固定電話（世帯で1つ） |
| 本人情報（2人分） | 氏名・ふりがな・性別・血液型・携帯電話・生年月日・**持病とお薬**・**かかりつけ医** |
| 緊急連絡先 | 2件（氏名・続柄・自宅・携帯） |
| 備考 | 伝えたいこと |

「電話機や冷蔵庫の近くに備え付けてください。救急隊がこのカードをすぐに
見つけることで、迅速な救急活動につながります」とある。

**2つの論点がある。**

1. **素案に位置づけがない。** 施策2-4（安全・安心な暮らしの確保）は
   緊急通報システムだけで組み立てている。緊急連絡カードは、
   固定電話がなく緊急通報装置を設置できない世帯にも届く手段であり、
   **1-5で挙げた「固定電話をお持ちの方」要件の穴を補う**位置にある。
   施策2-4に加えることを提案する。
2. **記入後は要配慮個人情報を含む。** 持病・お薬・かかりつけ医・血液型である。
   doc16 §1（本業務で取り扱う個人情報）の一覧に入っていない。
   **当方がこのカードを取り扱う予定があるか**を確かめる必要がある。
   取り扱わないのであれば一覧に加える必要はないが、
   記入済みのカードが調査票と一緒に届くことがないかは確認しておきたい。

## 3　成年後見センターの催し ― 施策4-7の記述と突き合わせる

| | 内容 |
|---|---|
| 日時・会場 | 令和8年10月23日（金）会津若松市文化センター（200名）／10月24日（土）金山町民体育館（100名） |
| 第1部 | 創作劇『ひとりでねぇ、ひとりぼっちでもねぇ〜会津で最後まで自分らしく生きる〜』（40分） |
| 第2部 | トークセッション『安心ライフのひけつ』（弁護士・終活アドバイザー・社会福祉士の3名／65分） |
| 主催 | 会津若松市・**北塩原村**・磐梯町・猪苗代町・会津坂下町・湯川村・柳津町・三島町・金山町・昭和村・会津美里町・会津権利擁護・成年後見センター |
| 申込期限 | **令和8年10月16日（金）** |

創作劇は「おひとり様になっても、地域の支えの中で自分らしく生き、最期まで
安心して暮らせる地域社会」をテーマとし、**エンディングノートや後見契約**を
通じて「老い」と向き合う筋立てである。

**素案4-7の記述と突き合わせる必要がある。**
素案は「任意後見制度については、周知・広報を実施していません。独居高齢者の増加を
見据えるうえで、判断能力が低下する前の備えを伝える必要があります」と書いている。
これは国の取組状況調査（市町村票）の回答によるものである。

ところがこの催しは、**北塩原村が主催者に名を連ね、後見契約を扱っている。**
判断能力が低下する前の備えを伝える取組が、現に広域で行われている。

**村が調査票でこれを「周知・広報」と数えていない可能性がある。**
数え方の問題か、村単独の周知を指して「実施していない」と答えたのかで、
素案の書き方が変わる。確認事項として起票した。

**素案4-7の取組には「中核機関である会津権利擁護・成年後見センターとの連携を
強め、相談につながる経路を整えます」がある。** この催しは連携の現れであり、
施策の裏づけとして書ける。

## 6　次にやるべきこと

**素案4-6（高齢者福祉サービスの量の目標）の全面的な見直し**が要る。
手引きにより12事業の内容が確定し、載っていない事業が9件見つかったためである。
ただし**実績値がないと量の目標は置けない**ため、
事業名と内容・確保の方策を実態に合わせるところまでを先に行い、
数値は村からのご提供を待つのが順当である。

作業の順位（doc75 §4）の中では、現在の順位1・2（集計側の備え）の次、
順位3（第3回資料）の前に入れるのが筋である。
**移動支援の記述は実態と違っており、このまま第2回策定委員会に出せない。**
