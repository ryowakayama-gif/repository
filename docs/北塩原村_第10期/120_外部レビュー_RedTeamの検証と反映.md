# 外部レビュー（Red Team）の検証と反映（令和8年10月24日）

村より受領した外部レビュー（点検基準日 令和8年10月24日。指摘 R01〜R26、重要数値表、国・県の方針との対応、KPIの修正方向）を、原典・正本の算定・組んだ docx で1件ずつ確かめ、修正方針を定めて反映した。レビューの原本は `data/外部レビュー/RedTeam外部レビュー_20261024.md` に置いた。

修正方針と必要書類は成果品23、証跡は成果品22（`scripts/build_evidence.py` が素案と同じ出どころから起こす）にまとめた。

## 1. 確かめた事実のうち、主なもの

- **R01 施行期日**：法律案要綱 第10の1（附則第一条関係）によれば、原則は令和9年4月1日。例外は (2) 第2の8（介護支援専門員の更新制の廃止）＝公布後1年6月以内、(3) 第2の3（特定施設の定義）・第2の14(3)の一部（登録有料老人ホームに係る入居定員の勘案）＝2年以内、(4) 第2の2(3)（被保険者証の添付等）・第2の16（登録施設介護支援）＝3年以内。中長期推計（第2の14(1)、第117条第2項第3号・第4号）と県の意見聴取（第2の14(4)、同条第14項）は原則どおり。厚生労働省の概要（001756936.pdf の5頁目）の束ねた書き方とも食い違わない。レビューの「中長期推計が3年以内」は採らず、例外を書いていなかった点（とくに登録施設介護支援を「令和9年4月に新設される区分」に並べていた）を直した。施行期日は `scripts/sekou_kijitsu.py` を唯一の表とした。
- **R02**：第2回資料5-3は、国の推計ワークシートを採用したあとも当方の独自算定（GH 23.6／24.3／24.5人、標準給付費854,014千円）のままだった。あわせて、**ワークシート自体のGHは27・28・29人で、県の整備量見込みシート（27人）と1〜2人違う**ことが分かった（どちらも村が県に提出したもの）。確認事項に起票した。
- **R03**：6サービスの令和6・7年度平均は計1,579千円／年。3か年で総給付費の0.55%、算定上の月額で約30円（ワークシートの総給付費1千円あたりの月額で換算）。
- **R11**：所得段階の第11段階4人・第12段階1人、成年後見の類型別内訳（後見1・保佐2・補助1）を、本計画の集計の公表基準（10人未満）に合わせて統合・削除した。
- **R14**：成果品15の段は未取得の全項目、素案6-3等の4区分は0点かつ全国該当率45%以上の32項目で、母集団が違う。段Ｂ9点＝本業務4点＋認知症施策推進計画5点、段Ｃ39点＝条件付き33点＋32項目の外の6点（推進2 庁内・庁外における連携体制 エ）。
- **R17**：決算の保険給付費278,692,538円＝サービス諸費258,845,294円＋補助給付等19,847,244円であり、標準給付費と同じ範囲。比較は成り立つ。
- **R23**：福島県の現行計画は「第10次福島県高齢者福祉計画・第9次福島県介護保険事業支援計画（ふくしま高齢者すこやかプラン）」であることを県ホームページで確かめた。素案施策4-6の「福島県が第10期介護保険事業支援計画において」は県の呼び方と合わないため改めた。素案1-4の「ふくしま高齢者いきいきプラン」は県の高齢者居住安定確保計画（令和4年3月）が引く当時の計画（2021）であることを原典で確かめ、そう明記した。
