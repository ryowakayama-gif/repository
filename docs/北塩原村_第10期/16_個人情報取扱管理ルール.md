# Ⅴ-94　個人情報の適正管理（アクセス制限・保管ルール）

作成時点：令和8年8月31日／適用：契約締結日〜業務完了後の消去まで
根拠：仕様書6「その他条件」／北塩原村個人情報保護条例／個人情報の保護に関する法律

**★調査票の発送前までに村と合意しておく必要があります。**発送後は対象者の氏名・住所を保有することになるため、それ以前にルールを確定させます。

| # | 情報 | 提供元 | 件数（想定） | 機微度 |
|---|---|---|---|---|
| 1 | 調査対象者の氏名・住所（宛名ラベル） | 北塩原村 | 約1,000件 | **高** |
| 2 | 調査対象者の管理番号と被保険者番号の対応表 | 北塩原村 | 約1,000件 | **高** |
| 3 | 回答済み調査票（紙） | 対象者 | 約500件 | **高** |
| 4 | ウェブ回答データ | 対象者 | 未定 | **高** |
| 5 | 要介護認定データ | 北塩原村 | 約200件 | **特に高** |
| 6 | 自由記述の内容 | 対象者 | ― | **高** |
| 7 | 策定委員の氏名・所属・連絡先 | 北塩原村 | 十数件 | 中 |

**★#5について**：要介護認定データは要配慮個人情報に該当し得ます。**調査票データとの関連付け（WBS Ⅰ-38）を行うため、突合中は最も慎重な取扱いが必要**です。

**★#2について**：第10期の新規要件である「被保険者番号と照合可能な管理番号」は、**単体では個人を特定しないが対応表と結合すれば特定できる**情報です。**対応表は調査票データと物理的・論理的に分離して保管**します。

## 2. 取扱いの基本原則（5点）

1. **目的外利用の禁止** — 本業務（第10期計画策定）以外の目的には一切使用しません。
2. **最小限の取得** — 業務に必要な項目に限って受領します。
3. **アクセスの限定** — 本業務の従事者として村に届け出た者に限ります。
4. **持出しの禁止** — 事業所外への持出しは原則禁止とし、例外は事前承諾を要します。
5. **完全消去** — 業務完了後、村の確認のうえ返還または消去し、報告します。

## 3. 従事者の管理

| 項目 | 内容 |
|---|---|

## 4. 物理的な保管ルール

### 4-1 紙媒体（宛名ラベル・調査票原本・対応表）

| 項目 | ルール |
|---|---|
| 保管場所 | **施錠可能なキャビネット**。作業スペースと分離 |
| 施錠 | 業務時間外は必ず施錠。鍵は**業務責任者が管理** |
| 持出し | **原則禁止**。やむを得ない場合は村の事前承諾を得たうえで持出簿に記録 |
| 作業場所 | 施錠可能な区画内。第三者の目に触れない配置 |
| 複写 | 必要最小限。複写物も原本と同一の管理 |
| 郵送 | 追跡可能な方法（簡易書留等）を用いる |

### 4-2 廃棄

| 対象 | 方法 |
|---|---|
| 調査票原本・宛名ラベル・対応表 | **溶解処理または細断（クロスカット）** |
| 誤印刷・試し刷り | 同上。一般ごみとして廃棄しない |
| 廃棄記録 | 日時・対象・方法・実施者を記録し、**業務完了報告に添付** |

## 5. 電子データの管理

| 項目 | ルール |
|---|---|
| 保管場所 | 業務専用の領域。**個人所有の端末・記録媒体への保存を禁止** |
| アクセス制御 | 従事者名簿に記載の者のみアクセス可能な権限設定 |
| パスワード | ファイル単位で設定。**パスワードはデータと別経路で伝達** |
| 暗号化 | 可搬媒体を用いる場合は暗号化を必須とする |
| ウェブ回答 | **通信の暗号化（TLS）を必須**。回答データは公開期間終了後ただちに専用領域へ移し、フォーム側から削除 |
| バックアップ | 業務専用領域内に限る。外部クラウドサービスの利用は村の事前承諾を要する |
| 送受信 | 村との授受はパスワード付きファイルまたは村指定の方法による。**一般のメール添付で氏名・住所を送らない** |
| 操作記録 | アクセス・複写・持出しの記録を残す |

### 5-1 ★対応表の分離保管

管理番号と被保険者番号の対応表は、**調査票データとは別のフォルダ・別のパスワードで保管**します。集計・分析の作業者は対応表にアクセスしません。関連付け作業（WBS Ⅰ-38）は業務責任者の管理下で行います。

### 5-2 ★要介護認定データ

- 受領は**関連付け作業の直前**とし、それ以前には受領しません。
- 関連付け完了後、**分析に用いるのは要介護度等の属性情報のみ**とし、氏名・被保険者番号は速やかに分離します。
- 認定データの原本は関連付け完了後、**村と協議のうえ消去または返還**します。

## 6. 集計・報告における匿名化

| 項目 | ルール |
|---|---|
| 集計単位 | 個人が特定されない集計単位とする |
| 少数値の扱い | **回答者が少数となるクロス集計は、区分を統合するか非表示とする**（目安：該当数10未満） |
| 自由記述 | 氏名・地区名・事業所名など**個人が特定され得る記述は、報告書掲載時に伏字または要約**とする |
| 地区別集計 | 北塩原村は人口2,315人と小規模。**地区×性別×年齢のような多重クロスは特定リスクが高い**ため、掲載前に確認する |

**★小規模自治体特有の注意点です。**総人口2,315人・高齢者1,015人という規模では、通常の匿名化基準でも個人が推定され得ます。**報告書掲載前に、特定リスクの観点で全図表を点検**します。

## 7. 事故発生時の対応

1. **発見者は直ちに業務責任者へ報告**します。
2. 業務責任者は**速やかに北塩原村へ報告**します（第一報は覚知後直ちに、遅くとも当日中）。
3. 被害の拡大防止措置を最優先で実施します。
4. 原因・影響範囲・再発防止策を書面で報告します。
5. 村の指示に従い、対象者への通知等の対応を行います。

**★連絡体制表（WBS ０-04）に、村側の緊急連絡先を必ず記載します。**

## 10. 村と協議すべき事項

1. 本ルールの内容で差し支えないか。村条例で追加の要求事項があるか。
2. 従事者名簿・誓約書の様式に村指定のものがあるか。
3. 要介護認定データの受領方法・時期・返還方法。
4. 電子データの授受方法（村指定の方法があるか）。
5. 匿名化の基準（少数値の非表示基準を「10未満」とすることの可否）。
6. 業務完了後に保管を認める集計データの範囲と保管期間。
