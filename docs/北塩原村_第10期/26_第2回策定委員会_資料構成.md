## 0. この委員会で何を決めるのか

キックオフ議事録は、第2回策定委員会の位置づけを次のように定めています。

> アンケートの分析結果、第9期の効果検証（令和7年度までの実績等）を報告。計画の骨子、施策体系、サービス見込み量、保険料の概算シミュレーション、**素案（完成度7割程度）**を提示し、委員から意見・合意を得る場とする。

つまり第2回は**報告の場ではなく、合意形成の場**です。第3回（1月下旬〜2月上旬）はパブリックコメントの結果報告が中心なので、**計画の中身について委員が意見を言える実質的な機会は、この第2回が最後**になります。

そこで資料は「**決めていただきたいこと**」を先頭に置き、根拠を後ろに置く構成とします。

## 2. 資料2　第9期計画の進捗と評価

**性格**：報告。ただし「第9期がどうだったか」は第10期の施策を決める前提なので、簡潔に、しかし逃げずに示します。

| 節 | 内容 | 出典 |
|---|---|---|
| 2-1 | 第9期の基本目標と施策の一覧 | doc14 |
| 2-2 | **施策の達成状況（◎○△✗の4段階評価・19施策）** | doc14 |
| 2-3 | **計画値と実績の乖離**（第1号被保険者数−6.6%／認定者数／給付費／保険料） | doc12 |
| 2-4 | **保険者機能の評価**（交付金 295→339→447点／全国順位1,564→1,005位） | doc20 |
| 2-5 | 第9期の課題（21件のうち重大度A 14件を要約） | doc17 |

### 2-1 資料2で正面から示すべきこと

**(1) 第1号被保険者数の推計が63人（6.6%）ずれたこと**

第9期は社人研推計をそのまま用いたため、住基ベースの実績を6〜8%下回りました。**この誤差は保険料に直結します。** 第1号被保険者数のみ実績に置き換えると基準月額は6,761円→6,346円となり、福島県平均6,340円とほぼ一致します。

**「保険料が県平均より高い」という村の課題認識の相当部分は、推計手法に由来していた**ことになります。これは委員に説明すべき重要な事実で、第10期で推計手法を変える（doc13の乖離率補正）ことの根拠にもなります。

**(2) 交付金評価が大きく改善したこと**

令和6年度295点（全国1,564位）→令和8年度447点（全国1,005位）。全国平均との差は−127点から−8点に縮まりました。**第9期期間中の保険者機能の底上げは数字で裏づけられます。** 委員への報告として前向きな材料です。

一方で、**支援交付金 目標Ⅱ（認知症総合支援）は32/100点**で全国平均を19.1点下回り、8つの目標のうち差が最大です。**目標Ⅳ（成果指標群）は令和8年度に25点低下**しています。ここは第10期の重点として提示します。

**(3) 除雪の施策が第9期になかったこと**

住民ニーズ第1位（27.5%）でありながら、第9期計画に独立した施策がありませんでした。**これは率直に示し、第10期で新設する（施策2-6）根拠とします。**

**性格**：報告であり、合意1（基本理念・基本目標）の根拠。**doc24 の報告書 第Ⅱ部（分析編）の要点を12頁に圧縮**したものです。

| 3-9 | 調査から見えた課題（8項目） | doc24 第7章 |

### 3-1 この資料でいちばん伝えたい1枚

**3-6「担い手の可能性」が、この委員会の資料の核です。**

生活機能で分けた第2層（**元気だが社会参加なし**）のうち、地域づくり活動に「是非参加したい」「参加してもよい」と答えた人が何人いるか。**この数字が、第10期で共助・互助の仕組みを何人規模で構想できるかの根拠**になります。

キックオフ議事録の

> 有償ボランティアや住民主体の支え合いの仕組み（共助・互助）の構築を強く打ち出す書きぶりにしたい

という村の方針を、**「やりたい」ではなく「これだけの人がいる」という形で委員に示せます。** 委員の合意を得るうえで、これに勝る材料はありません。

### 3-2 提示の仕方の注意

- **n<30 の区分は参考値である旨を明示します。** 回収450〜500件を4地区×3年齢階級に割ると1区分35〜42件で、さらに細分すると比較に耐えません
- **「疾病があっても元気」を前向きに示します。** 「高血圧や糖尿病があっても○割の方は生活機能が保たれています」という提示は、担い手が「特別に健康な人」ではないことを伝えます
- **X-02（元気な軽度者）の提示は慎重に。** 「要支援認定者のうち生活機能リスクがない人が○人」という事実は、読み方によっては「不適切な認定」と受け取られかねません。**認定は心身の状態だけでなく生活環境も踏まえて行われるため、単純に「不要な認定」を意味するものではない旨を必ず添えます**

**論点1：基本理念に「共助・互助」を明示するか**

議事録の方針は明確ですが、**基本理念に書き込むかどうかは委員の合意事項**です。「公助を減らす」と受け取られるリスクがあるため、**「公的サービスは維持したうえで、それだけでは足りない部分を地域で支え合う」という書き方**を提案します。2案を併記して選んでいただく形が適切です。

| 新設施策（案） | 根拠 |

### 5-1 資料5の最重要論点：施設整備

議事録では次のように整理されています。

> 第9期では施設サービスの利用が伸びず（重度化による病院への転院が主な要因）、一方で地域密着型サービス（グループホーム等）の利用は伸びている傾向がある。

この村側の見解と、調査結果（X-15 施設入所の検討状況 × 村内施設があれば）を突き合わせて提示します。

| 材料 | 内容 |
|---|---|
| 給付実績 | 特養 H29→R7で−23.6%／GH +22.4%／訪問系 −50.8% |
| 供給体制 | **村内は認知症対応型共同生活介護27人分と通所介護50人分のみ。施設系はゼロ** |
| 村の見解 | 施設利用が伸びない主因は重度化による病院への転院 |
| 在宅調査 | **X-15 潜在需要**（現在は検討していないが村内にあれば入所したい層） |
| ニーズ調査 | 問10(3) 介護が必要になった時どこで過ごしたいか |

**「村内に施設がないから村外を使っている」のか「そもそも施設志向がない」のかで、第10期の施策はまったく変わります。** 調査結果で切り分けたうえで委員に諮ります。

**保険料算定に必要な国の推計ワークシートは、第10期基本指針の告示（令和8年内予定）後の提供**となる見込みです。第2回委員会の時点では確定値を示せない可能性があります。

議事録の方針に従い、**令和9年度の介護報酬改定を見据えて現行単価で一旦試算し、単価確定後に補正する**旨を資料に明記します。

## 7. 資料7　成果目標・活動指標（案）

**性格**：合意5。第6章「計画の推進」に載せる指標です。

| 節 | 内容 |
|---|---|
| 7-1 | 指標の設定方針 |
| 7-2 | **成果目標（アウトカム）** |
| 7-3 | **活動指標（アウトプット）** |
| 7-4 | 進捗管理の仕組み |

### 7-1 指標の設定方針

**第四次生涯学習推進計画の作法を踏襲します。** 同計画は、①住民アンケートの設問番号と資料編のページを注記して出典を明示し、②国の現状値・目標値を備考欄に併記して水準の妥当性を示しています。**村の従来の作り方に合わせるのが自然です。**

指標は次の3系統から選びます。

| 系統 | 例 | 出所 |
|---|---|---|
| **調査指標** | 社会参加のある高齢者の割合／孤立層の割合／ACPを家族と話した人の割合 | ニーズ調査 |
| **事業指標** | 通いの場の箇所数・参加率／認知症サポーター養成数／給付適正化の主要3事業の実施数 | 村実績 |
| **交付金指標** | 国の評価指標をそのまま採用 | 厚労省 |

### 7-2 交付金の得点を数値目標にするかどうか

**当方は「置かない」ことを提案します。**

理由は、評価指標が毎年度改定されるため未達の説明が難しくなることです（doc20 §8-4）。代わりに、**「評価結果を毎年度、策定委員会に報告し、全ての評価項目ごとの得点獲得状況を公表する」という仕組みを書く**ことを提案します。

これは推進交付金 目標Ⅰ（ⅰ）指標4「評価結果の活用」（16点）の要件そのものであり、**北塩原村は令和8年度にこの16点を満点取得しています**。すでに実施している取組を計画に位置づける形になります。

令和8年度の交付金とりまとめ資料（都道府県分・市町村分）を受領し、目標別の県内比較と、計画への記載で取得できる61点を特定しました（doc41・doc42）。これを資料に反映し、**合意を得たい事項を8点から9点に改めます。**あわせて資料4に施策体系図を入れました。

### 15-1 合意事項に1つ加えます

| # | 合意事項 | 資料 | 効き |
|---|---|---|---|
| 1〜8 | （13-1のとおり） | | |
| **9** | **交付金で61点を取りにいくかどうか**（計画への記載・要綱改正・手順の明文化で取得できるもの11項目） | **資料7-3c** | **447点→508点／全国1,005位→525位／県内34位→18位** |

この9点目は**委員会で方針を確認しておく価値があります。**理由は3つです。

1. **61点のうち14点は、本計画を策定すること自体が条件を満たします。**認知症施策推進計画の策定着手（5点）、在宅医療・介護連携の4場面の整理（5点）、成年後見の要綱改正（4点）です。委員会で「そのように書く」と合意していただければ、それで足ります。
2. **残る47点は村の取組の可否に関わります。**とくに介護給付適正化の4項目（30点）は、実施するかどうかの判断が要ります。委員会での議論を経ておくと、村の庁内調整が進めやすくなります。
3. **交付金の額に直結します。**本村の得点は県の交付金（管内市町村の平均得点）にも反映されるため、県に支援を求める材料にもなります。

### 15-3 資料2-4で示す最も重要な数字

**認知症総合支援は福島県内59市町村のうち57位です。**

| | 本村 | 県平均 | 県内順位 | 全国平均 | 全国順位 |
|---|---:|---:|---:|---:|---:|

県平均との差22.5点は、全国平均との差19.1点より大きいものです。**福島県も認知症施策では全国をやや下回りますが、本村の低さは県全体の傾向では説明できません。**一方、介護人材の確保とサービス提供基盤の整備は福島県が全国平均を13.1点下回る県全体の課題であり、本村単独では動かしにくい領域です。この切り分けができたことで、施策4-6を「村の取組」ではなく「県の事業と定住自立圏の枠組みの活用」として組み立てる根拠ができました。

在宅医療・介護連携は県内24位ですが**全国では961位**です。福島県の市町村平均が全国平均を3.6点下回るため、県内比較だけを見ると実力を過大に評価します。資料では県内順位と全国順位を必ず併記しています。
