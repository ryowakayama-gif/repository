## 0. なぜいま作るのか

**集計軸を後から決めると、入力データの持ち方が合わずに手戻りが出ます。**

たとえば複数回答を「カンマ区切りの1列」で入力してしまうと、集計時に分解が必要になり、そこで誤りが混入します。地区別集計を後から決めると、地区の情報を持たないデータができあがります。

第2回策定委員会は**11月**です。9月18日発送・10月回収という日程では、**集計に使える時間は3週間程度**しかありません。**入力を始める前に仕様を固めることが唯一の余裕の作り方**です。

本仕様書は調査票の校了（9月9日予定）と同時に確定させます。

## 2. 集計の基本方針（8項目）

| # | 方針 | 内容 |
|---|---|---|
| 1 | **見える化への登録を最優先** | 必須項目・オプション項目は設問文・選択肢・順序を標準どおりとし、**集計区分も標準に合わせます**。独自の区分を作ると全国・県との比較ができなくなります |
| 2 | **全設問を同じ形式で出す** | 全体／地区別／年齢階級別／性別／前回比較の5点セットを全設問で統一 |
| 3 | **地区別集計を必須とする** | 4地区は地理的に分断されており、移動手段・外出抑制・除雪は地区差が大きいと想定されます |
| 4 | **端数処理の統一** | 構成比は小数第1位まで。合計が100.0%にならない場合は注記 |
| 5 | **n数の明示** | すべての図表にn数を記載。**n<30 の区分は参考値である旨を明示し、単独の根拠としません** |
| 6 | **複数回答の扱い** | 回答者数を分母とした％。「合計が100%を超えます」と注記 |
| 7 | **無回答の扱い** | 集計対象に含め分母から除外しません。ただし前回比較の際は前回の扱いに合わせます |
| 8 | **認定データとの紐付け** | 管理番号により認定状況を付与。**これがないと分析編の中核が作れません** |

### 2-1 方針5（n数）について

本村の高齢者は約940人、ニーズ調査の配布は約850件です。回収率50〜60%とすると回収は**425〜510件**。これを4地区×3年齢階級（12区分）に割ると**1区分あたり35〜42件**です。

**さらに性別で割ると1区分20件前後になり、統計的な比較には耐えません。** 地区別×年齢階級別のクロスは行いますが、**3重クロス（地区×年齢×性別）は原則として行わない**方針とします。

### 4-2 該当基準は「要確認」です（重要）

**手引き（令和7年8月版）に該当基準が明記されているのは、低栄養のBMI 18.5以下のみです。**

> 体重から算出されるBMI（体重（kg）÷｛身長（m）×身長（m）｝）が18.5以下の場合、低栄養が疑われる高齢者

他の9種については、手引きに算出方法の記載がありません。仕様書のxlsxには**基本チェックリストに準じた基準案**を記載していますが、すべて**【要確認】**を付しています。

**独自の基準を作ると全国・県との比較ができなくなるため、見える化システムの算出方法との突合が必要です。**（確認事項 K-91）

なお手引きには「**今後、地域包括ケア「見える化」システムへのデータ送付によりデータを全国の市町村から収集・蓄積し、分析していくプロセスで調査項目・選択肢・各種リスクの算出方法を将来的に更新する可能性があります**」との記載があり、**基準は年度によって変わり得ます**。第9期の集計基準をそのまま流用しないよう注意が必要です。

| 列 | 項目 | 出所 |

| 2 | 回答方法（紙／Web） | システム。重複回答の排除に使用 |
| 3 | 受付日 | 受託者。小分け送付の受渡し記録と突合 |
| 4 | 調査種別 | ― |
| 5 | 地区 | 名簿・問0 |
| 6 | 性別 | 名簿 |
| 7 | 年齢（基準日 R8.9.1 時点） | 名簿 |

| 9 | 認定日 | ★認定データ |
| 10〜 | 各設問の回答 | 調査票・Webフォーム |
| 末尾 | 派生変数 | 算出 |

### 6-2 入力上の留意点（6件）

1. **複数回答は「選択肢ごとに1列（0／1）」の横持ち**とします。カンマ区切りの1列にまとめると集計時に分解が必要になり、誤りが混入します
2. **自由記述は原文をそのまま保持**し、分類コードは別列に付与します。原文を書き換えないでください
3. 身長・体重は単位を統一し、明らかな入力誤り（身長20cm等）は欠測として扱い、その旨を記録します
4. 幸福度（問8(2)）は0〜10の整数。範囲外は欠測
5. **Web回答は必須入力の設定により無回答が発生しにくく、紙回答と無回答率が構造的に異なります。** 回答方法別の集計を必ず1回は行い、差が大きい設問は本文で注記します
6. **小分け送付**（村が100件程度ごとに送付）に対応するため、受付日とロット番号を記録し、入力の進捗を管理します

### 6-3 見える化への登録

手引きは次のとおり定めています。

> 調査項目の順番は、変更しないことが望ましいですが、入れ替えても調査結果に影響せず比較可能と考えます。なお、「見える化」システムに掲載するための入力の際には、**提示している調査票の調査項目順に入れ替え直す必要がある**のでご注意ください。

村独自設問（14問）は登録対象外です。**登録用データは標準様式の設問順に並べ替えた別ファイルとして作成**し、村独自設問を除外します。この並べ替え表は集計プログラムに組み込みます。
