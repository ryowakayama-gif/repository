# 見える化データの確認（交付金 W系列）

受領した見える化システムの出力のうち、保険者機能強化推進交付金等に係る
W系列 210冊を確認した。**本村の値のみを対象とし、県内の他自治体は参照値**
として扱った。

---

## 1　いちばん重要なこと：年度の呼び方が1年ずれている

**見える化は取組の年度で、厚生労働省の該当状況調査票集計表は評価・交付の
年度で呼ぶ。同じ評価が1年ずれた名で載る。**

| | 見える化 | 当方の素案（厚生労働省の集計表による） |
|---|---|---|
| 呼び方 | 令和5年度 | **令和6年度** |
| 保険者機能強化推進交付金 | 124点 | 124点 |
| 介護保険保険者努力支援交付金 | 171点 | 171点 |
| 合計 | 295点 | 295点 |

3つの値が完全に一致することから、**同じ評価を別の年で呼んでいる**と判断した。
目標別の内訳（推進 17／30／12／65、支援 27／40／39／65）も、それぞれ
推進計124・支援計171と合う。

素案2-8にこの対応を注記として加えた。両者を見比べる方（村・委員会・県）が
1年ずれた数値を突き合わせて食い違いと受け取ることを防ぐためである。

点検18・19として機械で確かめるようにし、摂動で検出することを確認した。

---

## 2　令和3・4年度は当方の系列に接続できない

W系列は**令和3〜5年度**を収める。このうち令和3・4年度は**旧い評価指標の
体系**であり、当方の素案が用いる令和6〜8年度（目標Ⅰ〜Ⅳ×推進・支援の
800点満点）とは構造が違う。

| | 令和3・4年度（見える化のW系列） | 令和6〜8年度（素案） |
|---|---|---|
| 大項目 | Ⅰ／Ⅱ／Ⅲ | 推進・支援それぞれ目標Ⅰ〜Ⅳ |
| 本村の得点 | Ⅱ合計 600点（令和3年度）→845点（令和4年度） | 合計 295→339→447点 |
| 県平均との関係 | Ⅱ合計で県平均612.5点を下回る | 県平均354.1点を下回る |

**得点の推移の図（図2-22）に令和3・4年度を足してはならない。** 満点も
区分も違うため、伸びているように見えても比べられない。

令和5年度は新しい体系（目標Ⅰ〜Ⅳ）で収められており、当方の令和6年度と
同じものである（上記1）。

本村の値がある103冊の内訳は、令和3年度5冊・令和4年度7冊・令和5年度25冊・

**本村の値がない107冊は、表のシートに福島県の列しか置かれていない。**

## 4　読み取りで直した誤り

W系列を読む過程で、**当方の取り出しに地域の取り違えがあった**ことが分かった。

地域別のファイルは**列が地域**である。表のシートに福島県の列しか置かれて
いないものについて、当方の取り出しは「このブックは北塩原村について出力した
ものである」という冒頭の記載だけを見て、**福島県の値を本村の値として**
読み込んでいた。

| | 直す前 | 直した後 |
|---|---|---|
| W系列で本村とした行 | 10,715 | **654** |
| 福島県とした行 | 107 | 763 |

列の見出しが地域名のときは列ごとに地域を割り当てる形に改めた。
あわせて、地域名は完全一致で判定するようにした
（「高齢化率（福島県）」のような行の見出しを地域と取り違えないため）。

この取り違えにより、P1・P2の本村の行が拾えていない不具合も見つかり、
あわせて直した。取り出しは738冊すべてを読み、本村26,480行となった。
