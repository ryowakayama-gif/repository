## 0. 結論（先に3点）

**(1) 初回で必ず決めるべきは9項目です。**
9月9日の入稿を守るには、調査票の内容・部数・発送日を左右する項目だけは、この場で決着させる必要があります。それ以外は方向性の確認にとどめて構いません。

**(2) 工程に1つ、見過ごせない問題があります。**
逆算表の発送日「9/18頃」は**金曜日**で、その翌日から**9/19（土）〜9/23（水）の5連休**が始まります。配達が連休明けにずれ込む可能性が高く、回収期限の設定と督促のタイミングに影響します。**この場で発送日を確定させるべきです。**

**(3) 第2回策定委員会は「12月中」でないと工程が破綻します。**
パブリックコメントに30日間を要するため、第2回が1月にずれると第3回（2月）までにパブコメが終わりません。資料では「12月〜1月頃」と幅を持たせていますが、**12月開催を前提に諮るべきです。**

## 2. 追加で確認・打合せが必要な事項（15件）

### 調査関連

**追-1　調査の基準日**（コメント#1・#6）
ニーズ調査は「令和◯年◯月◯日時点で要介護認定を受けていない65歳以上の方」、在宅介護実態調査は「令和◯年◯月◯日時点で在宅で生活している要介護認定を受けている方」と、資料が空欄になっています。**基準日が決まらないと村が対象者を抽出できません。**第9期は令和5年8月1日基準でした。

なお#6のコメントにより、ニーズ調査の対象は「**要介護1〜5以外**」＝要支援を含む、と読めます。これまで「①要支援を含むか」を論点としてきましたが、ニーズ調査については論点ではなく、**在宅介護実態調査の側の論点**として整理し直すべきです。

**追-2　在宅介護実態調査 問8・問9の基準月**
資料12⑤に「発送月の前月が通常」とあります。発送日が確定しないと基準月も決まりません。追-8とセットで決めます。

**追-3　ウェブ回答フォームにGoogleフォームを用いることの可否**（コメント#8）
コメントは「暗号化され安全なため」としていますが、**通信の暗号化と、データの保存先は別の論点**です。Googleフォームは回答データが村外（事業者）のサーバに保存されます。個人情報保護条例上の取扱い、および次の実務面の確認が要ります。

- 管理番号による重複回答の排除をどう実装するか
- 回答データのエクスポートと、エクスポート後の元データの削除手順
- 公開期間の管理と、期間終了後のフォーム停止
- 障がい福祉計画で同じ方式を用いた際の村の承諾の有無（コメント#7・#24と関連）

doc16（個人情報取扱ルール）§5では「外部クラウドサービスの利用は村の事前承諾を要する」としています。**Googleフォームを前提とするなら、この場で明示的に承諾を得てください。**

**追-4　依頼状の差出人名義**（コメント#9）
村名義か村長名か。障がい福祉計画は村名義とのことです。回収率に影響し得るため、村長名を推奨しますが、村の慣行に合わせます。

**追-5　調査票の印刷部数**
ニーズ約850人＋在宅約150人＝約1,000部に対し、予備を何部見込むか。発送後の追加印刷は工程上困難です。

**追-6　督促（リマインド）の実施可否**
第9期の在宅介護実態調査の有効回収率は45.8%（72人中33人）でした。今回150人でも同率なら約69件です。**要介護度別・介護者就労状況別のクロス集計に耐える件数**を確保するには督促が要ります。実施の可否と、その場合の追加の郵送費の扱いを確認します。

**追-7　集計・分析で村が最も確認したい事項**（コメント#13）
資料5の論点表（9論点）から、クロス集計の設計に落とします。**とくに地区別（北山・大塩・桧原・裏磐梯）は、第9期報告書が全設問で実施しているため踏襲が前提**ですが、地区×性別×年齢の多重クロスは、人口2,315人の規模では個人が推定され得ます。どこまで細分するかを確認します。

**追-8　発送日と5連休の関係**（コメント#20の補強）→ §4で詳述

### データ関連

**追-9　人口データの出所の統一**（コメント#2）
住民基本台帳・国勢調査・**福島県現住人口調査**の3系列があります。doc13では社人研推計（国勢調査ベース）を住基ベースの実績で補正する手法を確立しましたが、県現住人口調査を用いる案もあります。**計画書内で人口の数字が複数出ることを避けるため、出所を1つに決めます。**

**追-10　介護保険事業状況報告の原データの要否**（コメント#3・#15）
見える化システム経由でB系・D系を整理済みですが、月報・年報の原データがあれば、見える化に収録されていない項目（サービス種類別の利用者数の月次推移等）が扱えます。提供の可否を確認します。

**追-11　実績データの詳細**（コメント#4）
受領資料シートの未受領10件に加え、次が新規です。

- 家族介護者リフレッシュ事業の参加者数、紙おむつ等の介護用品支給実績
- 認知症サポーター養成講座の受講者数、成年後見の相談件数・村長申立件数・報酬助成件数
- 特定健康診査・後期高齢者健康診査の受診率、特定保健指導の実施率
- **南東北裏磐梯診療所・桧原診療所の診療日数および患者数**

診療所データは在宅医療・介護連携の分析に直結しますが、これまで把握していませんでした。

**追-12　見える化システムのアカウント**（コメント#23・#24）
障がい福祉計画で使用したアカウントを継続利用できるか、新たに手続きが要るか、**秘密保持契約を再度締結する必要があるか**を確認します。すでに19,591レコードを受領して分析していますので、遡って手続きが要る場合はその整理も要します。

### 計画・体制関連

資料には国の基本指針・第5次総合振興計画・第3次健康21が挙がっています。追加で確認すべきものとして、**障がい福祉計画・障がい者計画**、地域福祉計画、自殺対策計画、および**第六次総合振興計画の策定状況**があります。

**追-15　策定委員の改選手続き**（コメント#17・#19）
**現委員の任期は令和8年9月30日で満了**します。第1回策定委員会を11月に開催するには、10月中の改選・委嘱が必要です。**手続きの所要期間を確認し、逆算して動く必要があります。**

## 3. ★施設整備の論点について（コメント#5関連）

コメント#5と資料5の論点表にある「**在宅調査で『村内に施設等があれば将来的に入所したい』48.5%**」は、こちらで把握していなかった重要なデータです。素案（doc18）に反映が必要と考えます。

ただし**扱いに注意が要ります**。

| | 値 | 母数 | 実数 |
|---|---|---|---|
| 村内に施設等があれば将来的に入所したい | 48.5% | 回収33件 | **16人** |
| 除雪（在宅調査） | 24.2% | 回収33件 | **8人** |

**48.5%は16人の回答です。**施設整備という重い判断の根拠とするには標本が小さく、第9期の在宅介護実態調査（対象72人・回収33人）の限界がここに表れています。

一方でこの数字は、これまでの分析と方向が一致します。

- 村内に施設サービスがゼロ（K系・D25・D28すべて0）
- 短期入所系の自給率0%（村内にサービスがない）／**訪問系サービスが9年間で50.8%減少し給付の3.2%まで低下**
- 認定率は県内18位／59保険者と高いのに、1人あたり費用額は44位と低い

つまり**「村内にサービスがないために外に出ている」構造**を、住民側から裏付けるデータです。

**第10期での扱い方の提案**：48.5%を単独の根拠とせず、上記の供給側データと併せて示します。そのうえで、**今回の在宅介護実態調査（150人）で改めて確認する**という位置づけにします。標本を倍増させる意義がここにあります。

## 4. ★工程上の問題（資料そのものへの指摘）

### 指-1　発送日9/18（金）が5連休の直前です【最重要】

逆算表の日付を検証しました。曜日はすべて正しいのですが、**5連休への言及がありません**。

| 日付 | 曜日 | |
|---|---|---|
| 9/17（木） | 木 | 封入・封緘の完了予定 |
| **9/18** | **金** | **発送（案）** |
| 9/19 | 土 | |
| 9/20 | 日 | |
| 9/21 | 月 | **敬老の日** |
| 9/22 | 火 | **国民の休日** |
| 9/23 | 水 | **秋分の日** |
| 9/24 | 木 | 連休明け |

金曜発送では、**配達が連休明けにずれ込む可能性が高く**、また対象者が受け取っても連休中は回答しにくく、返送のピークが後ろにずれます。

**選択肢は3つです。**

| 案 | 内容 | 評価 |
|---|---|---|
| A | **9/17（木）に前倒し** | 連休前に届く可能性が高まる。ただし村のラベル提供（9/14）から中1日しかなく、余裕がない |
| B | 9/18（金）のまま | 現行案。回収期限を連休を織り込んで後ろに設定する必要 |
| C | **9/24（木）に後ろ倒し** | 確実に連休明けに届く。ただし全工程が6日後ろにずれる |

**この場で決めるべき事項です。**あわせて回収期限（第9期は発送から17日間）も確定させてください。

### 指-2　村作業の遅延に対する余裕がありません

宛名ラベル・封筒の提供が**9/14（月）まで**、貼付・封入が9/16〜17、発送9/18という段取りです。**村側の提供が1日でも遅れると発送が連休に食い込みます。**提供期限を9/11（金）に前倒しできないかを確認すべきです。

### 指-3　第2回策定委員会は12月中でないと工程が成立しません

| 日程 | 12月開催の場合 | 1月開催の場合 |
|---|---|---|
| 第2回策定委員会 | 12月中旬 | 1月中旬 |
| パブリックコメント（30日間） | 12月下旬〜1月下旬 | 1月下旬〜**2月下旬** |
| 第3回策定委員会 | 2月 ✓ | **3月**（履行期限に間に合わない） |

資料は「R8年12月〜R9年1月頃」と幅を持たせていますが、**1月開催では成立しません**。12月開催を前提として諮るべきです。

なお12月開催でもパブコメが**年末年始を挟む**ため、実質的な意見提出可能日数が減ります。開始日を12月上旬に寄せられないかも論点です。

### 指-4　国の基本指針の告示時期との関係

資料に「国の第10期基本指針の告示（令和8年内予定）が遅れた場合は暫定版で作業を進め、告示後に修正する二段構え」とあります。方針として妥当ですが、**令和8年内告示だと、保険料算定に必要な推計ワークシートの提供は12月以降**になる可能性が高く、第2回策定委員会（12月）に保険料の試算が間に合いません。

**第2回で何を諮るかを整理しておくべきです。**「保険料の考え方」と「試算値」は分けて、試算値は第3回に回す構成も選択肢です。

### 指-5　概要版の位置づけが不明確です

成果品一覧（資料10）に概要版はありませんが、末尾に「必要に応じては概要版も作成致します」とあります。**仕様書に概要版の記載はなく、第9期は2ページの概要版が作成されています。**作成する場合の位置づけ（仕様の範囲内か、追加対応か）を明確にすべきです。

### 指-6　軽微な誤り

- 逆算表の発送日が「**9/1８頃**」と全角と半角が混在しています。

## 5. ★優先順位

初回で全部は決まりません。**「決めないと止まるもの」から並べました。**

### S：この場で決着が必要（決定事項9つ／管理表では16行）

**9月9日の入稿・9月中旬の発送を守るために、これらが決まらないと作業が止まります。**

| # | 項目 | 決まらないと |
|---|---|---|
| S-1 | **調査の基準日**（両調査） | 村が対象者を抽出できない |
| S-2 | **在宅介護実態調査の手法（Ⅰ〜Ⅳ）** | 調査票そのものが確定しない |
| S-3 | **在宅調査の抽出条件**（要支援を含むか／更新・区分変更に限るか／サ高住等を含むか） | 対象者数＝印刷部数が決まらない |
| S-4 | **オプション項目の採否・村独自設問** | 頁数が決まらず入稿できない |
| S-5 | **印刷頁数の調整方針**（仕様書はニーズ約12頁／在宅約8頁） | 同上。設問の絞り込みが要る場合は再設計 |
| S-6 | **ウェブ回答フォームの方式**（Googleフォームの可否・個人情報の取扱い） | フォーム構築に着手できない |
| S-7 | **依頼状の差出人名義**（村名義／村長名） | 入稿データが確定しない |
| S-8 | **発送日**（9/17前倒し／9/18のまま／9/24後ろ倒し）と回収期限 | 以降の全工程が決まらない。**5連休の扱い** |
| S-9 | **宛名ラベル・配布用封筒の提供期限** | 発送日が守れない |

**S-8とS-9はセットです。**発送日を先に決め、そこから逆算して提供期限を確定させてください。

※ 管理表（Excel「村への確認事項」シート）では、上の9つの決定を**16行**に分解して優先度Sを付けています。基準日・抽出条件・対象者数・印刷部数のように**一つの話し合いでまとめて決まるもの**を、確認漏れが起きないよう項目単位で立てているためです。

**決定でなくてよいが、宿題として持ち帰る期限を握るべきものです。**
