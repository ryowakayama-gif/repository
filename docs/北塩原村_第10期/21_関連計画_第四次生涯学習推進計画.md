### 1-1 第10期介護保険事業計画との期間関係（重要）

第10期計画期間は**令和9〜11年度（2027〜2029年度）**である。本生涯学習推進計画は**2027年度（令和9年度）で満了**するため、第10期計画期間の**初年度のみ重なる**。したがって第10期計画の「関連計画との整合」の記述では、

- 令和9年度までは第四次生涯学習推進計画と整合を図る
- 令和10年度以降は第五次生涯学習推進計画（策定予定）との整合を図る

という書き分けが必要である。上位の第五次総合振興計画（2017〜2026年度）も令和8年度で満了するため、**第10期計画期間中は上位計画・関連計画がともに切り替わる**。この点は素案 第1章 §1-4（計画の位置づけ）の編集注記に反映する。

## 2. 高齢者福祉・介護保険計画に関係する記載

### 2-1 施策として明記されているもの

| 章・区分 | 施策名 | 内容 |
|---|---|---|
| 第2章 村の生涯学習施策 | 高齢者生きがい健康づくり事業 | 高齢者の生きがいと健康づくりを図るため、活動への支援や発表・交流の場を提供し、元気な高齢者を増やす |
| 第3章 ライフステージ別（高齢期） | 高齢期の学習支援 | 高齢者教室をはじめ、高齢者の余暇の充実、健康づくり、社会貢献活動につながる講座を開催するとともに、福祉施設などにおける高齢者の活動の場を提供する |
| 第4章 ≪活かせる≫ | 高齢者の生きがい健康づくりの発表・交流機会の提供 | 高齢者のサークル活動に対する支援のほか、発表・交流の機会を提供 |
| 第4章 ≪活かせる≫ | シルバー人材センターの充実 | 高齢者の健康で生きがいのある生活の実現と、地域社会の福祉の向上・活性化を支援 |
| 第4章 ≪つながる≫ | **地域で見守り・育む高齢者の支援** | 地域のつながり・支え合いをテーマとした講演会等を開催し、**一人暮らしなどで支援を必要とする高齢者を地域で見守る体制づくりを整備** |
| 第4章 ≪つながる≫ | 村民等のボランティア活動の支援 | 村ボランティアセンター、学校支援ボランティア等の情報提供・働きかけ・相談の充実 |

**「地域で見守り・育む高齢者の支援」は、介護保険事業計画側の見守り・支え合い体制整備（生活支援体制整備事業・第2層協議体・見守りネットワーク）と施策が重複する。** 第10期計画では所管（住民課／教育委員会）を明記したうえで、連携して実施する旨を記載することが望ましい。

また、**シルバー人材センター**は介護保険側でも「高齢者の社会参加・就労的活動」の受け皿として位置づけられる。両計画で同一の資源を扱うため、記述を揃える。

### 2-2 高齢者に関する住民ニーズの記載

第2章「第三次計画の成果と課題」において、村民アンケート調査の結果として次の記載がある。

> 年齢別にみると、20〜30歳代はスポーツやレクリエーション活動、**60歳以上では趣味や健康管理に関すること**など、世代で関心が異なっており、また、子育て世代は「時間に余裕がない」、**高齢者は「一緒に活動する仲間が少ない」**など直面している課題も様々で、関心やライフステージを踏まえて、参加の機会を充実させていくことが求められています。

**「一緒に活動する仲間が少ない」**という高齢者の課題認識は、第10期の通いの場・介護予防の施策（住民主体の通いの場が23か所281人、週1回以上は8か所123人にとどまる）と直結する。素案 第2章の介護予防・通いの場の分析、および第4章の施策（社会参加の促進）の根拠として引用できる。

また、団体アンケートでは村内団体が今後取り組みたい活動として**「高齢者の生きがいをつくる活動」が最多**となっている。生活支援体制整備事業における担い手の掘り起こしの根拠として使える。

## 3. 目標値の設定方法（第10期の参考）

本計画は、住民アンケートの回答割合をそのまま指標に用いる方式を採っている。第10期計画の目標値設定でも同様の方式が使えるため、村の従来の作法として押さえておく。

| 指標 | 現状値（2017年） | 目標値（2027年） |
|---|---|---|
| 生涯学習を行っている人を増やす | 61.5% | 65.0%（国の現状値47.5%） |
| 学んだ知識・技能を活かしている人を増やす | 53.2% | 65.0% |
| 生涯学習を通じて地域や社会とつながっている人を増やす | 23.7% | 50.0% |
| 村民ひとり1スポーツ運動（週1回以上の実施率） | 41.3% | 65.0%（国の目標値65.0%） |
| 村民ひとり1文化運動（月1回以上の実施率） | 33.7% | 50.0% |
| 生涯学習センターを利用する人を増やす | 5.7% | 20.0% |

**特徴**：①住民アンケートの設問番号と資料編のページを注記して出典を明示している、②国の現状値・目標値を「備考」欄に併記して水準の妥当性を示している。第10期計画の目標値でも、**根拠となる調査の設問番号と、全国・県の水準を併記する**方式を踏襲する。

なお、第四次計画は10年計画のため中間年（2022年度）の実績評価があるはずである。**第10期計画の記述に用いるには最新の進捗状況を確認する必要がある**（下記K-68）。

## 4. 計画の推進体制・進行管理

第5章に「計画の推進体制」「計画の進行管理」が置かれ、生涯学習推進本部・生涯学習推進会議による推進体制が示されている。第10期介護保険事業計画の推進体制（介護保険運営協議会等）との関係は直接には生じないが、**村の計画進行管理の作法（PDCA、年次評価の主体）は本計画に倣うことができる**。
