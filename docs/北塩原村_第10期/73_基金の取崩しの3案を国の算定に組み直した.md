# 介護給付費準備基金の取崩しの3案を国の算定の上に組み直した（令和8年10月9日）

作業順位1（Ⅱ-64）と2（Ⅱ-83）を行った。
**第2回策定委員会の中心論点である基金の取崩しの3案が、当方がワークシートの提供を
受ける前の算定の上に乗っていたため、国の算定の上に組み直した。**

---

## 1　何が問題だったか ― 向きが逆になっていた

資料6の6-0は「本日ご議論いただきたいのは①介護給付費準備基金の取崩しをどの規模で
行うか」としており、6-3bの3案がその議論の材料そのものである。
ところがこの3案は、国の推計ワークシートの提供（10月7日）より前に算定したものだった。

| | 当方の算定 | 国の算定 |
|---|---|---|
| 取崩なしの算定上の月額 | 6,756円 | **6,610.55円** |
| 条例上の基準額（百円未満四捨五入） | 6,800円 | **6,600円** |
| 第9期の条例基準額6,700円との差 | **＋100円** | **▲100円** |

**差は145円にとどまるが、第9期との向きが逆になる。**
当方の算定では「取崩しをしないと100円上がる」、国の算定では
「取崩しをしなくても100円下がる」である。

このため3案のうち**C案「保険料の据置きを優先し、基金を最大限取り崩す」は前提が
崩れていた。** 取崩しをしなくても第9期を下回るため、据置きを目標に置くと
取崩しは不要になる。A案（取崩なし6,756円）・B案（24,000千円6,054円）も
当方の算定ベースであり、C案の基準月額は【基金残高の受領後】のまま空いていた。

正本は `scripts/estimate_kikin.py` に置いた。素案5-7と資料6 6-3bは同じ算定を引く。

| 案 | 考え方 | 取崩額 | 第10期（算定上） | 第10期（条例上） | 第9期6,700円との差 | 第11期に残る残高 | 第11期（条例上） | 残高の緩衝力 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| A案 | 基金を取り崩さない | 0円 | 6,610.55円 | **6,600円** | ▲100円 | 42,128,183円 | **6,100円** | 月額1,155円分 |
| B案 | 第9期と同程度に取り崩す | 24,000,000円 | 5,952.45円 | **5,900円** | ▲800円 | 18,128,183円 | **6,700円** | 月額497円分 |
| C案 | 国の推計ワークシートの前提どおり | 40,000,000円 | 5,513.72円 | **5,500円** | ▲1,200円 | 2,128,183円 | **7,200円** | 月額58円分 |

条例上の基準額は**百円未満切捨て**である（§2-2）。

**第10期と第11期は逆の向きに動く。**
A案では第11期が6,133.10円で第10期を7.2%下回る。
C案では7,242.28円で31.4%上回る。
第10期で取り崩さずに残した分が、そのまま第11期の原資になるためである。

### 2-2　条例上の基準額の置き方を直した ― 第9期は切り捨てていた

**この表を作る途中で、当方が従来置いていた四捨五入が第9期の実例と合わないことに
気づいた。**

| | 値 |
|---|---|
| 第9期の算定上の月額（ワークシート） | 6,760.76円 |
| 同（第9期計画の記載値から復元。220,613千円÷99.5%÷2,733人÷12） | 6,760.63円 |
| **第9期の条例基準額** | **6,700円** |
| 百円未満四捨五入なら | 6,800円（**条例と食い違う**） |
| 百円未満切捨てなら | 6,700円（**条例と一致**） |

**本村の第9期は百円未満を切り捨てている。**
素案5-7は「条例で定める保険料の基準額は、この算定上の月額の百円未満を四捨五入した額と
することが一般的です」と書き、条例上の基準額の表と図5-4を四捨五入で置いていた。
第9期の実例で確かめずに一般論を当てていたものである。

第9期の実例に合わせて**切捨てを本体とし、四捨五入の値を参考として併記する**形に
改めた。影響が出るのは次のところである。

| 箇所 | 前（四捨五入） | 後（切捨て） |
|---|---|---|
| 基金の3案 B案の第10期 | 6,000円 | **5,900円** |
| 同 B案の第11期 | 6,800円 | **6,700円** |
| 5-7 基金取崩なし・推計どおり（当方の算定6,756円） | 6,800円（＋100円） | **6,700円（±0円）** |
| 5-7 基金取崩24,000千円（同6,054円） | 6,100円（▲600円） | **6,000円（▲700円）** |
| 図5-2 の矢印の右の値 | 四捨五入 | **切捨て** |

**「基金を取り崩さないと第9期から100円上がる」という従来の記載は、
切捨てでは「据え置き（±0円）」になる。**

置き方は `scripts/estimate_kikin.py` の `jorei()` を正本とし、
図の作成（build_figures）が四捨五入をじか書きしていたのも同じ関数を引く形に直した。
**条例の文言を確かめたものではないため、村への確認事項として起票した**
（影響度2・優先度A。四捨五入であればB案が100円動く）。

### 3つ目の軸 ― 基金の緩衝力

基金にはもう一つの役割がある。推計そのものの誤差を吸収することである。
5-4(10)③のとおり、本村の規模では推計の誤差が絶対値の平均で11.9%あり、
保険料に換算すると月額約700円である。

| 案 | 計画した取崩しの後に残る額 | 吸収できる誤差 |
|---|---|---|
| A案 | 42,128,183円 | 月額1,155円分 |
| B案 | 18,128,183円 | 月額497円分 |
| C案 | 2,128,183円 | **月額58円分（約700円の誤差を吸収できない）** |

**C案は保険料を最も下げるが、推計が上振れしたときの備えが残らない。**

したがって取崩額の判断は、①第10期の保険料を下げること、②第11期の上がり幅を
和らげること、③推計の誤差に備えることの3つの兼ね合いになる。
**当方からは案を示すにとどめ、どの水準を採るかは村のご判断である。**

## 3　第11期の値は当方の試算である ― 分母の組み方と、その確かめ

**国の中長期シートは第11期を令和12年度の単年で立てており、第11期の
所得段階別加入割合補正後被保険者数を持たない。**
このため次のように分母を組んだ。

| | 値 |
|---|---|
| 令和12年度の第1号被保険者数 | 988人 |
| 所得段階別加入割合補正係数（令和12年度） | 1.0190 |
| 予定保険料収納率 | 99.50% |
| 第11期を単年で見た分母 | 12,021人・月 |
| **3か年に均した分母** | **36,063人・月** |

**保険料は期を通じて同一に定めるため、残高を充てる効きは3か年の分母で
割った値になる。** シートの取崩額の欄に残高をそのまま入れると単年の分母で割られ、
3倍大きく出る（A案では3,796.70円）。これはシートが第11期を単年で立てていることに
よるもので、期の保険料の姿ではない。

**前回の報告では「単年基準と3か年に均した場合のどちらかを当方が決めない」と
書いたが、これは誤りだった。** 期の保険料を求めるのであれば3か年の分母で割るのが
正しく、単年基準の値はシートに機械的に入れた場合の数にすぎない。
素案・資料には3か年に均した値を本体として載せ、単年基準の値は
「シートに機械的に入れた場合」として注記に落とした。

### 分母の組み方が妥当かを第10期で確かめた

同じ組み方で第10期の分母を復元して比べた。

| | 人・月 |
|---|---|
| ワークシートの値（取崩額÷影響額） | 36,469 |
| 当方の組み方による復元 | 36,499 |
| 差 | **＋0.08%** |

第11期の基準額に換算すると月額5円以内にとどまる。
**組み方が通らなくなったことを機械で知るため、点検65を設けた（§4）。**

### なお国のシートの出力そのものは7,301.29円である

国の推計ワークシートは第11期の取崩額を0としている。
上表のC案の第11期7,200円は、残る残高2,128,183円を第11期に充てた場合の値であり、
充てない場合はシートどおりの7,301.29円になる。

**確実な値はワークシートを操作した再計算による。**
取崩額0円・24,000千円の場合の出力を村にお願いしている（照会票 束1）。

## 4　自己点検

### 点検65を新設した（素案 64件→65件）

**第11期の分母の組み方が第10期で復元できること**を見る。
素案の注記は差を印字するだけなので、差が大きくなっても文面は成り立ってしまう。
組み方が通らなくなったことを機械で知るための点検である。あわせて次を見る。

- 復元の差が0.5%以内であること
- 5-7の基金の節に「当方の試算」「単年」「3か年に均した」「ワークシートを操作」
  「第11期の取崩額を0」「百円未満を切り捨てた」「四捨五入」の断りがあること
- 3案の表の第10期・第11期（条例上）が estimate_kikin の算定と一致すること

**自己試験で3つの欠陥をそれぞれ戻し、いずれも検出することを確かめた。**

必須の断りに「百円未満を切り捨てた」「四捨五入」を加えたのは、
§2-2の取り違えを機械で防ぐためである。
**ただしこの取り違えは点検では見つからなかった。**
第9期の実例と突き合わせるという発想が点検になかったためで、
表を作りながら「第9期は6,760.76円なのに条例が6,700円なのはなぜか」と
手で確かめて気づいたものである。
点検は「書いてあるか」を見るにとどまり、「一般論を当てていないか」は見ていない。

| 戻した欠陥 | 検出 |
|---|---|
| 復元の差を3%にする（組み方が通らない状態） | 「復元の差が＋3.00%で許容(0.5%)を超える」 |
| 注記から「3か年に均した」を落とす | 「5-7の基金の節に『3か年に均した』の断りがない」 |
| 表のA案の第10期を6,700円に書き換える | 「A案 の第10期（条例上）が算定と合わない」 |

### 点検20を拡張した（委員会資料）

## 5　分量

**5-7に3案を加えたため本文が1頁増えた。**

| | 前 | 後 |
|---|---|---|
| 計画書（本文＋前付） | 115頁＋4頁＝119頁（+19頁） | **116頁＋4頁＝120頁（+20頁）** |
| 削減案をすべて行った場合 | 106頁 | **107頁** |

**削減案を1つ加えた。**

| 案 | 内容 | 減る頁 |
|---|---|---|
| L | 5-7 保険料基準額の12のパターン（当方の算定ベース）を別冊へ移す | 1頁 |

5-7の節の中に、前提の異なる2つの案の組（国の算定ベースの3案と、
当方の算定ベースの12のパターン）が並ぶことになった。
12のパターンは第1号被保険者負担割合と給付費の水準の効きを示すものだが、
その効きは感応度の表が示している。決定の材料は3案であるため、
12のパターンは別冊の「算定の根拠」へ移せる。
**「算定上の月額と条例上の基準額」の小見出しは3案の表が用いる四捨五入の説明である
ため残す。**

**到達できる最小は107頁である**（A〜L。G・Iを除く10案）。
素案が1頁増え、案Lで1頁戻るが、頁の送りの関係で到達点は1頁上がった。
目安100頁には収まらないため、点検52は不適合として報告し続ける。
