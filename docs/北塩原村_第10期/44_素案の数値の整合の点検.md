作成日：2026-09-28
方法の参照：大雪地区広域連合・金ケ崎町の各案件（他団体の数値は用いていない）
算定：`scripts/shihyo_dict.py`（指標辞書）／`scripts/verify_soan.py` 点検22〜24／`scripts/verify_shukei.py` 点検9〜16（§7）

## 1　なぜこの点検をしたか

大雪地区広域連合と金ケ崎町の案件で、外部レビューにより**同じ種類の欠陥**が多数指摘されていました。

| 指摘された欠陥の型 | 例 |
|---|---|
| **同じ指標に2つの値が併存する** | 1つの指標の基準値が2つの調査から2通り示されていた |
| **分母が混在する** | 設問ごとの有効回答と回収票の総数が混ざっていた |
| **指標の定義が複数箇所に散らばり食い違う** | 代表指標の定義が章ごとに別々に書かれていた |
| **時点の異なる値を足していた** | 時点の違う数を合計して総数としていた |
| **分母を表示しながら別の分母の値を使っていた** | n=474と書きながら無回答を除いたn=439の値を載せていた |

いずれも**個々の数字は正しいのに、並べたときに食い違う**種類の誤りです。算定が正しいかを確かめる自己点検（本村は21件）では捕まりません。**本村の素案にも同じ点検を当てました。**

## 2　見つかった不整合は3件でした

### 2-1　2-9 の令和6年度と令和7年度が入れ替わっていた（誤り）

第9期計画の進捗と評価で、第1号被保険者数の実績が入れ替わっていました。

| | 計画値 | 実績（訂正前） | 実績（訂正後） |
|---|---|---|---|
| 令和6年度 | 957人 | 1,011人 | **1,015人** |
| 令和7年度 | 950人 | 1,015人 | **1,011人** |

「見える化」システムのD2・D3・D4の第1号被保険者数（年度の値）は、令和5年度1,004人・令和6年度1,015人・令和7年度1,011人です。**素案5-4(9)の表は正しく入っていたため、2-9だけが逆でした。**差の欄も +54人／+65人 から **+58人／+61人** に直しました。

### 2-2　令和9年の第1号被保険者数が 1,003人 と 1,004人 に割れていた

同じ指標が章によって違う値になっていました。

| 節 | 訂正前 | 訂正後 |
|---|---|---|
| 2-2 将来人口の見通し | 1,003人 | **1,004人** |
| 5-2 第1号被保険者数の見込み | 1,004人 | 1,004人 |

原因は端数処理です。B案の令和9年は前期465人・後期538人で、**内訳を四捨五入してから足すと1,003人、合計を四捨五入すると1,004人**になります。保険料の算定（5-7）は1,004人を用いているため、**1,004人に統一**し、内訳の和と1人違うことを指標辞書に記録しました。

### 2-3　「令和7年（実績）」の行が令和8年と同じ値だった

5-2と2-2の推計表の先頭行が「令和7年（実績）486／526／1,012」で、次の令和8年の行とまったく同じ数字が並んでいました。

実績（住民基本台帳）は**令和7年12月末**の値で、推計ではこれを**令和8年1月1日**の推計用人口に置き直して延ばしています。したがって令和8年に同じ値が出るのは正しいのですが、**行のラベルが「令和7年」では対応が読み取れません。**「**令和7年12月末（実績）**」に改めました。

なお、B案の令和7年の推計値は1,021人です。実績1,012人は令和7年の値ではありません。

## 3　第1号被保険者数には出所が3つあります

本村の素案で最も混同しやすいのがこれです。**3つとも時点も定義も違います。**

| 出所 | 値 | 時点 | 用いる場面 |
|---|---|---|---|
| 見える化 D2・D3・D4 | 令和6年度1,015人／令和7年度1,011人 | 年度 | 2-9の乖離検証、5-4の受給率の分母 |
| 村の住民基本台帳 | 1,012人（前期486・後期526） | 令和7年12月末 | 5-2の推計の置き直しの基準 |
| B案の推計 | 令和9年1,004人→令和11年987人 | 各年1月1日相当 | 5-2〜5-7の見込みと保険料 |

これに加えて、

- **2-3の1,015人**は各年3月末の介護保険事業状況報告（認定率21.1%の分母）
- **5-7の所得段階別の合計1,015人**は令和8年度の合計所得金額分布調査
- **通いの場の分母1,009人**は令和6年度の65歳以上人口（地域包括支援センター運営状況調査）

**1,015人が3つの異なる意味で登場し、1,009人と1,012人も紛らわしい並びです。**2-9に注記を新設し、出所が複数あること、節ごとにどれによるかを明記していることを断りました。

## 6　残る課題

**アンケート調査の数値はこれからです。**本点検は既存の統計を対象としたもので、調査の集計値が入る箇所（2-10、第4章の施策の指標、資料3）は回収後に同じ点検を当てる必要があります。大雪で指摘された欠陥の多くはアンケート由来でした。

具体的には次の3点を、集計の設計段階で決めておく必要がありました。**2026/09/28に集計仕様書（doc25 §2）へ反映しました。**

| # | 内容 | 反映先 |
|---|---|---|
| 1 | **分母を設問ごとの有効回答に統一する。**回収票の総数で割る値と混在させない | 基本方針9（新設）。クロス表20件すべてに「分母」の欄を設けた。**報告書骨子（doc24 §2-1）に第1章1-5「報告書の見方」として7項目で明記** |
| 2 | **同じ指標を複数の設問から作らない。**やむを得ず作る場合は主と補を明示する | 基本方針10（新設）。§2-2に主指標・補足指標の表を新設（5件）。**doc24 §2-1 に同じ5件を「報告書での扱い」付きで再掲** |
| 3 | **クロス集計の分母を表ごとに明記する。**n<30は参考値である旨を付す | 基本方針11（新設）。時点の異なる値を足さないことも加えた。**doc24 §13 に20表と報告書の図表の対応表を新設し、分母を定義のまま転記** |

基本方針は8項目から**11項目**になりました。あわせて集計仕様書の自己点検を新設しています（`scripts/verify_shukei.py`・**16件**。うち9〜16は報告書骨子との照合で、§7-3に掲げました）。クロス表20件すべてに分母があること、分母に回収票の総数を用いていないこと、主指標に出所が書かれていること、在宅調査の要介護度が2区分に揃っていることなどを機械で確かめます。

**主指標・補足指標で最も注意を要するのは「社会参加・通いの場への参加」です。**村の実績（分母は65歳以上人口）とアンケートのP01（分母は問5(1)の有効回答）は**母集団が違います**。交付金の評価指標と計画の目標値は村の実績によるため、これを主指標とし、アンケートの値を並べるときは必ず注記します。大雪で指摘された「1つの指標の基準値が2つの調査から2通り示されていた」のと同じ構図であり、本村で最も起こりやすい箇所です。

なお、指標辞書（`shihyo_dict.py`）への集計値の追加は、回収・集計の完了後に行います。

## 7　報告書骨子（doc24）への反映と、そのとき見つかった不整合6件

**2026/09/28に、集計仕様書の分母の方針を報告書骨子（doc24）へ落としました。**集計の設計（doc25）で分母を決めても、報告書の書き方（doc24）が別に書かれていれば、集計が終わったあとに同じ食い違いが再発します。

### 7-1　doc24 に加えたもの

| 箇所 | 加えたこと |
|---|---|
| §2-1（新設） | 第1章 1-5「報告書の見方」に書く**分母の7項目**（設問ごとの有効回答／クロスは両設問／無回答は分母に含む／複数回答／対象者が限られる設問／n<30は参考値／時点の異なる値を足さない）と、**主指標・補足指標5件の報告書での扱い** |
| §4-1 | 掲載方式の1に「**分母の定義**」を加え、「分母：問◯に回答した票（n=◯）」を図表の下に必ず置くことと、3重クロスを行わないことを明記 |
| §4-3 | リスク判定の**分母は判定に必要な設問のすべてに回答した票**であること、欠測は「判定不能」として分母から除き件数を併記すること、**リスクごとに分母が違う**こと |
| §5・§5-1・§5-2・§5-3 | 在宅調査は回収54〜71件で区分別はほぼ n<30 になること、**A票とB票で分母が違う**こと、表4-X（X-16）と問6×問6-1（X-15）の分母 |
| §6-4・§6-5 | 表5-X（X-01）・表5-Y（X-02）の分母と、**両表で分母が違う**こと。4層区分（L01）の分母と「判定不能」の別掲、**第4層だけは認定データで判定できる**非対称 |
| §7-1・§7-2 | 図6-X（X-04）・担い手の推計表（X-03）の分母。**推計表の人数は回答者の人数であり高齢者全体ではない**こと、拡大推計は別の表にすること |
| §8・§10 | 課題の「現状」に分母と時点を添えること。**計画書に載せる値は報告書と同じ分母・同じ数字**を用い、回収後に指標辞書へ追加すること |
| §13（新設） | **20表と報告書の図表の1対1の対応表。**分母は集計仕様書の定義をそのまま転記した |

### 7-2　照合のときに見つかった不整合6件

doc24 と doc25 を突き合わせたところ、**アンケート関係の文書どおしでも§1と同じ型の食い違い**がありました。いずれも訂正しました。

| # | 不整合 | 訂正 |
|---|---|---|
| 1 | **問7の村独自3問の枝番が1つずれていた。**doc24 は問7(8)(9)(10)、doc25 は問7(9)(10)(11) | doc23の修正（問7(7)の復活）を反映した**doc25 を正**とし、doc24 の4か所を訂正。問7(8)は「よく会う友人・知人の関係」で、doc24 のICF対応表（環境因子）では正しく使われていた |
| 2 | **リスク判定の領域数が3通りあった。**doc24 §4-3 の表は8領域、doc24 §9-1 の資料1は「R01〜R11・R99の11領域」、doc25 は R01〜R10 の10領域 | **10領域＋R99 に統一。**doc24 の表に R08 知的能動性・R09 社会的役割を加え、**コード列を設けて doc25 の派生変数と同じ記号で引く**ようにした。4層区分（第1層＝全非該当）は領域数が違うと定義が変わるため、影響は分析編の全体に及んでいた |
| 3 | **BMI（B01）の出所が「問8の身長・体重」と書かれていた** | 実際は**問3(1) 身長・体重**。doc25 §2-2 と `shukei_data.py` の SHU_HO を訂正 |
| 4 | **集計軸I（要介護度）が3区分のまま残っていた。**doc25 §2-1 とクロス表は2区分に改めていたが、§3の集計軸の表と `AXES` は「要支援1・2／要介護1・2／要介護3〜5」のまま | **2区分（要介護1・2／要介護3〜5）に統一**し、名簿に要支援の方が含まれない理由（doc43）を併記 |

### 7-3　自己点検を8件追加しました（8件→16件・全件適合）
