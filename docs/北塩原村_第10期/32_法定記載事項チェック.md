## 2　訂正　素案の条項番号に誤りがあった

**素案5-8「介護給付適正化計画」で、根拠を「介護保険法第117条第3項第5号・第6号」と記載していたのは誤りである。正しくは第117条第2項第3号・第4号である。**

これは単なる番号の誤りではなく、**義務か努力義務かという性質が変わる**。

| | 誤（素案の記載） | 正 |
|---|---|---|
| 条項 | 第117条第3項第5号・第6号 | 第117条**第2項第3号・第4号** |
| 性質 | 定めるよう**努める**ものとする（努力義務） | 定める**ものとする**（**義務**） |

「介護給付適正化計画に関する指針」（令和5年9月12日老介発0912第1号）は「介護保険法第117条第2項第3号及び第4号の規定により、市町村介護保険事業計画において、介護給付等に要する費用の適正化に関し、市町村が取り組むべき施策に関する事項及びその目標を定めるものとされています」と述べている。

同じ誤りが20_交付金評価結果分析.md §8-1にもあった。両方を訂正した。

給付適正化が努力義務ではなく義務であることは、第5章5-8を置く判断をむしろ強める。

### 3-1　必要利用定員総数（第2項第1号）

**地域密着型3サービスの必要利用定員総数は、法が名指しで求める必須記載事項である。** 素案には2-5にサービス供給体制の実績（認知症対応型共同生活介護27人・通所介護50人）があり、5-9に稼働率の分析があるが、**「第10期の必要利用定員総数」として掲げた表がなかった**。

5-4に「(6) 地域密着型サービスの必要利用定員総数」を追加した。本村に関係するのは認知症対応型共同生活介護のみで、他の2サービスは実績・整備予定ともにない。

**あわせて論点が1つある。** 令和7年度の居住系サービス受給者は26.9人／月で、村内グループホームの定員27人に対する稼働率は93%である（doc30 §4-2）。第10期は居住系の利用が増える見込みであるにもかかわらず村内に余地がない。必要利用定員総数を27人（現状維持）とするか増床を見込むかは、村の判断を要する（依頼書 管理番号45-2）。

### 3-2　地域支援事業の量の見込み（第2項第2号）

素案5-5は地域支援事業**費**の見込みの様式であり、**量**の見込みがない。介護予防・生活支援サービス事業（訪問型・通所型の利用者数）と一般介護予防事業（実施回数・参加者数）の量を年度ごとに見込む必要がある。

村の事業実績（依頼書 管理番号36）の受領後に埋める。様式は5-5に追加した。

### 3-3　医療計画との整合（第5項）

素案1-4「計画の位置づけ」は村の関連計画との整合のみを述べており、**福島県保健医療計画・地域医療構想との整合に触れていない**。介護保険法は市町村介護保険事業計画が医療計画と整合が図られたものでなければならないと定めている。1-4に追記した。

### 4-1　老人福祉事業の量の目標（第2項）

**これが最も大きな欠落である。** 素案は介護保険サービスの見込量（5-4）を持つ一方、**介護保険外の老人福祉事業について量の目標を掲げた表がなかった**。老人福祉法が「定めるものとする」と規定する義務的記載事項である。

対象となるのは、施設サービス（養護老人ホーム、軽費老人ホーム、生活支援ハウス）と在宅福祉事業（配食、緊急通報、除雪支援、移動支援、家族介護者支援、介護用品の支給、高齢者の生きがい事業など）である。素案では施策2-1から2-6、4-5に個別の取組として書かれているが、量の目標としては整理されていなかった。

第4章の末尾に「4-6 高齢者福祉サービスの量の目標」を追加した。実績値は村からの提供待ちである（依頼書 管理番号25〜39）。

**なお、この節をどの章に置くかは村と協議したい。** 本計画は章立てを仕様書（第9期の構成）に合わせており、第9期計画のどこに老人福祉事業の量の目標があったかを当方は確認できていない。第9期計画の本文（81〜92ページの第5章）の提供を受けたうえで、配置を確定する。

### 5-1　高齢者虐待の防止（欠落）

素案に「虐待」の語が1度も出てこない。高齢者虐待防止法により市町村は通報の受理、事実確認、居室の確保等の責務を負っており、基本指針も権利擁護の一環として記載を求めている。地域包括支援センターの権利擁護業務の中核でもある。

施策4-1（地域包括支援センターの機能強化）または施策4-7（成年後見制度の利用促進）に虐待防止の取組を加えることを提案する。実績（相談・通報件数、虐待と判断した件数、やむを得ない事由による措置の件数）を村に照会する必要がある。

### 5-2　災害・感染症対策（不足）

施策2-4に「介護事業所と連携した災害訓練」があるが、基本指針が求める水準には届いていない。次の3点が不足している。

- 介護サービス事業所の業務継続計画（BCP）の策定状況と支援
- 水防法・土砂災害防止法に基づく要配慮者利用施設の避難確保計画の策定・訓練
- 感染症発生時の応援体制（都道府県・近隣市町村との連携）

村内の介護サービス事業所は2か所（グループホーム・通所介護）と限られるため、記載は簡潔で足りるが、触れないわけにはいかない。

## 7　共生社会の実現を推進するための認知症基本法第13条

| 記載事項 | 素案の該当箇所 | 判定 |
|---|---|---|
| 市町村認知症施策推進計画の策定（努力義務） | 1-2、施策4-4 | ○ |
| 認知症の人の社会参加・共生の視点 | 施策4-4 | △ |
| **基本理念（同法第3条）に即していることの明示** | ― | **✕ 欠落** |
| **認知症の人および家族等の意見を聴いて策定したこと** | ― | **✕ 欠落** |
| 認知症サポーター・チームオレンジ | 施策4-4 | ○ |
| 早期診断・早期対応（初期集中支援チーム） | 施策4-4 | ○ |
| 認知症バリアフリー・本人発信支援 | ― | △ |

認知症基本法は、市町村計画の策定にあたり**認知症の人および家族等の意見を聴くこと**を求めている。本計画は策定委員会とパブリックコメント、アンケート調査により意見を聴取しているが、**「認知症の人および家族等の意見を聴いた」ことを計画に書いていない**。

策定委員会の委員構成に認知症の人または家族の代表が含まれるかを確認し、含まれない場合は、家族会や認知症カフェでの意見聴取など、別途の機会を設けるかを村と協議する必要がある。**これは記述の追加では埋まらず、策定過程そのものに関わる**ため、第2回策定委員会（11月）までに方針を決める必要がある。
