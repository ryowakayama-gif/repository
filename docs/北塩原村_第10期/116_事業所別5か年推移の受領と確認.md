# 事業所別5か年推移の受領と確認（令和8年10月23日）

村より4つの圧縮ファイルを受領した。いずれも全国47都道府県分のExcelで、事業所ごとの値を令和3年から令和7年まで並べたものである。

| ファイル | 中身 | 対象 |
|---|---|---|
| 事業所別従事者数・減少率（５か年推移） | 看護職員等・介護職員の常勤・非常勤・常勤換算数 | 訪問系・通所系・短期入所系・多機能系・施設居住系 |
| 事業所別利用者数・減少率（５か年推移） | 1月あたりの利用者数（実数） | 同上 |
| 事業所別回転率・減少率（５か年推移、通所系サービス） | 1月あたり延べ利用者数・定員・回転率 | 通所系 |
| 施設別定員充足率・減少率（５か年推移、施設・居住系サービス） | 1月あたり延べ利用者数・定員・定員充足率 | 施設・居住系 |

各シートに「5年間連続減少アラート」と「5年前と比較した変化の割合」の列があり、従事者の項目は介護サービス情報公表システムの項目の合算であることが「【参考】情報公表 項目名対応表」に示されている。

## 1. 取り扱い

- 他市町村の値は取り込まない（「他の県内自治体の数値は参照値とする」）。本村の5事業所の値だけを `data/原典_事業所別5か年/北塩原村_事業所別5か年推移.csv` に取り出した（43行）
- 事業所名と職員の人数であり、個人を識別する情報は含まれていない。受領した圧縮ファイルそのものは版管理に入れていない
- 出どころ（配布元・取得の時点）はファイルに書かれていない。計画に引くには原典の名称が要るため、村に確認する

## 3. 素案との突き合わせ

| 素案の箇所 | いまの記述 | このデータで分かること |
|---|---|---|
| 5-4(12) 担い手の枠 | 「本村は介護サービス事業所の従事者数の実績を持たない」として、生産年齢人口に比例する仮定で試算 | 村内5事業所の介護職員は常勤換算で約29人、5年間ほぼ横ばい。仮定（生産年齢人口に比例して細る）を実績で確かめる材料になる。村内分の必要数を配置基準で算定できる |
| 5-4(5) 供給の制約・5-12 | グループホームは国の推計ワークシートの利用者数（本村の被保険者）を定員と並べ、村内の稼働率は不明として村に照会 | 村内2事業所は令和7年に満床（27人／27人）。本村の被保険者の利用者数（令和7年度24人）との差は、他市町村の被保険者の入居か、本村の被保険者の村外利用によるもので、内訳はまだ分からない |
| 5-4(5) 通所介護 | 本村の被保険者の受給者数（38.9人）÷定員50人＝77.8%を「到達率」として示す | 村内2事業所の実利用者は令和7年に65人で、延べで見ると定員の半分程度の稼働。受給者数と定員の比は稼働率ではなく、日ごとの受け入れには余地がある |
| 資6（基本指針の別表 事項七） | 従事者数は担い手の枠の試算で代えていると記載 | 従事者数を実績で示せる |
