## 2　受領した「見える化データ反映版」について

Word の内題は「第10期北塩原村高齢者福祉計画・介護保険事業計画（見える化データ反映版）」。
当方の素案を土台に、見える化の新しい値を反映したものである。

| 項目 | 当方の素案 | 反映版 |
|---|---|---|
| 図 | 25点 | **0点**（図を含まない） |
| 表 | 160 | 56 |
| 資料編 | 資1〜資8 | 資5まで |
| 5-4(14) 24時間対応サービスの確保方策 | あり | なし |
| 年齢階級別の認定率の時点 | 令和8年**3月末** | 令和8年**5月末** |

反映版は、当方が第49・50号で加えた記載（資6の別表対応・資7の参照資料・
資8の図表番号一覧・24時間対応サービスの確保方策・図25点）より前の版を
土台としている。**両者を合わせる必要がある。**

### 2-1　年齢階級別の認定率は、両版とも正しい

当方3月末・反映版5月末で値が違うが、**いずれもその時点の実物と一致する**。

| 項目 | 令和8年3月末（当方） | 令和8年5月末（反映版） | 裏づけ |
|---|---|---|---|
| 第1号被保険者数 | 1,015人 | 1,019人 | B1・B2 |
| 　前期高齢者 | 493人 | 495人 | B2 |
| 　後期高齢者 | 522人 | 524人 | B2 |
| 認定者数 | 214人 | 211人 | B3-a・P2 |
| 　後期高齢者 | 182人 | 182人 | B3-d |
| 　85歳以上 | 125人 | 121人 | B3-e |
| 後期高齢者の認定率 | 34.9% | 34.7% | B4-d |

**どちらの時点を採るかは村のご判断による。** 当方は3月末を用いている。
理由は、県・全国との比較が同一時点でそろうのが3月末であること、
人口・費用額など他の系列も年度末で揃っていることによる。

反映版は本村の値を5月末、県・全国との比較を3月末としている。
この扱いでは**同じ文書の中に認定率が21.1%と20.7%の2つ並ぶ**ため、
どちらの時点を正とするかを決めて統一する必要がある。

## 3　受領した長形式データの取り扱い

あわせて受領した `北塩原村値_長形式_20260930.csv`（26,701行）は、
**期（period）の欄が別の自治体の行の値になっていた。**

例：第1号被保険者1人あたり給付月額（認知症対応型共同生活介護）の本村の行で、
期が「362・396・474・626」と入っている。これは同じブックの別の自治体の
行の値であり、本来は「H18・H19・H20・H21」が入るべきところである。

値そのものは本村の行から正しく採られているが、**期が合わないため
時点をそろえた突合には使えない。** そこで実物から取り出し直した
（`scripts/parse_mieruka_batch.py`）。

| | 受領した長形式 | 当方の取り出し |
|---|---|---|
| 読んだブック | 583冊 | **738冊**（全件） |
| 本村の行 | 26,701（うち期と値が揃うもの18,290） | **49,803** |
| 期の欄 | **別の行の値が入っている** | 見出しの行から採っている |

取り出しは4通りの様式に対応している（自治体が行に並ぶもの、ブック全体が
1つの地域のもの、計画と実績のもの、地域別のもの）。
