# 表紙と図の見切れを直し、書体を障がい福祉計画にそろえた（令和8年10月23日）

村より「表紙や図3-1など文字の見切れがある。前回計画のフォント等を確認のうえ、添付の障がい計画の見え方との整合を踏まえて確認を」とのご指示を受けた。
添付は障がい福祉計画の本文（正本・移植後、150頁）である。

## 1. 見比べた結果

| | 前回（第9期）計画 | 障がい福祉計画（添付） | 当方（直す前） |
|---|---|---|---|
| 本文の書体 | HG丸ゴシックM-PRO | BIZ UDPゴシック | 游ゴシック |
| 本文の大きさ | 10.5pt（一部11pt） | 11pt | 10.5pt |
| 見出し | 下線のみ・単色 | 章は帯に白抜き、節・項は色文字 | 章は帯に白抜き、節は色文字 |
| 表紙 | 題2行・期間・年月・団体名。ヘッダー・頁番号なし | 絵入りの表紙。ヘッダー・頁番号なし | ヘッダー・頁番号あり |

前回計画の書体は PDF に埋め込まれた書体名（HGMaruGothicMPRO）で、本文の大きさは頁ごとの字の大きさの集計で確かめた。

## 2. 見切れの原因

| 箇所 | 原因 |
|---|---|
| 表紙の題（18pt）・「素案（公表用）」（22pt） | 全段落の行送りを15ptに固定（exact）していた。Word は固定の行送りからはみ出した字の上を切る。游ゴシックは字面の上下の余白が大きく、とくに切れやすい |
| 図3-1 施策の体系（その1） | 縦長の図を高さ8.9インチまで広げていた。節見出しと同じ頁に置くと、Word は行内の画像を分割も縮小もしないため、頁の下からはみ出して切れる |
| 図3-1 施策の体系（その2） | 図の中の凡例の行が、描画の範囲の下端からはみ出して切れていた |

この環境の LibreOffice は固定の行送りでも字を切らずに描くため、これまでの紙面の確認では見つけられなかった。

## 3. 直したこと

- **書体を BIZ UDPゴシック に改めた**（本文・図とも）。障がい福祉計画と同じで、Windows 10 以降に標準で入っているため村の端末で置き換わらない。村は第4次障がい者計画でユニバーサルデザインフォントの周知・啓発を掲げている。本文の大きさは前回計画に合わせて10.5ptのままとした
- **11ptを超える字の行送りを最小値指定（atLeast）に**した。本文・表の固定の行送りは頁数の推定のため残す。点検68に、大きい字に固定の行送りを掛けていないかの確認を加えた
- **図の高さの上限を8.0インチに**下げた（節見出し・表題・出典が同じ頁に収まる高さ）
- **図3-1**：凡例の行のぶん高さを足した。箱の中の改行を文字数ではなく語の切れ目（助詞・中黒・ひらがなから漢字への移り目）で折るようにした（「支／援」「インセ／ンティブ」のような切れ方をなくした）。長い施策名は字を少し小さくして収める
- **表紙**からヘッダーと頁番号を外した（前回計画・障がい福祉計画と同じ）
- 全図（28点）の四辺に字や線が掛かっていないことを機械的に確かめた

## 4. 書体を入れた方法

この環境に BIZ UDPゴシック が無いため、scripts/setup_fonts.py で npm の @fontsource/biz-udpgothic（5.3.0）から組み立てて入れた（SIL Open Font License）。fontsource の配布に無いローマ数字（Ⅰ〜Ⅳ）・α などの数文字は置き換わるが、頁数には効かない。

## 5. 紙面

書体を改めて全組み合わせを測り直した。BIZ UDPゴシック は游ゴシック（の置き換え）より字幅が詰まり、頁が減った。

| | 直す前 | 直した後 |
|---|---|---|
| 協議用の素案（本文） | 152頁 | 150頁 |
| 公表用の計画書（案なし） | 本文118頁＋前付4頁＝122頁 | 本文115頁＋前付4頁＝**119頁**（許容115頁まで4頁） |
| 同（案A〜E） | 114頁 | 112頁 |
| 同（案A〜E・H・J） | 111頁 | 109頁 |
| 同（案A〜E・G・H・J・K・L） | 108頁 | 107頁 |

紙面の洗い出しでは、表が頁をまたいで1行だけ残る箇所が1件戻った（改頁の位置が動いたため）。表頭が繰り返されるため読めること、Word では改頁が変わり得ることから、これまでの方針どおり直さず、控えを改めた。

## 6. 残したこと

- 色づかい（当方は紺、障がい福祉計画は緑）は変えていない。障がい福祉計画の緑は同計画の前回計画にならったもので、本計画の前回（第9期）は単色である。そろえるかどうかは村のご判断とする
- 委員会資料（成果品08・19）・照会票などは游ゴシックのままである。計画書に限って改めた
