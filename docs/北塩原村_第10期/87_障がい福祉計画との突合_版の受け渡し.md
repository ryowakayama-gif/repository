## 1　いちばん効く1件　版の受け渡しの事故

### 1-1　何が起きていたか

| | 突合した相手の版 | そのとき相手は |
|---|---|---|

| 本計画（doc81・10月10日）→ 障がい側 | 「令和8年10月4日が最終」（`307fe7e`） | **すでに60コミット進んでいた**（10/5に2件、10/7に1件、10/8に12件、10/9に8件、10/10に37件） |

その結果、障がい側が**10月8日に立てた照会Ｋ-1〜Ｋ-8**（`docs/北塩原村_障がい計画と
介護保険事業計画の整合.md`）が本計画に届かなかった。本計画が10月10日に
1-4・施策3-1・施策4-1・資9を新設したのは別の文書（網羅性チェック）によるもので、
照会に応えたものではない。

**判断の違いではなく受け渡しの事故である。** 日付で記録すると「最終」がいつの
最終か分からず、その日以降に進んだぶんが黙って落ちる。

### 1-2　版をハッシュで記録する

`scripts/seigo_han.py` を作った。持つものは3つである。

| | 中身 |
|---|---|
| `AITE` | 突合した相手・ブランチ・**版（コミットのハッシュ）**・その版の日付・突合した日・用いた資料 |
| `UKETORI` | 相手から受け取った照会1件ずつの、内容・当方の応答・反映した節・対応する確認事項 |
| `WATASHI` | 当方から相手へ渡す事項（相手の照会票に行として立ててもらう） |

**点検70**が番人になる。

1. 版がコミットのハッシュで書かれていること（日付だけでは不適合）
2. いちばん新しい突合の版が、手元にある相手の枝の先頭と一致すること
   （枝を取っていない環境では、その旨を示して判定しない）
3. 受け取った照会に全件、応答と反映先があること
4. 反映先の節が素案に実在し、指す確認事項が台帳に実在すること

2は、今回の事故をそのまま捕らえる形にしてある。`git fetch origin <相手の枝>`
のうえ点検を走らせると、突合した版が古ければ不適合になる。

## 2　期限のある2件

### 2-1　目標値を支えるアンケート設問（回収期限 10月16日）

調査票は令和8年9月9日に校了し、10月10日に発送が完了している。
**いまから設問を足すことはできない。** 支える設問のない指標は、計画の期間中
ずっと測れないまま残る。障がい側では現に1指標が測定不能になっている
（前回 問17 で測っていた「外出の目的」の設問が今回の調査票にない）。

アンケートを出所とする指標10件を1件ずつ設問に突き合わせた。

| 判定 | 件数 | |
|---|---|---|
| 支える設問がある | 9件 | ニーズ 問5(1)・問7(11)・問9(1)(2)・問10(5)・問11(1)(2) |
| **支える設問がない** | **1件** | 施策3-4「家族介護者の負担感（在宅介護実態調査）」 |

在宅介護実態調査B票は10設問あるが、**負担感を測る設問はない**。
最も近いのは問6（主な介護者が不安に感じる介護等）と問10（今後も働きながら
介護を続けていけそうですか）である。

**施策3-4の指標を、B票 問6 で測れるものに差し替えた。**
3つまで選択の複数回答のため目標値は置かず、実態把握とした。

対応表は `scripts/shihyo_setsumon.py` に置き、**点検71**が
①素案のアンケート出所の指標がすべて対応表にあること、
②対応表が指す設問がコードブックに実在すること、
③対応表に素案にない指標が残っていないこと、を確かめる。

※ コードブックは令和8年9月4日版の調査票から作られている。**選択肢までは
確かめられない**（校了版のWordが未受領）。施策2-5の「地域・近所の見守り、声かけ」は
問7(11)の選択肢にあることが前提であり、校了版を受領したら確かめる。

### 2-2　認知症の人および家族等の意見聴取（11月の第2回策定委員会まで）

doc32 が「記述の追加では埋まらず、策定過程そのものに関わる」としながら、
doc72 の作業順位にも doc86 の急ぎにも挙がっていなかった。

優先度をBからAに上げ、**影響度4（工程外・村の判断と日程を待つ）**を付した。

機会を設ける場合は日程の確保が要るため、期限を「11月（第2回策定委員会まで）」と明示した。

## 3　そのほか3件

### 3-1　法が定めることを求めている量が空欄である

| | 根拠 | 空欄 |
|---|---|---|
| 老人福祉事業の量の目標（4-6） | 老人福祉法第20条の8第2項 | **20事業のうち19事業**の令和9〜11年度 |
| 地域支援事業の量の見込み（5-5） | 介護保険法第117条第2項第2号 | 量の表19事業のうち10事業、事業費の表12区分のうち7区分 |

いずれも「定めるものとする」とされた事項である。**仮定を置いて進めることができない**
（実績がないまま目標の量は置けない）にもかかわらず、影響度2（仮置き）であった。

- 影響度1（停止）に上げ、新たに1件を起票して空欄の中身を列挙した
- **5-12（現時点で据え置いた項目）に2行を加えた。** 空欄であること自体が
  どこにも書かれていなければ、そのまま計画書になる
- **点検72**を新設し、4-6・5-5の見込が空欄の行があるときは5-12に掲げてあることを求める

### 3-2　処遇改善加算がブランチ全体で0件

施策4-6（介護人材の確保と生産性向上）に取組を加えた。令和6年度に3加算が
一本化され賃金改善の計画と実績の報告が要件となったこと、村内4事業所の取得区分を
把握し未取得・下位区分の事業所に県の相談窓口と事務の手引きを案内すること、
加算は介護報酬の一部として本計画の給付費に含まれること（5-4）を書いた。

### 3-3　共生型の指標が実態と合わない可能性

本計画は施策3-1に「共生型サービスについて協議した事業所数 0か所→村内3か所」を
置いている。障がい側は**社会福祉協議会がすでに居宅介護・生活介護を実施**している
（生活介護は基準該当）としている。同一の事業所であれば、現状値0は実態と合わない。

事業所番号での名寄せを確認事項に起票し、資9の「制度の扱いを揃える対象」にも置いた。
