# 法定記載事項の反映と、資料編への移行（令和8年10月15日）

村より「15頁は許容する」とのご判断をいただいた。これを受け、令和8年法律第51号に
より介護保険法第117条に加わった記載事項7件を素案に反映した。
あわせてご示唆のあった③（資料編への移行）を、中長期的な推計について採った。

| | 直す前 | 直した後 |
|---|---|---|

| 条文単位の対照 | 反映済み10・要反映7・確認待ち1 | **反映済み17・確認待ち1** |

## 1　中長期的な推計は資料編に置いた（③を採った）

法第117条第2項が義務として求めるのは「介護給付等対象サービスの**種類ごとの量**
及び**地域支援事業の量**に関する中長期的な推計」である。
5-11にあったのは総量（在宅サービス受給者数・サービス諸費）と給付費・保険料の
見通しであり、種類ごとでも地域支援事業の量でもなかった。

種類ごとの量は16種類、地域支援事業の量は19事業あり、本文に置くと表だけで
2頁を占める。**表が主であるため資料編が収まりがよい**と判断し、
**資10（中長期的な推計）**を新設した。5-11と施策4-3から参照している。

### 1-1　算定はすでにできていた

サービスの種類ごとの量は、`estimate_services.py` が令和12・17・22年度まで
算定し `data/第10期_サービス種類別見込量.csv` に書き出していた。
**計算を足したのではなく、算定済みの値を計画に載せていなかっただけ**である。

地域支援事業の量は令和11年度までしか延ばしていなかったため、
`scripts/estimate_longterm_ryo.py` を新設して令和12・17・22年度まで延ばした。
延ばし方は5-5(1)と同じ（介護予防・生活支援サービス事業は認定者数の伸び、
一般介護予防事業・包括的支援事業・任意事業は第1号被保険者数の伸び）。

**基準の取り方で5-5と食い違った。** はじめ令和5年度末（第1号被保険者1,004人）を
基準に置いたところ、通いの場の参加者数が5-5の279／276／274人に対し
281／278／276人となった。5-5は**令和8年度＝100**（第1号被保険者1,012人・
認定者214人）を基準にしている。基準を揃えたところ19事業すべてが一致した。
資10の値は `estimate_longterm_ryo.py` から引いており、じか書きしていない。

## 2　残る6件をどこに置いたか

| 条文 | 区分 | 置いた場所 |
|---|---|---|
| 法117条2項（新） | 義務 | **5-11**に「中長期的な観点から取り組むべき施策」を新設（担い手の確保／村外の事業所への依存の構造への対応／保険料の上がり方を抑えること） |
| 法117条3項（新） | 努力義務 | **施策4-6**に、県が設置する協議会の場で村内の事業所の状況を共有し県の人材確保・経営支援の施策につなぐ取組 |
| 法117条3項（新） | 努力義務 | **5-5**に、地域支援事業に従事する者の確保・資質の向上を県と連携して進める旨 |
| 法117条3項（新） | 努力義務 | **5-5**に、地域支援事業の実施における生産性の向上を県と連携して進める旨（上と同じ段落） |
| 法117条5項（新） | 勘案 | **施策4-3**に、会津区域の連携の状況を県に確認のうえ5-4・資10の算定に反映する旨。**5-12**に確定の条件 |
| 法117条14項（新） | 手続 | **1-6**に、中長期的な推計を定めるに当たりあらかじめ県の意見を聴く旨。**資10**の注記と**5-12**にも |

入居定員総数の勘案（法117条5項）だけは**確認待ち**とした。村内に有料老人ホーム・
サービス付き高齢者向け住宅がないため0であるが、村外の施設を利用している方が
いるため、県の区域ごとの入居定員総数を勘案する必要があるかを確かめる。
5-12に確定の条件として掲げている。

**号の番号は本文に書いていない。** 改正後の条文で既存の号が繰り下がるかは
新旧対照条文を得るまで分からないため、「介護保険法第117条第2項は」「同条第3項は」
のように項までで止めている（doc91・確認事項 優先度S）。
