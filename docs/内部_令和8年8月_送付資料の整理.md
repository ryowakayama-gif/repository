## 2　自己点検の記録の取扱い（ご確認をお願いします）

### 当方の整理

「レッドチームレビュー」という名称の資料は、受託者が自らの整理を批判的に検証した記録です。
**削除ではなく、次の3点で対応しました。**

1. **名称を改めた** ─ 「第9期評価の自己点検記録」
2. **用語を中立化した** ─ 「的中」→「指摘のとおりであることが確認された」、
   「自らの整理を否定する立場」→「自らの整理を批判的に検証する立場」ほか
3. **送付区分を「内部保管」とした** ─ 日常の送付資料には含めません

### 削除としなかった理由

- 業務仕様書４（10）の納品物に「その他業務で作成した資料　一式」があり、
  作業過程の記録もこれに該当します。廃棄は納品物の欠落にあたるおそれがあります。
- 点検により判明した**不足資料18件・確認事項56件**は、この記録を根拠としています。
  記録がないと、これらの依頼の根拠を示せません。
- ただし、そのままの表現・名称では発注者にお渡しする資料として適切ではないため、
  上記の中立化を行いました。

### ご確認をお願いしたいこと

**廃棄をご希望の場合はお申し付けください。** その場合も、不足資料・確認事項の一覧は
「必要事項の一覧」「確認依頼書」に移してありますので、業務への影響はありません。

対象は次の2件です。

| ファイル | 内容 |
|---|---|
| 第10期計画_第9期評価の自己点検記録.xlsx | 第9期評価に関する自己点検（指摘29件） |
| 第10期計画_主張の根拠水準の棚卸しと再レビュー.xlsx | 主張ごとの根拠水準の点検、不足資料18件 |

## 3　計画素案の版の管理

### 改めた点

| | 従前 | 改訂後 |
|---|---|---|
| ファイル名 | 第10期介護保険事業計画_素案_第12稿.docx | **第10期介護保険事業計画_協議用素案_令和8年8月.docx** |
| 表紙 | （版の表記なし） | **協議用素案（令和8年8月時点）** |
| 本文中の記述 | 「第9稿までは…」 | 「当初の整理では…」 |
| 変更履歴 | 第9稿／第10稿（2次）… | 令和8年7月　初版／令和8年7月29日　是正版… |

### 理由

稿番号は受託者内部の作業単位です。発注者・委員・住民にとっては
版の新旧が分かりにくく、また未成熟な段階のものが「素案」として流通する原因にもなります。
今後は「何のための版か」「いつ時点の資料か」を名称に含めます。

作業単位としての稿番号は、内部保管の修正指示書にのみ残しています。

## 6　送付前の点検の仕組み

`check_external.py` により、全成果品を機械的に点検します（送付区分表 03シート）。

### 点検の対象

| 区分 | 内容 |
|---|---|
| 内部品質管理 | レッドチーム、的中、自らの整理を否定 ほか |
| 稿番号 | 第○稿 |
| 禁止表現 | 上記4(1)の5表現 |
| 自己評価 | 所定の到達点、最大の特徴、明らかになった ほか |
| 記号 | 行頭に付した★（評価尺度としての★★★は対象外） |

### 現時点の結果

```
送付区分「内部保管」「対象外」の 15 件は対象から除いた
外部送付の観点による点検　対象 44 ファイル
該当ファイル数: 0 / 44
```

着手時は該当50/58ファイル・計1,397件でした。

### 点検で除外している文脈

- 用語を禁止・訂正するために引用している箇所
- 「撤回」「誤読」— 記述を改めた事実の説明として必要なため対象としません
- 送付区分表そのもの（用いない表現を列挙するファイルであるため）
