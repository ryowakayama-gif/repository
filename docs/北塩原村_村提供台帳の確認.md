# 1. 何を、どこから取ったか

| 年度 | 出所 | 理由 |
|---|---|---|
| 令和6年度・令和7年度 | 資料２－３の実績 | 村が協議会に出した年度の値。台帳は令和6年度が10月分まで、令和7年度もサービスにより途中までのため、年度の値は資料２－３を正とした |
| 令和8年度 | 台帳の実施月の平均 | 資料２－３は令和8年度の実績を持たない。台帳はサービスにより6月分から9月分まで |
| 括弧内（前回計画時の見込量） | 直さない | 資料２－３の見込量と一致している（就労継続支援Ａ型の令和8年度のみ資料２－３が10人日、正本が19人日） |

令和8年度の数え方：

- 利用者数・利用日数は、台帳にある月の平均（日数は整数に丸める）
- 計画相談支援は**実人数**（資料２－３の数え方に合わせた。毎月の請求で数えると月6〜7人程度）
- 排泄管理支援用具は**給付の決定の月数**（6人分×12か月＝72）
- 居宅介護のサービス提供時間は台帳に記載がないため「―」
- **台帳の提供がなかったサービスで、令和6・7年度を直した行は「―」**とし、値を作っていません（就労移行支援、就労継続支援Ａ型、障がい児のサービス4つ、理解促進研修・啓発事業、日常生活用具2種、日中一時支援事業、福祉ホーム事業）。Ｍ-137 で村に確かめています。

成年後見制度利用支援事業は直していません。資料２－３は令和6・7年度とも0人ですが、正本 第6章の表６-３（資料：北塩原村）は令和6年度2人・令和7年度3人で、**村の資料どうしで食い違う**ためです（Ｍ-138）。

# 4. 機微な情報の扱い

台帳は利用者ごとの記録です（氏名は伏せてありますが、障害支援区分・所得区分・利用先の事業所名・月ごとの利用日数と給付費が並びます）。本村の人口は約2,300人であり、区分と事業所の組合せで個人が分かりえます。

- **原本はリポジトリに置いていません。** `build_kitashiobara_daicho_chuushutsu.py` が落とした集計値（サービス・年度・月ごとの人数・日数・金額）だけを `source/村資料_台帳_20261022/台帳の集計.csv` に格納しました。原本は受領した圧縮ファイルのまま手元で保管します。
- 確認ブック・正本・照会のいずれにも、**利用者ごとの値と事業所の名は出していません。**
- 集計値の表の列・種別・事業の名・備考の形が想定のものだけであることを、生成のたびに確かめます（検査④）。
