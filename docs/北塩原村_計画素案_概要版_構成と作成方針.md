# 計画素案　概要版の構成と作成方針

作成日: 2026-09-17

対象: 北塩原村 第8期障がい福祉計画・第4期障がい児福祉計画
成果物: `output/北塩原村_計画素案_概要版.docx`（A4縦・4頁）

## 0. 結論

**概要版をA4・4頁で作成した。計画書とは別ファイルである。**あわせて計画書本編の**表題を「骨子案」から「素案」に改めた**（ファイル名も `北塩原村_計画素案.docx` に統一）。

前回の概要版（`source/現行計画/第4次障がい者計画等_概要版.pdf`、A4・4頁）の構成をそのまま踏襲したが、**今回の改定対象が2計画であること**と**成果目標が8区分に再編されたこと**から、3か所で構成を変えている。

| # | 前回の概要版 | 今回 | 理由 |
|---|---|---|---|
| 1 | 3計画（障がい者・障がい福祉・障がい児）を対象 | **2計画**（障がい福祉・障がい児） | 第4次障がい者計画は令和11年度までで改定対象外。その理念・目標・体系は「継承する内容」として整理した |
| 2 | 「4 SDGｓとの関連について」 | **「4 国の基本指針の見直しのポイント」** | ＳＤＧｓ対応表は今回は見送りと決定済み（G-3）。第8期で何が変わるのかを住民に示すほうが概要版の役割に合う |
| 3 | 成果目標を項目ごとの囲みで7区分 | **一覧表で8区分** | 8区分に増え、囲み形式では4頁に収まらない。表にすると現状と目標値が横並びで読める |

## 2. 数値の出所

概要版に載せた数値は、すべて計画素案本編と同じ出所から取っている。**概要版だけで独自に数値を持たない**方針とし、本編が更新されれば概要版も同じ値で更新する。

| 数値 | 出所 | 状態 |
|---|---|---|
| 人口2,394人・高齢化率41.4％（令和6年4月1日） | 住民基本台帳 | 確定 |
| 令和11年の人口2,185人 | 村公式推計 | 確定 |
| 手帳所持者数156人（令和5年4月1日） | 現行計画本編 | **【要更新】**令和8年4月1日現在の値を村に確認中 |
| 令和11年の手帳所持者数145人 | 方法A・Bの中位推計（第2章6） | 暫定 |
| 成果目標の現状値 | 現行計画・村提供実績 | **【要更新】**令和7年度末の実績を確認中 |
| 主なサービスの利用者数 | 現行計画（第7期）の令和8年度見込量 | **【要更新】**令和7年度実績と精査中 |
| 第4次障がい者計画の目標値 | 同計画（改定対象外） | 確定（現状値はアンケートで更新） |

概要版の本文には【要更新】の注記を3か所に入れており、どこが未確定かが読んで分かるようにしてある。

## 3. 表題の変更（計画書本編）

村の指示により、計画書本編の表題を「骨子案」から「素案」に改めた。変更したのは次の7か所である。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| 表紙 | 骨子案 | **素案** |
| 表紙 | 令和8年7月 | **令和8年9月** |
| 前書きの見出し | 本ドラフトの取り扱いについて | **本素案の取り扱いについて** |
| 前書き | 策定を支援するための作業用ドラフトです | **策定に向けた素案です** |
| 前書き・注記2か所 | 本ドラフトの… | **本素案の…** |
| 奥付 | 作成日：令和8年7月 | **作成日：令和8年9月** |
| 奥付 | 編集：北塩原村 住民課（ドラフト作成支援） | **編集：北塩原村 保健福祉課 福祉係** |

奥付の所管課は、令和8年8月に村から受けたアンケート調査票の修正指示（問合せ先を「医療福祉班」から「保健福祉課 福祉係」に変更）により確定したものである。

ファイル名も `北塩原村_骨子案_修正版.docx` から `北塩原村_計画素案.docx` に変更した。目次ビルダー・前回対比ブック・進捗管理ブックの参照も更新済みである。

## 4. 村に確認が必要なこと

| # | 事項 | 理由 |
|---|---|---|
| 1 | **概要版の印刷部数・仕様** | 業務委託仕様書5の成果品は①計画書②アンケート調査報告書③電子媒体の3点で、概要版は含まれていない。前回はA4・4頁で住民配布されている。計画書30部と同じ扱いにするのか、電子媒体への収録のみとするのかで作業量が変わる |
| 2 | **概要版の費用の扱い** | 同上。仕様書外の作業であるため |
| 3 | カラー・モノクロの別 | 前回の概要版はカラーのグラフを用いている。今回は帯と表の網掛けで構成しており、モノクロでも判読できる作りにしているが、村の配布方法に合わせたい |
| 4 | 手帳所持者数のグラフ化 | 前回はグラフを載せている。現在は表で示している。確定値を受領後、本編の図と同じ体裁でグラフに差し替えることができる |

なお、実態調査及びPDCAサイクルに関するマニュアル（令和8年8月、P.36）は「計画の概要を作成し、計画の全体とともにホームページ等に掲載すること」を求めている。**概要版の作成自体は必要**であり、残るのは部数・費用の整理である。
