# 第10期介護保険事業計画　人口推計（案C）の妥当性についての検証のお願い

大雪地区広域連合　第10期介護保険事業計画（令和9年度から令和11年度まで）

作成日　令和8年10月23日

---

## 1　このお願いの趣旨

第10期介護保険事業計画の保険料は、人口の推計を起点として、
認定者数 → サービス見込量 → 給付費 → 保険料収納必要額 → 保険料基準額
の順に算定します。**人口の置き方が算定の全体を動かします。**

本計画は人口の置き方として「案C」を採っています。
案Cの考え方・計算の順序・数値を本書に示しますので、
**第三者の目で妥当性をお確かめください。**
第8節に、特にお確かめいただきたい論点を13件掲げています。

お確かめいただきたいのは次の3点です。

1. 案Cの置き方が、介護保険事業計画の人口推計として妥当であるか
2. 案Cが他の置き方と比べて高めに出ているか低めに出ているか、その向きが保険料にどう働くか
3. 案Cのままとする場合に、計画本文へ書き加えるべき説明・注記があるか

## 2　案Cとは何か

### 2-1　位置づけ

介護保険事業計画の人口推計は、保険者が保有する総合計画等による
推計人口を用いることを基本とし、これを用意できない場合に
国立社会保障・人口問題研究所（以下「社人研」）の推計を用いることと
されています。

構成3町（東川町・美瑛町・東神楽町）はいずれも地方創生総合戦略
（人口ビジョン）を持つため、本計画はこれを基礎とすることとしました
（令和8年8月6日のキックオフ会議及び令和8年8月31日のご指示）。

### 2-2　総合戦略が持つのは総人口だけである

認定者数の推計には年齢階級別の人口が必要ですが、
総合戦略は年齢階級別の内訳を持ちません。
そのため、案Cは次の2つを組み合わせています。

| 要素 | 置き方 |
|---|---|
| 水準の起点 | 介護保険事業状況報告の実績（令和8年3月末）の第1号被保険者数 |
| 伸び率 | 住民基本台帳の実績趨勢（平成31年から令和7年までの年平均変化率） |
| 総合戦略の目標人口 | 総人口の水準の妥当性を確かめる材料として用い、伸び率の補正には用いない |

第1号被保険者の資格は住民基本台帳によるため、
水準・伸び率のいずれも住民基本台帳という同一の基準によることになります。

### 2-4　階級を3区分としている

階級は65〜74歳・75〜84歳・85歳以上の3区分です。
5歳階級の趨勢をそのまま延ばすことは採っていません。
5歳階級の変化率には特定の世代が階級を移っていく動きが含まれるため、
そのまま延ばすと階級の構成比が実態から離れていきます。

### 2-5　伸び率を一定とする期間

第10期（令和9年度から令和11年度まで）は上記の伸び率を一定として延ばし、
**令和12年度以降は令和11年度の水準を起点に社人研推計の伸び率で**
**接続します**。総合戦略は令和11年度より先の目標を持たないためです。

## 5　案Cが保険料に及ぶ経路と大きさ

### 5-1　算定の順序

```
人口（案C）
  → 性別・年齢5歳階級別・要介護度別の認定率を乗じて認定者数
  → 要介護度別の利用率を乗じてサービス見込量
  → 要介護度別の1人1月あたり給付費を乗じて給付費
  → 上乗せ・地域支援事業費・調整交付金を加減して保険料収納必要額
  → 予定収納率・補正後被保険者数で除して保険料基準額
```

### 5-2　算定の結果（第10期3か年）

| 項目 | 額 |
|---|---|
| A　標準給付費見込額 | 9,569,019,924円 |
| B　地域支援事業費 | 531,483,777円 |
| C　第1号被保険者負担分相当額 | 2,323,115,851円 |
| D　調整交付金相当額 | 494,520,394円 |
| E　調整交付金見込額 | 729,464,444円 |
| J　保険料収納必要額 | 2,088,171,801円 |
| 補正後被保険者数（3か年） | 27,301.19人 |
| **算定上の月額基準額** | **6,438.26円** |
| **保険料基準額（百円未満四捨五入）** | **6,400円** |

第9期の保険料基準額は6,400円であり、**基準額としては据え置きになります。**

### 5-3　人口の置き方を改めない場合の効き

見える化システムの直近の推計（推計名1006）は人口の設定が
社人研推計のままです。所得段階別第1号被保険者数の計を
画面が表示する人数にそろえて算定すると次のようになります。

| 置き方 | 第10期3か年の第1号被保険者数 | 補正後被保険者数 | 月額 |
|---|---|---|---|
| 案C（本計画） | 27,539人 | 27,298.8人 | 6,438円 |
| 社人研のまま（画面の値） | 27,333人 | 27,099.5人 | 6,486円（＋47円） |

**人口の置き方を案Cに改めないと、被保険者数が少なく出るため**
**保険料が月額47円ほど高く出ます。**
案Cに改めることは保険料を下げる向きに働きます。

### 5-4　人口以外の前提で月額を動かすもの

人口の置き方の効き（＋47円）と比べていただくために掲げます。

| 前提 | 置き方を変えた場合の月額の動き |
|---|---|
| 1人1月あたり給付費の趨勢（年率1.32％）を織り込む | ＋245円 |
| 同（年率1.75％） | ＋327円 |
| 介護報酬改定率1％ | ＋61円 |
| 地域支援事業費を0とした場合 | ▲353円 |

注）いずれも当該の前提のみを動かした場合の値であり、重ねて適用しません。

## 6　当方が機械で確かめている範囲

次は算定の中で機械的に確かめており、
合わない場合は算定そのものが成り立たないようにしています。

- 要介護度別の認定者数の合計が、年齢階級別に求めた認定者数と一致すること
- 基準年度（令和7年度）の給付費が、見える化システムの総括表と円単位で一致すること
- 基準年度の1人1月あたり利用回（日）数が、総括表詳細と小数第4位まで一致すること
- 在宅サービス利用率の分母が、認定者数から施設・居住系サービス利用者数を差し引いた数であること（見える化システムの画面が表示する率と全21区分で一致すること）
- 第9期の保険料基準額（6,428円）が、同じ算定式で再現できること
- 所得段階別の人数の合計が、第1号被保険者数と一致すること
- 施設・居住系サービスの見込量が、区域内の定員と対照できること

## 7　確かめていない（確かめられていない）こと

- 伸び率の基礎とした住民基本台帳の実績趨勢が、第10期以降も続くかどうか（過去6年の趨勢の延長である）
- 認定率が令和7年度末の水準で続くかどうか（年齢調整後の認定率は低下の傾向にあるが、低下を織り込んでいない）
- 1人1月あたり給付費が令和7年度の水準で続くかどうか（単価は年率1.3％から1.8％で伸びているが、織り込んでいない）
- 介護報酬改定率・第1号被保険者負担割合・所得段階の政令改正（いずれも国の告示及び政令の公布を待つ）
- 町別の将来推計（本計画は3町計のみを本文に掲げる）

### 確かめる手掛かり

**1　伸び率の期間**

住民基本台帳の各年1月1日現在の値は年度別の基礎データとして収めています。期間を3年・5年・10年に変えた場合の年平均変化率を求め、令和11年度の65歳以上人口がどれだけ動くかをお確かめください。新型コロナウイルス感染症の影響を受けた年を含むことの扱いも併せてご検討ください。

**2　時点のそろえ方**

住民基本台帳は各年1月1日現在、介護保険事業状況報告の第1号被保険者数は各月末現在、計画本文の人口は各年10月1日現在です。時点の違いが令和11年度の値にどれだけ影響するかをお確かめください。

**3　水準の起点**

第1号被保険者の資格は住民基本台帳によりますが、住所地特例・適用除外により両者は一致しません。令和7年度の年報による第1号被保険者数と、住民基本台帳による65歳以上人口を突き合わせ、差の大きさと向きをお確かめください。

**4　階級の区分**

5歳階級の変化率には特定の世代が階級を移る動きが含まれます。5歳階級でそのまま延ばした場合に階級の構成比がどう動くかを求め、3区分による結果と比べてください。認定率は5歳階級別に持っているため、3区分の結果を5歳階級へ配分する際の構成比の置き方も論点になります。

**5　伸び率を一定とする期間**

令和11年度と令和12年度の65歳以上人口及び階級別の内訳を並べ、変化の大きさが前後の年と比べて不自然でないかをお確かめください。改正後の介護保険法は令和22年度までの中長期的な推計を求めるため、接続の方法は中長期推計の妥当性にも及びます。

**6　総合戦略の用い方**

総合戦略は総人口の目標のみを持ち、年齢階級別の内訳を持ちません。計画本文の説明と計算の内容が読み手に同じものとして伝わるか、書き加えるべき説明があるかをご指摘ください。

**7　社人研推計との差の向き**

令和11年度で案C 9,213人・案A 9,072人（差＋141人）です。認定率・利用率・単価を変えずに人口だけを案Aに置き換えた場合の保険料基準額を求め、差の大きさをお確かめください。

**8　85歳以上の伸び**

85歳以上は要介護認定率が最も高い層であり、ここを低く見込むと保険料が不足する側に誤ります。3町別の変化率を並べ、町により大きく違わないかをお確かめください。社人研推計による85歳以上の伸びとも比べてください。

**9　前期高齢者の減少**

団塊の世代が75歳以上へ移る局面にあるため、前期高齢者の減少は一時的なものである可能性があります。社人研推計による65〜74歳の推移と比べ、減少が続く前提の妥当性をお確かめください。

**10　認定率の固定**

年齢調整後の認定率は、重度（要介護3から要介護5まで）が低下を続け、軽度（要支援1から要介護2まで）は底を打って横ばいです。低下を織り込むと保険料は下がる向きに働きます。固定することは不足する側に誤らない置き方ですが、過大に見込んでいないかをお確かめください。

**11　コーホート変化率法との関係**

同じ住民基本台帳を基礎としてコーホート変化率法で組み直すと、65歳以上は案C比1.4％から4.9％低く出ます。方法の違いが結果の差をどれだけ説明するかをお確かめください。

**12　町別の扱い**

サービス見込量・給付費・保険料は、介護保険法第3条及び地方自治法第284条により保険者（広域連合）を単位として算定します。一方、構成3町は人口の動きも認定者数の動きも異なります。町別の将来推計を示さないことによる不都合がないかをご指摘ください。

**13　見える化システムへの入力**

画面の設定が社人研推計のままであると、第1号被保険者数が第10期3か年で206人少なく、保険料が月額47円ほど高く出ます。改めることの可否と、改めた場合に画面の中で計が合うかをお確かめください。
