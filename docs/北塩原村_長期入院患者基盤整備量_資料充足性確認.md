# 福島県の長期入院患者基盤整備量 ― 受領資料の充足性確認

作成日: 2026-08-05

## 0. 何を算定しようとしているのか

第8期基本指針（令和8年3月31日 こども家庭庁・厚生労働省告示第4号による改正後）は、精神病床の長期入院患者について次の構造を定めている。

**別表第四**

| 項 | 式 | 得られる値 |
|---|---|---|
| 一 | Σ(A1)×(1−X1) ＋ Σ(A2)×(1−X2) | 令和11年度末の**65歳以上**（及び75歳以上）の1年以上長期入院患者数 |
| 二 | Σ(B1)×(1−X1) ＋ Σ(B2)×(1−X2) | 令和11年度末の**65歳未満**の1年以上長期入院患者数 |
| 三 | (C) − (一の項 ＋ 二の項) | **令和11年度末の長期入院患者の地域生活への移行に伴う地域の精神保健医療福祉体制の基盤整備量（利用者数）** |

| 記号 | 定義 |
|---|---|
| A1 | 1年以上入院・**65歳以上**・当該都道府県に住所・**認知症を除く**・**令和11年における年齢階級別の推計患者数** |
| A2 | 同上・**認知症に限る** |
| B1 | 1年以上入院・**65歳未満**・認知症を除く・令和11年の推計患者数 |
| B2 | 同上・認知症に限る |
| C | **令和5年**における精神病床の入院期間1年以上の入院患者数 |
| X1・X2 | 令和11年の人口当たり慢性期推定入院患者数と「令和5年時点で人口当たり慢性期入院患者数が少ない県の水準」を比較し、差分が2割未満なら差分の半分、2割以上なら0.1を標準として、**都道府県知事が定める値** |

**別表第二 三の項㈠⑤**（市町村障害福祉計画の「定めなければならない事項」）

> 当該市町村が属する都道府県が別表第四の三の項に掲げる式により算定した、当該都道府県の区域における令和十一年度末の長期入院患者の地域生活への移行に伴う地域の精神保健医療福祉体制の基盤整備量（利用者数）を勘案して、**当該市町村の区域における**令和十一年度末の…基盤整備量（利用者数）を定めること。

したがって必要なのは、**福島県の三の項の値**と、それを勘案して定める**北塩原村の区域の値**である。

## 1. 結論

**受領資料により実績側（Cを含む）は確定した。空いているのは「令和11年の推計」と「県知事裁量のX1・X2」、そして三の項の値そのものである。**

| 別表第四の要素 | 受領資料での充足 | 判定 |
|---|---|---|
| C（令和5年の1年以上入院患者数・福島県） | **令和5年度630調査 Ⅲ.2.(11) 住所地ベース 2,591人**（65歳未満901人・65歳以上1,690人） | **○ 確定** |
| A1・A2・B1・B2 の**実績側** | 同付表から4区分すべて取得可 | **○** |
| A1・A2・B1・B2 の**令和11年推計値** | 無し。ただし付表3.3に入院受療率（人口10万対）があり、福島県の令和11年年齢階級別推計人口と組めば算定可能 | **△ 算定可** |
| 75歳以上の1年以上長期入院患者数（第8期新設） | 付表3.3の75〜84歳・85歳以上から取得可 | **○** |
| **40歳以上の認知症**である者の1年以上長期入院患者数（第8期新設） | 366日以上は0〜64／65〜74／75〜84／85歳以上でしか公表されておらず、0〜64歳のうち40歳以上を切り出せない | **× 算定不可** |
| **X1・X2** | 無し。「少ない県の水準」は国が示す値、X自体は県知事が定める | **×** |
| **三の項＝基盤整備量（利用者数）** | 無し。福島県第7期計画にも三の項の記載は無く、一・二の項に相当する長期在院者数のみ | **×** |
| **北塩原村の区域の値** | 無し。NDB・630調査とも都道府県単位 | **×** |

### 2-2. 福島県 第7期計画で判明したこと【重要】

第7期計画 第1編 第3の2「精神障害にも対応した地域包括ケアシステムの構築」の目標値表：

| 項目 | 元年度 | 2年度 | 3年度 | 4年度 | 第7期目標（令和8年度末） |
|---|---:|---:|---:|---:|---:|
| ① 退院後1年以内の地域における平均生活日数 | 321.3日 | 国集計中 | 国集計中 | 国集計中 | **325.3日以上** |
| ② 長期在院者数 65歳未満 | 1,132 | 1,114 | 1,074 | 995 | **898人** |
| ② 長期在院者数 65歳以上 | 1,857 | 1,869 | 1,905 | 1,813 | **1,656人** |
| ③ 入院後3か月時点の退院率 | 62.8％ | ― | ― | ― | 68.9％ |
| ④ 入院後6か月時点の退院率 | 79.8％ | ― | ― | ― | 84.5％ |
| ⑤ 入院後1年時点の退院率 | 88.0％ | ― | ― | ― | 91.0％ |

**福島県は第7期計画で、別表第四の一・二の項に相当する「長期在院者数」の目標値は掲げているが、三の項＝基盤整備量（利用者数）は掲げていない。**第8期でも同じ扱いになる可能性が高く、その場合、市町村が「勘案」すべき県の値は**計画本文からは読み取れず、県への個別照会が必須**になる。

なお第8期では区分が2区分（65歳未満／65歳以上）から4区分（65歳未満／65歳以上／75歳以上／40歳以上の認知症）に拡張されており、第7期の様式のままでは第8期の要求を満たさない。

また第7期の目標値325.3日は当時の国基準そのままであり、第8期は319.3日に引き下げられている。

### 2-4. 数値の系統が3つあることに注意

同じ「1年以上入院患者数」でも、出典により値が異なる。

| 出典 | 時点 | 値 | 単位の性質 |
|---|---|---:|---|
| 福島県第7期計画（630調査ベース） | 令和4年度 | 2,808人（995＋1,813） | 6月30日時点の実人数 |
| **630調査 Ⅲ.2.(11) 住所地ベース** | **令和5年6月30日** | **2,591人（901＋1,690）** | **実人数** |
| 630調査 Ⅲ.2.(11) 病院所在地ベース | 令和5年6月30日 | 2,542人（891＋1,651） | 実人数 |
| NDB付表3.3 通常集計 | 令和5年度 | 2,449.2人 | 年間の1日平均在院患者数 |
| NDB付表3.3 公費含む | 令和5年度 | 2,757.7人 | 同上 |
| ReMHRAD（630調査） | 令和7年6月30日 | 2,220人 | 実人数 |

**令和5年度630調査の受領により、Cは確定した。**別表第四のA1〜B2はいずれも「**当該都道府県の区域に住所を有する者**」を要件としており、Ⅲ.2.(11)の**住所地ベース**がこれに対応する。さらに、福島県第7期計画が掲げる長期在院者数（令和4年度 65歳未満995人・65歳以上1,813人）と系統が一致する（令和5年 901人・1,690人へ推移）ことから、**Cは630調査の住所地ベース実人数で2,591人**と解するのが整合的である。

NDBの1日平均在院患者数（2,449.2人）は年間平均であり、6月30日時点の実人数とは定義が異なる。認知症区分での按分にはNDB付表3.3を用いるが、総数はCに合わせる必要がある。

## 4. 県の値を待たずに進める方針

告示は市町村に「県の値を**勘案して**当該市町村の区域における基盤整備量を定めること」を求めており、県の値を人口按分せよとは書いていない。北塩原村には現行計画に**1年以上の長期入院者 令和5年度5人**という実数があり、これを起点に個別に定めることができる。

| 手順 | 内容 | 担当 |
|---|---|---|
| 1 | 令和7年度末時点の1年以上長期入院者の実数、年齢（65歳未満／65歳以上／75歳以上／40歳以上の認知症の別）、入院先を確認 | 村・会津保健所 |
| 2 | 個々の退院可能性を協議の場・自立支援協議会で判定し、令和11年度末の見込みを置く | 村・協議会 |
| 3 | 差分（現在数−令和11年度末見込）を当該市町村区域の基盤整備量（利用者数）とする | 当社 |
| 4 | 退院者の受け皿となる共同生活援助・自立生活援助・地域移行支援等の見込量に反映 | 当社 |
| 5 | 福島県 第8期計画の公表後、県の三の項の値と整合を確認 | 当社 |

利用者数が一桁の本村では、県値の人口按分（総人口比で約0.15％）よりも実数による方が確実に正確である。手順1〜3は当方の個別積上げ方式と同じ構造であり、県の公表を待たずに骨子案 第4章(2)を埋められる。
