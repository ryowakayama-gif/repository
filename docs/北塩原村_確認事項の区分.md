# 1. 他団体の案件から採った方法

同じ会社の他団体の案件（高齢者福祉計画・介護保険事業計画）で、確認事項70件を4区分に整理し直した例があります。そのブランチを確認し、**方法だけを採りました。**他団体の資料・数値・固有の事実は一切用いていません（生成のたびに機械で確かめています）。

採った考え方は4つです。

| | 考え方 |
|---|---|
| ① | **当方で解消すべき計算上・資料解釈上の疑問を、相手の確認責任に転嫁しない。**これを区分の基準に明記する |
| ② | 「相手」「当方」の二分法では粗い。**「公表資料で先行し、不足分のみ照会する」区分（Ｃ）を設ける** |
| ③ | **同じ事項を尋ねている照会は1件にまとめる** |
| ④ | 区分の件数は機械で検算する（合計・欠番・重複・統合の連鎖） |

## 当方の制約を区分に織り込んでいます

当方の環境から村ホームページ・県のサイト・e-Gov・厚生労働省・内閣府へ接続できません。このため**「公表されているが当方が取れない」資料は、Ｂ（当方で確認）ではなくＣ**（資料のご提供をお願いし、中身の判断は当方で行う）に置いています。

# 6. この整理で見つけた不整合1件

**Ｓ-11（特定地域サービス等の対象地域の基準）が、他メンバーへの確認の節5から参照されているのに、照会の単一出所（`atsumeru()`）から漏れていました。**

Ｓ-11 は第2回レビューの確認事項（`K_R2`）に置かれており、宛先の形が違うため `atsumeru()` の対象外になっていました。照会文を組むときには別に合流させているため文書には出ていましたが、**件数を数えるときに落ちていました。**区分を割り付ける際に全件を突き合わせて見つけました。

`zenbu()` を設けて、`atsumeru()` に `K_R2` のうち生きている番号を加えた集合を作り、これを母集合としています。

# 8. 検査

| | 内容 |
|---|---|
| ① | 区分が照会の単一出所と1対1であること（実在しない番号に区分を付けていない／区分のない照会がない） |
| ② | 件数の検算（区分ごとの合計＝112、Ｍの番号に欠番なし、重複なし） |
