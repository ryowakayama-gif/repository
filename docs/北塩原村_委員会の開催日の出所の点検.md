# 4. 直したこと

## ① 工程の各行に「精度」を持たせました

`kitashiobara_koutei.py` の工程16件に精度の欄を足しました。

| 精度 | 意味 | 件数 |
|---|---|---|
| **確** | 日まで出所がある。原典（仕様書）に日がある、案Ａに日があって村がご採用、又は当社の手の内で日を決められる工程 | 12件 |
| **仮** | **他者の日程であって、当社が営業日を数えるために置いた日。**出所は月又は旬まで。**対外の文書には月又は旬で書く** | 4件 |

## ② 検査を3つ足しました（1つでも合わなければ生成が止まります）

- **⑩** 出所が「案Ａ」である工程の日が、案Ａに実在する日であること（`ANA_HI` の11件と照合）。**今回の誤りはこれで止まります。**精度が「仮」の行には、仮置きであることと照会番号（Ｍ-125）が出所に書かれていること
- **⑪** 仮置きの一覧（`KARIOKI`）と精度「仮」の工程が一致すること
- **⑫** 仮置きの日が、対外の文書に載せる表（`GAIYOU_HYO`）に**日として現れていない**こと。月又は旬で書かれていること

あわせて、村へ渡す文書の生成器に **②b**（仮置きの日が1か所も現れていないこと／開催日をうかがったように書いていないこと）、進捗管理表の生成器に**仮置きの日を着手順・WBSの備考に書いていないこと**の検査を足しました。

さらに、**生成器ごとの検査では新しい生成器が同じ誤りを繰り返しうる**ため、再現性点検（`check_reproducibility.py`）に横断の検査 **C-7「仮置きの日が成果物に出ていない」**を足しました。成果品96点の全文（docx・xlsxの中のXML）から仮置きの4日を和暦で探します。

| | 範囲 |
|---|---|
| **止めるもの** | 和暦の日（「令和８年11月18日」「令和8年11月18日」）。対外の文書で人が読む形はこれです |
| **止めないもの** | 内部の逆算表の `2026-11-18`（ISO）。営業日の数え方を追えるようにするため残し、隣に**精度「仮」**の欄と「日は当方の仮置き（Ｍ-125で村に照会）」という出所を並べています |
