# 3. まだ差し替えていません

**集計表は差し替えず、`報告書用集計表_令和8年10月21日版_回収40.xlsx` として並べて格納しています。**

いま差し替えると、正本 第2章7 の割合39点を集計表と照合している検査（`build_kitashiobara_anke_kaitei.py` の③）が落ち、正本が生成できなくなります。第2章7 は他メンバー版の本文であり、当方だけでは直せません。

**順序は次のとおりです（令和8年10月22日に改めました）。**

1. **報告書の直し残し11か所を直していただく（Ｓ-40・10月31日）**
2. 他メンバーに第2章7 の差し替えをお願いする（Ｓ-39・**11月14日**）
3. 差し替えられた素案を受領する
4. 集計表を新しいものに差し替え、当方の8件（ＡＫ-2〜ＡＫ-9）を直す
5. 再生成して、39点すべてが新しい集計から出ることを確かめる

**1を2より前に置いた理由**は、直し残し11か所のうち4か所は同じ文が正本の第2章7にあるためです。直る前に差し替えると、崩れた文が計画の本文に入ります（`docs/北塩原村_報告書の修正方針と計画への影響.md`）。

**39点のうち新しい集計で説明できるのは18点です。**残り21点は差し替えが要ります（当方の8件を含む）。
