## 2　ご提案の6区分への見解

> 単純集計、クロス集計、課題整理、要因分析、ニーズ、計画策定時の注意点

| ご提案 | 見解 | 要点 |
| --- | --- | --- |
| 単純集計 | 変えたい | 手法名は章題に向かない。現行の「障がい者調査の結果」を残す |
| クロス集計 | 変えたい | 同じ理由。ただし現行の章題は既に機能している |
| 課題整理 | 変えたい | 章としては必要。**位置を後ろに**。計画との二重を避ける |
| 要因分析 | 変えたい | **新設に賛成**。ただし中身と表題を変える |
| ニーズ | **賛成** | 最も賛成。法令上の使い道がある |
| 計画策定時の注意点 | **賛成** | 節ではなく章に上げる価値がある |

「変えたい」は反対ではなく、**章として置くことには賛成した上で表題・中身・並び順を変えたい**という意味です。6区分のいずれも不要とは考えていません。

### なぜニーズを独立させるべきか

基本指針 別表第一は、見込量の勘案要素として「**障害者等のニーズ**」を挙げています。
ニーズの章は法令上の使い道があります。**課題の中に溶かすと、見込量から遡れません。**

前回計画が報告書の P40・P42 を「知的障がいの地域移行者数0人」の根拠として引用したのは、
まさにこの部分です。ニーズを章として独立させておけば、
次期計画でも同じ引用ができます。

### なぜ「要因分析」の中身と表題を変えるべきか

**統計的な要因分析は成り立ちません。** 有効回答38件、基数5未満の区分が
n付きの区分65件のうち28件（43％）です。検定も回帰もできません。
「要因分析」という表題は読者に過大な期待を抱かせます。

代わりに**村の給付実績・事業所の分布・地理・人口構成との突合**に置けば、
回答数に左右されずに書けます。

例を1つ挙げます。問27-2「内容をよく知らないサービス」の上位は
**重度訪問介護・同行援護・行動援護・就労選択支援・移動支援の各23.7％**です。
一方、村内の事業所は令和7年で**居宅介護1・重度訪問介護1・生活介護1のみ**で、
就労継続支援Ｂ型・短期入所・就労移行支援・自立訓練は0か所です
（就労継続支援Ｂ型は猪苗代町1か所、短期入所は猪苗代町3か所）。

**知らないサービスは、村内に事業所がないサービスとおおむね重なります。**
これは回答数ではなく事実の突合から言えることで、
「身近に事業所がないことが制度の認知を妨げている」という背景が示せます。
そして実績ゼロのサービスを見込量0で据え置く扱いが、
ニーズの不在ではなく認知と供給の問題である可能性を計画に書き添える根拠になります
（別表第二 三㈠②「見込量の確保のための方策」）。

表題は「**調査結果の背景**」が実態に合うと考えます。
「要因分析」をお使いになる場合は、柱書きで
「統計的な検定ではなく、村の実績及び地域特性との突合による」と明記してください。

### なぜ「単純集計」「クロス集計」を章題に勧めないか

手法の名前であって、協議会委員・村民・庁内の読者が探す単位ではありません。
前回報告書も「Ⅱ 集計結果」の下に分野別の◇を並べ、手法名を表に出していません。

また**障がい児調査が別にあります。**「単純集計」の章に障がい者と障がい児の
両方を入れるのか分けるのかが曖昧になります。
現行の「第3章 障がい者調査の結果」「第5章 障がい児調査の結果」の方が迷いがありません。

手法は章の柱書きで述べ、目次の副題に（単純集計）と添える形をお勧めします。
庁内・協議会に「どこまでやったか」を示す意図であれば、それで足ります。

### なぜ並び順を変えるか

ご提案は 課題整理 → 要因分析 → ニーズ の順ですが、
**課題は事実と背景とニーズを踏まえた結論**です。

> 事実（単純集計・クロス集計）→ 背景 → ニーズ → 課題 → 留意点

この順が自然で、現行の報告書も課題を最後に置いており、この並びに沿っています。

## 7　少数回答への向き合い方

分母が小さいことは弱点ですが、**書き方を選べば使える材料は多くあります。**

### やってよいこと

* **実数で示す** — 「施設入所支援を今後利用したい9人」は n に依存せず意味を持つ
* **村の実績・地理・人口構成と突き合わせる** — 回答数に左右されない
* **全員一致を示す** — 「3件全て」と書けば誤解がない（割合100％より正確）
* **自由記述を活かす** — 少数回答では相対的に比重が上がる（ただし個人特定に注意）
* **補完調査の必要性を明記する** — 国のマニュアルもヒアリング調査・事業所調査を示している

### 避けたいこと

* **基数5未満の割合を本文で断定的に引用する** — 知的障がい n=2 の「100.0％」は2人中2人
* **前回調査との割合の比較** — 回収率も回答者の構成も変わっている
* **統計的な有意差・相関・回帰** — n=38 では検定の前提を満たさない
* **割合の小数第1位での順位付け** — 2.6ポイント差は1人の差
* **無回答を除いた分母と含む分母を混ぜる** — 報告書は38件で統一しており適切

## 8　人材確保・生産性向上について

> 小規模町村ということもあり、明確化することが得策と考えていないため、項目としては外してあります。

**設問として外す判断に異論はありません。** 人材確保・生産性向上は事業所側の事項で、
住民（サービスの利用者）に尋ねて答えが得られる設問になりにくいです。
国のマニュアルもこの分野は事業所調査で把握する枠組みを示しています。
設問を増やせば有効回答率がさらに下がる懸念もあります。

**ただし、調査の対象外であることと計画の記載事項であることは別です。**

令和8年7月10日の改正で別表第二に**六の項**（人材確保、ケアの充実のための生産性向上
及び経営基盤の確立）が新設されました。告示 第三の二は、市町村計画について
同表の六の項を「**定めるよう努めなければならない事項**」としています（努力義務）。

**計画側は対応済みです。** 計画素案 第5章13「障がい福祉人材の確保・定着、
生産性向上及び経営基盤の確立」を新設しており、根拠は調査ではなく
県の研修実績・圏域の事業所の状況・村の委託先の状況に置いています。

**報告書側は項目を立てず、留意事項に1行置けば足ります。**
「本調査は住民（サービスの利用者）を対象としており、障がい福祉人材の確保・定着
及び生産性向上に関する事項は対象としていない。これらは事業所及び県の研修実績等に
より把握する」旨を置けば、成果目標8区分のうち七・八に対応する課題がない理由が
読者に伝わります。

10月5日のレビューで挙げた R-5 は、**設問を足すべきという指摘ではなく、
住民調査の対象外である旨の注記を置けば足りるという趣旨**でした。
ご判断は妥当で、注記の追加で解消します。
