# 協議会・庁議・パブリックコメント 資料構成案

## 0. 位置づけ

業務委託仕様書 4-Ⅱ(7)「計画策定委員会の支援（会議資料の作成、会議への出席、会議記録の作成）」に対応する。**協議会の開催は村が行い、受託者は資料作成・出席・記録作成を担う**。

開催日が確定してから資料を作り始めると間に合わないため、先に構成と論点を固めておく。数値が入っていない箇所は村資料の受領後に埋める。

## 1. 【先に確認したいこと】協議会1回で足りるか

工程案では **北塩原村障がい者自立支援協議会は令和8年12月に1回** となっている。第8期は次の点で第7期より審議事項が増えており、1回で計画全体を審議するのは負荷が高い。

| 第8期で増えた審議事項 | 内容 |
|---|---|
| 成果目標が7項目→8項目 | 「障がい福祉人材の確保・定着、生産性向上」が新設 |
| 就労系の目標が階層化 | 全体1.31倍に加え、就労移行支援1.14倍・Ａ型1.52倍・Ｂ型1.67倍を事業種別に設定 |
| 活動指標の任意分の取捨 | 別表第一の項目のうち、村が設定するもの・しないものを判断（本村分65項目） |
| 施設入所者の意向確認 | 「全ての施設入所者の意向を把握・確認し、市町村は協議の場において共有する」（第二 一）——**協議会が共有の場になる** |
| 強度行動障害の状態にある者の支援ニーズ把握 | 各市町村又は圏域で把握し支援体制を整備（第二 五） |
| のぞまないセルフプランの解消 | 令和11年度末までにゼロ。個別事例の検討を通じた課題抽出 |
| 圏域の訪問系提供体制 | 会津北部圏域で訪問系を提供する事業所が本村の1か所のみという状況の共有 |

**提案**：協議会を2回に分けることを村と協議したい。

| 回 | 時期 | 内容 |
|---|---|---|
| 第1回 | 令和8年10月頃 | 策定方針・国の基本指針の改正点・現行計画の評価・アンケート結果の速報 |
| 第2回 | 令和8年12月 | 素案の審議（成果目標・見込量・活動指標） |

1回のままとする場合は、**事前に委員へ資料を送付し、当日は論点に絞る運用**が必要になる。いずれにせよ村の判断事項。

## 6. 会議記録

仕様書 4-Ⅱ(7)は「会議記録の作成」も業務としている。次の様式で作成する。

| 項目 | 内容 |
|---|---|
| 会議名・回次 | |
| 日時・場所 | |
| 出席者 | 委員（出席・欠席）、事務局、受託者 |
| 議事 | 次第に沿って |
| 主な意見 | 発言者を「委員」と匿名化するか実名とするかを村と確認 |
| 計画への反映 | 意見ごとに反映の有無と反映箇所を記録する |
| 次回までの宿題 | |

**「計画への反映」の欄を設けることを推奨する。**意見を受けて計画のどこをどう直したかを記録に残しておくと、パブリックコメントや議会説明の際に経緯を示せる。
