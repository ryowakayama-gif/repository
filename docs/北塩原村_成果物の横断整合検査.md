# 0. なぜ置いたか

令和8年10月24日の他ＡＩの横断レビューで、成果物どうしの食い違いが多数見つかりました。アンケートの回収数（38件と40件）の混在、前回計画の評価が台帳で直す前の実績のまま、概要版の見込量が正本と違う、第4次障がい者計画を「改定対象外」としている、照会の期限の曜日の誤り、などです。

**いずれも、各生成器の自己点検は通っていました。** 自己点検は「自分の出力と自分の入力」を見るだけで、他の成果物と食い違っていても止まりません。そこで、成果物の現物どうしを横に並べて照らす点検を一か所に置きました。

**対象**は、委員会・村・他メンバーに出す23点と、その他の output の作業の成果物69点です。作業の成果物にも村や他メンバーに渡したものがあり、曜日の誤り・他団体の名前・古い実績が残ると同じ誤りが広がるため、K1・K3・K12・K15 を当てます。K13・K14 は23点に限ります（作業の成果物には、移植前の当方の素案の章立てを指すものが多いため）。

# 2. 誤検出を防ぐ工夫と、否定試験

- **直す前を示す成果物は外す**：対応履歴・差し替えの新旧・他ＡＩのレビューの確認・横断レビューへの対応は、古い記述を「直す前」として引くため、K2・K3・K8・K15 の対象から外します。外す理由は成果物ごとに02シートに書いてあります。
- **正本ではない文書の参照は照合しない**：K13・K14 は、参照の直前に「前回」「県」「医療計画」「報告書」等の語がある場合は照合しません。
- **否定試験74**：各点検に誤りをわざと入れた文を与えて、止まることを確かめます。あわせて、正しい文（例：「第５章２（６）」「第８次福島県医療計画の第10章」「令和３〜５年度とも実績0だった」）で止まらないことも確かめます。

# 4. 不合格にしないもの（ご判断事項）

**04シート「委員会に出す前の確認」**は、委員会・住民に出す資料に残る照会番号（Ｍ-・Ｓ-）や「確認中」の注記を数えたものです。照会番号を委員会資料に残すかどうかは、村とご相談のうえで決める事項ですので、不合格にはしていません。とくに**協議会資料3には照会番号が55か所**あります。
