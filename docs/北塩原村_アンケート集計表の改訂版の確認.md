令和8年10月3日に当方が洗い出した不整合11件が改訂版でどうなったかを、**新旧の現物を突き合わせて**確かめました。旧版はgitの履歴から取り出しています。

# 1. いちばん大きな変更 — 割合の基数が変わりました

| | 旧 | 新 |
|---|---|---|
| 割合の基数（分母） | 各設問の**有効回答数**（無回答を除く）。設問ごとに n が違う（n=36・34・33・30 など） | 各設問の**回答者数**（無回答を含む）に統一。**n は38で固定** |
| 無回答 | 表に出ない | **選択肢として明示** |
| 目次の注記 | 「割合は表示上、小数点第2位を四捨五入…」 | 「**割合は、各設問の回答者数（無回答を含む）を基数として算出し**…」 |

**これは当方の指摘Ａ-1への対応です。**「単純集計は無回答を除く分母、クロス集計は無回答を含む分母で、同じ設問が報告書の中で2つの異なる基準で示される」と申し上げていました。**単純集計とクロス集計が同じ基準になりました。**

基数が変わると、ほとんどの割合が動きます。たとえば日常生活で困っていること「将来の生活」は**30.6％（旧・n=36）→ 28.9％（新・n=38）**です。

## 当方の計画素案は動きません

**計画素案 第2章7 はもともと「割合は無回答を含む回答者数に対する割合」として書いており、改訂版と同じ基準です。**

生成のたびに、**第2章7 に現れる割合39点すべてが改訂版の集計から出ること**を確かめています。足した割合（「今の自宅で暮らしたい」＋「家族と一緒に暮らしたい」＝55.3％など）は足し算で、有効回答率（38÷172＝22.1％など）は割り算で確かめます。1点でも合わなければ生成が止まります。

障がい別の表（表2-7）の8項目も、新設された「集計_障がい別」シートと全項目一致しています。
