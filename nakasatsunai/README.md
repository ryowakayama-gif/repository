## 重要：Excelは一度開いて保存し直すこと

`xlsx` は **OOXMLを直接編集**している。openpyxl で開き直すとチャートシート7枚・
グラフ7点・図14点が失われるため、この方法を採った。副作用として計算結果の
キャッシュが古いままなので、以下の対応を入れてある。

- `workbook.xml` に `fullCalcOnLoad="1"` を設定（開いた瞬間に全再計算される）
- 古い `xl/calcChain.xml`（363KB）を削除し、`[Content_Types].xml` と
  `workbook.xml.rels` の参照も除去（Excelが再生成する）

**建設改良費の令和7年度が +65,676千円 になるため、減価償却費・支払利息・企業債残高
が令和7年度以降で動く。** 経常収支比率・経費回収率・シミュレーション各パターンの
結果は再計算後の値を確認すること。本文の図表はすべて貼り付け画像（EMF 27点）なので、
再計算後に貼り直しが必要。

### 確認事項4：令和7年度の建設改良費を公表版に合わせる

公表版の資本的支出（様式第2号）は令和7年度 **93,100千円**。Word本文 p.25 も
