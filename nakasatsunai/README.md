## 重要：Excelは一度開いて保存し直すこと

`xlsx` は **OOXMLを直接編集**している。openpyxl で開き直すとチャートシート7枚・
グラフ7点・図14点が失われるため、この方法を採った。副作用として計算結果の
キャッシュが古いままなので、以下の対応を入れてある。

- `workbook.xml` に `fullCalcOnLoad="1"` を設定（開いた瞬間に全再計算される）
- 古い `xl/calcChain.xml`（363KB）を削除し、`[Content_Types].xml` と
  `workbook.xml.rels` の参照も除去（Excelが再生成する）

**建設改良費の令和7年度が +65,676千円 になるため、減価償却費・支払利息・企業債残高
が令和7年度以降で動く。** 経常収支比率・経費回収率・シミュレーション各パターンの
結果は再計算後の値を確認すること。本文の図表はすべて貼り付け画像（EMF 27点）なので、
再計算後に貼り直しが必要。

## 将来人口の推計根拠の確定（2026-10-03）

公表中の経営戦略の成果品（検討報告書・将来人口予測ファイル・議事録）を受領し、
B-2／B-3／B-4 の根拠が確定したため本文へ反映した。

### 決め手になった資料

`02_下水道/1検討報告書/財政sim/将来人口・有収水量予測【R6中札内村】.xlsx` の「行政人口」シートに、
社人研・人口ビジョン・まちづくり計画を並べた比較表と **「採用値」列**があり、備考は全年度
「採用値＝総合計画」。採用値（R7=3,846／R12=3,771／R17=3,670）はすべてまちづくり計画の値と一致し、
社人研（R7=3,795／R12=3,664）は採用されていない。5年刻みの計画値を採り、間は線形補完している。

検討報告書にも「行政人口の将来推計値は、村の将来の最新展望である『第7期中札内村まちづくり計画
（令和4年3月策定）』における将来推計値を**採用する**」と明記。さらに同報告書は
「処理区域内人口は、普及率が過去5年間でほぼ横ばいであるため、**令和5年度の普及率を基準**とした
以下の式により算定した」「**将来の普及率=70.9%**」「**将来の水洗化率=98.5%**」としている。

### 本文への反映（4箇所）

| ID | 修正前 | 修正後 |
| --- | --- | --- |
| B-2 | 総人口は国立社会保障・人口問題研究所による推計から算出 | 「第7期中札内村まちづくり計画」（令和4年3月策定）の村独自推計を採用 |
| B-3 | 普及率・水洗化率は令和4〜6年度の3か年実績の**平均** | 過去5年間ほぼ横ばいのため**令和5年度実績を基準** |
| B-3 | 令和4〜6年度の3か年実績から一人当たり処理水量及び有収率を設定 | 令和5年度実績の原単位（0.249㎥/人/日）を基に推計 |
| B-4 | 下水道普及率 **69.5%**（経営比較分析表の値） | **70.9%**（成果品の採用値） |

B-4 は 10/1 に当方が仮反映した69.5%の訂正。経営比較分析表の69.48%とは分母が異なる
（分析表 2,670/約3,843、成果品 2,670/3,764）。推計の前提として70.9%を採っている以上、
本文も70.9%で揃えるのが整合する。

これで「3か年実績の平均」という記述は、選択肢として挙げていた令和3〜5年度でも令和4〜6年度でも
なく、**そもそも平均ではなかった**ことが判明した。

### あわせて判明した新規論点 B-6

成果品は有収水量原単位を 0.249㎥/人/日 として日次で積み上げている（0.249×365＝90.885㎥/人/年）
のに対し、改定案のExcelは 91.1㎥/人/年 を直接乗じている。令和7年度で510㎥（0.21%）、
使用料収入で約87千円/年の差。影響は小さいが、公表済みの成果品と推計方法が食い違う。

### その他に確定した事項

工場排水の 117,600㎥/年 は、成果品の「有収率」シートに
**計画工場排水量 490㎥/日 × 240日 = 117,600㎥** と明示されており、当方の推定どおりだった。
使用料単価 170.5円/㎥ も令和5年度実績の据置であることが確認できた。
