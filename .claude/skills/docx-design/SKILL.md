# 成果品のWord文書　―　デザインと点検

## 0. 最初にすること

**`docs/kanegasaki/委員会資料のデザインルール.md` を読む。**体裁・図・文章・構成の規則はそこに集約している。本ファイルは、**そのうち「守れているかを確かめる手順」**を定める。

実装は `docs/kanegasaki/style/` にある。**新しいセッションでは、まずこの3つをスクラップパッドに複写する。**

| ファイル | 内容 |
|---|---|
| `fmt.py` | 体裁のヘルパー（`P` `H1` `H2` `H3` `BUL` `TBL` `SRC` `FIG`、目次、ページ番号） |
| `figs.py` | 図の配色・書体・保存の規則と、策定委員会資料の図 |
| `figs_soan.py` | 計画素案の図（規則は `figs.py` から取り込む） |

## 1. 色の規則　―　1つの図の中で、色は1つの意味しか持たない

**これが最も破りやすく、最も目につく。**

### 比較図（本町・県・全国などの系列がある図）

| 系列 | 色 |
|---|---|
| **金ケ崎町** | **#C00000（赤）** |
| **岩手県平均** | **#ED7D31（オレンジ）** |
| **全国平均** | **#A6A6A6（グレー）** |
| **配点・満点などの背景の帯** | **#F2F2F2（枠 #D9D9D9）** |

**系列の色を条件で変えてはならない。**「県平均を下回る項目だけ赤にする」は、凡例と図が食い違うため禁止である。**下回っていることを示したいときは、色ではなく `▲` と注記で示し、その意味を図の中に書く。**

**多系列の図では、値ラベルを系列の色にする。**（金ケ崎町の値＝赤、県平均＝オレンジ、全国平均＝グレー）

### 内訳図・順位図（本町のデータだけの図）

| 用途 | 色 |
|---|---|
| **注目させたい項目** | **#C00000（赤）** |
| **主** | **#2E75B6（青）** |
| **背景的な項目・参考** | **#BDD7EE（淡い青）** |
| **減少・対象外** | **#A6A6A6（グレー）** |
| **値ラベル** | **#1F3864（濃紺・太字）** |
| **基準線・参照値** | **#ED7D31（オレンジ・破線）** |

**赤が何を指しているかを、図の中か出典行に1文で書く。**（例：「赤は前年を下回る系統」）

**閾値で塗り分ける場合は2段階までとし、オレンジは使わない**（オレンジは基準線と県平均に予約している）。

### 形と規則

- **順位・項目間の比較は横棒**（`barh` ＋ `invert_yaxis()`）、**推移は折れ線**（3系列まで）または**縦棒**。
- **値ラベルを必ず付す。軸ラベルに単位を（）で入れる。**
- **基準値は破線＋文字ラベル。凡例は棒や線に重ねない。**
- **縦軸を0から始めない場合は、出典行にその旨を書く。**
- **時系列を等間隔でない年で描くときは、横軸を数値にする**（Ｒ12・Ｒ15・Ｒ17…をカテゴリにすると形が歪む）。

## 2. 置き方の規則

- **キャプションは図の上に【図N】、出典は図の下に8pt。**番号は `FIG()` が自動で付す。
- **出典には、その図から読み取ってほしいことを1文添える。**直前の表と同じ資料なら「資料：上表に同じ。」で足りる。
- **図は、その図が説明する表または段落の直後に置く。**
- **キャプション・図・出典は `keepNext`／`keepTogether` で離れないようにする。改ページを手で入れない。**
- **幅は12〜15cm**（本文幅17.0cmいっぱいにしない）。**数の目安は本文5ページに1点程度。**
- **表の列幅は `TBL(rows, widths)` で明示し、合計を17.0cm以下にする。**セル幅とグリッドの両方に書く（`fmt.py` が行う）。

## 3. 提示前の点検

**ビルドしたら必ず実行する。**

```
python3 .claude/skills/docx-design/check_docx.py \
    out/計画素案_第10期.docx out/第2回策定委員会資料.docx \
    out/交付金の体系と本町の位置.docx out/確認事項照会_第10期.docx \
    --figs figs.py figs_soan.py
```

点検する内容は次のとおり。**指摘が残ったまま提示しない。**

| 区分 | 点検 |
|---|---|
| **図** | キャプションの形式と連番／画像との対応／出典の有無／`keepNext` の有無 |
| **表** | 行ごとの列数の一致／列幅の合計が本文幅以内／セル幅とグリッドの一致／見出し行の塗り |
| **検算** | **「計」「合計」の行がある表について、各行の和と突き合わせる**（表の中の数値のずれを見つける） |
| **記号** | `【　】` `【案】` `《要確定》` `《要回答》` の実数と、0-1の集計表との一致 |
| **参照** | 本文が参照する「図N」の有無／`《要確定N》` の番号が本文から参照されているか |
| **文言** | 表記ゆれ（金ヶ崎→金ケ崎、半角％→％、半角カタカナ） |
| **図の素** | **凡例のある系列に条件付きの色指定がないか**／規定パレット外の色がないか |

### 機械では見つからないもの　―　目視で確かめる

1. **図の凡例と棒・線の色が合っているか**（条件で塗り分けていないか）。
2. **図のキャプション・出典の文言が、直前の表・段落の言い方と合っているか**（同じものを違う名前で呼んでいないか）。
3. **表の数値と、その前後の本文の数値が一致しているか**（とくに「○件」「○人」「○点」）。
4. **図の縦軸・横軸の範囲が、前後の図と揃っているか。**
5. **LibreOffice組版のPDFで、図と出典・表と見出しが別ページに分かれていないか。**

## 4. ビルドの手順

```
cp docs/kanegasaki/style/{fmt,figs,figs_soan}.py .      # 新しいセッションの最初に
python3 figs.py && python3 figs_soan.py                 # 図を先に生成する
{ cat fmt.py; echo; cat ch_XXX.py; } > mkf_XXX.py && python3 mkf_XXX.py
python3 mk_toc.py                                       # 計画素案のみ。目次のページ番号
soffice --headless --convert-to pdf --outdir out out/XXX.docx
python3 .claude/skills/docx-design/check_docx.py out/XXX.docx --figs figs.py figs_soan.py
```

**要るもの**　`python-docx` `matplotlib` `pymupdf` `openpyxl`、日本語フォント `IPAGothic`、`libreoffice-writer` `libreoffice-calc`。

**留意**　組版はLibreOfficeによる。BIZ UDPゴシックが導入されていない環境ではIPAゴシック等で代替されるため、**Wordでの組版と1〜2ページずれることがある。**目次のページ番号はフィールドであり、Wordで開いた時点で更新される。

## 5. 文章の規則（成果品に共通）

- **変更履歴を書かない。**「第○版からの変更」「本文素案への修正履歴」は載せない。
- **業務仕様に記載のある分析の語のみを用いる。**手法名や内部の作業名は提示用資料に含めない。
- **大雪地区広域連合のデータが混ざっている場合は、金ケ崎町では用いない。**
- **全国一覧表は金ケ崎町（保険者番号033811）の行のみを抽出する。**県内比較を行う場合も、個別の団体名と個別の得点は出さず、分布（最大・四分位・中央値・平均・最小）と本町の順位のみを用いる。**図の出典行にもその旨を明記する。**
- **推測で数値を埋めない。**`【　】`（数値未確定）・`【案】`（当方の案）・`《要確定》`（町の判断）・`《要回答》`（照会中）で示し、件数を素案0-1で集計する。
